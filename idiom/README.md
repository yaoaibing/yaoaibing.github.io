# 成语填空 (📜 成语填空 · 国学达人)

> 分类:**烧脑益智** · 入口:/idiom/ · 免费在线 · 手机即点即玩

**目标:**每题一个**缺了一个字**的成语,四选一补全。题库 100 个常用成语(寓言/历史/数字/自然类),3 颗心容错,每题限时 10 秒。

**操作:**点选项或按 `1``2``3``4`。答对 +100 起连对每题 +10;答错/超时扣一颗心并 -30 分。

> 💡 **拿分要点:**① **把成语读一遍**,语感往往直接告诉你缺哪个字;② 数字类成语有套路:一心一意、两全其美、三生有幸、四海为家、五谷丰登、六神无主、八仙过海、十拿九稳,按数字顺序记;③ 寓言类(守株待兔/掩耳盗铃/刻舟求剑)记故事就记住了字;④ 拿不准时排除**明显不像成语用字的选项**(生僻字多是干扰项);⑤ 三星线:一局答对 25 题。

**结算:**答对题数、答错数、最大连对、总得分、历史最高分。
