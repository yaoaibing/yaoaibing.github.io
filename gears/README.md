# 齿轮传动 (⚙️ 齿轮传动 · 机械迷阵)

> 分类:**烧脑益智** · 入口:/gears/ · 免费在线 · 手机即点即玩

**目标:**在迷宫中摆放齿轮,让动力从 **S 大齿轮正交咬合**一路传到 💡 机器即过关;齿轮越接近最短路数得分越高。8 关由直廊到螺旋。

| 元素 | 效果 |
|---|---|
| ⚙️ 齿轮 | 点空位放置,点已放的收回 |
| 🔗 咬合 | 上下左右相邻才传动,斜角不算 |
| 💡 机器 | 被咬合的齿轮挨着即点亮过关 |
| 🧮 最省 | 每关有理论最少齿轮数 |
| 📈 计分 | 每多用一个 -25 分 |

**操作:****点击格子**放/收齿轮;**重摆**清空本关。先找大齿轮到机器的最短路再动手!

> 💡 **打法:**① 传动只认<b>上下左右</b>,斜着摆是死齿;② 先在心里画出 S 到 💡 的<b>最短折线</b>,再沿线摆;③ 绕墙时贴着墙走转角最少;④ 摆错了点一下就收回,大胆试;⑤ 齿轮数已经等于「最省」时别再手滑多放,一个就是 -25 分!

**结算:**通过关卡、本关用齿数、理论最省数、本局得分(每关 200 - 超用 x25)、历史最高分、已玩局数。
