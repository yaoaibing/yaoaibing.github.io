> 分类:**解压休闲** · 入口:/hidden/ · 免费在线 · 手机即点即玩

**目标:**满屏 64 个 emoji,底部列出**要找的 6 样**,限时 60 秒全部找出。三大主题场景(森林/海底/房间)依次推进,全通 +300。

**操作:**点中目标 +100;点到干扰物**-3 秒**并震动提示。目标每样有 2~3 个,找齐该样即从清单划掉。

**结算:**总得分、推进到的场景、历史最高分。
