# 沙狐球 (🥌 沙狐球 · 冰道滑滑)

> 分类:**解压休闲** · 入口:/shuffleboard/ · 免费在线 · 手机即点即玩

**目标:**冰道尽头的同心圆是得分区(10/5/2 分):双方**轮流各滑 4 球**,按住球往上滑出手,可撞开对方球。8 球滑完后,只有停在得分区且<b>比对方更靠近圆心</b>的球计分,总分高者胜。

| 元素 | 效果 |
|---|---|
| 🥌 滑球 | 按住自己的球往上甩,松手出发 |
| 🎯 得分圈 | 圆心 10 分,中圈 5 分,外圈 2 分 |
| ⚔️ 碰撞 | 球与球相撞会互相挤开,战术核心 |
| 🔁 轮次 | 你一球我一球,各 4 球 |
| 🏆 计分 | 结束后只给更靠近圆心的一方计分 |

**操作:**按住<b>底部滑球区</b>往上滑动出手;**新局**重开。电脑会瞄准圆心,但也会失误!

> 💡 **打法:**① 力度宁小勿大,出圈的球一分没有;② 对手球压圆心时,用一球<b>撞飞它</b>比自己塞更稳;③ 先手球放个「保镖」堵在圆心前面,后手球跟着补位;④ 最后一球决定胜负,留全力;⑤ 电脑力度有随机误差,它失误就是你反超的机会。

**结算:**双方得分、撞球次数、本局得分(净胜分 x10 + 胜 300)、历史最高分、已玩局数。
