# 电梯调度 (🛗 电梯调度 · 高楼急送)

> 分类:**解压休闲** · 入口:/elevator/ · 免费在线 · 手机即点即玩

**目标:**8 层楼 1 部电梯:**点楼层号派电梯**前往;到层自动上下客,乘客被送到目的楼层记 1 单。乘客耐心耗尽记 1 次投诉,3 次投诉被开除,完成的单数就是成绩。

| 元素 | 效果 |
|---|---|
| 🛗 派梯 | 点楼层号,电梯直达该层 |
| 🧍 上下客 | 开门自动完成,容量 4 人 |
| ✅ 送达 | 乘客到目的层 +1 单 +分 |
| 😡 投诉 | 乘客头上耐心条见底即投诉,3 次开除 |
| 📈 难度 | 时间越久客流越大,耐心越短 |

**操作:****点楼层号**派电梯;**重开**立刻重开。电梯一次只执行一个目标,到站后自动接新指令。

> 💡 **打法:**① 顺路优先:电梯在 3 层,先接 4 层的人再上 6 层,别来回空跑;② 头顶耐心条<b>变红</b>的乘客最优先,投诉就是丢命;③ 车里两人目的地相同层时,先去那一层清仓;④ 高峰期宁可让 2 楼多等,保住 7 楼的长耐心单;⑤ 电梯移动中也能改指令,但会先到原目标,想清楚再点。

**结算:**完成单数、投诉次数、总载客人次、本局得分(单数 x15)、历史最高分、已玩局数。
