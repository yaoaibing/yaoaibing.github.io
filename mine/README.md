# 扫雷英雄 (💣 扫雷英雄)

> 分类:**烧脑益智** · 入口:/mine/ · 免费在线 · 手机即点即玩

**目标:**翻开所有**没有雷**的格子就赢,踩雷即败。数字表示周围 8 格里的雷数。
| 操作 | 键位 |
|---|---|
| 翻开 | 点一下格子
插旗 / 取消 | **长按**格子约 0.35 秒 |
| 快速展开 | 数字上的旗插够了,**双击**它自动翻周围
难度 | 初级 9×9/10雷 · 中级 16×16/40雷 · 高级 24×24/80雷 |

> 💡 **推理技巧:**① **首点必安全**,第一下随便点,会帮你炸开一片;② 从"1"和边角入手最稳;③ 经典定式:角上的 **1-2-1**、边上的 **1-2** 都能直接定雷;④ 双击数字是提速关键,插够旗就双击;⑤ 剩下的雷数看 HUD,最后几格用**数雷法**反推比硬猜强。
