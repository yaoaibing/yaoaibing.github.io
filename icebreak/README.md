# 破冰救鹅 (🐧 破冰救鹅 · 一击必碎)

> 分类:**街机动作** · 入口:/icebreak/ · 免费在线 · 手机即点即玩

**目标:**拖动瞄准发射冰球,冰球在场地内**反弹撞击冰块**,冰块碎裂后其后的企鹅获救;冰球数量有限,6 关全部救完即通关。

| 元素 | 效果 |
|---|---|
| 🐧 拖动 | 按住底部滑块拖动瞄准线 |
| 🧊 冰块 | 被冰球撞到即碎,连锁反弹 |
| 🐧 企鹅 | 冰块碎后获救 +100 |
| ❄️ 冰球 | 每关 5 颗,用完结算 |
| 🏁 过关 | 救出全部企鹅进下一关 |

**操作:****按住底部区域拖动**瞄准,松手发射;**重排**复位本关。台球思路:想反弹 2-3 次的路线!

> 💡 **打法:**① 反弹角=入射角,画一条<b>折线</b>再出手;② 先打<b>冰块密集区</b>,一石多鸟;③ 企鹅躲在冰后,必须打碎冰才能救;④ 冰球快用完时,选最有把握的弹道;⑤ 空中多颗球同时反弹,场面越乱越爽!

**结算:**救援企鹅数、发射冰球数、通关数、本局得分(救援 x100 + 剩余冰球 x30)、历史最高分、已玩局数。
