# 引力航路 (🚀 引力航路 · 太空导航)

> 分类:**太空导航** · 入口:/space/ · 免费在线 · 手机即点即玩

**目标:**引力导航:飞船受行星**引力持续牵引**,按住屏幕**朝指尖喷气**推进(耗燃料);贴行星过近坠毁、飞出航区失联;抵达右上空间站过关,燃料越多分越高,共五段航路。

| 元素 | 效果 |
|---|---|
| 🪐 引力 | 260px 内持续吸引,质量越大越强 |
| 👆 喷气 | 按住朝指尖 240 推力,耗油 14%/秒 |
| 🛰️ 航站 | 右上角,靠近 26px 内入站 |
| 💥 失败 | 撞行星 / 出航区 |
| ⛽ 燃料 | 每段 100→70 递减,剩油计分 |

**操作:****按住屏幕**喷气,**拖动**改变喷气方向,松手惯性滑行(方向键无,全靠手感)。建议先小口喷,微调入轨!

> 💡 **打法:**① 起手朝<b>右上方轻点两下</b>获得初速,然后**松手看引力表演**;② 想左转就喷右下——**喷气方向与Want去的方向相反**;③ 行星不是敌人:<b>从引力边缘擦过</b>能免费拐弯,省下的油就是分;④ 感觉被行星拽住,**提前 45 度侧喷**比反向硬顶省油;⑤ 第五段三颗行星,走**下方缝隙**直线滑行最稳!

**结算:**完成航段、剩余燃料、本局得分(胜 400 + 燃料 x3 + 航段 x60)、历史最高分、已玩局数。
