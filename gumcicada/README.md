**目标:**瞄准甩杆:**转竿粘蝉**,十杆连环。

| 元素 | 效果 |
|---|---|
| 🍃 长竿 | 竿头有胶 |
| 🦗 鸣蝉 | 惊则跳枝 |
| 👆 甩杆 | 对准即出 |
