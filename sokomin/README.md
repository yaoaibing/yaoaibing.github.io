# 推箱子迷你 (📦 推箱子迷你 · 四关入门)

> 分类:**烧脑益智** · 入口:/sokomin/ · 免费在线 · 手机即点即玩

**目标:**迷你推箱子:4 个 BFS 验证过的精选关卡,方向键推箱上目标点;支持撤销,步数计入得分。

| 元素 | 效果 |
|---|---|
| 📦 箱子 | 只能推,不能拉 |
| 🎯 黄点 | 箱子全部到位过关 |
| ⚠ 死角 | 推进墙角就重开 |
| ↩ 撤销 | 悔一步不扣分 |
| 🏆 计分 | 每关 100 + 剩余步数奖励 |

**操作:**点**方向按钮**或按**方向键**(Z 撤销)。

> 💡 **打法:**① 先想**最后一步**:箱子从哪边推到位最顺;② **别把箱子贴墙推**,墙边只能左右滑;③ 撤销是免费的,**大胆试错**;④ 第 2 关两个箱子**先下面的后上面的**;⑤ 感觉推死了就多退几步,**回滚比重开快**!

**结算:**通过关卡数、行走步数、本局得分、历史最高分、已玩局数。
