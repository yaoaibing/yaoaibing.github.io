# 合纵连横 (📜 合纵连横 · 战国博弈)

> 分类:**策略战棋** · 入口:/hezong/ · 免费在线 · 手机即点即玩

**目标:**多策博弈:**结盟/攻伐/休养/拆盟**,信义归零盟散;八轮计国力。

| 元素 | 效果 |
|---|---|
| 🤝 会盟 | 得一盟友,有信义值 |
| ⚔️ 攻伐 | 耗兵 2-3,得地 2-4 |
| 🌾 休养 | 练兵 +3 |
| 💔 拆盟 | 得 3 地,众国失信任 |
| 🏆 结算 | 地×30 + 盟×40 + 兵×5 |

**操作:**点底部**策略按钮**施行。

> 💡 **打法:**① **前期多结盟**,中期再攻伐;② **信义值两三的盟友最危险**,该巩固就巩固;③ 攻伐前**看兵数**,不足就休养一轮;④ 拆盟**得不偿失**,除非急缺地;⑤ 八轮拓地二十,**战国策里记你一笔**!

**结算:**疆土、盟国数、历史最高分、已玩局数。
