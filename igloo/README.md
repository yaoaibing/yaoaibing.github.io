# 雪屋搭建 (⛄ 雪屋搭建 · 穹顶之下)

> 分类:**建造物理** · 入口:/igloo/ · 免费在线 · 手机即点即玩

**目标:**拱顶砌筑:27 格穹顶逐层堆雪砖,上层需**两块下层砖支撑**;单侧支撑的「危险砖」会在大风时被卷走;60 秒 30 砖内砌满。

| 元素 | 效果 |
|---|---|
| 🧱 砌砖 | 点空格放置,耗 1 块 |
| 🧱 支撑 | 上层须两端各有砖 |
| 🌪 大风 | 定期来袭,卷走危险砖 |
| 🏠 门洞 | 装饰,不占格 |
| 🏆 封顶 | 27 块全满 +300 |

**操作:****点空格**放雪砖,注意下方支撑。

> 💡 **打法:**① **自下而上**,一层铺满再上二层;② 橙边危险砖是**定时炸弹**,能免则免;③ 顶部两层格子少,**最后收顶很快**;④ 时间充足,**宁可慢也要稳**;⑤ 大风来临前把危险砖补上支撑,是最优节奏!

**结算:**砌砖数、本局得分、历史最高分、已玩局数。
