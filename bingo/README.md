# 宾果 (🔢 宾果大赛 · 五连线)

> 分类:**对战棋牌** · 入口:/bingo/ · 免费在线 · 手机即点即玩

**目标:**双方各持随机 5x5 号码卡,号码球自动开出:**点掉你卡上出现的号码**,横竖斜连满 5 个算 1 条线,先集满 **5 条线**者 BINGO 获胜。号码每 1.6 秒开一颗,反应要快!

| 元素 | 效果 |
|---|---|
| 📣 开球 | 每 1.6 秒自动开一颗 1-75 的号 |
| 👆 点号 | 你卡上有就点掉,点错无效但不扣分 |
| 📈 连线 | 横竖斜 5 连 = 1 条线,实时计数 |
| 🤖 电脑 | 自动标记自己的卡,速度稳定 |
| 🏁 胜负 | 先满 5 线者胜,号码开完比线数 |

**操作:****点卡片上的号码**标记;**新局**换卡重开。开出未点的号会在顶部亮起,扫一眼卡就知道了!

> 💡 **打法:**① 目光扫卡的路线固定:<b>Z 字形</b>扫全卡,别乱看;② 优先点能同时贡献两条线的<b>交叉格</b>;③ 对角线最长凑,前面有空就顺手点;④ 电脑稳定不犯错,你的优势是<b>眼睛快</b>;⑤ 还剩 20 颗球时算算自己最短凑线路径,集中点那几个号。

**结算:**双方连线数、开出号码数、胜负、本局得分(胜 600 + 我的线 x80)、历史最高分、已玩局数。
