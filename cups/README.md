# 三仙归洞 (🥤 三仙归洞 · 杯下寻踪)

> 分类:**解压休闲** · 入口:/cups/ · 免费在线 · 手机即点即玩

**目标:**每局下注 20 金币:看小球放入杯中,三杯**快速交换**若干次后停下,**点中藏球的杯子**赢 40 金币,猜错损失下注。速度随局数上升,金币见底结束。

| 元素 | 效果 |
|---|---|
| 🥤 下注 | 每局固定下注 20 金币 |
| 👀 洗牌 | 杯子两两交换 4-8 次,速度渐快 |
| 👆 猜杯 | 停下后点一个杯子 |
| 💰 输赢 | 猜对 +40,猜错 -20 |
| 💸 结束 | 金币不足 20 时结束 |

**操作:****点杯子**下注猜球;**重开**重新开始。别眨眼,高手靠余光!

> 💡 **打法:**① 盯<b>球最后消失的那只杯</b>,别的都别看;② 杯子交叉时最容易看丢,视线放低看杯底;③ 洗牌次数越多越别慌,只跟最初那只;④ 连胜后速度会涨,见好就收;⑤ 这是眼力游戏,累了就休息,眼睛疲劳必输。

**结算:**剩余金币、连胜数、总局数、本局得分(剩余金币)、历史最高分、已玩局数。
