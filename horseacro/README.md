# 马上倒立 (🐎 马上倒立 · 一拍一定)

> 分类:**街机动作** · 入口:/horseacro/ · 免费在线 · 手机即点即玩

**目标:**节奏马技:**起倒有度**,连击称雄。

| 元素 | 效果 |
|---|---|
| 🐎 奔马 | 蹄下生风 |
| 🤸 倒立 | 绿圈撑起 |
| 🔴 颠簸 | 红圈伏低 |
| ⚠️ 落马 | 逞强必摔 |
| 🏆 结算 | 马技折分 |

**操作:**点屏**起立或伏鞍**。

**结算:**马技拍数、当前姿态、本局得分、历史最高分、已玩局数。
