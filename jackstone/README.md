# 抓子儿 (🪨 抓子儿 · 石落手翻)

> 分类:**解压休闲** · 入口:/jackstone/ · 免费在线 · 手机即点即玩

**目标:**节奏抓取:抛石后**在落地前抓够地上的石子**,再接住空中那颗;每关需求递增。

| 元素 | 效果 |
|---|---|
| 🪨 抛接 | 一抛一接一循环 |
| ✋ 抓取 | 空中点石子 |
| 📈 递增 | 关数=需抓数 |
| ❤️ 容错 | 落地/接空 -1♥ |
| 🏆 评级 | 五关全过抓子仙 |

**操作:**点「**🪨 抛**」→ **点石子**抓 → 点「**🤚 接**」。

> 💡 **打法:**① **抛要竖直**,歪了来不及抓;② 先把**该抓的数清楚**,别多抓漏抓;③ 石子**快落地才接**,抛高一点从容;④ 五子关**手速要求极高**,深呼吸;⑤ 失一关别慌,**石头还是那堆石头**!

**结算:**通过关数、抓子数、本局得分、历史最高分、已玩局数。
