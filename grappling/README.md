# 飞爪登城 (🪝 飞爪登城 · 一索上墙)

> 分类:**街机动作** · 入口:/grappling/ · 免费在线 · 手机即点即玩

**目标:**摆荡攀爬:抓锚点摆荡,**最高点松手**飞向更高锚点;45 米登顶,跌落扣爪。

| 元素 | 效果 |
|---|---|
| 🪝 锚点 | 两侧交替向上 |
| 🌀 摆荡 | 正弦节奏 |
| 🏁 城头 | 45 米插旗 |
| ⚠️ 跌落 | -1 爪,共三只 |
| 🏆 评级 | 登顶夜行飞爪侠 |

**操作:****点锚点**抓索,**再点画面**(空格)松手。

> 💡 **打法:**① **摆到最高点松手**,半空松是自杀;② 锚点**左右交替**,提前看好下一个;③ 落点差一点**也能抓**,先荡再说;④ 高处风大,**摆速会变**,用心记;⑤ 三只爪,**最后一只留给红旗**!

**结算:**攀升高度、本局得分、历史最高分、已玩局数。
