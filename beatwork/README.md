# 卡点大师 (🎼 卡点大师 · 全民节拍)

> 分类:**音乐节奏** · 入口:/beatwork/ · 免费在线 · 手机即点即玩

**目标:**三轨下落音游:音符压到判定圈时**点击对应轨道**(±60ms Perfect 三倍分,±130ms Good),**青色长条双倍分**;BPM 100 渐进 140,连击叠加加成,42 秒后按准确率结算。

| 元素 | 效果 |
|---|---|
| 🎼 三轨 | 左中右三条轨道,点哪条判哪条 |
| 🟪 音符 | 粉色单击,青色长条双倍分 |
| ✨ 判定 | Perfect ±60ms / Good ±130ms / 其余 Miss |
| 🔥 连击 | 连击每 8 次加成一档,断连清零 |
| 📈 提速 | BPM 100 起步,每拍 +0.7 封顶 140 |

**操作:**点对应**轨道**(键盘 **←/↑/→** 或 **1/2/3** 同效);节奏游戏戴耳机体验翻倍!

> 💡 **打法:**① **眼睛盯判定圈**,用余光扫上方来音,不要抬头追音符;② 心里默打拍子,宁可稳定 Good 也别忽快忽慢追 Perfect;③ 青色长条出现后**同轨下一拍大概率空**,腾出手准备另一轨;④ 连击加成每 8 连一档,断了别上头,**稳住下一拍**比懊恼值钱;⑤ 后半段 BPM 140 时拍距 0.43 秒,提前半拍把手指放轨上!

**结算:**准确率、Perfect/Good/Miss 计数、最大连击、本局得分、历史最高分、已玩局数。
