# 沙画瓶 (🫙 沙画瓶 · 一层一层来)

> 分类:**创意涂鸦** · 入口:/sandbottle/ · 免费在线 · 手机即点即玩

**目标:**分层创作:选色→按住倒沙→松手定层,**七层成瓶**;用色数与层厚决定评分,零失败可反复创作。

| 元素 | 效果 |
|---|---|
| 🎨 五色沙 | 金/橘/蓝/绿/紫 |
| ⏳ 倒沙 | 按住时长=层厚 |
| ✨ 薄层 | 全部 ≤20% 加成 80 |
| 🌀 摇匀 | +10 紧实度 |
| 🏆 计分 | 用色 x70 + 层数 x30 |

**操作:**点**色盘**选沙,**按住倒沙**松手定层。

> 💡 **打法:**① **先深后浅**层次最清楚;② 薄层(≤20%)有大师加成,**短按勤倒**;③ 相邻层**别用近似色**,融在一起白搭;④ 摇匀会压实但不改配色,**成瓶前摇两下**;⑤ 分数只是顺带,**截图你的瓶子才是正经**!

**结算:**铺层数、用沙色、成品得分、历史最高分、已做作品数。
