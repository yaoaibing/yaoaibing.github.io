# 空当接龙 (♠️ 空当接龙 · 全开纸牌)

> 分类:**对战棋牌** · 入口:/freecell/ · 免费在线 · 手机即点即玩

**目标:**52 张明牌开局 8 列:牌只能移到**红黑交替且点数小 1** 的牌上,或放进空自由格(共 4 格);基础堆从 A 起同花色收牌,收满 52 张即胜。全明牌无运气成分,是纯逻辑纸牌。

| 元素 | 效果 |
|---|---|
| ♠️ 牌桌 | 8 列明牌,列内必须红黑交替降序叠放 |
| 🆓 自由格 | 4 格,每格暂存 1 张,随时取回 |
| 🅰️ 基础堆 | 按花色从 A 到 K 逐张收,不可反悔 |
| 👇 操作 | 点选牌再点目标,点错自动取消 |
| 🏆 胜负 | 52 张全部收进基础堆获胜 |

**操作:****点牌选中**(高亮),再点目标列/自由格/基础堆完成移动;**新局**重开。电脑不参与,全程自己想。

> 💡 **打法:**① 优先翻牌列里的<b>小牌和 A</b>,尽早清基础堆;② 自由格是黄金资源,放之前想好什么时候取回;③ 同点数的牌优先移<b>黑色</b>还是红色?看哪边压着更多暗牌就先腾哪边;④ 列头出现连续可排的降序就立刻整理,别攒;⑤ 实在卡死:把一张大牌塞自由格换整列流通,经常一步活全局。

**结算:**完成张数、步数、用时、本局得分(收 1 张 20 分,胜局 +500)、历史最高分、已玩局数。
