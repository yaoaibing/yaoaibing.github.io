# 旋律侦探 (🕵️ 旋律侦探 · 找出不同音)

> 分类:**音乐节奏** · 入口:/pitchpick/ · 免费在线 · 手机即点即玩

**目标:**音高分辨训练:**五个音顺序播放**,其中一个音高不同;**点编号**(1-5)选出异类,连对加分,10 轮随机出题。

| 元素 | 效果 |
|---|---|
| 👂 听音 | 每轮自动播放五个音 |
| 🔢 选号 | 点你认为不同音的编号 |
| 🔄 重播 | 按 R 键重听 |
| 📈 递增 | 音高差随机 1-3 半音 |
| 🏆 评级 | 连对 6 次金耳朵 |

**操作:**听完**点编号**(1-5)或按 **R** 重听。

> 💡 **打法:**① 四个音一样,一个不同——**找「突然怪」的那个**;② 别逐个记忆,**感受旋律流是否顺畅**;③ 错了会告诉你正确编号,<b>下组同位置注意</b>;④ 连对越多分越高,**不确定时选第一感觉**!

**结算:**轮数、连对、本局得分、历史最高分、已玩局数。
