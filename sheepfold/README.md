**目标:**几何围栏:**点两点连栏杆**,闭合多边形圈住羊;60 秒内圈住越多越好。

| 元素 | 效果 |
|---|---|
| 🐑 六只 | 在草地上乱跑 |
| 📐 闭合 | 首尾相接才算 |
| ✅ 圈住 | 每只 +30 |
| ✅ 全圈 | 六只全围 +200 |
| 🏆 评级 | 六只全圈好牧人 |

**操作:****点两点**连栏杆,**闭合**围羊。
