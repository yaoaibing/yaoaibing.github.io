# 困棋孤行 (♟ 困棋孤行 · 走后焚格)

> 分类:**对战棋牌** · 入口:/isolate/ · 免费在线 · 手机即点即玩

**目标:**焚地困敌:**走后焚格断退路**,困死对手;三局结算。

| 元素 | 效果 |
|---|---|
| ♟ 走法 | 直线任意远 |
| 🔥 焚格 | 离开即毁 |
| 🚫 焦土 | 谁都不能走 |
| 🏳 困死 | 无路者输 |
| 🏆 结算 | 三局胜负 |

**操作:**点**白子**再点**绿框落点**。

> 💡 **打法:**① **开局抢中央**,路最宽;② **别贴边走**,边路烧完自己先困死;③ 盯着**对手的出路数**,比他还多就稳;④ **对称走位**最稳,镜像他;⑤ 三局困两局,**棋摊挂你的困局谱**!

**结算:**对局数、出路数、本局得分、历史最高分、已玩局数。
