# 灌溉引水 (💧 灌溉引水 · 一渠活水)

> 分类:**烧脑益智** · 入口:/irrigate/ · 免费在线 · 手机即点即玩

**目标:**水路连通:挖渠让水**自动漫延**到庄稼;60 秒内引到即过关。

| 元素 | 效果 |
|---|---|
| 💧 水源 | 在最左列 |
| 🌾 庄稼 | 随机一格,枯黄待水 |
| 🪣 挖渠 | 点格打通,水漫延 |
| ⏱ 时限 | 60 秒 |
| 🏆 评级 | 10 格内引到引水师 |

**操作:****点格子**挖渠,水自动流向连通格。

> 💡 **打法:**① **先看庄稼在哪**,规划最短路径;② **直线最快**,别拐弯;③ 水**自动漫延**,连通就够;④ 挖错了**水会白流**,先想后点;⑤ 引到庄稼,**全田都绿了**!

**结算:**挖渠数、本局得分、历史最高分、已玩局数。
