# 虎羊棋 (🐯 虎羊棋 · 一虎六羊)

> 分类:**对战棋牌** · 入口:/tigerboard/ · 免费在线 · 手机即点即玩

**目标:**围猎博弈:虎沿直线走一步或**跳吃隔一只的羊**;羊每轮走一步;虎无路可走则羊胜,吃满 4 羊虎胜。

| 元素 | 效果 |
|---|---|
| 🐯 跳吃 | 隔一只羊跳过去即吃 |
| 🐑 围堵 | 让虎无处可走 |
| 👣 步伐 | 羊虎都走一步 |
| 🤖 AI | 虎贪吃也会绕 |
| 🏆 计分 | 胜 420 连胜滚 |

**操作:****点羊**选中,**点绿圈**走一步。

> 💡 **打法:**① **羊别一字排开送虎跳**,错落成网才安全;② 虎跳吃时**看它落点**,落点差就大胆送;③ 中路最空,**先占中心点**;④ 虎会贴着羊找跳板,**收网时补缺口**;⑤ 数空点:**虎的出路越少,网越成功**!

**结算:**比分、被吃羊数、本局得分、历史最高分、已玩局数。
