> 分类:**组装拼装** · 入口:/assemblyln/ · 免费在线 · 手机即点即玩

**目标:**顺序装配:随机 3-5 道工序的工单,**按序点击工位**;全对出厂,点错报废换新;60 秒冲产量。

| 元素 | 效果 |
|---|---|
| 📋 工序卡 | 每件产品随机 3-5 道 |
| 🔨 五工位 | 冲压/焊接/喷漆/质检/包装 |
| ✓ 出厂 | +80 |
| ✗ 报废 | -20 换新产品 |
| 📈 难度 | 每 3 台加一道工序 |

**操作:**点**工位按钮**(键盘 **1-5**)。
