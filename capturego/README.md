> 分类:**对战棋牌** · 入口:/capturego/ · 免费在线 · 手机即点即玩

**目标:**吃子棋:7 路棋盘黑白对弈,**围死无气即提**,先提 4 子胜;含禁着点(自杀)与打劫规则,AI 贪心提子救子。

| 元素 | 效果 |
|---|---|
| 🔒 气 | 棋子上下空的交叉点 |
| ✂️ 提子 | 对方棋组无气即全部提掉 |
| 🚫 禁着 | 自杀手不可下(红圈) |
| 🎯 目标 | 先提 4 子获胜 |
| 🏆 计分 | 胜 400 + 提子 x30 |

**操作:****点击交叉点**落子。

> 💡 **打法:**① **叫吃**(只差一口气)要连追,**一口气都不能给**;② 自己的子被叫吃,**长气或反提**;③ **双叫吃**一子两用最凶;④ 边角气少,**别把子下到墙角送吃**;⑤ 红圈禁着点,**AI 不会犯的错你也别犯**!
