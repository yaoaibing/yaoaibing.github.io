# 影子搭档 (👥 影子搭档 · 同步走位)

> 分类:**烧脑益智** · 入口:/rewind/ · 免费在线 · 手机即点即玩

**目标:**一人多机关的同步谜题:**先走一段路,按「分身」留下影子**,影子会从起点重放你到那一刻的全部走位(含撞墙的空白步);用「原地等」错开节拍,让我和最多 4 个影子同时踩住所有压力板,5 关递增。

| 元素 | 效果 |
|---|---|
| 👥 分身 | 复制你到当前为止的完整走位 |
| ⏳ 原地等 | 空转一拍,用来卡影子的到站时间 |
| 🟡 压力板 | 必须同一回合全部被踩住 |
| 🧱 墙 | 人和影子都撞不过去,撞墙也算一拍 |
| 🏁 5 关 | 最少步数 6/9/11/14/17 步 |

**操作:**滑动或方向键走路,「分身」投放影子,「原地等」调节拍;**本关**重来。先想清楚谁留在哪块板上!

> 💡 **打法:**① 影子从<b>起点</b>开始重放,投放时机决定它停在哪;② 想让影子留在板上,就在它到板那一刻之后别再动它,<b>让它撞墙空转</b>也行;③ 「原地等」是最强的节拍工具,多等一拍就错开一格;④ 先规划终态站位,再倒推每段路;⑤ 卡住就「本关」重来,别在乱局上硬走!

**结算:**通关数、总步数、影子使用数、本局得分(每关 300 - 步数 x3 - 影子 x20)、历史最高分、已玩局数。
