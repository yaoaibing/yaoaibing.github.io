# 火烧连营 (🔥 火烧连营 · 借风纵火)

> 分类:**策略战棋** · 入口:/lianying/ · 免费在线 · 手机即点即玩

**目标:**蔓延模拟:**下火选风看火势**,焚营计分;三轮结算。

| 元素 | 效果 |
|---|---|
| 🔥 火种 | 限两处 |
| 🧭 风向 | 四方可选 |
| 🏕 敌营 | 焚一座+10 |
| 🚫 粮车 | 烧了-60 |
| 🏆 结算 | 三轮总分 |

**操作:**点**两处格子**下火,点**风向钮**放火。

> 💡 **打法:**① **火种下在营密处**,火多路宽;② **风向先想好**,别点完火再找风;③ 粮车**别点别烧**,一车赔六座营;④ 风向**压着连营长边**烧最赚;⑤ 三轮**记着上次的风路**,越烧越精!

**结算:**焚营座数、本局得分、历史最高分、已玩局数。
