# 弹射靶场 (🎯 弹射靶场 · 一发入魂)

> 分类:**街机动作** · 入口:/bullseye/ · 免费在线 · 手机即点即玩

**目标:**从发射器**拖拽**调整角度与力度发射弹球,考虑风力影响,命中远处靶标得分;10 发弹药打完结算。

| 元素 | 效果 |
|---|---|
| 🎯 拖拽 | 按住弹射器拖拽调角度力度 |
| 💨 风 | 每发随机风力,顺逆影响弹道 |
| 🟡 靶标 | 大靶 50 / 中靶 100 / 小靶 200 |
| 🏹 弹药 | 共 10 发 |
| 🏁 结束 | 10 发用完结算 |

**操作:****按住弹射器拖拽**瞄准,松手发射;**重来**重开。记住上一发的落点,微调比重瞄更准!

> 💡 **打法:**① 第一发用中等力度试弹,<b>记落点</b>;② 顺风减力逆风加力,差值凭感觉记;③ 小靶分高但难打,先保大靶稳拿分;④ 连续命中同位置靶标时,弹道参数几乎不用改;⑤ 最后一发全力以赴,可能翻盘!

**结算:**总分、命中数、最好一击、本局得分(总分)、历史最高分、已玩局数。
