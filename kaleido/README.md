# 万花筒 (🎨 万花筒 · 对称画板)

> 分类:**创意涂鸦** · 入口:/kaleido/ · 免费在线 · 手机即点即玩

**目标:**对称创作画板:任意涂抹自动生成 **6 重 ×2 镜像对称**花纹;六色画笔三档粗细,撤销清空随便折腾;点完成后按笔画数结算创作分,纯解压零失败。

| 元素 | 效果 |
|---|---|
| 🎨 对称 | 6 重旋转 × 镜像,共 12 瓣 |
| 🌈 调色 | 粉/金/绿/蓝/紫/白 六色画笔 |
| ✍️ 笔刷 | 细/中/粗 三档 |
| ↶ 修改 | 撤销上一笔,一键清空 |
| ✅ 完成 | 笔画 x40 + 100 结算创作分 |

**操作:****按住拖动**作画;点**色块**换色、**圆点**换粗细;**撤销/清空/完成**(键盘 Z/C)。完成后再来一局从头画!

> 💡 **打法:**① 先从中心向外画<b>放射线</b>定骨架,再沿外圈补花纹;② 相邻两笔换色,<b>层次立刻不一样</b>;③ 粗笔铺底、细笔勾边,两步就有精品感;④ 撤销只退一笔,<b>大胆画</b>,十二重对称会替你美化一切;⑤ 完成后记得截图保存,作品不支持存档,创作分只是留念!

**结算:**笔画数、创作分(100 + 笔画 x40)、历史最高分、已玩局数。
