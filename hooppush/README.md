# 推铁环 (🦯 推铁环 · 稳步向前)

> 分类:**体育竞技** · 入口:/hooppush/ · 免费在线 · 手机即点即玩

**目标:**平衡推进:**按住推杆**加速,**松手**起跳过坑;掉坑三次收场。

| 元素 | 效果 |
|---|---|
| 🦯 推杆 | 按住加速 |
| 🕳️ 缺口 | 松手跳过 |
| ⚠️ 掉坑 | -1 环共三只 |
| 🏁 计分 | 里程+跳分 |
| 🏆 评级 | 300 米推环高手 |

**操作:****按住「推」**(空格)前进,**松手**跳。

> 💡 **打法:**① **按住别松**,铁环越滚越稳;② 看到**黑色缺口**提前半秒松手;③ 跳完立刻**按住继续推**;④ 缺口变密,**手要更快**;⑤ 三只环,**最后一只别浪**!

**结算:**推出距离、本局得分、历史最高分、已玩局数。
