# 音程听辨 (🎼 音程听辨 · 度数之耳)

> 分类:**音乐节奏** · 入口:/interval/ · 免费在线 · 手机即点即玩

**目标:**音程听辨:播放**根音+上方音**两个音,从 4 个选项里选出音程;纯一度到八度共 8 种随机出题,连对每题 +100 + 连对 x10。

| 元素 | 效果 |
|---|---|
| 🎵 根音 | 随机 C4-A4 起始 |
| 🔢 音程 | 小三大三/纯四纯五/大小七/八度 |
| 🔁 重听 | 随时重放,不限次数 |
| 🔥 连对 | 每题 100 + 连对 x10 |
| 🏆 评级 | 连对 7 次度数之耳 |

**操作:****点选项**(键盘 **1-4**)作答;下方「🔁 重听」重放。

> 💡 **打法:**① 先哼根音再哼第二音,**身体会记住距离**;② 「稳」多是纯四五度,「亮」是大三度,「涩」是小二/小七;③ 排除法:**同度和八度最好认**,先排除它们;④ 重听不扣分,**多听两遍不亏**;⑤ 每天练 10 轮,一周见效!

**结算:**连对、本局得分、历史最高分、已玩局数。
