# 蒸汽竞速 (🚂 蒸汽竞速 · 锅炉豪赌)

> 分类:**竞速赛车** · 入口:/loco/ · 免费在线 · 手机即点即玩

**目标:**资源管理:**气压水位两手抓**,爆管即停;两圈竞速。

| 元素 | 效果 |
|---|---|
| 🪵 加煤 | 气压+8 |
| 💨 排汽 | 气压-16 |
| 💧 添水 | 水位+26 |
| ⚠️ 爆管 | 超压停车 |
| 🏁 赛程 | 两圈分胜负 |

**操作:**点**加煤/排汽/添水**管锅炉,跑赢对手。

> 💡 **打法:**① **起步先加两煤**,气压就是速度;② 气压 **88 以上必排汽**,别赌;③ **水位低于四分之一**赶紧添,烧干掉压更快;④ 排汽**别连点**,过犹不及;⑤ 终点前**可以赌一把高压**,冲线要紧!

**结算:**完成圈数、本局得分、历史最高分、已玩局数。
