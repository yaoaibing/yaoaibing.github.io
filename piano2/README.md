# 掌上电子琴 (🎹 掌上电子琴 · 自由弹奏)

> 分类:**解压休闲** · 入口:/piano2/ · 免费在线 · 手机即点即玩

**目标:**8 键电子琴:教学模式下**跟着高亮键弹奏**内置 8 首曲目(小星星/欢乐颂/生日歌等),按对前进按错重来;也可切到自由弹奏随便创作,三种音色可换。

| 元素 | 效果 |
|---|---|
| 🎹 琴键 | 8 个白键,音高从 do 到高音 do |
| ⭐ 教学 | 高亮键依次亮,跟按即可 |
| 🎵 曲库 | 小星星/两只老虎/欢乐颂/生日歌/小蜜蜂/茉莉花/雪绒花/粉刷匠 |
| 🎚 音色 | 钢琴/八位音/电子琴三种波形 |
| ✨ 连击 | 教学曲全对无失误有连击加成 |

**操作:****点琴键**发声;**曲目**换歌,**音色**换波形(键盘 A-K 对应 8 键)。教学曲里高亮键就是下一个该按的!

> 💡 **打法:**① 跟歌先听一遍<b>旋律节奏</b>,心里有拍子再上手;② 连击加成要求零失误,慢一点没关系;③ 欢乐颂开头两音相同,别当成手滑按了两次;④ 自由模式下试试同时按两个键,和弦立刻高级;⑤ 音色换了旋律感会变,选顺耳的练!

**结算:**完成曲目数、连击记录、自由弹奏时长、历史最高分、已玩局数。
