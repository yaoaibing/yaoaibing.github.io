# 造桥大师 (🌉 造桥大师 · 千斤一发)

> 分类:**建造物理** · 入口:/bridge/ · 免费在线 · 手机即点即玩

**目标:**物理造桥:两次点击**连出钢梁**(锚点/节点之间,单梁 ≤210px),搭出能扛卡车的桁架;点**试车**后卡车真实压过,**梁应变超 9% 会断裂**;三座桥全通车即通关,剩余钢材折分。

| 元素 | 效果 |
|---|---|
| 🌉 工程 | 3 座桥,跨度 290→450 递增 |
| 📐 节点 | 每关 6-8 个,两两之间自由连线 |
| 💰 预算 | 钢材总长度有限,按长度扣 |
| 🧪 试车 | 卡车重量真实压弯桥梁 |
| 💥 断裂 | 应变 >9% 崩断,断梁不承重 |

**操作:****点锚点→点落点**连梁(可连任意两点构成三角);**试车**(空格)验收;**重搭**清空本关。

> 💡 **打法:**① 桥面下<b>先铺一根直梁</b>连通两岸,再从梁中点向崖壁拉斜撑组成三角;② 三角形是不变形结构,<b>每个节点至少 3 根梁</b>交汇;③ 跨中(最中间)受力最大,<b>中间多放节点</b>缩短单跨;④ 试车看红梁位置,<b>塌哪补哪</b>最省钢材;⑤ 预算剩一半也能过:短桥斜撑从两岸向中间对搭,别从中间悬挑!

**结算:**通过工程数、剩余钢材、梁数、本局得分(每桥 300 + 剩余预算一半)、历史最高分、已玩局数。
