# 荒野求生 (🏕️ 荒野求生 · 孤岛四十里)

> 分类:**生存挑战** · 入口:/survive/ · 免费在线 · 手机即点即玩

**目标:**生存规划:每天 **3 点行动力**分配给觅食/取水/伐木/探索,入夜各消耗 1 食物和水,断供重伤,夜间有随机事件;攒 **12 木材 + 打火石**点燃篝火,15 天内获救获胜。

| 元素 | 效果 |
|---|---|
| 🍖 觅食 | 随机 +2~4 食物 |
| 💧 取水 | 随机 +2~4 水 |
| 🪵 伐木 | 随机 +1~3 木材,点火刚需 |
| 🧭 探索 | 补给/打火石/受伤,概率事件 |
| 🔥 点火 | 木材 12 + 打火石,立即获救 |

**操作:**点 **四个行动按钮**(键盘 **1-4**)消耗行动力,行动力用尽自动入夜结算;**🔥点火**(F)在资源达标后可用。

> 💡 **打法:**① 前 3 天<b>食物和水优先</b>,断一晚 -18 血,两晚就没;② 打火石只能靠<b>探索</b>,中期每天留 1 点给探索;③ 木材 12 根按平均 2 根/次,大约 6 次伐木,<b>分摊到多天</b>更安全;④ 夜间冷雨会湿柴 -1 木材,木材目标<b>多备 2 根</b>容错;⑤ 血量低于 40 就别探索了,稳定觅食取水回节奏,活到点火才是赢!

**结算:**存活天数、剩余生命、本局得分(获救 400 + 剩余天数 x40 + 生命 x3)、历史最高分、已玩局数。
