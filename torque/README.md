# 六角扭矩 (🔧 六角扭矩 · 对角拧紧)

> 分类:**组装拼装** · 入口:/torque/ · 免费在线 · 手机即点即玩

**目标:**扭矩装配:按**对角星形顺序**逐颗拧紧,**按住蓄力、绿区(68-88)松手**;超力滑牙扣分,五颗完成结算。

| 元素 | 效果 |
|---|---|
| 🔧 顺序 | 1→3→5→2→4 星形防翘 |
| 🟢 绿区 | 扭矩 68-88 达标 |
| ⚠ 滑牙 | >88 扣 30 重新拧 |
| 📈 蓄速 | 越到后面冲得越快 |
| 🏆 计分 | 每颗 100,零滑牙 +100 |

**操作:****按住「🔧 拧紧」**蓄力,**松手**定格(按住空格同效)。

> 💡 **打法:**① **看指针别看螺丝**,指针到绿区中部就松;② 每颗螺栓**蓄力速度不同**,前慢后快;③ 滑牙一次 -30,**宁欠勿过**;④ 星形顺序是防翘曲的行规,**游戏里也照办**;⑤ 最后一颗最容易手抖,**深呼吸慢慢来**!

**结算:**完工螺栓数、滑牙次数、本局得分、历史最高分、已玩局数。
