# 猜成语 (🟩 猜成语大师 · 六次机会)

> 分类:**烧脑益智** · 入口:/wordle/ · 免费在线 · 手机即点即玩

**目标:**Wordle 玩法猜成语:每题 6 次机会输入四字成语,系统按位给出**绿(对)/黄(有但错位)/灰(无)**反馈,推理出正确成语即胜。

| 元素 | 效果 |
|---|---|
| 🟩 绿格 | 字和位置都对 |
| 🟨 黄格 | 成语含此字但位置不对 |
| ⬛ 灰格 | 成语不含此字 |
| 👉 输入 | 从候选成语列表点选提交 |
| 🏁 胜负 | 6 次内猜中即胜 |

**操作:****点候选成语**提交猜测(键盘 1-4 选);**换一题**跳题。第一猜用字面差异大的成语,信息量最大!

> 💡 **打法:**① 第一猜选<b>四字互不重复</b>的成语,排除面最大;② 黄格字别浪费:把它挪到没试过的位置;③ 绿格字直接锁死,围绕它组词;④ 剩 2 次时优先选「不与其他候选冲突」的答案;⑤ 灰格字在后续猜测中绝对不要再出现!

**结算:**答对题数、平均尝试次数、连对最高、本局得分(胜 200 + 剩余机会 x50)、历史最高分、已玩局数。
