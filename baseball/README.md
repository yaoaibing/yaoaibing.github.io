# 棒球 (⚾ 棒球全垒打 · 挥棒时机)

> 分类:**街机动作** · 入口:/baseball/ · 免费在线 · 手机即点即玩

**目标:**看准球飞进手套的瞬间挥棒,**越晚越甜**。时间差越小得分越高,累计三次好球结束打席。

| 元素 | 效果 |
|---|---|
| ⚾ 挥棒 | 点屏幕或按空格,球飞行途中都能挥 |
| 🏆 全垒打 | 进垒前 0.05 秒内挥中,+4 分 |
| 🥈 安打 | 0.1 秒内二垒安打 +2,0.15 秒内一垒安打 +1 |
| 🚫 好球 | 挥太早、界外、球进手套没挥都算 1 次好球 |
| ⏱️ 加速 | 得分越高,球飞得越快 |

**操作:**点屏幕任意位置或按<kbd>空格</kbd>挥棒,底部**新局**重开。

> 💡 **打法:**① **别抢拍**,球快进手套那一下再挥,越晚越甜;② 快速球飞行时间短,提前半拍准备;③ 曲球路径有弧度,盯住球本身别盯投手;④ 已经两好球时宁可放过边缘球,别乱挥;⑤ 连续得分后球会提速,更要盯紧。

**结算:**得分、打席球数、三振次数、称号、历史最高分、已玩局数。
