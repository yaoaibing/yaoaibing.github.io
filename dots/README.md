# 点格成圈 (⚫ 点格成圈 · 圈地博弈)

> 分类:**策略战棋** · 入口:/dots/ · 免费在线 · 手机即点即玩

**目标:**经典点格棋:5x5 点阵,轮流**连相邻两点**成线,围住四方成格得分,**闭格者连走**;25 格圈完,多者胜。

| 元素 | 效果 |
|---|---|
| ⚫ 连线 | 相邻两点间画线,一人一笔 |
| ⬜ 圈格 | 补齐方框第四边即得格 |
| 🔁 连走 | 圈到格子可以继续画 |
| 🤖 AI | 贪心闭格,偶有失误 |
| 🏆 胜负 | 格子多者胜 |

**操作:****点两个相邻点**画线;**双击同点**取消选择。

> 💡 **打法:**① 前期避免画出<b>第三边</b>——那等于送 AI 一格;② 圈格可以连走,<b>闭一格后环顾全盘</b>找连锁;③ 数格阶段(最后)常出现<b>长链</b>,会算赠格的赢;④ AI 贪心闭格,**故意留双格链让它吃小头**;⑤ 中央格四邻八线,优先控制中腹!

**结算:**双方格子数、本局得分、历史最高分、已玩局数。
