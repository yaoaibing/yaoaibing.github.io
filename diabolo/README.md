# 抖空竹 (🧶 抖空竹 · 竹哨嗡嗡)

> 分类:**街机动作** · 入口:/diabolo/ · 免费在线 · 手机即点即玩

**目标:**节奏技巧:左右交替抽杆攒转速;**转满自抛**,落回 0.42 秒窗口内点接得高分;停转或脱手扣心。

| 元素 | 效果 |
|---|---|
| 🧶 抽杆 | 同手连抽会泄劲 |
| 📈 转速 | 满 100 自动抛起 |
| 🧤 接抛 | 窗口内点任意键 |
| ⚠️ 失手 | 停转/漏接 -1❤ |
| 🏆 评级 | 接抛 8 次空竹高手 |

**操作:**点「**◀ 左手 / 右手 ▶**」(键盘 **z / m**)交替抽,抛起后**点任意键**接。

> 💡 **打法:**① **左右左右**像抖绳子,别同手连抽;② 转速过半哨音就响,**手感来了别停**;③ 抛起后**眼睛盯落点**,别提前点;④ 接抛窗口很短,**手放在键上等**;⑤ 失一球深呼吸,**节奏找回来**!

**结算:**接抛数、本局得分、历史最高分、已玩局数。
