# 骰子庄园 (🌾 骰子庄园 · 点数成金)

> 分类:**骰子冒险** · 入口:/dicefarm/ · 免费在线 · 手机即点即玩

**目标:**骰子种田:每回合掷两骰**选一颗**种进 4x4 田;收获时每格得分=点数+相邻同点数×3;三季(3 块田)累计结算。

| 元素 | 效果 |
|---|---|
| 🎲 双骰 | 二选一种下 |
| 🤝 加成 | 正交相邻同点各 +3 |
| 🌾 三季 | 田满即收获开新季 |
| 🧮 得分 | 点数+加成累加 |
| 🏆 评级 | 300 收成庄园主 |

**操作:****点骰子**选中 → **点空田格**种下。

> 💡 **打法:**① **相邻同点是核心**,点数大小不如位置重要;② 优先把大点数**种进已有同点的角落**;③ 一块田 16 格,**中前期铺底子**;④ 别为 +3 追小点数,**6 邻 6 才是 15 分大户**;⑤ 最后几格没得挑,**见缝就插**!

**结算:**收成总分、田块进度、历史最高分、已玩局数。
