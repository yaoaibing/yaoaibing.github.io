# 窗花剪纸 (🧧 窗花剪纸 · 一剪开花)

> 分类:**创意涂鸦** · 入口:/papercut/ · 免费在线 · 手机即点即玩

**目标:**对称剪纸:折叠红扇面上**点出剪口**,展开后按对折层数**对称开花**;4/8/12 层可切换,展开即结算,可反复创作。

| 元素 | 效果 |
|---|---|
| ✂️ 剪口 | 扇面上点出镂空 |
| ✖️ 对折 | 4/8/12 层对称切换 |
| 🧧 展开 | 呈放射窗花并计分 |
| 🎨 计分 | 剪口 x20 + 层数 x10 |
| 🏆 评级 | 零失败创意工坊 |

**操作:****点纸面**下剪口;「**对折**」「**展开**」在下方。

> 💡 **打法:**① 靠近**扇心剪大口**,边缘剪小口,层次分明;② 12 层对称一点成花,**别剪太密**;③ 展开有惊喜,**每次都值得截图**;④ 想要雪花感就用 12 层+多小口;⑤ 剪纸不计成败,**年味自己剪出来**!

**结算:**剪口数、作品数、累计得分、历史最高分、已做作品数。
