# 陶艺工坊 (🏺 陶艺工坊 · 一抔土一炉火)

> 分类:**模拟经营** · 入口:/pottery/ · 免费在线 · 手机即点即玩

**目标:**制陶两段式:**按住拉坯自动塑型**(贴合轮廓计相似度),进窑后**在目标温度 ±4° 时停火**。

| 元素 | 效果 |
|---|---|
| 🏺 拉坯 | 按住塑形,相似度 70% 才收 |
| 📐 轮廓 | 虚线是标准答案 |
| 🔥 炉温 | 摆动指针停在色带 |
| 🏺 三件 | 素坯碗/梅瓶/茶盏 |
| 🏆 评级 | 三件上品陶艺师傅 |

**操作:****按住屏幕**拉坯,进窑后点「**🔥 出窑**」停火。

> 💡 **打法:**① 拉坯**全程按住别松**,松手那段就细了;② 相似度不到 70% 会**报废重拉**;③ 炉温指针**来回摆**,预判它的速度;④ 色带中央 ±4° 是满分,**宁等一圈别乱点**;⑤ 三件器型不同,**轮廓宽窄看仔细**!

**结算:**出品件数、坯型分、本局得分、历史最高分、已玩局数。
