# 打字达人 (⌨️ 打字达人 · 字母雨)

> 分类:**烧脑益智** · 入口:/typing/ · 免费在线 · 手机即点即玩

**目标:**字母不断从屏幕上方落下,点下方**虚拟键盘**的对应字母键将其击碎得分;字母<b>落地扣一条命</b>,3 条命用完结束。金色字母分值三倍,连击有倍率,掉落速度持续加快。

| 元素 | 效果 |
|---|---|
| ⌨️ 键盘 | 屏幕下方是 QWERTY 虚拟键盘,点键射击 |
| 🎯 击碎 | 同屏可有多个字母,击中最下面的最划算 |
| ✨ 金字母 | 随机出现,击中 90 分 |
| 💔 落地 | 字母砸到地面扣 1 命,共 3 命 |
| 🚀 加速 | 每 15 秒掉落速度上一档,后期很考验眼手 |

**操作:**直接**点虚拟键盘**的字母键;物理键盘也支持(电脑上直接敲)。**难度**切换三档速度,**新局**重开。

> 💡 **打法:**① 优先打**最低**的字母,它马上要落地;② 两颗字母快重叠时,先打金色的;③ 手指放在键盘中央(F/G/H/J 一带)少移动;④ 连击别断:宁可放过高分也不打错键,打错键连击清零;⑤ 后期别盯着单颗,用余光扫整片天。

**结算:**得分、击碎字母数、最大连击、漏掉个数、难度、历史最高分、已玩局数。
