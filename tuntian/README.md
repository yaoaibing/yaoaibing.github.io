# 屯田令 (🌾 屯田令 · 且耕且守)

> 分类:**策略战棋** · 入口:/tuntian/ · 免费在线 · 手机即点即玩

**目标:**资源分配:每季 6 丁分屯田/修墙/哨探;夜里按城防拒敌,**墙破粮空即败**。

| 元素 | 效果 |
|---|---|
| 🌾 屯田 | 每丁 +3 担粮 |
| 🧱 修墙 | 每丁 +1 城防 |
| 🔍 哨探 | 报敌军人数 |
| ⚔️ 夜袭 | 城防≥敌军守住 |
| 🏆 评级 | 五季全守屯田都尉 |

**操作:****点三栏**分派(键盘 **1-3**),点「**🍂 入秋**」(空格)结算。

> 💡 **打法:**① **粮是发饷的根本**,前两季多屯田;② 不哨探就是盲打,**至少留一丁侦察**;③ 城防叠上去**一劳永逸**,修墙不吃亏;④ 敌军 3-7 人,**墙高过 5 基本稳**;⑤ 每季发粮,**存粮见底也会输**!

**结算:**守土次数、存粮、本局得分、历史最高分、已玩局数。
