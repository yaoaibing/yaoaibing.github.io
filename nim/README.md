# 取子对弈 (🪵 取子对弈 · 抢最后一步)

> 分类:**对战棋牌** · 入口:/nim/ · 免费在线 · 手机即点即玩

**目标:**Misère Nim(反尼姆)对战:桌上 3~5 堆木柴,双方轮流从<b>任意一堆</b>取走至少一根(可整堆拿走),**取到最后一根者判负**。每局都由系统先发,而且只发"先手有必胜解"的局——你走对了就能赢,输了说明算错了。电脑按尼姆和出招:堆里出现大堆时用标准尼姆把异或和清零,一旦只剩 1 根的小堆就改用奇偶规则(把奇数堆 1 留给对手)。胜 3 局封胜,输 3 局结束。

| 元素 | 效果 |
|---|---|
| 🪵 木堆 | 3~5 堆,每堆 2~7 根,每局重新发 |
| 👉 取柴 | 选一堆,取 1 / 2 / 3 / 全拿 |
| 💀 判负 | 拿走最后一根的人输这一局 |
| 🤖 电脑 | 按尼姆和 + 末盘奇偶规则应招 |
| 🏁 胜负 | 先取满 3 胜定胜负,输 3 局结束 |

**操作:****点一堆选中**(高亮描边),再按 <b>取1 / 取2 / 取3 / 全拿</b>——按钮只在选中堆够数时可点,灰掉就是不能点;**↻ 重开**重发一局。键盘 1/2/3/A 对应四个取法,↑↓ 换堆。

> 💡 **打法:**① 把每堆根数写成<b>二进制</b>,各列 1 的个数全为偶数就是安全位;② 留给对手 <b>1-1 / 1-1-1-1</b> 这种奇偶格局才稳,末盘规则会翻脸;③ 只剩一堆时别整堆端走,留 1 根最毒;④ 对手只剩两堆且都是 1,<b>拿掉一整堆</b>就赢;⑤ 拿不准就 ↻ 重开重发一局,换一副牌再算。

**结算:**本局胜场、剩余生命、桌上余柴、本局得分(每胜一局 +120 与余柴奖励)、历史最高分、已玩局数。
