# 邮包分拣 (📦 邮包分拣 · 六十秒爆仓)

> 分类:**模拟经营** · 入口:/postsort/ · 免费在线 · 手机即点即玩

**目标:**分拣挑战:包裹按颜色标签进入传送带队列,**按 1-4 分进对应桶**;连对加分递增,积压 4 件爆仓扣分;60 秒结算。

| 元素 | 效果 |
|---|---|
| 📦 包裹 | 圆点颜色=应进的桶 |
| 🎨 四桶 | 红蓝黄绿对应 1-4 键 |
| 🔥 连对 | 每件 10 + 连击 x2 |
| 💥 爆仓 | 积压 4 件挤掉最旧的 -25 |
| 🏆 评级 | 分拣 42 件分拣站之光 |

**操作:**点**四个桶按钮**(键盘 **1-4**)分拣队首包裹。

> 💡 **打法:**① **眼睛看第二件**,手上分第一件;② 连击是复利,**宁可慢半拍别按错**;③ 爆仓挤掉的是最旧包裹,**队首优先处理**;④ 后期速度起飞,**手指悬在键上别离开**;⑤ 错了深呼吸,**下一件找回节奏**!

**结算:**分拣件数、连对、本局得分、历史最高分、已玩局数。
