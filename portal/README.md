# 传送门 (🌀 传送门逃脱 · 空间跳跃)

> 分类:**烧脑益智** · 入口:/portal/ · 免费在线 · 手机即点即玩

**目标:**点墙**开启蓝橙一对传送门**,走/跳进门从另一门穿出且**保留动量**;利用速度与高度组合飞跃尖刺与深渊,摸到旗帜过关。12 关,失败无限重试。

| 元素 | 效果 |
|---|---|
| 🌀 开门 | 点任意墙面上半开蓝门,再点开橙门 |
| 🚶 行走 | 点画面左右走,点上方跳 |
| ⚡ 动量 | 出门速度=进门速度,方向随门向 |
| ⚠️ 危险 | 尖刺与深渊碰到即重置本关 |
| 🏁 旗帜 | 碰到旗帜过关,传送次数影响得分 |

**操作:****点墙**开传送门(先蓝后橙),**点左右**走动,**点上方**跳跃;**重来**复位本关。键盘 ←→ 走、↑ 跳、鼠标点墙开门。

> 💡 **打法:**① 高处往低处门里跳,出来时<b>速度最快</b>;② 蓝门放头顶、橙门放脚下,可实现「无限加速」;③ 尖刺墙前先把橙门开在它<b>正对面</b>;④ 传送不是万能的,有时候老实走更稳;⑤ 记住:出来的方向看进门方向,别搞反了!

**结算:**通关数、总传送次数、总用时、本局得分(过关 x150 - 传送 x5,最低 100)、历史最高分、已玩局数。
