# 牛角棋 (🐂 牛角棋 · 两犬困牛)

> 分类:**对战棋牌** · 入口:/niujiao/ · 免费在线 · 手机即点即玩

**目标:**追逐棋:**牛单步冲顶,双犬拦截**;被围死输,登顶赢;三局定比分。

| 元素 | 效果 |
|---|---|
| 🐂 牛 | 你执,上下皆可走 |
| 🐕 双犬 | AI 执,只向山下行 |
| 🚫 困局 | 牛无路可走即败 |
| ⛰ 登顶 | 到 0 或 1 位即胜 |
| 🏆 赛制 | 三局两胜 |

**操作:****点相邻岔位**走牛。

> 💡 **打法:**① **开局先往边上岔走**,中路犬多;② 犬**只进不退**,把它引过头顶再折返;③ **一步一步看犬的落点**,别送围;④ 被困前**提前留退路**,角底翻盘;⑤ 三局两胜,**输一局摸清犬脾气再战**!

**结算:**手数、比分、历史最高分、已玩局数。
