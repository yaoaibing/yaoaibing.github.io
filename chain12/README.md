# 数字链变 (🔗 数字链变 · 合并进化)

> 分类:**烧脑益智** · 入口:/chain12/ · 免费在线 · 手机即点即玩

**目标:**点相邻同数字**连成链**后合并成一个 +1 的大数,合并 3 次补充 3 个新数字;合出 **12** 赢得一盘,棋盘塞满且无可合并时结束。

| 元素 | 效果 |
|---|---|
| 🔗 连链 | 点一张牌,相邻同数字高亮成链 |
| 💥 合并 | 再次点击,整链变成一个大数(+1) |
| 🆕 补给 | 每合并 3 次随机落 3 个新数字 |
| 🎯 目标 | 合出 12 获胜,继续无限挑战 |
| 🏁 结束 | 无可合并组合即结算 |

**操作:****点数字牌**选中链,**再点**合并;**新局**重开。长链合并分数按块数平方增长,能连就多连!

> 💡 **打法:**① 链越长合并收益越高,<b>5 连以上</b>分数翻着涨;② 别急着合 2,先攒一波再一口气连锁反应;③ 把大数字往<b>角落</b>引,中间留给新数字;④ 合并前看一眼合并后会不会拆散别的链;⑤ 目标 12 不难,难的是合出 15+ 的强迫症之路!

**结算:**得分(合并块数平方累加)、最大数字、合并次数、历史最高分、已玩局数。
