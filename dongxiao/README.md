# 洞箫吹月 (🌙 洞箫吹月 · 一息一音)

> 分类:**音乐节奏** · 入口:/dongxiao/ · 免费在线 · 手机即点即玩

**目标:**节奏按孔:**滑音点孔**,三曲连环。

| 元素 | 效果 |
|---|---|
| 🌙 月下 | 静夜宜箫 |
| 🎵 孔圈 | 滑到线就按 |
| 📏 长音 | 双倍分 |
| 🌀 连音 | 按得越连越厚 |
| 🏆 结算 | 吹箫折分 |

**操作:**点屏**按孔**。

> 💡 **打法:**① **眼盯红线**,孔圈进线那一下出手;② 长音孔**双倍分**,别为赶下一个漏了它;③ 按空**连音清零**,宁慢半拍不按空;④ 二三曲**速度渐起**,手指先悬着;⑤ 三曲吹罢,**月亮都探下来听**!

**结算:**箫曲句号、连音数、本局得分、历史最高分、已玩局数。
