# 识字小课堂 (🔤 识字小课堂 · 看图选词)

> 分类:**学习教育** · 入口:/edu2/ · 免费在线 · 手机即点即玩

**目标:**幼儿识字:**大 emoji 出题**,四选一点出正确名称;答对连对加分,答错显示正确答案并温柔纠正;40 个常用词题库(动物/水果/交通/物品),15 题一节课。

| 元素 | 效果 |
|---|---|
| 🐘 大图出题 | emoji 放大展示,一眼认识 |
| 🔤 四选一 | 正确 + 干扰项 3 个 |
| 🔥 连对 | 每题 100 + 连对 x10 |
| 📖 题库 | 40 词覆盖动物/水果/交通/物品 |
| 👨‍👩‍👧 陪读 | 建议家长读题,孩子指选 |

**操作:****点正确答案**(键盘 **1-4**)作答;答错会展示正确写法,<b>别批评孩子</b>,下一题继续!

> 💡 **打法:**① 先让孩子<b>说出名字</b>,再由家长点选,识字效果翻倍;② 干扰项常是同类(水果配水果),<b>看清字再点</b>;③ 连对是复利,<b>不求快只求对</b>;④ 答错界面就是教学,<b>让孩子念一遍正确词</b>再继续;⑤ 每节课 15 题,<b>一天一节</b>比一口气十节记得牢!

**结算:**最长连对、本局得分(100 + 连对 x10)、历史最高分、已玩局数。
