# 星图连线 (✨ 星图连线 · 按亮度成座)

> 分类:**太空导航** · 入口:/starlink/ · 免费在线 · 手机即点即玩

**目标:**星等排序连线:每座 5 星按亮度降序连成星座,连错重连;五座通关。

| 元素 | 效果 |
|---|---|
| ⭐ 星等 | 编号 1=最亮(黄圈提示) |
| 📏 连线 | 按 1→5 依次点亮 |
| ✗ 连错 | 提示先连最亮 |
| 🔭 星座 | 小熊/仙后/天鹅/天琴/猎户 |
| 🏆 计分 | 每座 150 + 关卡奖励 |

**操作:****点星星**(黄圈=下一个目标)。

> 💡 **打法:**① **黄圈会闪烁**,跟着黄圈走就是正确答案的舞蹈;② 想练真本事就**先找最大星**再盲连;③ 星座形态**先看整体轮廓**再动手;④ 连错不扣分只提示,**大胆试**;⑤ 连完一座**记住形状**,下次夜观星空用得上!

**结算:**成座数、连线进度、本局得分、历史最高分、已玩局数。
