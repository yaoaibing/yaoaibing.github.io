# 网球对决 (🎾 网球对决 · 挥拍制胜)

> 分类:**街机动作** · 入口:/tennis/ · 免费在线 · 手机即点即玩

**目标:**把来球**回击到对方场内**:拖动球拍对准来球自动挥拍,轻点屏幕蓄力扣杀;出界、下网、没接到都丢分。真实网球计分(15/30/40/占先),先赢 3 局获胜。

| 元素 | 效果 |
|---|---|
| 🎾 发球 | 每局轮流发球,自动发球开打 |
| 🏃 移动 | 左右拖动/方向键,球拍对准来球 |
| ⚡ 挥拍 | 球进入拍前范围自动回击,越正中越有力 |
| 💥 扣杀 | 球到拍前轻点屏幕,回球提速 32% |
| ⚠️ 失分 | 出界/下网/两跳没接到都丢分 |

**操作:****左右拖动**或**方向键**移动球拍;来球靠近时**自动挥拍**;球到拍前**轻点屏幕**蓄力扣杀;**新局**重开。

> 💡 **打法:**① 球拍要<b>提前站到来球落点</b>上,越正中回球越稳;② 球到拍前瞬间轻点蓄力,回球更快,电脑来不及退;③ 电脑站左边就往**右边空档**打,拉开再扣杀;④ 蓄力别乱按,击球点偏了容易出界;⑤ 40:40 关键分沉住气,先保住自己的发球局!

**结算:**局分、实时比分(含占先)、回合数、胜负、本局得分、历史最高分、已玩局数。
