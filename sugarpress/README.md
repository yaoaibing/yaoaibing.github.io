**目标:**三段火候:**喂碾熬**,三锅连做。

| 元素 | 效果 |
|---|---|
| 🍯 石碾 | 双轮轧蔗 |
| 🥄 糖锅 | 色变定生死 |
| ⚙️ 碾劲 | 绿区最当 |
| ⚠️ 过火 | 苦糖没人买 |

**操作:**每道工序**点屏落手**。
