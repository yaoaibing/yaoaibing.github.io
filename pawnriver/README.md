> 分类:**对战棋牌** · 入口:/pawnriver/ · 免费在线 · 手机即点即玩

**目标:**对弈推进:**过河横行**,冲线制胜。

| 元素 | 效果 |
|---|---|
| ♟️ 兵卒 | 四路对进 |
| ⬆️ 直进 | 未过河 |
| ↔️ 横走 | 过河后 |
| 🚩 冲线 | 抵底线+100 |
| 🏆 结算 | 吃子折分 |

**操作:**点**己方卒**看绿圈,**点落点**行棋。
