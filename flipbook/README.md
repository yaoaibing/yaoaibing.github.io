# 翻页动画书 (📓 翻页动画书 · 页页连贯)

> 分类:**解压休闲** · 入口:/flipbook/ · 免费在线 · 手机即点即玩

**目标:**逐帧创作:**连贯点球**,三本递进。

| 元素 | 效果 |
|---|---|
| 📓 书页 | 六页一册 |
| 👆 点球 | 逐页落笔 |
| 📏 挪幅 | 小半屏内 |
| 🎞 回放 | 自动翻页 |
| 🏆 结算 | 连贯折分 |

**操作:**照影子**点屏**画下一页。

> 💡 **打法:**① **先看影子的动向**,顺着趋势落笔;② 每页**挪小半屏**,跳太远动画就断;③ 越到后几本**限制越紧**,手要越来越细;④ 离影子越近**分越高**,贴着描最稳;⑤ 翻页那一刻,**纸上的球真的跳起来了**!

**结算:**画册进度、页码、本局得分、历史最高分、已玩局数。
