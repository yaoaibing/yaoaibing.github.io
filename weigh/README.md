# 天平配重 (⚖️ 天平配重 · 算数平衡)

> 分类:**学习教育** · 入口:/weigh/ · 免费在线 · 手机即点即玩

**目标:**算数天平:左盘摆**加减乘算式**,从四个砝码里**选出平衡值**;选错天平倾斜(沉的一侧=放重了),连对加分,12 题逐级升档。

| 元素 | 效果 |
|---|---|
| ⚖️ 天平 | 倾斜方向暗示答案偏大/偏小 |
| 🔢 算式 | +/−/× 三档难度 |
| 🎯 四选一 | 干扰项 ±15% 内 |
| 🔥 连对 | 每题 100 + 连对 x10 |
| 📈 升档 | 每 5 题升一级 |

**操作:****点砝码**(键盘 1-4)作答;**倾斜方向**是最大的提示!

> 💡 **打法:**① 天平向右沉 = 你的砝码<b>太重</b>,往小了改;② 乘法档先背口诀再选,**6x7=42 7x8=56 8x9=72 高频**;③ 连对分是复利,<b>宁可慢半拍</b>;④ 答错只扣节奏不扣分,<b>大胆试</b>;⑤ 每 5 题升档,**第五题是档位信号**,后面会更难!

**结算:**最长连对、本局得分、历史最高分、已玩局数。
