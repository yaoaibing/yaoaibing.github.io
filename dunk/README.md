# 蹦床扣篮 (🏀 蹦床扣篮 · 空中作业)

> 分类:**街机动作** · 入口:/dunk/ · 免费在线 · 手机即点即玩

**目标:**蓄力弹跳:按住蓄力(100 封顶)起跳,空中每转体一周 +40;落点接近篮筐即算扣进;篮筐随机换位。

| 元素 | 效果 |
|---|---|
| 💪 蓄力 | 越高飞得越高 |
| 🌀 转体 | 空中每圈 +40 |
| 🎯 判定 | 横向接近即扣进 |
| ⚠ 失手 | 蓄力不足够不到 |
| 🏆 评级 | 800 分空中飞人 |

**操作:****按住「蓄力」**松手起跳(空格),空中点「**转体**」(↓)。

> 💡 **打法:**① 蓄力 70-90 最佳,**太满反而不容易对准**;② 转体是白送的,**空中能点几点点几点**;③ 篮筐位置在起跳前看一眼,**心里有个横向修正**;④ 失手一球别上头,**下一球稳稳扣**;⑤ 连续扣进没有连击,**转体才是分数核心**!

**结算:**扣进数、转体周数、本局得分、历史最高分、已玩局数。
