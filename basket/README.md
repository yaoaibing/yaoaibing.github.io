**目标:**经纬交织:**亮格压暗格过**,逐纬编满;三篮结算。

| 元素 | 效果 |
|---|---|
| 🧺 纬条 | 匀速右移 |
| ⬜ 亮格 | 压 +8 |
| ▪️ 暗格 | 压了 -3 |
| 🧺 整纬 | 到底 +15 |
