# 骰子叠塔 (🎲 骰子叠塔 · 五层高塔)

> 分类:**骰子冒险** · 入口:/dicestack/ · 免费在线 · 手机即点即玩

**目标:**叠叠乐:三颗骰轮换上塔,**同点相贴 +15**;塔越高越晃,摇塌即结束;60 秒或 12 层结算。

| 元素 | 效果 |
|---|---|
| 🎲 手牌 | 三骰轮换补 |
| 🧱 同面 | 相邻同点 +15 |
| 📉 晃动 | 随高度加剧 |
| 💥 倒塌 | 随机触发即终 |
| 🏆 评级 | 叠满 12 层塔主 |

**操作:****点手牌骰子**(键盘 **1-3**)叠上塔顶。

> 💡 **打法:**① **开局随便叠**,前五层塌不了;② **同面加成是分数大头**,有同就贴;③ 六层之后**每次都深呼吸**;④ 塌了也别懊恼,**分数已落袋**;⑤ 冲十二层,**宁可放弃加成也要稳**!

**结算:**塔高、本局得分、历史最高分、已玩局数。
