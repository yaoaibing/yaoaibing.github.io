# 忍者跳跳 (🥷 忍者跳跳 · 双墙攀登)

> 分类:**街机动作** · 入口:/ninja/ · 免费在线 · 手机即点即玩

**目标:**忍者贴墙而立,**点屏幕**即向对面墙跳(自动瞄准落点),墙上的**尖刺段**随高度变密,碰到即结束。爬升高度就是分数,连续安全跳跃有连击加成。

| 元素 | 效果 |
|---|---|
| 🥷 蹬墙 | 点屏幕向对面墙跳,自动瞄准 |
| ⚠️ 尖刺 | 墙上的红刺段,碰到即结束 |
| ⚡ 连跳 | 连续 4 次不碰刺,加成 x2 |
| 📈 加速 | 越高跳得越快,刺越密 |
| 🏁 结束 | 碰到尖刺即落幕,高度计分 |

**操作:****点屏幕任意处**起跳;**重来**立刻重开。节奏感比手速重要,等忍者到稳态再跳!

> 💡 **打法:**① 忍者滑到<b>刺段边缘前</b>起跳,别贴着刺等;② 心里数拍子,双墙节奏是固定的;③ 连跳加成很香,但要拿命换,见刺就稳;④ 高处刺会连成排,提前换边;⑤ 屏幕下半看落点,上半看下一组刺,视线别乱。

**结算:**高度(米)、最高连跳、跳跃次数、本局得分(高度 x8 + 连跳 x40)、历史最高分、已玩局数。
