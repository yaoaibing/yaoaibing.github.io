# 标声调 (🗣️ 标声调 · 一调定音)

> 分类:**学习教育** · 入口:/pintone/ · 免费在线 · 手机即点即玩

**目标:**拼音声调四选一:16 个常用字的声调辨析,连对计分,答错显示正确读音。

| 元素 | 效果 |
|---|---|
| 🗣️ 拼音 | 汉字+无声调骨架 |
| ✅ 四选一 | ā á ǎ à 四版任选 |
| 🔥 连对 | 每题 100 + 连对 x10 |
| ❌ 答错 | 断连 -15 并公布答案 |
| 🏆 评级 | 连对 8 次声调通 |

**操作:****点选项**(键盘 **1-4**)作答。

> 💡 **打法:**① **先读三遍**,嘴里拐弯的方向就是声调;② 三声最骗人,**马鞍形降-升别记成四声**;③ 轻声字不在题里,**别多想**;④ 干扰项只换调号,**韵母一模一样**,盯声调就行;⑤ 拿不准的**默念词语**(比如「下雨」),语境帮你定调!
