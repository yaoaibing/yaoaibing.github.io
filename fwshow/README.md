# 烟花编排 (🎆 烟花编排 · 夜空点画)

> 分类:**创意涂鸦** · 入口:/fwshow/ · 免费在线 · 手机即点即玩

**目标:**烟花创作玩具:点夜空发射,**烟花升空至指定高度绽放**成 26 粒光雨;夜空按 40px 分格,照亮的格子数即覆盖率;12 发后按覆盖率+分数结算。

| 元素 | 效果 |
|---|---|
| 🎆 发射 | 点击位置即爆点,火箭自动升空 |
| 🌈 六色 | 粉/金/绿/蓝/紫/白 |
| 🗺 覆盖率 | 夜空分格,照亮格数/总格 |
| 💥 光雨 | 每发 26 粒火花 + 重力 |
| ✅ 结算 | 12 发后自动收官 |

**操作:****点夜空**发射(每次一发);**底部圆点**选颜色。

> 💡 **打法:**① 四角最难铺,<b>前 4 发先点四角</b>;② 同一位置重复炸不加分,<b>铺开才是分</b>;③ 火箭会过冲一点点,<b>瞄准比目标低 20px</b>;④ 色彩混搭,<b>相邻两发换色</b>画面更华丽;⑤ 这玩具零失败,覆盖率只是成就感的刻度!

**结算:**覆盖率、发射数、本局得分、历史最高分、已玩局数。
