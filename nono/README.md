# 数织 (🔢 数织 · 逻辑涂色)

> 分类:**烧脑益智** · 入口:/nono/ · 免费在线 · 手机即点即玩

**目标:**按每行、每列左边的数字提示涂格子,涂对了会浮现出一幅像素画。**共 14 关**,从 5×5 一路到 15×15,图案有爱心、笑脸、房子、蘑菇、猫脸、小船、松树、螃蟹、圣诞树、蝴蝶结、火箭。
| 操作 | 键位 |
|---|---|
| 涂黑 / 取消 | 点一下格子
打叉(标记确定不涂) | 长按格子,或切到叉模式 |

**数字怎么看:**一行标着 `2 3` = 这一行里有两段黑格,一段 2 格、一段 3 格,两段之间**至少空 1 格**,顺序从左到右。标着 `0` 就整行都不涂。

> 💡 **推理技巧:**① 从**大数字**入手(比如 5×5 里的 5 = 整行涂满);② 先扫一遍"确定能涂"和"确定不能涂"的格子,把叉打满;③ 边缘最值钱:**行首/行尾**的段位置常能直接锁定;④ 开自动校验,涂错会立刻标红,适合新手;⑤ 卡住用提示,每关有限次。
