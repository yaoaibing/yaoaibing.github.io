# 独钓寒江 (🎣 独钓寒江 · 一洞一雪)

> 分类:**寻宝推理** · 入口:/snowfish/ · 免费在线 · 手机即点即玩

**目标:**时机垂钓:**观漂提竿**,四洞连环。

| 元素 | 效果 |
|---|---|
| 🎣 钓竿 | 一竿一洞 |
| 🧊 冰洞 | 三凿即成 |
| 👀 漂相 | 沉顶斜三种 |
| ⚠️ 空军 | 七咬换洞 |
| 🏆 结算 | 钓雪折分 |

**操作:**凿洞**点屏三下**,钓鱼**见沉点屏**。

> 💡 **打法:**① 凿冰**针到红线**,三凿准成洞;② 浮漂**猛一沉**,半秒内提竿正当时;③ **大鱼沉得深**,别被吓住;④ 七次咬钩不中**这洞就废**,换!;⑤ 四洞得三鱼,**今晚熬一锅鱼汤**!

**结算:**钓冰洞号、得鱼尾数、本局得分、历史最高分、已玩局数。
