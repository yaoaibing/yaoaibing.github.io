# 组装大师 (🔧 组装大师 · 匠心拼装)

> 分类:**组装拼装** · 入口:/assembly/ · 免费在线 · 手机即点即玩

**目标:**空间装配:零件散落工作台,**拖拽**到对应虚线轮廓并**旋转对向**,靠近正确位置自动吸附;全部装完竣工,操作次数越少分越高,共 5 件作品。

| 元素 | 效果 |
|---|---|
| 🔧 零件 | 每件 3-8 个,横竖两种形态 |
| 📤 虚线框 | 图纸轮廓,位置和尺寸的唯一依据 |
| 🔄 旋转 | 选中零件转 90°,横竖互换 |
| 🧲 吸附 | 位置 ±20 内且方向正确自动锁定 |
| 📈 计分 | 每件 200 - 操作 x8 |

**操作:****按住拖动**零件;**点选后按 🔄**(R 键)旋转;吸附有轻微容差,贴上就锁。

> 💡 **打法:**① 先装<b>最大的零件</b>定骨架,小件位置一目了然;② 虚线框是横是竖一眼分辨,<b>先转对方向再拖</b>省一半操作;③ 相似零件(四条桌腿)可以互换位置——只要尺寸一样都算对;④ 拖到附近就松手,<b>吸附有 ±20 容差</b>,不用像素级对齐;⑤ 操作分是每件独立结算的,新的一局尽管大胆试!

**结算:**竣工件数、操作次数、本局得分(每件 200 - 操作 x8)、历史最高分、已玩局数。
