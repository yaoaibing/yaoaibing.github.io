# 切水果 (🍉 切水果 · 刀光果影)

> 分类:**街机动作** · 入口:/fruitninja/ · 免费在线 · 手机即点即玩

**目标:**滑动手指挥刀,切开飞起的水果。连击越高分越多,切到炸弹或漏掉 3 个水果就结束。

| 元素 | 效果 |
|---|---|
| 🍉 水果 | 每个 +10 分,⭐ 金星 +30 分 |
| 🔥 连击 | 连续切中每个额外 +2,单次最高 +20 |
| ⚔️ 一刀多切 | 同一次滑动切中 3 个以上,每个再 +5 |
| 💣 炸弹 | 切到立即结束,别碰 |
| ❤️ 生命 | 漏掉水果扣 1 条命,3 条扣完结束 |

**操作:**在屏幕上**快速划过**水果即切开,一次滑动可以串起多个;**新局**重开。鼠标和触屏都支持。

> 💡 **打法:**① **划长线**而不是点按:一刀串 3 个水果,每个多 +5;② 连击不断,分数滚得最快,优先切聚在一起的水果;③ 炸弹通常混在水果堆里,看到 💣 提前收刀;④ 水果飞得高时别急着切,等它落到刀口再挥;⑤ 宁可少切一个,也别为了追水果漏掉一串导致掉命。

**结算:**得分、切中数量、最高连击、称号、历史最高分、已玩局数。
