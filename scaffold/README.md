# 高空铺板 (🏗️ 高空铺板 · 脚手架工程)

> 分类:**建造物理** · 入口:/scaffold/ · 免费在线 · 手机即点即玩

**目标:**建造模拟:点击铺板(**不能与已有板重叠**),工人自动向右走;走到没板处坠落 -50 分并回起点;30 秒内铺到 100% 交付。

| 元素 | 效果 |
|---|---|
| 🏗️ 铺板 | 点击空白铺 70px 木板 |
| 🚶 工人 | 自动 55px/s 前进 |
| 💥 坠落 | 没板踩 -50 分回起点 |
| 📏 交付 | 走到最右端 |
| 📈 计分 | 进度 x4 - 坠落 x30 |

**操作:****点空白处**铺板(自动居中);工人**自动前进**不用控制!

> 💡 **打法:**① 板子要<b>重叠 4px 以上</b>才能踩过,断桥走不了;② **铺在工人前面**2-3 块板远,别等他走到悬崖再铺;③ 重叠检查很严格,<b>两板间不能有任何缝隙</b>;④ 坠落扣 50 分,<b>别贪快</b>;⑤ 分数 = 进度 x4 - 坠落 x30,**铺远比铺多值钱**!

**结算:**铺设进度、木板数、坠落次数、本局得分、历史最高分、已玩局数。
