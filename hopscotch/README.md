# 跳房子 (🏠 跳房子 · 踩点小达人)

> 分类:**街机动作** · 入口:/hopscotch/ · 免费在线 · 手机即点即玩

**目标:**节奏跳跃:小人按固定节拍逐格前进,**在落地拍 ±0.09 秒内点击**为完美;脱拍或点偏扣心,每 12 格提速。

| 元素 | 效果 |
|---|---|
| 🏠 格局 | 单格双格经典排布 |
| 🎯 判定 | ±0.09s 完美 +连击 |
| 📈 提速 | 每 12 格拍子变快 |
| 💔 失拍 | 空拍或点偏 -1 心 |
| 🏆 评级 | 连跳 20 格踩点达人 |

**操作:**跟着落地节奏**点屏幕/空格**。

> 💡 **打法:**① **心里默数**:哒-哒-哒,跟小人一起念;② 宁可**稍慢半拍**,别抢在拍子前面;③ 提速后别慌,**节奏感比手速重要**;④ 连跳分滚得快,**稳住别断**;⑤ 失一颗心深呼吸,**下一拍找回来**!

**结算:**跳格数、连跳、本局得分、历史最高分、已玩局数。
