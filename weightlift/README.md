# 举重神力 (🏋️ 举重神力 · 力量节奏)

> 分类:**街机动作** · 入口:/weightlift/ · 免费在线 · 手机即点即玩

**目标:**力量槽来回摆动,**在红区瞬间按下**发力:红心=完美,红区边缘=勉强成功,区外=失手。三次试举重量递增,成功后槽速加快,总举重量就是成绩。

| 元素 | 效果 |
|---|---|
| 🏋️ 发力 | 点屏幕,力量槽停在红区即成功 |
| ✅ 完美 | 红区正中心,额外 +50% 重量 |
| ⚠️ 勉强 | 红区边缘,算举起但不加分 |
| ❌ 失手 | 红区外按下,消耗一次试举 |
| 🏁 结束 | 三次试举用完,按总重量结算 |

**操作:****点屏幕**发力(键盘空格同);**重赛**重开。槽速递增,后两次是关键!

> 💡 **打法:**① 别盯着指针,用<b>余光+节奏</b>按,像打拍子;② 第一次试举求稳,举到就赚;③ 完美加成 50%,值得为它多等半拍;④ 槽速翻倍时提前按下,留出手部延迟;⑤ 心跳越快越容易按早,深呼吸再上台!

**结算:**总举重量、完美次数、失手次数、本局得分(总重量)、历史最高分、已玩局数。
