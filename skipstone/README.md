# 打水漂 (🌊 打水漂 · 石片飞人)

> 分类:**解压休闲** · 入口:/skipstone/ · 免费在线 · 手机即点即玩

**目标:**从岸边按住**向后下方拉**出角度和力度,松手掷出石片,**贴着水面连跳**。每次弹水算一漂,弹跳次数×100+距离分。速度衰减,漂到停为止。

**操作:**按住石片拖动(往下拉=蓄力,横向偏移=角度),松手掷出。理想出手角约 **5~10 度**,力量 80%+ 才能连漂。

> 💡 **物理要点:**① **角度越平越容易弹**:拉杆横向分量大、纵向分量小,石片出手角就平;② 力量不够时第一次弹跳就沉,**先拉满一次找感觉**;③ 每次弹跳损失 14% 速度、38% 弹跳力,**第一跳后的剩余速度**决定总漂数;④ 3 漂是入门,6 漂算会玩,10 漂以上是石片之神;⑤ 现实中打水漂的世界纪录是 88 漂,游戏里超过 15 漂请截图炫耀。

**结算:**本次连漂次数、漂行距离、得分、历史最高。
