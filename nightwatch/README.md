# 孤灯塔 (🗼 孤灯塔 · 守塔人一夜)

> 分类:**互动剧情** · 入口:/nightwatch/ · 免费在线 · 手机即点即玩

**目标:**分段叙事:黄昏到黎明**七更剧情**,每更三选一;**仁心/守则/存油**三属性随选择流动,剧情节点互相影响;终章按属性组合分出三个结局(致敬/灯/长夜)。

| 元素 | 效果 |
|---|---|
| 🗼 七更 | 黄昏到黎明,每更一个抉择 |
| 💧 存油 | 关键资源,部分选项消耗 |
| 🚪 水手 | 敲门的一百年前亡灵,仁心线关键 |
| 🚢 货轮 | 第 6 更驶向暗礁,灯灭即撞 |
| 🌅 三结局 | 致敬/灯/长夜 |

**操作:**每更**三选一**(键盘 **1-3**);八更即终章,选择影响属性与结局!

> 💡 **打法:**① 存油是硬约束:<b>烧桌烧外套都 + 油</b>,但只有特定剧情点能触发;② 水手是剧情钥匙,<b>递毯子的选项性价比最高</b>(仁心+守则双加);③ 第 7 更擦灯罩=仁心+守则双加但耗时——<b>游戏没有时间惩罚</b>,放心选;④ 仁心 ≥5 且守则 ≥5 且存油 ≥1 才出「致敬」真结局;⑤ 一局 3 分钟,<b>三个结局各走一遍</b>才是完整故事!

**结算:**三种结局(收集)、仁心/守则/存油终值、本局得分、历史最高分、已玩局数。
