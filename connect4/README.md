# 四子连珠 (⚪ 四子连珠 · 连四对决)

> 分类:**策略战棋** · 入口:/connect4/ · 免费在线 · 手机即点即玩

**目标:**重力四子棋:点一列**从底部堆起**,横竖斜任一方向**连成四子**即胜;AI 会优先堵你、再找自己的连四;三档难度。

| 元素 | 效果 |
|---|---|
| ⚪ 落子 | 点一列,重力落底 |
| 🔵 蓝子 | 你执蓝,先手 |
| 🟠 橙子 | AI 执橙 |
| 🔒 连四 | 横/竖/斜 4 子连线 |
| 🎚 难度 | AI 策略逐步增强 |

**操作:**点一列或按 **1-7** 落子;落子后 AI 自动回应。

> 💡 **打法:**① **抢中间三列**:连接可能性最多;② 发现 AI 两子连线立刻<b>堵住第三格</b>;③ 双重威胁是必杀技:一手棋造两个连三点;④ 底行最稳定,<b>底层连四</b>最常见;⑤ 困难档 AI 会做双威胁,**提前破坏它的底行布局**!

**结算:**比分、本局得分(胜 400 + 累计 x50)、历史最高分、已玩局数。
