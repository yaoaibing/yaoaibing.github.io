| 元素 | 效果 |
|---|---|
| 🔢 数字格 | 10 + 邻雷数 x3 |
| 💣 踩雷 | -30 并全场示众 |
| 🤖 AI | 八成避开,两成失手 |
| ⚖️ 轮流 | 你先手略有优势 |
