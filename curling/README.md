# 冰壶 (🥌 冰壶 · 精准一投)

> 分类:**街机动作** · 入口:/curling/ · 免费在线 · 手机即点即玩

**目标:**3 局 x 4 壶,把冰壶投进营垒。离圆心越近分越高:**红心 5 分、中环 3 分、外环 1 分**,三局总分越高越好。

| 元素 | 效果 |
|---|---|
| 🥌 投壶 | 从冰壶往目标方向拖动,拖得越远力度越大 |
| 🎯 计分 | 红心内 5 分,中环 3 分,外环 1 分,每局最高 20 分 |
| 🌀 旋球 | 右旋/左旋让冰壶走弧线,可以绕开前面的壶 |
| 💥 碰撞 | 冰壶相撞会改路线,能把自己的壶顶进红心,也可能撞飞 |
| 📉 缩圈 | 第三局营垒缩小 6%,精度要求更高 |

**操作:**从冰壶**往目标方向拖动**,拖得越远力度越大,松手投出;底部 **↻ 右旋/↺ 左旋** 切换旋向,**新局**重开。键盘 <kbd>←</kbd><kbd>→</kbd> 调方向,<kbd>↑</kbd><kbd>↓</kbd> 调力度,<kbd>空格</kbd> 投出。

> 💡 **打法:**① **力度别拉满**:冰面摩擦小,满力基本会冲出营垒;② 前几壶先占圆心前方当盾牌,后几壶再借碰撞把自己的壶顶进红心;③ 旋球会走弧线,直线上有壶挡路时用旋球绕过去;④ 第三局营垒缩小,力度和方向都要更保守;⑤ 每局 4 壶投完自动结算,最后一壶可以大胆撞壶救分。

**结算:**三局总分、单局最高 20 分、称号、历史最高分、已玩局数。
