# 比大小速算 (⚖️ 比大小速算 · 天平闪电)

> 分类:**学习教育** · 入口:/compare/ · 免费在线 · 手机即点即玩

**目标:**算式比大小:左右两式加/减/乘组合,**点 A 大、B 大或相等**;连对每题 +10 + 连对 x2,答错断连;30 秒结算。

| 元素 | 效果 |
|---|---|
| ➕ 算式 | 加减乘混合,两位数为主 |
| ⚖️ 三键 | A 大 / 相等 / B 大 |
| 🔥 连对 | 每题 10 + 连对 x2 |
| ❌ 答错 | 断连 -10 |
| 🏆 评级 | 260 分心算闪电 |

**操作:**点 **⬅️ / ＝ / ➡️**(键盘 **← = →** 或数字方向)。

> 💡 **打法:**① **先看位数**:位数差得多直接比,别硬算;② 加法**比大头**(十位),减法**看被减数**;③ 乘法口诀不熟就**拆成整十**估;④ 「相等」出现率不低,**算不准时是正经选项**;⑤ 连对是复利,**10 秒 5 题不如 30 秒对 12 题**!

**结算:**连对、本局得分、历史最高分、已玩局数。
