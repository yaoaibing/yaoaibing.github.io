# 方块1010 (🟪 方块1010 · 满行消除)

> 分类:**烧脑益智** · 入口:/block10/ · 免费在线 · 手机即点即玩

**目标:**9x9 棋盘,每轮给 3 块随机形状的方块,**拖到空位**放置;摆满整行或整列立即消除。放置得分 + 消除奖励,**连续消除**有倍率。三个方块都放不下时结束。

| 元素 | 效果 |
|---|---|
| 🟪 方块 | 单格/条形/L 形/方格等 19 种形状随机出现 |
| 👆 拖放 | 按住托盘里的方块拖上棋盘,虚影预览 |
| 📏 消除 | 任意一行或一列填满即消,多行同消加分更多 |
| 🔥 连消 | 连续 3 次放置都触发消除,倍率最高 x5 |
| 🏁 结束 | 3 块都无处可放,按总分结算 |

**操作:**按住方块**拖到棋盘**松手;**新局**重开。拖动时棋盘会高亮可放位置和将被消除的行列。

> 💡 **打法:**① 大块(长条/3x3)优先往**中央**放,边角留给单格小块;② 永远别把某一整行只留一个洞,那行等于废了;③ 看到下一组方块前,先把最怪的形状处理掉;④ 连消比单次大消除更划算,规划时多凑**十字交叉**;⑤ 留至少一整行空位当安全区,专收长条。

**结算:**总分、消除行列数、最大连消倍率、放置块数、历史最高分、已玩局数。
