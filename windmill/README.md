# 风向标 (🌬️ 风向标 · 风力发电)

> 分类:**烧脑益智** · 入口:/windmill/ · 免费在线 · 手机即点即玩

**目标:**旋转风车改变风向路径,让风从源头通过所有风车到达发电站;全部灯亮即过关,10 关逐步加大电网规模。

| 元素 | 效果 |
|---|---|
| 🌬️ 风车 | 点一下旋转 90°,改变风向 |
| 💡 灯泡 | 通电后亮起 |
| 🔌 源头 | 风的起点,固定方向 |
| 🗺️ 电路 | 风沿网格流动,遇墙壁反弹 |
| 🏆 过关 | 所有灯泡亮起 |

**操作:****点风车**旋转 90°;**下一城**跳关重抽。先看源头方向,再一路跟着风走!

> 💡 **打法:**① 从<b>源头</b>开始顺藤摸瓜,比从灯泡倒推直观;② 风车旋转 4 次回到原位,转 3 次等于反向转 1 次;③ 每个风车只影响自身,别动不该动的;④ 最后一个灯亮之前的思考最关键;⑤ 关卡越大越需要画图辅助,拿出纸笔!

**结算:**通过城市数、总步数、用时、本局得分(城市 x150)、历史最高分、已玩局数。
