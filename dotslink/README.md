# 彩球连接 (🔵 彩球连接 · 链式消除)

> 分类:**烧脑益智** · 入口:/dotslink/ · 免费在线 · 手机即点即玩

**目标:**网格上拖动连接**相邻同色球**成链,松手消除得分为链长 x 链长;限定步数内达到目标分即过关。消除后新球从上方掉落。

| 元素 | 效果 |
|---|---|
| 🔵 连链 | 按住拖到相邻同色球,松手消除 |
| 💥 得分 | 链长平方,链越长收益指数增长 |
| 🆕 掉落 | 消除后上方掉新球可引发连锁 |
| 🎯 目标 | 每关目标分递增 |
| 🏁 结束 | 步数用完但未达标即失败 |

**操作:****按住拖动**连链,**松手**消除;**新局**重开。尽量连最长的链,短链浪费步数!

> 💡 **打法:**① 链长从 3 变 5,得分从 9 变 25,<b>将近 3 倍</b>;② 消除后掉落的球可能自动形成新链,提前预判;③ 优先消除<b>底层</b>的球,上面的掉下来可能有惊喜;④ 步数快用完时,找一条最长的链一击必杀;⑤ 别只看当前颜色,想想消除后上面会掉什么颜色下来!

**结算:**得分、最大链长、剩余步数、通过关卡、历史最高分、已玩局数。
