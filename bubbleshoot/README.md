# 泡泡龙 (🫧 泡泡龙 · 精准连爆)

> 分类:**街机动作** · 入口:/bubbleshoot/ · 免费在线 · 手机即点即玩

**目标:**经典泡泡龙:拖动瞄准发射泡泡,粘上后**同色 3 个以上**消除,失去连接的泡泡整串掉落;顶棚逐关下压,泡泡越过底线结束。

| 元素 | 效果 |
|---|---|
| 🫧 发射 | 拖动调角度,松手发射 |
| 🎨 三连 | 同色 3+ 即爆,掉落额外加分 |
| 🔄 换球 | 当前球与下一球互换 |
| ⬇️ 顶棚 | 每 N 发下压一行,压迫感拉满 |
| 🏁 结束 | 泡泡越过警戒线即结束 |

**操作:****按住拖动**瞄准(有虚线辅助),**松手**发射;**换球**交换,**新局**重开。角度反弹靠墙是过难关的核心技巧!

> 💡 **打法:**① 打不到的同色堆,用<b>侧墙反弹</b>;② 优先打<b>连着顶棚</b>的颜色,掉落一大片;③ 换球键是战略资源,别当习惯性操作;④ 顶棚下压前留一手,别把通路堵死;⑤ 隔山打牛:打掉支撑点,上面全掉!

**结算:**关卡数、总得分、最大连消、历史最高分、已玩局数。
