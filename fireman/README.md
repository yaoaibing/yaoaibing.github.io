# 灭火英雄 (🚒 灭火英雄 · 烈焰围城)

> 分类:**烧脑益智** · 入口:/fireman/ · 免费在线 · 手机即点即玩

**目标:**网格火场:**点火点或相邻格**喷水灭火,每回合结束火向相邻可燃格蔓延;房屋格被烧到即失败,扑灭全部火点过关,8 关难度递增。

| 元素 | 效果 |
|---|---|
| 🚒 喷水 | 点火焰或相邻格,灭一格 |
| 🔥 蔓延 | 每回合火向四周扩散 |
| 🏠 房屋 | 灰色格,被烧即失败 |
| 💧 策略 | 优先灭靠近房屋的火 |
| 🏁 过关 | 场上无火即进入下一关 |

**操作:****点火焰或相邻格**喷水;**重来**复位本关。水枪无冷却但每回合只能喷一次,选点要准!

> 💡 **打法:**① 先灭<b>贴着房屋</b>的火,它威胁最大;② 把火逼进<b>死角</b>(被岩石围住的格子)它就无法蔓延;③ 别追着火尾巴跑,拦住蔓延方向才是关键;④ 数一数回合:灭火速度要快于蔓延速度;⑤ 大火场先分成两半,分片扑灭!

**结算:**通关数、总回合数、使用水量、本局得分(每关 300 - 回合 x15)、历史最高分、已玩局数。
