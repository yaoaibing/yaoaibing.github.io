# 找规律 (🔢 找规律 · 数列接龙)

> 分类:**学习教育** · 入口:/nextnum/ · 免费在线 · 手机即点即玩

**目标:**数列推理:屏幕出**五格数列**(等差/等比/斐波那契),四选一选下一项;连对加分,12 题逐级升档,规律猎人非你莫属。

| 元素 | 效果 |
|---|---|
| 🔢 等差 | 恒定差值,如 +3 +3 +3 |
| 📈 等比 | 恒定倍数,如 x2 x2 x2 |
| 🌿 斐波那契 | 前两项相加=后一项 |
| 🔥 连对 | 每题 100 + 连对 x10 |
| 📈 升档 | 每 4 题升一级 |

**操作:****点正确答案**(键盘 **1-4**)作答。

> 💡 **打法:**① 先算相邻差值,<b>差值恒定 = 等差</b>;② 差值不恒定试**除法**,商恒定 = 等比;③ 斐波那契类:**前两项之和 = 第三项**;④ 别忘了递减数列,<b>差值可以是负数</b>;⑤ 最后几题难度最高,**稳住心态**一题一题来!

**结算:**最长连对、本局得分、历史最高分、已玩局数。
