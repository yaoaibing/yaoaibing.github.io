# 企鹅破冰 (🐧 企鹅破冰 · 别踩裂点)

> 分类:**解压休闲** · 入口:/icepick/ · 免费在线 · 手机即点即玩

**目标:**敲冰休闲:点冰块敲碎得分,企鹅脚下五格是**支撑区**敲了累积晃动,晃满 4 次落水;每 6 块企鹅跳跃换位;60 秒结算。

| 元素 | 效果 |
|---|---|
| 🧊 敲冰 | 每块 +10 |
| 🐧 支撑 | 企鹅所在+四邻,敲之晃 +1 |
| 💧 落水 | 晃满 4 次结束 |
| 🚶 跳位 | 每 6 块换一次位置 |
| 🏆 评级 | 40 块破冰专家 |

**操作:****直接点冰块**敲碎。

> 💡 **打法:**① 白框区**永远最后动**,先清外圈;② 企鹅跳走后**第一时间找新白框**;③ 晃 2/4 就该**绕着走**,别头铁;④ 相邻整片敲,**扫荡效率高**;⑤ 时间快到时**保守收尾**,落水前敲的都是分!

**结算:**敲碎冰数、晃动次数、本局得分、历史最高分、已玩局数。
