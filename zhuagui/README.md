# 抓羊拐 (🎲 抓羊拐 · 一掷一翻)

> 分类:**解压休闲** · 入口:/zhuagui/ · 免费在线 · 手机即点即玩

**目标:**手眼协调:**抛翻接**,五轮渐进。

| 元素 | 效果 |
|---|---|
| 🎲 羊拐 | 凹鼓立卧 |
| 👆 抛包 | 点底行 |
| 🔄 翻拐 | 点拐翻面 |
| ⚠️ 包落 | 折十五分 |
| 🏆 结算 | 抓拐折分 |

**操作:****抛包后点拐翻面**。

> 💡 **打法:**① **先抛再翻**,顺序乱了全白搭;② 一抛**翻一只**,贪多必失;③ 求「鼓」面**就点不是鼓的拐**;④ 轮越深**要翻越多**,抛高点;⑤ 五轮翻齐,**羊拐在你手里像活的**!

**结算:**轮数、求翻面、本局得分、历史最高分、已玩局数。
