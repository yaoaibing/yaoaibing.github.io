# 拼豆豆 (🟠 拼豆豆 · 方格像素画)

> 分类:**解压休闲** · 入口:/fusebeads/ · 免费在线 · 手机即点即玩

**目标:**像素拼贴:对照浅色底图**点格放豆**,五色调色盘;匹配 92% 熨豆换新图。

| 元素 | 效果 |
|---|---|
| 🟠 五色 | 红蓝黄绿白 |
| 🖼️ 底图 | 浅色轮廓作参考 |
| ✅ 匹配 | 92% 即可熨豆 |
| 🗑️ 改错 | 同色再点即取下 |
| 🏆 评级 | 三幅出品手作达人 |

**操作:****点左列选色**,再**点格子**放豆(键盘 1-5 换色)。

> 💡 **打法:**① **先看清底图大色块**,由外向内铺;② 放错**同色再点一下**就取下;③ 匹配卡在 80% 多半是**边角漏豆**;④ 熨豆分按匹配度算,**越准越赚**;⑤ 深色豆最后点,**一眼找漏**!

**结算:**成品数、匹配度、本局得分、历史最高分、已玩局数。
