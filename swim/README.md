# 极速游泳 (🏊 极速游泳 · 节奏划水)

> 分类:**街机动作** · 入口:/swim/ · 免费在线 · 手机即点即玩

**目标:**50 米游泳对决:**左右交替点按**划水,节奏越稳越快,连点同侧呛水减速,体力耗尽速度骤降;先触壁者胜,三档 AI。

| 元素 | 效果 |
|---|---|
| 🏊 划水 | 左右键交替点按,节奏决定速度 |
| 💦 体力 | 划水消耗,自动缓慢回复 |
| 🥵 呛水 | 连点同侧减速惩罚 |
| 🤖 对手 | 学徒/剑士/宗师三档节奏 |
| 🏁 胜负 | 50 米先触壁者胜 |

**操作:****左右按钮交替点按**(键盘 ←→);**重赛**重开。找自己的节奏:哒-哒-哒,像划船号子!

> 💡 **打法:**① 前程<b>七分力</b>,留体力给最后 15 米冲刺;② 连点同侧是最常见失误,口中念「左-右-左-右」;③ 体力条低于 30 就放松两拍,回一点再冲;④ 对手提速时别慌,乱节奏输得更快;⑤ 触壁前最后一划最关键,差一个身位就是金牌与铜牌!

**结算:**胜负、用时、最高速度、呛水次数、本局得分(胜 500 + 领先米数 x8)、历史最高分、已玩局数。
