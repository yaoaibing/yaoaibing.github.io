# 海战棋 (🚢 海战棋 · 猎潜对决)

> 分类:**对战棋牌** · 入口:/battleship/ · 免费在线 · 手机即点即玩

**目标:**在 10x10 海域里找到并击沉电脑的 5 艘战舰(5/4/3/3/2 格)。每回合点一格开火,命中后沿上下左右追击,先全歼敌舰者胜。

| 元素 | 效果 |
|---|---|
| 🚢 舰队 | 双方各 5 艘:5/4/3/3/2 格,共 17 格 |
| 🎯 开火 | 点上方敌方海域格子,白点是落空 |
| 💥 命中 | 红点是命中,打光一艘舰全部格子即击沉 |
| 🤖 电脑 | 命中你的舰后沿四周追打,落空后按奇偶格搜索 |
| 🎲 布阵 | 开局前可重新布阵,开火后不能改 |

**操作:**点上方敌方海域开火;开局前点**重新布阵**更换自己的舰位。键盘 <kbd>R</kbd> 新局。

> 💡 **打法:**① 开火按**棋盘格**隔一跳一点,命中率翻倍;② 命中后先沿一个方向打到底,再回头打另一边;③ 优先补刀已经受伤的舰,5 格长舰最费时;④ 一片红点围出的空地说明那艘舰已经沉了,换区搜索;⑤ 布阵时把大舰放边上、小舰藏中间,电脑更难找。

**结算:**胜负、剩余舰格、开火次数、本局得分(胜利 1200 + 我舰剩余格 x30)、历史最高分、已玩局数。
