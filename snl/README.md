# 蛇梯争霸 (🐍 蛇梯争霸 · 掷骰竞速)

> 分类:**对战棋牌** · 入口:/snl/ · 免费在线 · 手机即点即玩

**目标:**经典蛇梯棋:**掷骰前进**,落梯子爬升、落蛇头滑落;要**恰好到 100 格**,超出部分反弹回走;与两只 AI 轮流行动,先到终点者胜。

| 元素 | 效果 |
|---|---|
| 🎲 掷骰 | 轮到你时点屏幕(或空格) |
| 🪜 梯子 | 从梯底直升梯顶,最大捷径 |
| 🐍 蛇头 | 从蛇头滑到蛇尾,一朝回到解放前 |
| 💯 终点 | 必须恰好 100,超出的点数反弹回走 |
| 🤖 对手 | 两只 AI 轮流掷骰,节奏一样公平 |

**操作:****点屏幕**或按**空格**掷骰,棋子逐格自动走;**新对局**随时重开。全程只需出手掷骰,运气管够!

> 💡 **打法:**① 蛇梯棋纯靠运气,但**心态节奏**是策略:连滑别慌,大家都要滑;② 记住几条大梯子的位置(28→84、71→91),接近时安全感翻倍;③ 87、93、95 三个蛇头最凶,**最后关头多掷几轮小点数**反而稳;④ 超点反弹规则意味着领先者也可能卡在 99;⑤ AI 不会选择,你唯一能优化的是**别误触**:看清轮次再掷!

**结算:**名次、你停的格子、本局得分(胜 400 + 对手差距分,负 40)、历史最高分、已玩局数。
