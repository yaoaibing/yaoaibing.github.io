# 寻龙尺 (🪄 寻龙尺 · 地脉指北)

> 分类:**寻宝推理** · 入口:/dowsing/ · 免费在线 · 手机即点即玩

**目标:**方位探测:探测返回**指向方位**(北/南/东西组合);次数内挖中升级。

| 元素 | 效果 |
|---|---|
| 🪄 寻龙尺 | 始终指向泉眼 |
| 🧭 方位 | 八向粗定位 |
| 💧 挖中 | +110+剩余×30 |
| 🗺️ 换图 | 每关泉眼换位 |
| 🏆 评级 | 三关全清地脉师 |

**操作:****点格子**探测,推准后点格挖掘。

> 💡 **打法:**① **先点四角**,两次就能锁定象限;② 「北」只说南北,**配合东西要再测**;③ 正南北向的格**直接挖一排**;④ 记住测过的格子,**别重复浪费**;⑤ 高关卡次数多,**泉眼也更远**!

**结算:**寻得泉眼、关卡、本局得分、历史最高分、已玩局数。
