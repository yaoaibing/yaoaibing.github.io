# 搭瓜架 (🎋 搭瓜架 · 一架千金)

> 分类:**建造物理** · 入口:/melonframe/ · 免费在线 · 手机即点即玩

**目标:**结构连接:立柱+搭横杆,**大风卷走孤立无连接的柱**;60 秒搭出稳固瓜架。

| 元素 | 效果 |
|---|---|
| 🎋 立柱 | 点空地放置,限 8 根 |
| 🔗 搭杆 | 两柱之间连线 |
| 🌬 大风 | 定期吹倒孤柱 |
| 📐 得分 | 每杆 +15 |
| 🏆 评级 | 8柱12杆架师 |

**操作:****点空地**立柱,**点柱**再**点柱**搭杆。

> 💡 **打法:**① **先立满柱**,再慢慢连;② **每根柱至少连一根杆**,否则风吹就倒;③ 三角形结构**最抗风**;④ 大风前**查一圈孤柱**;⑤ 横杆越多分越高,**连成网**!

**结算:**立柱数、搭杆数、本局得分、历史最高分、已玩局数。
