# 独轮车 (🎪 独轮车 · 摇摆向前)

> 分类:**竞速赛车** · 入口:/unicycle/ · 免费在线 · 手机即点即玩

**目标:**平衡竞速:重心条受坡度与随机力干扰,**◀▶ 轻推保持绿区**,居中速度最快;倾倒退距扣命,500 米或 3 次摔车结算。

| 元素 | 效果 |
|---|---|
| ⚖️ 重心 | 绿区居中=最快 |
| ⛰ 坡度 | 随机上下坡牵引 |
| 💥 摔车 | 退 15 米,3 次结算 |
| 📈 速度 | 随时间+平衡度提升 |
| 🏆 计分 | 距离 x2 + 余命奖励 |

**操作:****◀ 左倾 / 右倾 ▶**(左右方向键)。

> 💡 **打法:**① **提前量是全部**:感觉要偏就在偏之前点;② 坡顶换坡时**重心会甩**,提前压住;③ 别死按,**点按节奏感**比按住稳;④ 摔车后**先稳三秒再提速**;⑤ 心理上接受摇摆,**独轮车本来就是 S 形前进**!

**结算:**骑行距离、重心偏差、剩余机会、本局得分、历史最高分、已玩局数。
