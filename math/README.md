# 口算闪电战 (➕ 口算闪电战 · 心算狂飙)

> 分类:**学习教育** · 入口:/math/ · 免费在线 · 手机即点即玩

**目标:**限时心算:**加减乘混合四选一**,连对每题 +10 递增,答错 -3 秒;题目难度每 6 题升档(两位加法 → 三位加减 → 乘法混合),60 秒后按最长连对评级。

| 元素 | 效果 |
|---|---|
| ➕ 题型 | 加/减/乘混合,进度自动升档 |
| 🔢 四选一 | 1 正确 + 3 相近干扰项 |
| 🔥 连对 | 每题 100 + 连对 x10 |
| ⏱ 惩罚 | 答错 -3 秒并断连 |
| 🏆 评级 | 连对 20 心算之神 / 12 高手 / 6 入门 |

**操作:****点答案卡**或按 **1-4** 键作答;心算时**先看运算符**再动眼找选项,别按惯性选!

> 💡 **打法:**① 升到乘法档后,口诀不熟的(6×7/8×9)<b>拆成 6×7=6×5+6×2</b> 两步算;② 干扰项通常是 ±1 或 ±10%,<b>算完核对位数</b>再点;③ 连对分是复利,<b>十拿九稳的题快答</b>,拿不准的宁可慢半拍;④ 答错 -3 秒比漏答更贵,但卡住超过 4 秒就<b>果断猜</b>;⑤ 屏幕上方时间条变红时,切换到只做加法题保节奏!

**结算:**最长连对、本局得分、历史最高分、已玩局数。
