# 台球 (🎱 台球 · 8 球)

> 分类:**街机动作** · 入口:/billiards/ · 免费在线 · 手机即点即玩

**目标:**把属于自己那一组(全色 1-7 或 花色 9-15)全部打进袋,最后打进 8 号黑球获胜。
| 操作 | 键位 |
|---|---|
| 瞄准 | 手指从**白球往目标方向拖动**,会显示预测线与先撞到的球
击球 | 拖得越远力度越大,**松手出杆** |

**规则要点:**白球落袋 → 罚球放回开球点;先碰到对方的球、或者白球什么都没碰到 → 犯规换对手;打进自己组的球可以**继续击球**,没进就换人。

> 💡 **进球技巧:**① 先看**白球—目标球—袋口**这三点的连线,找「假想球」位置;② 打不进就做防守,把白球藏到别的球后面比硬拼强;③ 力度别总开满,轻杆更准;④ 全色球看得清,花色球容易混,开球后先确认自己是哪组;⑤ 打 8 号球前一定要把本组清干净,否则打进黑球直接输。
