# 独竹漂 (🎋 独竹漂 · 一漂一滩)

> 分类:**街机动作** · 入口:/duzhu/ · 免费在线 · 手机即点即玩

**目标:**动平衡:**微调重心**,三滩顺漂。

| 元素 | 效果 |
|---|---|
| 🎋 楠竹 | 一漂一滩 |
| 👆 压脚 | 点左右压 |
| 🌊 急流 | 滩滩更急 |
| ⚠️ 落水 | 折六十退程 |
| 🏆 结算 | 漂竹折分 |

**操作:****点左半屏压左**,右半屏压右。

> 💡 **打法:**① **倾条一偏就点**,小碎点最稳;② 滩越深**竹越贼**,手别离屏;③ 落水**折六十又退二十二程**,亏大了;④ 倾着走**反而慢**,正身才快;⑤ 三滩漂过,**两岸喝茶的都站起来叫好**!

**结算:**滩数、行程、本局得分、历史最高分、已玩局数。
