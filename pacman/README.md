# 吃豆人 (👻 吃豆人 · 迷宫追逐)

> 分类:**街机动作** · 入口:/pacman/ · 免费在线 · 手机即点即玩

**目标:**滑动屏幕操控吃豆人吃光迷宫里的所有豆子。吃掉**能量豆**后幽灵会变蓝,可以反吃得分;被正常幽灵碰到扣一条命,3 条命用完结束。

| 元素 | 效果 |
|---|---|
| 🟡 吃豆 | 走过豆子自动吃掉,每颗 10 分 |
| ⚡ 能量豆 | 四角的大豆,吃掉后 7 秒内幽灵变蓝 |
| 👻 反吃 | 蓝色幽灵每只 200 分,连续反吃翻倍 |
| 🚪 关卡 | 吃光全部豆子进入下一关,幽灵提速 |
| ❤️ 生命 | 被正常幽灵碰到扣 1 条命,共 3 条 |

**操作:**在画面上滑动改变方向,也可以点吃掉豆人想去的方向;键盘方向键/<kbd>WASD</kbd> 移动。**新局**重开。

> 💡 **打法:**① 先绕外圈吃豆,把四角**能量豆**留到幽灵逼近时再吃;② 幽灵变蓝后别追太深,先算好逃跑路线;③ 迷宫中间有传送通道,被追时钻进去换边;④ 每关开始先清一条边,给自己留退路;⑤ 幽灵速度逐关提升,别贪最后几颗豆。

**结算:**得分、通关数、反吃幽灵数、本局得分(得分即成绩)、历史最高分、已玩局数。
