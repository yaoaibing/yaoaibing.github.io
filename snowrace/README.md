# 雪地漂移 (🏎️ 雪地漂移 · 冰封赛道)

> 分类:**街机动作** · 入口:/snowrace/ · 免费在线 · 手机即点即玩

**目标:**三条车道上高速竞速:**点屏幕左右半**换道躲避树木与岩石;冰面段会让车辆**侧滑半格**,速度越快雪雾越浓视野越窄,撞上即结束,距离计分。

| 元素 | 效果 |
|---|---|
| 🏎️ 换道 | 点左半/右半屏切换车道 |
| ❄️ 冰面 | 雪白路段会侧滑,提前半格变道 |
| 🌲 障碍 | 树木/岩石/雪堆,撞上即翻车 |
| 🌫️ 雪雾 | 速度越快雾越浓,视野收窄 |
| 🏁 结束 | 撞障碍即结束,距离计分 |

**操作:****点屏幕左右半**换道(键盘 ←→);**重跑**立刻重开。侧滑是最大陷阱,冰面段落提前规划!

> 💡 **打法:**① 看到路面<b>发白</b>就提前留在目标车道,别在冰上变道;② 雪雾最浓时只看路面正中,余光扫障碍;③ 三车道中间道障碍最少,保守就常驻中道;④ 速度上 200 后,提前量要给到两格;⑤ 深呼吸,越慌越撞!

**结算:**距离、最高时速、换道次数、本局得分(距离 x3)、历史最高分、已玩局数。
