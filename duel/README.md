# 双人反应对决 (🆚 双人反应对决 · 抢拍大战)

> 分类:**解压休闲** · 入口:/duel/ · 免费在线 · 手机即点即玩

**目标:**同屏双人反应对决。红屏随机等待 1~3.5 秒后**变绿**,两人各自拍**自己那半屏**,先拍的赢一回合;**抢跑直接送对方 1 分**。先赢 5 回合获胜。

**操作:**左半屏=左玩家、右半屏=右玩家,支持双指同时拍。也支持单人左右互搏练反应。

> 💡 **对决心得:**① **抢跑是最亏的**:白送 1 分还打击士气,红屏期间把手悬在屏幕上方 1 厘米;② 真正比的是**绿灯后的 0.2 秒**,看到绿色别犹豫直接拍;③ 心理战:故意在红屏时轻拍一下屏幕(不算),干扰对面节奏——注意别拍重了;④ 三局两胜改五局三胜都行,规则自己定;⑤ 人类极限反应约 0.15 秒,能稳定 0.25 秒内出拍已经很快了。

**结算:**双方比分、完赛场次。
