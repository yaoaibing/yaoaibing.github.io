# 顺流放舟 (🛶 顺流放舟 · 一滩一泻)

> 分类:**竞速赛车** · 入口:/boatrip/ · 免费在线 · 手机即点即玩

**目标:**水路竞速:**避礁防涡**,三滩连下。

| 元素 | 效果 |
|---|---|
| 🛶 轻舟 | 顺水自疾 |
| 🪨 礁石 | 触之即翻 |
| 🌀 漩涡 | 暗劲偏航 |
| 🏁 滩尾 | 冲线加分 |
| 🏆 结算 | 放舟折分 |

**操作:**按住**左/右半屏**拨桨。

> 💡 **打法:**① 水急**船漂得快**,拨桨要短点短放;② **漩涡看纹转**,逆着它的劲拨;③ 滩尾**浪更乱**,收着点速度;④ 翻船**分数照给**,下滩找回;⑤ 三滩冲罢,**李白都要抄你的句子**!

**结算:**过滩序号、行程丈数、本局得分、历史最高分、已玩局数。
