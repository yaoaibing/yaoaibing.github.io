# 顶碗平衡 (🍵 顶碗平衡 · 一碗定乾坤)

> 分类:**街机动作** · 入口:/bowlbalance/ · 免费在线 · 手机即点即玩

**目标:**平衡行走:**点两侧回正碗**,倾斜表安全时**点中间迈步**;摔碗三次收场。

| 元素 | 效果 |
|---|---|
| 🍵 顶碗 | 持续漂移需回正 |
| 👣 迈步 | 倾斜 <55% 才稳 |
| 📉 倾斜表 | 红区=危险 |
| 💥 摔碗 | 三只碗定胜负 |
| 🏆 评级 | 40 步顶碗高手 |

**操作:****点左/右半屏**扶碗,**点中间**(空格)迈步。
