# 皮划艇激流 (🛶 皮划艇激流 · 过门夺分)

> 分类:**体育竞技** · 入口:/kayak/ · 免费在线 · 手机即点即玩

**目标:**激流回旋:左右桨交替推进(单边会偏航),水门与礁石顺流而下;**过门 +20**、漏门/撞石记失误,3 次结算。

| 元素 | 效果 |
|---|---|
| 🟢 水门 | 门间距随时间收窄 |
| 🪨 礁石 | 撞上 -25 且记失误 |
| 🛶 双桨 | 左桨右偏/右桨左偏 |
| 📈 流速 | 120→250 m/s |
| 💥 结算 | 3 次失误翻船 |

**操作:**点「**🛶 左桨 / 右桨**」(键盘 **← →**)交替划。

> 💡 **打法:**① **左-右-左-右**节奏划,单桨连按必跑偏;② 水门快到**先对中线**,进门前微调;③ 礁石和水门同现,**保门弃石位**;④ 流速加快后**提前半屏**做动作;⑤ 失误 2 次后**苟住**,门可以漏命不能丢…不对,漏门也算!所以**门必须过,石头必须躲**!

**结算:**过门数、失误数、流速、本局得分、历史最高分、已玩局数。
