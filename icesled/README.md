# 冰上爬犁 (🛷 冰上爬犁 · 江道飞驰)

> 分类:**竞速赛车** · 入口:/icesled/ · 免费在线 · 手机即点即玩

**目标:**四道冰面:自动加速,**切道躲冰裂缝**;卡裂 -1 爬犁,三条爬犁滑到黑。

| 元素 | 效果 |
|---|---|
| 🛷 四道 | 左右点切或键盘 |
| 🟦 冰裂 | 撞上 -1 且减速 |
| ⚡ 提速 | 每秒 +2.6 |
| 🏁 计分 | 滑行距离+得分 |
| 🏆 评级 | 滑行 500 米江道飞人 |

**操作:****点冰道**切道(键盘 ← →)。

> 💡 **打法:**① **四道视野一样**,别迷信中间;② 冰裂缝**蓝得发亮**,提前三秒看到;③ 提速后**少切为妙**,一次切一道;④ 卡裂掉速,**顺势缓一缓**;⑤ 尾段极速,**专注就是刹车**!

**结算:**滑行距离、本局得分、历史最高分、已玩局数。
