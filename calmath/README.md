# 日历算术 (📅 日历算术 · 翻页有数)

> 分类:**学习教育** · 入口:/calmath/ · 免费在线 · 手机即点即玩

**目标:**日历推算:**星期与间隔**,十题连对。

| 元素 | 效果 |
|---|---|
| 📅 基准日 | 题干给出 |
| ➕ 推星期 | 余数定日 |
| 📐 间隔 | 最少天数 |
| ✅ 连对 | 错则归零 |
| 🏆 结算 | 十题折分 |

**操作:**点**选项**作答。

> 💡 **打法:**① **先把基准星期圈出来**,再动笔数;② 推星期**只看余数**,别傻数三十天;③ 间隔题**问最少**,直走七天是一周;④ 连对**分才厚**,宁可慢半拍;⑤ 十题全对,**翻日历都比别人快**!

**结算:**答题进度、连对数、本局得分、历史最高分、已玩局数。
