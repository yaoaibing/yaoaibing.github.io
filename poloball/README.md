# 马球击鞠 (🐎 马球击鞠 · 一杖一球)

> 分类:**竞速赛车** · 入口:/poloball/ · 免费在线 · 手机即点即玩

**目标:**驰马击球:**时机挥杖**,五球竞逐。

| 元素 | 效果 |
|---|---|
| 🐎 骑马 | 匀速前行 |
| 🏑 挥杖 | 点到即击 |
| 🥅 球门 | 门位常换 |
| ⚠️ 越位 | 冲过白跑 |
| 🏆 结算 | 马球折分 |

**操作:**点屏**挥杖击球**。

> 💡 **打法:**① **球在杖头虚线里**再点,早半拍挥空;② 打得越正**球越听话**,角度直奔门心;③ **门位每球都换**,先看清再催马;④ 马冲过头**这球就废**,收着点缰;⑤ 五球穿三,**看台的喝彩压过马蹄**!

**结算:**击球次序、进门次数、本局得分、历史最高分、已玩局数。
