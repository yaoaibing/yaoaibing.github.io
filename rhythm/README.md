# 节奏敲击 (🎵 节奏敲击 · 音浪达人)

> 分类:**街机动作** · 入口:/rhythm/ · 免费在线 · 手机即点即玩

**目标:**音符沿四条轨道下落,落到**判定线**瞬间敲击对应轨道,60 秒内拿高分。键盘 `D``F``J``K` 对应四轨,手机直接点轨道。
| 判定 | 窗口 | 得分 |
|---|---|---|
| ⚡ PERFECT | ±34px | +150 起,连击每击再 +2% |
| ✅ GOOD | ±90px | +60 |
| ✗ MISS | 错过/按空 | 清空连击 |

**节奏:**音符随时间**越来越密、下落越来越快**(最高 1.7 倍速),60 秒一首"曲子"。

> 💡 **拿分要点:**① **眼睛盯判定线**而不是追着音符跑,余光扫四轨;② PERFECT 的分是 GOOD 的 2.5 倍,连击加成更肥,**宁可稳一点也别乱敲**;③ 手机党双手四指各管一轨最稳,单指狂点容易按空;④ MISS 只清连击不扣分,断连后深呼吸找回节拍;⑤ 5000+ 分算节奏入门,8000+ 就是手耳并用的高手。

**结算:**总得分、Perfect/Good/Miss 数、最大连击、评级、历史最高分。
