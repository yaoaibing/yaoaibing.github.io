# 快递分拣 (📦 快递分拣 · 极速仓库)

> 分类:**街机动作** · 入口:/sorting/ · 免费在线 · 手机即点即玩

**目标:**包裹在传送带上限时停留,按品类标签把它送进对应格口。**送错或超时**各扣 1 条命,3 条扣完结束。

| 元素 | 效果 |
|---|---|
| 📦 包裹 | 每个包裹带品类标签,限时内送达 |
| 🥬 四个格口 | 生鲜 / 数码 / 服饰 / 文件,点或按 1-4 |
| 🔥 连击 | 连对越多每单加分越高,送错清零 |
| ⚡ 加急件 | 带闪电的加急件分数翻倍,限时更短 |
| ❤️ 生命 | 送错或超时扣 1 条命,3 条扣完结束 |

**操作:**点下方四个格口,或按键盘 <kbd>1</kbd>-<kbd>4</kbd> 送件;**新局**重开。

> 💡 **打法:**① 先看**标签首字**再动手,别凭包装颜色猜;② 连击比单件分数值钱,宁可慢半拍也别送错;③ 加急件时间更短,优先处理;④ 传送带上有 5 件预览,提前记住下一件品类;⑤ 每送对 6 件限时缩短一次,越到后面越要果断。

**结算:**得分、分拣件数、最高连击、称号、历史最高分、已玩局数。
