# 结绳密语 (🪢 结绳密语 · 大事大结)

> 分类:**密码破译** · 入口:/knotcode/ · 免费在线 · 手机即点即玩

**目标:**位置编码:**结的大小 0-4 对口令**,校验解锁;四题通关。

| 元素 | 效果 |
|---|---|
| 🪢 绳位 | 四位各挂一结 |
| 📜 口令 | 四位数字明示 |
| 👉 换结 | 点绳位循环 0-4 |
| ✅ 校验 | 全对进入下一绳 |
| 🏆 评级 | 四绳全解记事官 |

**操作:****点绳位**换结,点**校验**对密。

> 💡 **打法:**① **口令明摆着**,抄稳再系;② **从左到右**一位位对,别跳位;③ 校验会告诉你**错了几位**,缩小范围;④ 空位也是信息,**别见位就打结**;⑤ 四绳全解,**部落的账都归你记**!

**结算:**解绳数、本局得分、历史最高分、已玩局数。
