# 跳一跳 (🐸 跳一跳 · 摘星)

> 分类:**街机动作** · 入口:/jump/ · 免费在线 · 手机即点即玩

**目标:**按住蓄力、松手起跳,一路跳到更远更小的方块上。落空就掉下去。
| 判定 | 奖励 |
|---|---|
| 踩中**正中心** | 连击翻倍:**+2 → +4 → +8 …**
🎵 音符块 | 踩正有彩蛋加分 |
| 🏪 小卖部 | 踩正有彩蛋加分
🎁 礼盒 | 踩正有彩蛋加分 |

> 💡 **跳法:**① 蓄力时**盯着方块中心**而不是方块边缘,松手时机才准;② **连击比距离值钱**:一次正中 +8 顶上好几次普通落地;③ 有彩蛋块时,宁可少跳一点也要踩正;④ 方块越跳越小,后期靠节奏不靠蛮力——长按到"感觉够了"就放,别死盯着力度条。
