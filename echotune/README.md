# 旋律跟弹 (🎹 旋律跟弹 · 回音键)

> 分类:**音乐节奏** · 入口:/echotune/ · 免费在线 · 手机即点即玩

**目标:**旋律记忆:先**听一遍随机旋律**(3-6 音),再在 6 个琴键上**按顺序复述**;弹错扣一颗心并重听,三心用尽结束,8 轮音数递增。

| 元素 | 效果 |
|---|---|
| 🎹 琴键 | D-E-F-G-A-B 六键 |
| 🎧 听音 | 每音 0.35 秒,自动播放 |
| 🔁 复述 | 按顺序点琴键(1-6) |
| ❤️ 容错 | 三颗心,弹错重听 |
| 📈 音数 | 3→6 递增 |

**操作:**听完**按顺序点琴键**(键盘 **1-6**);**R** 键重听。

> 💡 **打法:**① 先数<b>旋律有几个音</b>,心里打个拍子;② **记相邻音的走向**(高/低/重复)比记绝对位置容易;③ 弹错只扣一颗心,<b>重听时专注错的位置</b>;④ 6 音旋律 = <b>拆成两组三音</b>分别记;⑤ 每天练一次,**耳朵是肌肉**!

**结算:**完成轮数、剩余心数、本局得分、历史最高分、已玩局数。
