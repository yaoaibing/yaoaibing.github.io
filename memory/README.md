# 记忆翻牌 (🃏 记忆翻牌)

> 分类:**烧脑益智** · 入口:/memory/ · 免费在线 · 手机即点即玩

**目标:**牌面全扣着,点两张翻开,**动物相同**即配对成功留在场上;配不成对的牌会抖一抖,**0.7 秒后自动扣回**。全部配对完成即通关。
| 棋盘 | 对数 | 分数系数 |
|---|---|---|
| 4×3 萌新 | 6 对 | ×1 |
| 4×4 日常 | 8 对 | ×1 |
| 5×4 烧脑 | 10 对 | ×1 |
| 6×5 地狱 | 15 对 | ×2.2 |

**操作:**手机直接点牌即翻;键盘 `↑↓←→` 移光标、`空格` 翻牌。底部**提示键每局限 2 次**(全场亮 0.9 秒),但**每用 1 次结算扣 120 分**。

> 💡 **拿分要点:**分数由**步数、用时、星级**共同决定,步数越接近「对数」越高 —— 理论上每对 2 步翻完就是最优。① **别乱翻**,翻开看到新牌就记住位置,哪怕这步配不上;② 优先翻**你已见过另一半**的牌,那是稳赚的一步;③ 提示很贵(120 分),地狱档都不一定回本,**能不用就不用**;④ 地狱档 6×5 系数 ×2.2,想冲高分就打它。

**结算:**配对对数、步数(对比最优)、用时、评级、本局得分。
