# 割绳子 (🍬 割绳子 · 糖果快递)

> 分类:**解压休闲** · 入口:/cutrope/ · 免费在线 · 手机即点即玩

**目标:**用绳子挂着的糖果在重力下摆动,**点击绳子割断**它,让糖果凭借摆动与重力**落进小怪嘴里**即过关;路上可以顺路收集星星,糖果飞出屏幕则重试本关。共 15 关,双绳关卡讲究割的顺序。

| 元素 | 效果 |
|---|---|
| 🪢 绳子 | 点任意位置割断,糖果失去拉力开始下落 |
| 😋 小怪 | 糖果进嘴过关,位置每关不同 |
| ⭐ 星星 | 糖果碰到即收集,计入总星数 |
| 🪢 双绳 | 两根绳同时挂,先割哪根决定摆的方向 |
| ↺ 重试 | 糖果丢失自动重置本关,随时可手动重试 |

**操作:****点绳子**割断;**重试**复位本关,**重开全部**回到第 1 关。绳在摆,糖在飞,手感是关键!

> 💡 **打法:**① 糖果<b>荡到最低点</b>时绳张力最大,这时割它飞得最远;② 想让它垂直下落,等摆到最高点再割;③ 双绳关先割<b>短的那根</b>,留长的控制方向;④ 星星别硬追,顺路为主,三颗全收是高手的活;⑤ 多试几次记住摆动周期,预判比反应重要。

**结算:**通关数、收集星星总数、各关尝试次数、本局得分(过关 x100 + 星 x20)、历史最高分、已玩局数。
