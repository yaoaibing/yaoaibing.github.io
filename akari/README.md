# 燃灯谜阵 (💡 燃灯谜阵 · 一灯照壁)

> 分类:**烧脑益智** · 入口:/akari/ · 免费在线 · 手机即点即玩

**目标:**约束点灯:**照亮全部白格**,灯不互照,数字格邻灯精确;检查通过进下一阵。

| 元素 | 效果 |
|---|---|
| 💡 放灯 | 点白格切换 |
| 🔆 照明 | 横竖穿透白格 |
| 🚫 冲突 | 灯照灯即违例 |
| 🔢 数字 | 邻灯数必须相等 |
| 🏆 递进 | 第 3 阵起六路盘 |

**操作:****点白格**放灯,点**检查**验阵。

> 💡 **打法:**① **带数字的黑格是钉子**,先满足它;② **两灯斜对角最安全**,互不相照;③ 整行没有黑格,**一行一灯就亮透**;④ 检查会告诉你**错在哪一类**,对症下药;⑤ 连破五阵,**你把黑夜都管明白了**!

**结算:**破阵数、本局得分、历史最高分、已玩局数。
