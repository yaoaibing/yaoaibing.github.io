# 拳击争霸 (🥊 拳击争霸 · 拳台之夜)

> 分类:**体育竞技** · 入口:/boxing/ · 免费在线 · 手机即点即玩

**目标:**拳台对战:**出拳**进攻(连击伤害递增),对手**举⚠️蓄力**时按住**格挡**可免伤,蓄力瞬间出拳触发**完美反击**(1.6 倍伤害并打断);你连中 3 拳对手会举盾;60 秒内打空血条 KO,否则按剩余血量点数定胜负。

| 元素 | 效果 |
|---|---|
| 🥊 出拳 | 冷却 0.45 秒,连击 +伤害 |
| 🛡 格挡 | 按住免伤,松手恢复进攻 |
| ⚠️ 预警 | 对手蓄力 0.38-0.75 秒,随难度缩短 |
| ⚡ 反击 | 蓄力期命中 = 1.6 倍伤害 + 打断 |
| 🤖 AI | 连挨 3 拳必举盾,骗盾再打 |

**操作:**点 **🥊出拳**(J/空格)进攻;**按住 🛡格挡**(K)防守;**难度**三档切换。手要快,眼要更准!

> 💡 **打法:**① 核心节奏:**看⚠️→举盾→等收拳→反打两拳**,稳赢公式;② 反击是 16+连击 x2 的伤害,比盲打高一半,<b>宁可少出拳也要抓反击</b>;③ 你连中 3 拳 AI 必举盾,第 3 拳打完先撤,等盾消失;④ 困难档蓄力只有 0.38 秒,靠余光盯它的拳而不是屏幕中央;⑤ 时间打满按血量点数算,落后时放弃防守换血反而划算!

**结算:**双方剩余血量、是否 KO、难度、本局得分(胜 500 + 剩血 x5 + 时间分)、历史最高分、已玩局数。
