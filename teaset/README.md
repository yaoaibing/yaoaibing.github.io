# 茶艺冲泡 (🍵 茶艺冲泡 · 一泡一世界)

> 分类:**模拟经营** · 入口:/teaset/ · 免费在线 · 手机即点即玩

**目标:**工序冲泡:**控温→注水**交替,五步全优通关;每步独立评分。

| 元素 | 效果 |
|---|---|
| 🔥 烧水 | 控火候到目标温度 |
| 🍵 五步 | 烧水温杯投茶冲泡出汤 |
| ⏱ 注水 | 0.7-1.3s 满分 |
| 📊 评分 | 每步独立计分 |
| 🏆 评级 | 总评 180+ 茶艺师 |

**操作:**点「**🔥 加火**」(z)控温,点「**🍵 下一步**」(x)推进。

> 💡 **打法:**① **温度条有黄线**,指到黄线附近就停;② 烧过头**扣分还影响下一步**;③ 注水**数半秒**:一到一点三最佳;④ 每泡**温度不同**,看清再烧;⑤ 总评 180 以上,**茶香自来**!

**结算:**总评分、本局得分、历史最高分、已玩局数。
