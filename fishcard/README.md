# 小猫钓鱼 (🐱 小猫钓鱼 · 童年牌局)

> 分类:**对战棋牌** · 入口:/fishcard/ · 免费在线 · 手机即点即玩

**目标:**经典「小猫钓鱼」:轮流把牌堆顶打出<b>排成长列</b>;若出的牌与桌面任意一张<b>同点数</b>,把两张之间(含两端)的牌全部收走并压回牌堆底;先没牌可出的一方输。

| 元素 | 效果 |
|---|---|
| 🃏 牌堆 | 1-9 各 4 张共 36 张,每人 18 张 |
| 🎣 钓鱼 | 出的牌与桌面同点数,收走中间整段 |
| 📥 回底 | 钓到的牌压回自己牌堆底 |
| 🈳 落败 | 轮到自己却没牌即输 |
| 🤖 对手 | AI 出牌无脑快,节奏靠自己掌握 |

**操作:**轮到你时**点屏幕**或按**空格**出牌;**新局**重发。看准长列里同点数的距离再出!

> 💡 **打法:**① 桌面上同点数<b>隔得越远钓得越多</b>,长桌是宝藏;② 自己快没牌时,故意出桌面已有的点数钓一大串回血;③ AI 完全按顺序出牌,<b>记住它刚出过的点数</b>就能预判桌面变化;④ 开局先把大点数(7/8/9)留在桌面,中盘钓它们最肥;⑤ 这游戏没有操作技巧,纯怀旧,享受钩走一大串的爽感!

**结算:**胜负、你钓到的张数、对手钓到的张数、本局得分(胜 300 + 净胜 x8,负 10 x 钓数)、历史最高分、已玩局数。
