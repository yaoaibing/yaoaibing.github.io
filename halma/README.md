# 弹珠跳棋 (⚪ 弹珠跳棋 · 对岸竞速)

> 分类:**对战棋牌** · 入口:/halma/ · 免费在线 · 手机即点即玩

**目标:**对战跳棋:棋子可 8 方向走一步或**跳过邻子**并可**连续跳**;先把全部 8 子送到对岸者胜;AI 按推进度贪心行棋。

| 元素 | 效果 |
|---|---|
| ⚪ 蓝子 | 你执蓝,在下岸出发 |
| 🦘 连跳 | 跳后可继续跳,点原子收手 |
| 🏁 对岸 | 8 子全到家获胜 |
| 🤖 AI | 贪心推进,偶尔抢跳 |
| 🏆 计分 | 胜 400 起,连胜利滚 |

**操作:**点蓝子选中,点**圈中空位**走/跳;连跳中点**原子**结束回合。

> 💡 **打法:**① 中路一条**直线跳板**胜过散兵游勇;② 自己的子**故意留在半路**当桥;③ 别让最后一颗子掉队,**梯队推进**;④ AI 会堵,提前一格预判;⑤ 对面家门口的格子**先占再说**!

**结算:**到家棋子数、对局比分、本局得分、历史最高分、已玩局数。
