# 雪岭求生 (🏔️ 雪岭求生 · 寒冬十二夜)

> 分类:**生存挑战** · 入口:/survive2/ · 免费在线 · 手机即点即玩

**目标:**冬季生存:每天 **3 点行动力**分配给狩猎/拾柴/修雪橇/探路;夜里**柴火与干粮各消耗 1**、断供重伤、暴风雪狼群随机来袭;**2 捆柴修 1 个雪橇部件**,集齐 3 个即可逃生,12 天为限。

| 元素 | 效果 |
|---|---|
| 🍖 狩猎 | +2~4 干粮 |
| 🪵 拾柴 | +2~3 柴火,夜间刚需 |
| 🛷 修雪橇 | 2 柴换 1 部件,共需 3 件 |
| 🧭 探路 | 部件/干粮/雪崩,概率事件 |
| ❄️ 寒夜 | 柴+粮双耗,断柴 -20 比断粮 -16 更狠 |

**操作:**点 **四个行动按钮**(键盘 **1-4**)消耗行动力,用尽自动入夜;**修雪橇**(2)随时可点,柴够就修。

> 💡 **打法:**① 柴火每晚都烧,**优先级高于食物**(断柴 -20 更狠);② 修雪橇的 2 捆柴别一次全修,<b>部件齐 3 个才是胜利</b>,柴要留过夜;③ 探路是唯一白嫖部件的途径,**每 2 天探 1 次**最划算;④ 暴风雪会撕毁柴堆,木材目标<b>多备 2 捆</b>容错;⑤ 最后 3 天只做两件事:囤食物、修完雪橇,别再冒险!

**结算:**存活天数、雪橇部件数、本局得分(胜 500 + 剩余天数 x50 + 生命 x3)、历史最高分、已玩局数。
