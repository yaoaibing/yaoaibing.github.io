# 加油员 (⛽ 加油员 · 一滴不洒)

> 分类:**模拟经营** · 入口:/fuel/ · 免费在线 · 手机即点即玩

**目标:**加油站模拟:按住**油枪键**出油(带抖动),对照目标线松手;±0.5L 内加满计奖金,溢出罚款;90 秒结算总收入。

| 元素 | 效果 |
|---|---|
| 🎯 目标 | 每车 18-45L 随机 |
| ⚡ 油流 | 2.1L/s 带轻微抖动 |
| ✨ 神准 | ±0.1L 内 +50 |
| 💦 溢出 | 超 2L 罚 60 |
| 🏆 结算 | 服务数 x 收入 |

**操作:****按住「⛽ 加油」**出油,**松手**停止(按住空格同效)。

> 💡 **打法:**① 目标线前**半秒松手**,余流正好补满;② 油流有抖动,**越接近目标越要点刹**;③ 神准奖比多接一单划算,**准比快值钱**;④ 大油箱别怕,**流量大容错高**;⑤ 最后 10 秒至少跑一单小的,**保底落袋**!

**结算:**服务车辆数、总收入、本局得分、历史最高分、已玩局数。
