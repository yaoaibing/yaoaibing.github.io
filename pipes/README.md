# 管道大师 (🔧 管道大师 · 接通水流)

> 分类:**烧脑益智** · 入口:/pipes/ · 免费在线 · 手机即点即玩

**目标:**点击管道旋转,让左侧水泵的水流经**每一格**。所有管道口必须两两对接,全部格子通水即过关,每局由程序生成,保证可解。

| 元素 | 效果 |
|---|---|
| 🔧 旋转 | 点管道顺时针转 90 度,步数加一 |
| 🚰 水泵 | 水从左侧中央流入,沿对接的管道扩散 |
| 🚫 漏水 | 管道口没对上就断流,先接通主路 |
| 🎚 难度 | 5x5 入门、6x6 经典、7x7 挑战 |
| 🏁 过关 | 所有格子都通水即过关,步数越少分越高 |

**操作:**点管道旋转;**难度**切换并开新局,**新局**重开。键盘 <kbd>1</kbd>-<kbd>3</kbd> 切难度,<kbd>R</kbd> 新局。

> 💡 **打法:**① 从水泵那一格开始,顺着水流方向一格一格接;② 先接主干,再处理边角的弯头;③ 十字和丁字接头方向多,先确定它的主方向;④ 别乱点已经接好的格子,每转一次都算步数;⑤ 卡住就整体看一遍,漏水点通常就在缺口旁边。

**结算:**步数、用时、难度、本局得分(难度基础分 - 步数 x10 - 秒数 x2,最低 120)、历史最高分、已玩局数。
