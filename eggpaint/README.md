**目标:**顺序上色:按配色单**逐区涂色**,全对过关;顺序错扣心重来。

| 元素 | 效果 |
|---|---|
| 🥚 六款 | 福/柳/寿/锦/竹/喜 |
| 🎨 五色 | 白红绿金黑 |
| 📋 配色单 | 区块顺序即答案 |
| ❤️ 容错 | 三颗心 |

**操作:****点色盘**取色,**点区块编号**上色。
