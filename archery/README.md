# 射箭挑战 (🏹 射箭挑战 · 百步穿杨)

> 分类:**街机动作** · 入口:/archery/ · 免费在线 · 手机即点即玩

**目标:**朝靶心拖动拉弓,松手射箭。箭会受**重力**和**风**影响,命中黄心得 10 环,越靠外分越低,**10 支箭**累计总分。

| 元素 | 效果 |
|---|---|
| 🏹 拉弓 | 按住屏幕朝靶心方向拖,越远力量越大 |
| 🌬️ 风 | 顶部风标显示风向风速,顺风抬高、逆风压低 |
| 🎯 靶环 | 黄心 10 环,向外依次 9/8/7/6 环 |
| 💨 弹道 | 箭会下坠,想打黄心要瞄高一点 |
| 🏁 计分 | 10 支箭射完,累计环数即成绩 |

**操作:**按住屏幕朝靶心方向拖动拉弓,松手射箭;底部**新局**重开。键盘 <kbd>空格</kbd> 用上次力度再射,<kbd>R</kbd> 新局。

> 💡 **打法:**① 先小力试一箭,记住**下坠幅度**再调;② 顺风时瞄低一点,逆风时抬高;③ 靶心偏上时别硬拉满,角度比力量重要;④ 连续偏左说明拉弓方向歪了,松手前停半秒;⑤ 最后一两支箭落后时,先求上靶再求十环。

**结算:**总环数、十环数、脱靶数、本局得分(环数 x100 + 十环 x50)、历史最高分、已玩局数。
