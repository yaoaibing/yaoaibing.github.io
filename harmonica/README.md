# 口琴独奏 (🎵 口琴独奏 · 吹吸之间)

> 分类:**音乐节奏** · 入口:/harmonica/ · 免费在线 · 手机即点即玩

**目标:**吹吸记忆:听样曲后按**吹/吸提示与音序复奏**;全对通关,曲长随关卡增加。

| 元素 | 效果 |
|---|---|
| 🎵 四曲 | 欢乐颂/小星星等 |
| 💨 吹吸 | 奇数吹偶数吸 |
| 🔊 试听 | 可反复重听样曲 |
| ❤️ 容错 | 三颗心 |
| 🏆 评级 | 四曲全奏口琴手 |

**操作:**看提示**点「吹」或「吸」**(键盘 **z/x**),可点「**🔁 重听**」。

> 💡 **打法:**① **先听曲子**,心里默念吹吸交替;② 提示字样**大而清晰**,跟着念就行;③ 「欢乐颂」开头**吹吹吹吸**,口诀在手;④ 敲错别慌,**重听一遍再上手**;⑤ 嘴里哼着,**手自然跟上**!

**结算:**演奏曲数、连过、本局得分、历史最高分、已玩局数。
