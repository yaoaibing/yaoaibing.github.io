# 杂耍抛球 (🤹 杂耍抛球 · 左右开弓)

> 分类:**解压休闲** · 入口:/juggle/ · 免费在线 · 手机即点即玩

**目标:**杂耍节奏玩法:屏幕下方两只手套一起跟着手指左右移动,球从上方受重力落下,落到哪只手附近就自动接住并抛向另一侧的弧线。<b>关键在于必须左右交替</b>——同一只手连着接两个球就破功,漏接一个球掉到地上也算失误,两者都扣一条命(共 3 条)。接得越顺连击越长,每 12 次成功接球加一个球,最多 6 个。够不着时可以按「换手」把该接的手翻过来,代价是断连击。

| 元素 | 效果 |
|---|---|
| 🤹 两只手 | 左右手套一起横移,标记指出该谁接 |
| 🎾 球 | 重力下落,接住抛向另一侧,碰壁回弹 |
| 🔁 交替 | 同手连接破功,连击清零 |
| 🔄 换手 | 救急翻面,断连击不扣命 |
| 🏁 结束 | 漏球或破功扣命,三条用完下台 |

**操作:****在屏幕上左右拖动**整对手套对位,球到手上自动接抛;按 <b>🔄 换手</b>切换该接的手(断连击),<b>↻ 重开</b>立刻回场。键盘 ← → 也可平移。

> 💡 **打法:**① 不要追着球跑,<b>提前把手挪到落点</b>更省力;② 看那只亮标记的手,别信自己的记忆;③ 球变密后走<b>小步快移</b>,一次挪一大步必漏;④ 换手是救急不是常态,连击倍率比安全分值钱;⑤ 破功后先接稳两下,再图长连击。

**结算:**接球次数、最高连击、本局得分(每次接球按连击倍率 1~5 分累加)、纪录分(接球 x10 + 最高连击 x5)、历史最高分、已玩局数。
