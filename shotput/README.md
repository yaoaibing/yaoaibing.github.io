# 铅球出手 (🥎 铅球出手 · 一掷定音)

> 分类:**体育竞技** · 入口:/shotput/ · 免费在线 · 手机即点即玩

**目标:**两段投掷:第一次按键锁定**扫动角度**(38°-44° 最优),第二次锁定**力量**,物理抛物线落地计距离;三投取最佳。

| 元素 | 效果 |
|---|---|
| 📐 角度 | 15°-55° 往复扫动 |
| 💪 力量 | 0-100 往复扫动 |
| 🎯 黄金区 | 38°-44° 飞最远 |
| 🏁 计分 | 最佳距离 x100 |
| 🏆 评级 | 15 米一掷定音 |

**操作:**点「**💪 出手**」或**空格**:一次锁角度,一次锁力量。

> 💡 **打法:**① **角度优先**:38°-44° 之外力气再大也白搭;② 力量表**等满格**再按,别抢半程;③ 角度扫动快,**心算提前量**在绿区前一点按;④ 三投策略:**第一投试手感**,后两投冲最佳;⑤ 物理不会骗人,**抛物线高点在屏幕上半区**就对了!

**结算:**最佳距离、投掷轮次、本局得分、历史最高分、已玩局数。
