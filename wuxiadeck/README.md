# 侠客行囊 (🎒 侠客行囊 · 一包闯江湖)

> 分类:**卡牌构筑** · 入口:/wuxiadeck/ · 免费在线 · 手机即点即玩

**目标:**行囊牌组:每回合 **3 点行动**出牌;⚔️ 攻直伤、🛡️ 防护挡本回合、💨 气牌 +2 行动;结束回合挨敌方刀,胜利后**二选一添新牌**,连闯 5 波。

| 元素 | 效果 |
|---|---|
| ⚔️ 攻牌 | 直接削敌血 |
| 🛡️ 防牌 | 抵挡本回合伤害 |
| 💨 气牌 | +2 行动并摸一张 |
| 🎁 战利品 | 每关二选一入牌组 |
| 🏆 评级 | 五关通关一代大侠 |

**操作:****点手牌**出招(键盘 **1-4**),点「**结束回合**」(空格)过。

> 💡 **打法:**① **气牌是发动机**,行动多一回合多砍一刀;② 敌人攻击前**留 1 防牌保命**;③ 头目攻击高,**护体叠加能硬抗**;④ 新牌先拿**攻 4**,前中期碾压最快;⑤ 血量就是回合数,**算好斩杀线再过**!

**结算:**通关波次、本局得分、历史最高分、已玩局数。
