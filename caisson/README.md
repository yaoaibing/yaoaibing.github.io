# 藻井描彩 (🏛️ 藻井描彩 · 层层生莲)

> 分类:**创意涂鸦** · 入口:/caisson/ · 免费在线 · 手机即点即玩

**目标:**对称配色:**环环描彩**,三层递进。

| 元素 | 效果 |
|---|---|
| 🏛️ 扇格 | 一环八格起 |
| 🎨 矿彩 | 四色任选 |
| 🪞 对径 | 自动同色 |
| ⚠️ 违例 | 相邻撞色 |
| 🏆 结算 | 三层折分 |

**操作:**点**扇格**再点**矿彩**。

> 💡 **打法:**① **对径自动跟上**,只管描一半;② **相邻两格别同色**,描前扫一眼左右;③ 环越大**格越多**,越到后面越要稳;④ 撞色**清环重来**,亏十分不亏心;⑤ 三层描成,**抬头看都是自己画的莲**!

**结算:**描彩层号、违例数、本局得分、历史最高分、已玩局数。
