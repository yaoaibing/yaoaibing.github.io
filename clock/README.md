# 认识时钟 (⏰ 认识时钟 · 时间大师)

> 分类:**烧脑益智** · 入口:/clock/ · 免费在线 · 手机即点即玩

**目标:**看表盘读时间,四选一选正确的数字时间。12 道题,整点/半点/一刻/随机分钟混合,3 颗心容错。儿童时间启蒙首选。

**操作:**点选项或按 `1`-`4`。答对 +100 起连对滚分;答错 -1 心并显示正确答案。

> 💡 **教学要点:**① 口诀:**短针=时针看几点,长针=分针看分钟**;② 长针指 12=整点、指 6=半点、指 3=一刻(15 分)、每个数字代表 5 分钟;③ 时针在两个数字之间=**取小的那个**(过了 3 没到 4 就是 3 点多);④ 家长陪玩时让孩子先说「长针指几」,再算分钟;⑤ 连对 12 题全对 = 时间大师认证。

**结算:**答对题数/12、最大连对、总得分、历史最高分。
