# 铁路调度 (🚉 铁路调度 · 疏导高峰)

> 分类:**烧脑益智** · 入口:/rail/ · 免费在线 · 手机即点即玩

**目标:**彩色列车依次驶过道岔:**点道岔切换**轨道走向,把每列车送进同色车站;送错记失误,3 次失误结束。12 关,颜色数与车流密度递增。

| 元素 | 效果 |
|---|---|
| 🚉 列车 | 按时刻表依次进岔,不可回头 |
| 🔀 道岔 | 点击切换轨道走向,即时生效 |
| 🎨 车站 | 列车进同色站 +1,进错站失误 |
| ⏱ 密度 | 后车紧跟前车,提前预判 |
| 🏁 过关 | 全部列车正确进站 |

**操作:****点道岔**切换;**重来**复位本关。盯紧下一列车,再瞄一眼后一辆的颜色!

> 💡 **打法:**① 别只看当前车,<b>余光扫后一辆</b>的颜色;② 同色连续来车时,道岔别动,省操作;③ 失误 2 次后进入保命模式:宁可慢半拍也别猜;④ 道岔在车头压上之前切换都来得及,别慌;⑤ 记住每关的列车序列,第二轮心中就有时刻表!

**结算:**通关数、正确进站数、失误次数、本局得分(进站 x50)、历史最高分、已玩局数。
