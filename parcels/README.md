# 快递分拣 (📦 快递分拣 · 夜班仓库)

> 分类:**模拟经营** · 入口:/parcels/ · 免费在线 · 手机即点即玩

**目标:**分拣模拟:包裹沿传送带左行,**进入扫码区**后按对应**东/西/北**分拣口;分错 -30,漏件 -40,连对每件 +10 递增;60 秒分满 14 件达标,带速随进度加快。

| 元素 | 效果 |
|---|---|
| 📦 包裹 | 三色区标:红东/蓝西/黄北 |
| 🔍 扫码区 | 虚线框内才能识别分拣 |
| 👆 分拣口 | 三个按钮(键盘 1/2/3)对应三区 |
| 💸 罚则 | 分错 -30、漏件 -40 并断连击 |
| 🚀 提速 | 每分拣一件,带速 +3.2 |

**操作:**包裹进虚线框后点对应**分拣口按钮**(或键盘 **1/2/3**、方向键);眼观整条带,手只管前件!

> 💡 **打法:**① 视线别跟着手上的件,**提前看传送带右端**下一个是什么区;② 扫码区有富余,进框瞬间就可以按,<b>不用等它走到中间</b>;③ 连对加成是本命的分数来源,拿不准的那件宁可漏(−40)也别乱按(−30 还占按钮);④ 后段带速翻倍,**两只手分工**:左手东/西,右手北;⑤ 漏件不可怕,连断才伤,稳住节奏比抢快重要!

**结算:**分拣件数、漏件数、连对、是否达标、本局得分(分拣分 + 达标奖 250)、历史最高分、已玩局数。
