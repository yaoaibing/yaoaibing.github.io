# 帆船竞速 (⛵ 帆船竞速 · 抢风过标)

> 分类:**体育竞技** · 入口:/sailing/ · 免费在线 · 手机即点即玩

**目标:**抢风航行:船固定以 45° 航行,**左右舷切换**改变方向;依次接近三个浮标绕标;65 秒内完成获胜。

| 元素 | 效果 |
|---|---|
| ⬆️ 顶风 | 正对风走不动(设定禁用) |
| ↖↗ 之字 | 左舷/右舷 45° 切换 |
| 🛟 浮标 | 三标顺序绕行 |
| ⏱ 限时 | 65 秒完赛 |
| 🏆 结算 | 完赛 + 用时奖励 |

**操作:**点「**↖ 左舷 / 右舷 ↗**」(键盘 ← →)换舷。

> 💡 **打法:**① **之字幅度别太碎**,每舷多走一段再换;② 浮标在正上?**先斜到一侧再换舷切进去**;③ 第二标在右边,**提前两拍换右舷**;④ 换舷瞬间船身横倾,**是正常的不用慌**;⑤ 路线规划:**两点之间,之字最短**!

**结算:**绕标数、船速、本局得分、历史最高分、已玩局数。
