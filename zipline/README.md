# 索道货运 (🚡 索道货运 · 惯性刹车)

> 分类:**建造物理** · 入口:/zipline/ · 免费在线 · 手机即点即玩

**目标:**角度+惯性双段:锁角度决定初速,滑行中**点按刹车**停进站台;自动停判定与冲出索道均有惩罚;六单递进。

| 元素 | 效果 |
|---|---|
| 📐 角度 | 0-60°,越大越快 |
| 🛑 刹车 | 再次点击落定 |
| 🎯 站台 | 中心 ±30% 满分 |
| 💨 摩擦 | 速度随程衰减 |
| 🏆 计分 | 满分 100+台宽奖励 |

**操作:**点「**🪝 出手/刹车**」(空格)。

> 💡 **打法:**① 先**记站台位置**,再决定角度;② 角度≈**距离的四分之一**起步试;③ 货筐过半程再刹车,**早刹全是短杆**;④ 站台变窄后,**宁可停台边也别冲出去**;⑤ 速度太低会自己停,**半路趴窝也算脱靶**!

**结算:**货运单号、滑行距离、本局得分、历史最高分、已玩局数。
