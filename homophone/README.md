# 同音密语 (📨 同音密语 · 别字还原)

> 分类:**密码破译** · 入口:/homophone/ · 免费在线 · 手机即点即玩

**目标:**别字测验:电文中**一处同音别字**,四选一还原正字;的得/在再/带戴/做作/已以/固顾等易混字库,连对计分。

| 元素 | 效果 |
|---|---|
| 📨 电文 | 12 组易混同音字句 |
| 🔤 还原 | 四选一选出正字 |
| 🔥 连对 | 每题 100 + 连对 x10 |
| ❌ 答错 | 断连 -15 |
| 🏆 评级 | 连对 7 次文字警察 |

**操作:****点选项**(键盘 **1-4**)作答。

> 💡 **打法:**① **的/得**:动词后面接「得」(跑得快),名词前用「的」;② **在/再**:表地点动作用「在」,表重复用「再」;③ **带/戴**:身上穿戴用「戴」,携带用「带」;④ **做/作**:具体动作用「做」,抽象名目用「作」;⑤ 逐字默读,**别字的语感会硌牙**!

**结算:**连对、本局得分、历史最高分、已玩局数。
