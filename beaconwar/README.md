# 烽火边关 (🏯 烽火边关 · 长城夜守)

> 分类:**策略战棋** · 入口:/beaconwar/ · 免费在线 · 手机即点即玩

**目标:**布防博弈:每夜 8 兵分守五关,AI 率胡骑来攻;**守军≥敌军则关守住**,失关扣城墙,五回合墙碎即败。

| 元素 | 效果 |
|---|---|
| 🏯 五关 | 雁门/居庸/玉门/嘉峪/山海 |
| ⚔️ 攻防 | 守军≥敌军即守住 |
| 🧱 城墙 | 失一关损一格 |
| 🔥 全守 | 五关齐守计一胜 |
| 🏆 评级 | 五夜全守戍边名将 |

**操作:****点关隘**布兵(键盘空格=点烽火)。

> 💡 **打法:**① **每关至少一个兵**,空关就是白送;② 敌军会集中扑一两关,**别把兵摆成铁板**;③ 前几夜试探**均匀布防**;④ 城墙只剩两格时,**保关比保兵重要**;⑤ 五关全守的奖励分**是赢的关键**!

**结算:**全守夜数、城墙余量、本局得分、历史最高分、已玩局数。
