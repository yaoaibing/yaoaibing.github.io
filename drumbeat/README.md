# 节奏鼓手 (🥁 节奏鼓手 · 敲击大师)

> 分类:**解压休闲** · 入口:/drumbeat/ · 免费在线 · 手机即点即玩

**目标:**底部三鼓面对应屏幕提示圈:**在圈缩到最小时敲击**对应鼓面,精准度决定得分;BPM 逐关加速,连击有加成。

| 元素 | 效果 |
|---|---|
| 🥁 三鼓 | 底鼓(下)/军鼓(中)/镲片(上) |
| 🟢 提示圈 | 缩到最小时敲=Perfect |
| ⭕ 计分 | Perfect x2 / Good x1 / Miss x0 |
| 📈 BPM | 60→180 逐关加速 |
| 🏁 结束 | 全部音符敲完结算 |

**操作:****点底部鼓面**敲击(键盘 ←↓→);**重来**重敲。听节拍器的声音,眼睛看提示圈,手跟耳朵走!

> 💡 **打法:**① 别看手,看<b>提示圈</b>的大小变化;② Perfect 的窗口只有几帧,提前一点点按下;③ 底鼓通常在强拍,军鼓在弱拍,掌握规律;④ 连击 10 以上分数翻倍,保连击比追 Perfect 更划算;⑤ BPM 高时别慌,只关注最近的提示圈!

**结算:**总分、Perfect 数、最大连击、精准率、历史最高分、已玩局数。
