# 国际象棋 (♞ 国际象棋 · 人机对弈)

> 分类:**对战棋牌** · 入口:/chess/ · 免费在线 · 手机即点即玩

**目标:**你和电脑各执一方,白棋先行,先把对方的王**将死**即获胜。王车易位、吃过路兵、兵升变等规则全部生效。

| 元素 | 效果 |
|---|---|
| ♞ 走子 | 点自己的棋子,绿点可走,红圈可吃 |
| 👑 升变 | 兵走到底线自动升变皇后 |
| 🏰 王车易位 | 王和车都没动过、中间无子且不被将军时可用 |
| 💨 吃过路兵 | 对方兵一次走两格时,可斜吃它经过的格子 |
| 🏁 胜负 | 将死获胜,无子可走且被将军即被将死,否则为逼和 |

**操作:**点自己的棋子选中,再点绿点或红圈落子;**悔棋**退回上一回合,**新局**重开一局,底部切换难度。键盘 <kbd>U</kbd> 悔棋,<kbd>R</kbd> 新局。

> 💡 **打法:**① **先出马和象,再出兵抢中心**,开局别急着用皇后乱冲;② 每次落子前先看对方有没有将军的招;③ 王车易位把王藏到边上,比留在中间安全;④ 子力落后时多换子,少对换兵;⑤ 困难 AI 会搜 3 层,走错就用悔棋退回来重试。

**结算:**胜负、子力差、难度、本局得分(胜利 1000 + 子力优势 + 难度 0/100/200,和棋 300)、历史最高分、已玩局数。
