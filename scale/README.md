# 天平称重 (⚖️ 天平称重 · 数学天平)

> 分类:**烧脑益智** · 入口:/scale/ · 免费在线 · 手机即点即玩

**目标:**左盘放着目标重物(如 275g),从砝码栏**点选砝码放到右盘**,让左右完全平衡。8 关目标重量越来越刁,砝码越少用分越高。

**操作:**点砝码放置/取回。超重会晃动提示;平衡瞬间过关 +300,砝码超过 3 枚每个 -30。

> 💡 **称重要点:**① 先看**目标尾数**:尾数 5 必须用 5g 砝码,尾数 0 用 10/20/50/100 组合;② **贪心法**:从最大砝码开始放,超了就换小的;③ 例:275=200+50+20+5(4 枚);④ 砝码可重复出现(两个 20、两个 5),**别漏用同面值**;⑤ 少于等于 3 枚砝码有满分,多用一枚 -30,先想后放。

**结算:**8 关全部配平、总得分、历史最高分。
