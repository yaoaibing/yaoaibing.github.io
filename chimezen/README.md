# 风铃小筑 (🎐 风铃小筑 · 檐下一曲)

> 分类:**解压休闲** · 入口:/chimezen/ · 免费在线 · 手机即点即玩

**目标:**弹拨解压:点风铃发声,**相邻音连续拨动计和音**滚分;铃摆碰撞也有小惊喜。

| 元素 | 效果 |
|---|---|
| 🎐 五铃 | 宫商角徵羽五音 |
| 🎵 和音 | 相邻音连拨分高 |
| 🔄 碰铃 | 摆动互撞小加分 |
| 🌙 闲坐 | 60 秒计时 |
| 🏆 评级 | 连音 15 檐下乐师 |

**操作:****点风铃**(键盘 **1-5**)拨响。

> 💡 **打法:**① **1-2-3 往上拨**再 **3-2-1** 回来,就是小曲;② 和音要**相邻两枚**,隔着拨不算;③ 拨得越快铃摆越大,**撞铃的意外之喜就多**;④ 别追求快,**听清每一声**;⑤ 60 秒不长,**留给喜欢的顺序**!

**结算:**铃声分、连音、本局得分、历史最高分、已玩局数。
