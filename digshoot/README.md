**目标:**寻踪深浅:**认裂纹控锄深**,绿区起笋;十锄结算。

| 元素 | 效果 |
|---|---|
| 🌱 裂纹 | 有笋的暗号 |
| ⛏ 下锄 | 按住加深 |
| 🟩 绿区 | 松手最完好 |
| 💥 挖断 | 超深颗粒无收 |
| 🏆 结算 | 完好笋高分 |
