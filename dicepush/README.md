# 骰子孤注 (🎲 骰子孤注 · 收手还是再掷)

> 分类:**骰子冒险** · 入口:/dicepush/ · 免费在线 · 手机即点即玩

**目标:**风险累积:**掷骰计分入本轮**,收分入袋或再掷;掷出无效组合本轮清零。

| 元素 | 效果 |
|---|---|
| 🎲 计分 | 1 点 100,5 点 50 |
| 🎯 三同 | n 点三同 = n×100 |
| 💥 爆 | 无效掷本轮清零 |
| ♻️ 全计分 | 六骰全用上则重开 |
| 🏆 五局 | 累计总分定评级 |

**操作:**点底部**再掷**或**收分**按钮。

> 💡 **打法:**① **1 点和 5 点永远有效**,掷前心里有底;② 本轮过 300 就**可以考虑收手**;③ 剩骰越少**越容易爆**,三骰以下慎再掷;④ 爆了别上头,**下一局从头来**;⑤ 五局总分,**稳比贪走得远**!

**结算:**累计得分、本轮分、历史最高分、已玩局数。
