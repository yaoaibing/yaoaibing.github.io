# 中国象棋 (帅 中国象棋 · 人机对弈)

> 分类:**对战棋牌** · 入口:/xiangqi/ · 免费在线 · 手机即点即玩

**目标:**你执红棋在下方先行,把黑方**将死**即获胜。马走日、象走田、炮翻山、将帅不照面等规则全部生效,被将军必须应将,无子可走也算输。

| 元素 | 效果 |
|---|---|
| 帅 走子 | 点红子看绿点,再点目标点落子 |
| 🐴 马/象 | 马腿被挡不能走,象眼被挡不能飞,象不能过河 |
| 💣 炮 | 不吃子时走直线,吃子必须隔一个棋子 |
| 👑 将帅 | 只能在九宫内走,双方将帅不能照面 |
| 🏁 胜负 | 将死对方获胜,自己被将死或无子可走即输 |

**操作:**点自己的棋子选中,再点绿点或红圈落子;**悔棋**退回上一回合,**难度**切换 AI 强度,**新局**重开。键盘 <kbd>U</kbd> 悔棋,<kbd>R</kbd> 新局。

> 💡 **打法:**① 开局先出**车马炮**,别急着用兵冲;② 炮要留炮架,空头炮最凶;③ 马腿容易被兵和炮别住,走马前先看落点;④ 将帅同线时中间必须有子,别自己让开;⑤ 困难 AI 会算 3 层,走错就悔棋换招。

**结算:**胜负、回合数、剩余子力、本局得分(胜利 1000 + 剩余子力 x20 + 难度 0/100/200)、历史最高分、已玩局数。
