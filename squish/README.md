# 捏捏乐 (🫧 捏捏乐 · 慢回弹解压)

> 分类:**解压休闲** · 入口:/squish/ · 免费在线 · 手机即点即玩

**目标:**解压玩具:六只慢回弹捏捏乐,**按住捏扁、松手慢回弹**,捏扁会眯眼微笑;零目标零失败,点完成后按只数结算创作分。

| 元素 | 效果 |
|---|---|
| 🫧 六只 | 不同色相,随你捏 |
| 😌 表情 | 捏扁会眯眼,松手恢复 |
| 🧘 无压力 | 零目标零失败 |
| ✅ 收工 | 只数 x40 结算 |
| 🔊 音效 | 捏下有轻微挤压声 |

**操作:****按住捏扁**、松手回弹;想怎么捏就怎么捏。

> 💡 **打法:**① 按住不放会<b>越捏越扁</b>,回弹更慢;② 快速连点=高频解压,**长按=深度解压**,看心情;③ 六只颜色不同,情绪不同;④ 这游戏没有技巧,<b>解压本身就是玩法</b>!

**结算:**捏捏乐只数、创作分(100 + 只数 x40)、历史最高分、已玩局数。
