# 拼图 (🧩 拼图 · 碎景重圆)

> 分类:**解压休闲** · 入口:/jigsaw/ · 免费在线 · 手机即点即玩

**目标:**三幅原创风景依次挑战,把打乱的图块点对点交换,拼回完整画面。3x3 → 4x4 → 5x5,步数和时间都算分。

| 元素 | 效果 |
|---|---|
| 🖼️ 三幅图 | 晨雾山谷 3x3、落日海滩 4x4、夜空星河 5x5 |
| 🔁 交换 | 点两块图块互换位置,每次交换计 1 步 |
| 👁️ 看原图 | 点「看原图」或按 P 预览 2.5 秒 |
| ⏱️ 计分 | 基础分 + 步数奖励 + 时间奖励,三幅累计 |
| 🏁 通关 | 三幅全部拼完结算总分 |

**操作:**点第一块,再点第二块互换;**看原图**预览 2.5 秒,**重打乱**只重排当前这关,**新游戏**从第一幅重开。键盘 <kbd>P</kbd> 看原图。

> 💡 **打法:**① 先找**四个角**——四角图块只有一种正确位置;② 用天空、地平线这类**大色块**先分区,再抠细节;③ 步数奖励上限 260,每次交换扣 6,别乱点;④ 时间奖励上限 420,该看原图就看,犹豫更费时间;⑤ 5x5 关卡先拼边框,再填内部。

**结算:**三幅图总分、称号、历史最高分、已玩局数。
