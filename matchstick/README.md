# 火柴算式 (🔥 火柴算式)

> 分类:**烧脑益智** · 入口:/matchstick/ · 免费在线 · 手机即点即玩

**目标:**每题的等式都是**错的**,移动**恰好一根火柴**(从一根数字上拿走、放到另一个数字的空位上)让等式重新成立。共 **16 道**经典题,全解完通关。

**操作:**先点一根**火柴**拿起(会发金光),空位会显示虚线圆圈,再点目标空位放下。放下的瞬间自动验算:**拿走火柴的数字和放上火柴的数字都必须还是合法数字**,且新等式成立才算过关。点已拿起的火柴=放回。`↑↓←→` 选火柴/空位,`空格` 确认,`Esc` 放回。

**计分:**基础 **+100**,**连对每题再 +20** 滚雪球;修错扣 10 分并断连;点 **💡提示**(闪一根可动的火柴)该题只得 60 分;点 **↻复原** 重摆本题不另扣分。

> 💡 **拿分要点:**① 记住常见变形:**8 能变 9/6/0,9 能变 3/5/0,6 能变 5,5 能变 3/6/9,7 能变 1**;② 差号右边的结果一般**只差一根**,先盯结果数字想它能由什么变来;③ 数字间的火柴**可以借来借去**,别只想着"减一根";④ **零失误零提示**通关直接三星,分差非常大,想不清楚先按复原重摆,别硬试。

**结算:**用时、失误次数、提示次数、评级(星级)、本局得分、历史最高分。
