# 忍墙飞檐 (🥷 忍墙飞檐 · 双壁腾挪)

> 分类:**街机动作** · 入口:/walljump/ · 免费在线 · 手机即点即玩

**目标:**双墙忍者:点击在两面墙间**交替腾跃**,腾空有抛物线、登墙缓慢下滑;墙上随机长尖刺,黑暗从底部上涌,双重威胁下比拼爬升高度。

| 元素 | 效果 |
|---|---|
| 🥷 腾跃 | 抛物线跳跃,自动登墙 |
| 🔻 尖刺 | 登墙点附近随机出现 |
| 🌑 黑暗 | 加速上涌,触碰即败 |
| 📈 计分 | 爬升米数=分数 |
| 🏆 评级 | 爬得越高越强 |

**操作:****点击屏幕**或按**空格**蹬墙(空中不可再蹬)。

> 💡 **打法:**① 蹬墙时机是全部:**登墙瞬间就按**,别等下滑;② 尖刺总长在你下一面墙,**登墙前扫一眼**;③ 黑暗加速**宁高勿低**,高度就是缓冲;④ 空中别乱点,**一跳一蹬节奏最稳**;⑤ 后期墙刺密集,**贴屏中线跳**容错高!

**结算:**攀爬高度、本局得分、历史最高分、已玩局数。
