# 消灭星星 (⭐ 消灭星星 · 爆破消除)

> 分类:**烧脑益智** · 入口:/popstar/ · 免费在线 · 手机即点即玩

**目标:**10×10 的五色星星盘,点击**相连的同色组**(≥2 个)整组爆破。得分=数量²×5,全部清空额外 **+2000**,没清完按剩余数折算奖励。无法消除即结束。

**机制:**爆破后上方星星下落补位,**空列整列左移**——所以炸中间能把两边颜色挤到一起,这是规划的核心。

> 💡 **拿分要点:**① **数量是平方计分**:两个 5 连(50 分)不如一个 10 连(500 分),**能憋大组就憋大组**;② 优先炸**竖长组**,下落后更容易促成新的大组;③ 盯住"空列左移"的连锁:炸穿一列能把左右两个同色区域接壤;④ 开局先扫一遍盘面找**最大的三组**再动手;⑤ 结束前若还剩 2-3 组,先算算能不能顺手清空拿 2000。

**结算:**总得分、剩余星星数、是否全清、历史最高分。
