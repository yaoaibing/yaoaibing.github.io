**目标:**科学把戏:**盐冻线钓冰**,五块连钓。

| 元素 | 效果 |
|---|---|
| 🧊 冰块 | 水中浮块 |
| 🧂 撒盐 | 三撮结冰 |
| 🧵 提线 | 寸寸慢提 |
