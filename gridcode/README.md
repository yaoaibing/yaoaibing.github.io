# 方格密码 (🗺️ 方格密码 · 坐标译电)

> 分类:**密码破译** · 入口:/gridcode/ · 免费在线 · 手机即点即玩

**目标:**坐标密码:密文是 **(列,行) 坐标串**,对照 5x5 字母密表译出英文单词,四选一作答;连对计分,8 轮结算。

| 元素 | 效果 |
|---|---|
| 🗺️ 密表 | A-Y 按行列排布 |
| 🔢 坐标 | (列,行) 如 (2,3)=H |
| 👀 译码 | 逐字查表拼出单词 |
| 🔥 连对 | 每题 100 + 连对 x10 |
| 🏆 评级 | 连对 6 次译电员之魂 |

**操作:****点选项**(键盘 **1-4**)作答。

> 💡 **打法:**① 口诀**先列后行**,先横着数再竖着数;② 第一个坐标先译出首字母,**用首字母排除选项**;③ 词长 5 个字母,**数坐标个数防漏译**;④ 高频首字母:T、H、A、B,**心里有谱**;⑤ 查表**用手指按住行**,眼睛找列不迷路!

**结算:**连对、本局得分、历史最高分、已玩局数。
