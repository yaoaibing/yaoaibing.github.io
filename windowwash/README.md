# 洗窗工 (🧽 洗窗工 · 高空作业)

> 分类:**模拟经营** · 入口:/windowwash/ · 免费在线 · 手机即点即玩

**目标:**网格作业:方向键移动平台,**擦**清脏格(按脏污程度计分、耗水),💧格补满水;乌鸦随机横穿,撞上扣分;60 秒结算。

| 元素 | 效果 |
|---|---|
| 🧽 擦拭 | 重污 x2 分,耗水 1 |
| 💧 补水 | 站上水箱格补满 |
| 🐦 乌鸦 | 撞人 -30 并下坠 |
| 📈 难度 | 脏污随机分布 |
| 🏆 评级 | 700 分高空蜘蛛人 |

**操作:**点 **▲▼◀▶** 移动(方向键),「**🧽 擦**」清理(空格),「**💧 补水**」(f)。

> 💡 **打法:**① **蛇形走位**一行行扫,不跑回头路;② 水剩 3 就该**找水箱**,别等渴死;③ 乌鸦撞人很难受,**它横穿你竖躲**;④ 重污格分高,**顺手先擦深色的**;⑤ 最后一分钟**放弃远格**,收眼前的最划算!

**结算:**擦净窗数、剩余水量、本局得分、历史最高分、已玩局数。
