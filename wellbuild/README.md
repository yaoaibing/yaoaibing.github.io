# 水井砌壁 (🪣 水井砌壁 · 弧砖错缝)

> 分类:**建造物理** · 入口:/wellbuild/ · 免费在线 · 手机即点即玩

**目标:**环形砌砖:**每层凑满 8 份**,砖缝须与上层错开;漏缝扣分,四层成井。

| 元素 | 效果 |
|---|---|
| 🧱 弧砖 | 1-3 份三种规格 |
| 📐 封层 | 凑满 8 份自动合 |
| 💧 通缝 | 与上层缝重合 -20 |
| 🪣 层成 | +60 起评 |
| 🏆 结局 | 四层全成大功 |

**操作:****点砖块**(键盘 1-6)砌入。

> 💡 **打法:**① **先用长砖打底**,缝少好错开;② 看好上层缝位,**这层的缝避开它**;③ 砖不够凑层**宁可先留**,换短的接;④ 漏一两条**别慌**,后面层补回来;⑤ 四层严丝合缝,**村口打水都夸你**!

**结算:**砌层数、漏缝数、本局得分、历史最高分、已玩局数。
