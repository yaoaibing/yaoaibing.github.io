# 拼辐装轮 (☸️ 拼辐装轮 · 一辐一轮)

> 分类:**组装拼装** · 入口:/wheelmake/ · 免费在线 · 手机即点即玩

**目标:**交替装配:**左右轮下**,三轮校圆。

| 元素 | 效果 |
|---|---|
| ☸️ 车轮 | 一轮十二辐 |
| 👆 下辐 | 点辐口插 |
| ⚖️ 偏摆 | 乱序即涨 |
| ⚠️ 废轮 | 摆满重来 |
| 🏆 结算 | 装轮折分 |

**操作:**点**辐口下辐**。

> 💡 **打法:**① **记口诀:左一下右一下**,手感就顺;② 点错的辐**不算废**,下回补正;③ 偏摆**每轮自减**,缓一缓再下;④ 装完一轮**余摆越少赏越厚**;⑤ 三轮装罢,**车行的老把式都来摸你的轮**!

**结算:**轮号、下辐数、本局得分、历史最高分、已玩局数。
