# 狐鹅围猎 (🦊 狐鹅围猎 · 一狐十三鹅)

> 分类:**对战棋牌** · 入口:/foxgeese/ · 免费在线 · 手机即点即玩

**目标:**经典棋类:**执鹅围狐**,防跳吃;围死即胜。

| 元素 | 效果 |
|---|---|
| 🦢 鹅方 | 你执十三鹅 |
| ➡️ 行棋 | 沿线一步 |
| 🦊 狐方 | 跳吃连环 |
| 🧱 目标 | 困住狐狸 |
| 🏆 胜负 | 鹅少于六负 |

**操作:**点**己方鹅**,再点**相邻落点**。

> 💡 **打法:**① **横排齐进**,别让哪只鹅冒头;② **守住斜线**,狐狸跳吃全靠斜跳;③ **背后留伴**,落单的鹅最先没;④ 一步步**压缩狐狸空间**,别贪先手;⑤ 围死狐狸,**全村棋摊都来围观**!

**结算:**对局回合、鹅存数、本局得分、历史最高分、已玩局数。
