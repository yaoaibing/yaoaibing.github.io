# 考古挖掘 (🏺 考古挖掘 · 文物出土)

> 分类:**解压休闲** · 入口:/excavate/ · 免费在线 · 手机即点即玩

**目标:**按住格子刷开沙土,发现文物 +100~500,碰到石头扣体力;体力耗尽本层结束进入下一层,深层文物更值钱。

| 元素 | 效果 |
|---|---|
| 🏺 挖掘 | 按住格子刷土,露出下面物体 |
| 🏺 文物 | 碎瓷 100 / 青铜 200 / 玉器 300 / 金器 500 |
| 🪨 石头 | -15 体力 |
| 🖌 细刷 | 消耗少,精确刷一格 |
| 🏁 过关 | 体力耗尽进入下一层 |

**操作:****按住格子**刷土;「细刷」精确操作。体力有限,别大面积乱刷!

> 💡 **打法:**① 文物往往<b>成片出现</b>,挖到一个就扫周围;② 石头是深色的,先扫边缘探路;③ 深层比浅层多金器,值得下潜;④ 体力低于 30 时只用细刷;⑤ 记住:考古比的是耐心,不是力气!

**结算:**发现文物数、总收入、到达层数、本局得分(总收入)、历史最高分、已玩局数。
