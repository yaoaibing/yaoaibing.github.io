# 沙丘冲刺 (🏜️ 沙丘冲刺 · 越野拉力)

> 分类:**竞速赛车** · 入口:/dune/ · 免费在线 · 手机即点即玩

**目标:**越野飞跃:赛车自动全速穿越随机沙丘,**冲上丘顶自动腾空**,飞越高/滞空久得分越多;沙丘密度随时间增加,40 秒结算飞越总数与滞空时间。

| 元素 | 效果 |
|---|---|
| 🏜️ 沙丘 | 高度/宽度随机,迎面而来 |
| ✈️ 腾空 | 丘顶自动起飞,抛物线落地 |
| 📈 计分 | 每座 +80,滞空每秒 +15 |
| 📉 密度 | 沙丘间隔随时间缩短 |
| ⏱ 时长 | 40 秒 |

**操作:**全自动!**看沙丘形状预判腾空**即可,零操作压力。

> 💡 **打法:**① 双丘相连时<b>第一丘飞得远</b>,能直接飞过第二丘;② 分数与滞空时间挂钩,**高丘比宽丘值钱**;③ 密度 30 秒后飙升,<b>前段攒分后段保命</b>;④ 这游戏没有失败,<b>纯看物理引擎表演</b>的解压局;⑤ 连飞计数只看腾空次数,<b>小丘也算</b>,数量堆出高分!

**结算:**飞越沙丘数、滞空总时长、本局得分、历史最高分、已玩局数。
