> 分类:**卡牌构筑** · 入口:/winechip/ · 免费在线 · 手机即点即玩

**目标:**风险抽签:**抽筹行令**,三席定输赢。

| 元素 | 效果 |
|---|---|
| 🎴 筹筒 | 十二支满筒 |
| 📜 雅令 | 抽到即得分 |
| 🍷 罚酒 | 抽到倒扣 |
| ✋ 收席 | 按抽数加赏 |
| 🏆 结算 | 行令折分 |

**操作:**点**再抽一筹**,或点**收席结算**。

> 💡 **打法:**① **前两抽大概率是甜的**,大胆抽;② 筹分**掉到负三十自动收席**,别赌到那一步;③ 抽得越多**收席赏越厚**,但罚酒随时来;④ 三席**每筒都重装**,运气不求人;⑤ 三席皆妙,**行令的水平全桌服气**!
