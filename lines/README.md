# 彩球连线 (🔵 彩球连线 · 五珠消除)

> 分类:**烧脑益智** · 入口:/lines/ · 免费在线 · 手机即点即玩

**目标:**9x9 棋盘上每回合**移动一颗彩球**(需有空格连通路径),同色球横竖斜**连成 5 颗**即消除并得分;若本次移动没有消除,棋盘随机落下 3 颗新球。棋盘填满时结束,分数越高越好。

| 元素 | 效果 |
|---|---|
| 🔵 选球 | 点彩球选中(发光),再点空格移动 |
| 🛣️ 路径 | 走空格 BFS 连通路径,一次一格 |
| ✨ 消除 | 同色 5 颗及以上连成直线就消掉,同时多条分数翻倍 |
| 🆕 落球 | 每回合结束不消除就落 3 颗,顶部可预览颜色 |
| 🏁 结束 | 新球无处可落即游戏结束 |

**操作:**点彩球选中,再点空格移动;**难度**切换 5/6/7 种颜色,**新局**重开。消不掉就会落球,能连消是高分关键。

> 💡 **打法:**① 别只顾眼前,先看**预览球**的颜色再决定动哪颗;② 把同色球往同一个**象限**聚,斜线比横竖更好凑;③ 棋盘过半后每步都问自己:这步是不是让路更堵了?④ 一次移动能同时消两条线最赚,分数直接翻倍;⑤ 快满时优先消<b>中间区域</b>的球,给后续留机动空间。

**结算:**分数(每球 10 分,同次多线翻倍)、最长连线、盘面球数、颜色数、历史最高分、已玩局数。
