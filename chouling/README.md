> 分类:**卡牌构筑** · 入口:/chouling/ · 免费在线 · 手机即点即玩

**目标:**险中求稳:**抽收之间**,六巡定夺。

| 元素 | 效果 |
|---|---|
| 🎫 筹 | 红五白四黑三 |
| 👆 抽 | 左半屏抽 |
| 💰 收 | 右半屏收彩 |
| ⚠️ 黑筹 | 座彩全吐 |
| 🏆 结算 | 押彩折分 |

**操作:****左半屏抽筹**,想收**点右半屏**。
