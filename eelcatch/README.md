> 分类:**寻宝推理** · 入口:/eelcatch/ · 免费在线 · 手机即点即玩

**目标:**时机夹捕:**引鳝出洞绿区夹**,八洞结算。

| 元素 | 效果 |
|---|---|
| 🦑 泥洞 | 八个随机 |
| 👀 冒泡 | 有鳝暗号 |
| 🟢 夹环 | 绿区下钳 |
| 💨 滑走 | 早晚皆空 |
| 🏆 结算 | 得鳝折分 |

**操作:**点**冒泡泥洞**,绿环时**再点**夹。

> 💡 **打法:**① **先扫全场**,把冒泡的洞记下来;② **一次一个洞**,别贪连点;③ 夹环**转得快**,盯住绿区那半圈;④ 滑走**不扣大分**,下一个补回;⑤ 八洞七鳝,**鳝贩子预订你的篓**!

**结算:**探洞数、得鳝数、本局得分、历史最高分、已玩局数。
