# 指尖沙画 (⏳ 指尖沙画 · 流沙艺术)

> 分类:**创意涂鸦** · 入口:/sand2/ · 免费在线 · 手机即点即玩

**目标:**落沙模拟玩具:四种材料(流沙真实堆积/清水流动铺平/岩石定型/抹除),按住涂抹倾倒,沙粒逐粒物理掉落;点完成后按落沙量结算创作分,零失败纯解压。

| 元素 | 效果 |
|---|---|
| 🟨 流沙 | 真实掉落堆积,斜坡会滑 |
| 💧 清水 | 下落后向两侧流平 |
| 🪨 岩石 | 静止定型,搭容器骨架 |
| 🧽 抹除 | 擦掉重来 |
| ✅ 完成 | 落沙粒数即创作分 |

**操作:****选材料 → 按住涂抹**;底部按钮切换材料(键盘 1-4);**清空**重开。怎么倒都好看!

> 💡 **打法:**① 先用<b>岩石搭 V 形漏斗</b>,再用流沙从顶倒,沙流穿漏斗的瞬间最解压;② 水要<b>倒在高处</b>,看着它自己找平;③ 沙山堆太高会<b>自然滑坡</b>,坡度是真实模拟的;④ 石头永远不倒,大胆用它做悬空结构;⑤ 完成分只看沙量,<b>放心乱涂</b>,成品交给物理引擎美化!

**结算:**落沙粒数、创作分(100 + 落沙数,上限 2100)、历史最高分、已玩局数。
