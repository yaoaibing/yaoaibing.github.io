# 音阶排序 (🎼 音阶排序 · 听辨挑战)

> 分类:**音乐节奏** · 入口:/toneorder2/ · 免费在线 · 手机即点即玩

**目标:**音序听辨:播放 **re 到 si 六个音的随机排列**,按**从低到高**的顺序点琴键还原;排错扣一颗心并重听,三心用尽结束,8 轮排列随机。

| 元素 | 效果 |
|---|---|
| 🎼 出题 | 6 音全排列,保证非升序 |
| 🎹 复奏 | 按音高升序点键(1-6) |
| ❤️ 容错 | 三颗心,排错重听 |
| 🔊 重听 | R 键/按钮随时重播 |
| 📈 轮次 | 8 轮排列不同 |

**操作:****听→点琴键**(键盘 **1-6**)按升序还原;**R** 重听。

> 💡 **打法:**① 先找到<b>最高的 si</b> 放最后,再找次高,倒序填空;② 相邻两音的<b>相对高低</b>比绝对音高好判;③ 排错重听时,<b>只验证错的位置</b>,别全盘推翻;④ 心里把六个音唱一遍,<b>唱得出就排得出</b>;⑤ 前三轮排列简单,<b>攒命进后五轮</b>才是正解!

**结算:**完成轮数、剩余心数、本局得分、历史最高分、已玩局数。
