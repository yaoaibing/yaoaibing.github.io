# 红绿灯 (🚦 红绿灯 · 路口指挥官)

> 分类:**解压休闲** · 入口:/traffic/ · 免费在线 · 手机即点即玩

**目标:**十字路口四向来车:**点一条路把它放成绿灯**,其余方向红灯。绿灯方向的车依次通过路口得分;不同方向的两辆车同时在路口相交即追尾,游戏结束。车流密度随时间上升。

| 元素 | 效果 |
|---|---|
| 🚦 放行 | 点任意一条路,该路绿灯、其余红灯 |
| 🚗 通行 | 绿灯方向的车加速通过,通过 +1 分 |
| 💥 追尾 | 两车在路口中央相交立即爆炸结束 |
| 🅿️ 积压 | 红灯方向的车排队,越积越多但不扣分 |
| 📈 难度 | 时间越长车距越短,四向车流不均 |

**操作:****点对应方向的路**切换绿灯;**重开**立刻重开。切换前确认路口已经清空,不然必撞!

> 💡 **打法:**① 切灯前看路口<b>中间还有没有车尾</b>,车尾没过线千万别切;② 车多的方向多给两秒,少车的方向点到为止;③ 连续放同一方向可以攒连击效率,车少时再切换;④ 听声音:急刹车音效意味着你切早了;⑤ 后期车距小于 2 秒时,绿灯时间宁短勿长。

**结算:**通过车辆数、最高同时待行数、指挥时长、追尾时车速、本局得分(通过 x10)、历史最高分、已玩局数。
