# 滚石下山 (🪨 滚石下山 · 越滚越大)

> 分类:**竞速赛车** · 入口:/boulder/ · 免费在线 · 手机即点即玩

**目标:**下坡竞速:巨石持续加速,**左右移动躲树**、撞旗 +50 并增大;撞树 -1 命、缩号减速;60 秒按距离+得分结算。

| 元素 | 效果 |
|---|---|
| 🪨 巨石 | 吃旗变大,撞树变小 |
| 🌲 松树 | 撞上 -1 命、减速 |
| 🚩 绿旗 | +50,顺手长个头 |
| 📈 速度 | 每秒都在变快 |
| 🏆 评级 | 900 米滚石之神 |

**操作:****左右拖动**转向(方向键同效)。
