# 重力反转 (🔄 重力反转 · 天地奔跑)

> 分类:**街机动作** · 入口:/gravflip/ · 免费在线 · 手机即点即玩

**目标:**无尽奔跑:**点屏幕翻转重力**在地板/天花板之间切换,跳过障碍收集星星;碰撞即结束,距离计分。

| 元素 | 效果 |
|---|---|
| 🔄 翻转 | 点屏幕重力反转,飞向对面 |
| 🪨 障碍 | 地面尖刺+天花板尖刺+浮空块 |
| ⭐ 星星 | +20 分,挂在需要翻转才能到的地方 |
| 📈 难度 | 速度和障碍密度递增 |
| 🏁 结束 | 碰撞即结束 |

**操作:****点屏幕**翻转重力;**重来**重跑。翻转需要提前量,不是贴脸才翻!

> 💡 **打法:**① 看到前方障碍在地面上,就<b>提前翻转</b>去天花板;② 翻转有飞行时间,别等撞了才按;③ 星星往往在「必须翻转」的位置,拿到星星=正确路线;④ 后期连续翻转,节奏像打拍子;⑤ 深呼吸,反应游戏拼的是冷静!

**结算:**距离、翻转次数、星星数、本局得分(距离 x3 + 星星 x20)、历史最高分、已玩局数。
