# 火牛破阵 (🐂 火牛破阵 · 一夜一营)

> 分类:**策略战棋** · 入口:/firebull/ · 免费在线 · 手机即点即玩

**目标:**记位突袭:**记防冲路**,五营夜袭。

| 元素 | 效果 |
|---|---|
| 🐂 火牛 | 三头为本钱 |
| 🔥 火把 | 有伏之地 |
| 🌑 选路 | 上中下三道 |
| 💥 破营 | 一路一百二 |
| 🏆 结算 | 破阵折分 |

**操作:**点**一条路**冲锋。

> 💡 **打法:**① 侦看**只有一瞬半**,用手指虚点记位置;② 三个火把**也可能只点两个**,黑路不止一条时挑远端;③ 撞火把**折一头牛**,三头折尽夜袭就散;④ 每营**布防全换**,别信上一夜的记忆;⑤ 五营皆破,**即墨城头火把通明**!

**结算:**夜营序号、存牛数、本局得分、历史最高分、已玩局数。
