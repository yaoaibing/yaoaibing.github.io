# 磁轨飞车 (🧲 磁轨飞车 · 换极求生)

> 分类:**街机动作** · 入口:/magnet/ · 免费在线 · 手机即点即玩

**目标:**双轨磁悬浮跑酷:**点屏幕(或按空格)切换极性**,车就被吸向对应的轨道;上吊刺要从红轨躲到蓝轨,立柱刺反过来,磁暴带内控制反向;连续快速换极可以在轨道中间悬停,穿两侧同时长刺的窄缝。撞刺扣命,3 条命用完结束,里程计分。

| 元素 | 效果 |
|---|---|
| 🧲 换极 | 点屏幕/按空格,吸力方向立刻翻转 |
| 🔺 吊刺 | 从红轨垂下,贴在上面的车必撞 |
| 🔻 立柱刺 | 从蓝轨长出,和吊刺交替出现 |
| ⚡ 磁暴带 | 紫色区域里极性反向,按键是反效果 |
| ✨ 磁能球 | 吃一个加分,可以悬在河中间拿 |

**操作:****点屏幕任意处**换极,或按 **空格 / ↑↓**;底部 **🔻 吸下轨** 按钮同样换极,**↻ 重开** 立刻重跑。磁暴带里先想清楚再按!

> 💡 **打法:**① 别一路贴着同一条轨,提前半拍<b>点一下</b>换轨最稳;② 上下都有刺时,<b>连点两下</b>把车悬在中间穿过去;③ 看到紫色磁暴带就先别按,进出各按一次正好抵消;④ 磁能球常在中间,顺手拿比硬贴轨道安全;⑤ 速度上去后换极要早,晚半拍就是撞。

**结算:**行驶里程、磁能球数、剩余生命、本局得分(里程 + 磁能球 x40)、历史最高分、已玩局数。
