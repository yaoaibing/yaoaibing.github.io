> 分类:**烧脑益智** · 入口:/ninebend/ · 免费在线 · 手机即点即玩

**目标:**路径推理:**循灯走阵**,两阵连环。

| 元素 | 效果 |
|---|---|
| 🏮 灯阵 | 外圈套中宫 |
| 👆 走桩 | 相邻亮桩 |
| 🕳 暗桩 | 踩中即遣返 |
| 🟢 出口 | 绿圈在下方 |
| 🏆 结算 | 走阵折分 |

**操作:**点**相邻亮桩**走阵。

> 💡 **打法:**① **只走亮桩**,暗桩一踩回起点;② **先顺外圈**,再进中宫绕一圈;③ 出口**绿圈标着**,到那即出;④ 步数**越少奖励越厚**,想想再走;⑤ 两阵皆出,**灯官都赞你识阵法**!

**结算:**走阵序号、已行步数、本局得分、历史最高分、已玩局数。
