# 和弦听辨 (🎵 和弦听辨 · 和谐之耳)

> 分类:**音乐节奏** · 入口:/chordpick/ · 免费在线 · 手机即点即玩

**目标:**听双音叠放效果判断**和谐与不和谐**:和谐=纯五度+八度,不和谐=摩擦频率比;10 轮随机出题。

| 元素 | 效果 |
|---|---|
| 🎵 和谐 | 纯五度+八度,听感「稳」 |
| 😖 不和谐 | 摩擦比,听感「涩」 |
| 🔥 连对 | 每题 +100 + 连对 x12 |
| 🎧 耳机 | 建议佩戴,效果翻倍 |
| 🏆 评级 | 连对 7 次和谐之耳 |

**操作:**点 **和谐**(1)或**不和谐**(2);**戴耳机**效果翻倍。

> 💡 **打法:**① 和谐的双音听起来「稳」,像已经到位了;② 不和谐的会「发涩」或「抖」,这是拍频在打架;③ **闭眼听**,排除视觉干扰;④ 前三题用排除法找感觉;⑤ 确实听不出就选和谐——概率各半,别慌!

**结算:**连对、本局得分、历史最高分、已玩局数。
