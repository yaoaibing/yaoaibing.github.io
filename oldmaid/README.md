# 抽鬼牌 (👼 抽鬼牌 · 别抽到我)

> 分类:**对战棋牌** · 入口:/oldmaid/ · 免费在线 · 手机即点即玩

**目标:**37 张特殊牌(4 套 x 9 点 + 鬼牌 1 张):开局自动丢掉手牌中的对子,之后轮流**从对方手里抽一张**,抽到能成对的自动丢弃。牌先出完的一方获胜,**最后持有鬼牌**的一方落败。

| 元素 | 效果 |
|---|---|
| ♻️ 丢对 | 开局与每次抽牌后,自动弃掉成对的牌 |
| 👉 抽牌 | 点电脑的任意一张背牌抽走 |
| 🃏 鬼牌 | 单独一张,永远配不成对 |
| 🤖 电脑 | 随机抽你的牌,数量越少越危险 |
| 🏁 胜负 | 先出完手牌胜;捏着鬼牌者负 |

**操作:**轮到你时**点电脑的背牌**抽卡,抽牌/丢对全自动;**新局**重开。手牌点数可见,推理电脑手里剩什么!

> 💡 **打法:**① 记住电脑<b>抽过什么</b>,它没丢对说明手里有单张;② 自己剩 2 张时,鬼牌概率大增,祈祷别被抽到;③ 电脑牌多时随便抽,牌少时靠记忆;④ 你先出完就赢,把手牌快速配对丢光是王道;⑤ 鬼牌永远只会落在最后没配对的人手里,中后期数一数就懂!

**结算:**胜负、局数、双方剩牌、本局得分(胜 500 + 对手剩牌 x30)、历史最高分、已玩局数。
