# 旋律记忆 (🎹 旋律记忆 · 听音复奏)

> 分类:**音乐节奏** · 入口:/melody/ · 免费在线 · 手机即点即玩

**目标:**听觉记忆:**先听**一段旋律(琴键同步亮起),再在 8 个琴键上**按顺序复奏**;每过一轮加一个音(3→8 连音),弹错扣一颗心重听,两心用尽结束。

| 元素 | 效果 |
|---|---|
| 🎧 听音 | 每个音 0.56 秒,对应琴键闪亮 |
| 🎹 复奏 | 点琴键或按数字键 1-8 |
| 📈 爬梯 | 10 轮,音数 3/3/4/4/5/5/6/6/7/8 |
| ❤️ 容错 | 两颗心,弹错重听当前旋律 |
| 🎵 音域 | do 到高音 do,一个八度大调音阶 |

**操作:****点琴键**复奏,或键盘 **1-8** 对应 do 到高音 do;全程自动出题,专注听就好!

> 💡 **打法:**① 别逐个死记音名,**把旋律哼出起伏**("哆咪嗦"比"1-3-5"好记);② 记**相邻音的走向**(上/下/平)比记绝对位置轻松;③ 前两轮长音少,趁机建立手感;④ 错一次别慌,重听时**只记出错处的前后两个音**;⑤ 到 6 连音以上,在心里把旋律拆成两个短句更好记!

**结算:**轮数、最长复奏连音、剩余心数、本局得分(每轮 100 + 25 x 音数)、历史最高分、已玩局数。
