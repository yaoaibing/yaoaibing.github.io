# 山地速降 (🚵 山地速降 · 飞驰而下)

> 分类:**竞速赛车** · 入口:/downhill/ · 免费在线 · 手机即点即玩

**目标:**速降竞速:车速持续提升,路上岩石/原木需**跳跃**、树枝需**低头**,撞 3 次结算;距离与余命换算得分。

| 元素 | 效果 |
|---|---|
| 🪨 岩石 | 跳过(贴地障碍) |
| 🌿 树枝 | 低头(悬空障碍) |
| 🪵 原木 | 跳过 |
| 📈 车速 | 200→400 km/h 递增 |
| 💥 失误 | 3 次出局 |

**操作:**「**▲ 跳**」/「**▼ 低头**」(键盘 **↑**/**↓**)。

> 💡 **打法:**① 认准障碍类型:**贴地跳、悬空低**,按反必撞;② 车速 300 后**提前半屏做动作**;③ 低头是按住,**树枝过了再松手**;④ 连续障碍间隔短,**小跳比大跳落地快**;⑤ 心态:距离越长分越多,但**命比距离值钱**!

**结算:**滑降距离、车速、失误次数、本局得分、历史最高分、已玩局数。
