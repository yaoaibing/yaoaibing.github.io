# 自行车装配 (🚲 自行车装配 · 修车铺学徒)

> 分类:**组装拼装** · 入口:/bikebuild/ · 免费在线 · 手机即点即玩

**目标:**顺序装配:按蓝图槽位把打乱零件**对号入座**;正确 +20,整车 +60 进下一辆(公路/山地/折叠)。

| 元素 | 效果 |
|---|---|
| 🦴 车架 | 永远是第一件 |
| 🛞 前后轮 | 名字不同别装反 |
| 🔗 车链 | 装在轮子之后 |
| ✋ 车把 | 装错最不痛 |
| 🏆 评级 | 三车下线修车师傅 |

**操作:****点零件**再**点槽位**(键盘 **1-5** 直装)。

> 💡 **打法:**① **看清槽位顺序**,车架永远打头;② 前轮后轮**图标一样**,认准文字;③ 零件架顺序是打乱的,**从左往右扫**;④ 装错别慌,**2 秒而已**;⑤ 第三辆折叠车槽位最刁,**慢就是快**!

**结算:**下线车辆、本局得分、历史最高分、已玩局数。
