# 点篙行船 (🛶 点篙行船 · 一篙一里)

> 分类:**街机动作** · 入口:/puntboat/ · 免费在线 · 手机即点即玩

**目标:**水路穿行:**点篙避石**,里程计分。

| 元素 | 效果 |
|---|---|
| 🛶 点篙 | 提速+调向 |
| ⬅➡ 借岸 | 微调船位 |
| 🪨 礁石 | 撞损一船 |
| 💧 流速 | 自然衰减 |
| 🏆 结算 | 里程折分 |

**操作:**点屏**点篙**,点左右**调位**。

> 💡 **打法:**① **篙要勤点**,船一慢就随波逐流;② 看前**两块石头**,提前调位;③ 点边**小步借力**,一下顶到岸就难救;④ 三条船**条条金贵**,第二条起就得稳;⑤ 撑出千米,**渡口的都喊你师傅**!

**结算:**行船里程、船只数、本局得分、历史最高分、已玩局数。
