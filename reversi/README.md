# 黑白棋 (⚫ 黑白棋 · 翻转对决)

> 分类:**对战棋牌** · 入口:/reversi/ · 免费在线 · 手机即点即玩

**目标:**8x8 棋盘,把对方的棋子夹在中间就能翻成自己的颜色,下满 64 格或双方都无子可下时,**子多的一方获胜**。你执黑棋先手。

| 元素 | 效果 |
|---|---|
| ⚫ 黑棋 | 你执黑先手,只有能夹住白棋的位置才能落子 |
| ⚪ 白棋 | 电脑 AI,三档难度:简单 / 普通 / 困难 |
| 🔄 翻转 | 横、竖、斜任意方向夹住的白子,全部翻成黑棋 |
| 🚫 无子可下 | 自动跳过一手,由对方继续走 |
| 🏁 终局 | 双方都无子可下或棋盘下满,按棋子数定胜负 |

**操作:**点棋盘上的黄色圆点落子;**悔棋**可连续回退,**新局**重开一局;底部 🎚 按钮切换难度。键盘 <kbd>U</kbd> 悔棋,<kbd>R</kbd> 新局。

> 💡 **打法:**① **四个角最值钱**——角上的子永远翻不掉,开局宁可少翻子也要抢角;② 贴着边线的棋子更稳,中间一大团反而容易被反吃;③ 别贪图一次翻很多子,翻得越多,对手可选的好位置可能越多;④ 对方无子可下时会自动跳过,这时可以连续落子扩大优势;⑤ 困难 AI 会算 4 层,走错就用悔棋退回来重试。

**结算:**双方棋子数、难度、本局得分(胜利 +1200,平局 +400,难度奖励 +0/150/300,每个空格 +2)、历史最高分、已玩局数。
