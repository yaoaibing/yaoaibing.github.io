# 投篮大师 (🏀 投篮大师 · 神射手)

> 分类:**街机动作** · 入口:/basketball/ · 免费在线 · 手机即点即玩

**目标:**45 秒限时投篮。篮筐每次随机换位置,力度条来回摆动,**点屏幕定格力度**出手,球自动飞向篮筐,越接近"黄色甜蜜点"越准。
| 距离 | 分值 | 占比 |
|---|---|---|
| 近筐 | 2 分 | 约 55% |
| 远筐 | 3 分 | 约 45% |
| 🔥 连中 3 球 | 得分 ×2 | 投丢即熄火 |

**操作:**点屏幕任意处或 `空格` 出手;绿色力度条停在黄色甜蜜区内基本必进。球在空中时不用等,系统已备好下一投。

> 💡 **拿分要点:**① 每球的甜蜜点位置不同,**先看黄块在哪再出手**,别凭肌肉记忆;② 远筐 3 分且甜蜜区和近筐一样宽,**收益更高优先打远筐**;③ 手感 ×2 期间是刷分窗口,**宁可慢半拍也要稳**,打铁一次全清零;④ 命中率 60% 以上、单场 30+ 分算入门高手;⑤ 打铁后心态别崩,回近筐找节奏重启连胜。

**结算:**总得分、出手/命中/命中率、历史最高分。
