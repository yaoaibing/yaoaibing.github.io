# 失重搬运 (📦 失重搬运 · 太空理货员)

> 分类:**太空导航** · 入口:/zerogcargo/ · 免费在线 · 手机即点即玩

**目标:**惯性物流:**点箱推拉**给速度,同色泊入货舱得分;90 秒理货结算。

| 元素 | 效果 |
|---|---|
| 📦 货箱 | 三色随机刷新 |
| 🎯 货舱 | 顶部三色对号 |
| 🌌 惯性 | 速度不衰减 |
| 🛑 撞壁 | 弹性反弹 |
| 🏆 评级 | 入舱 12 件金牌理货 |

**操作:****点箱子周围**推它(键盘方向键推最近箱)。

> 💡 **打法:**① **点箱子外侧**才是推,**点内侧变拉**;② 推完它**匀速漂**,提前算好泊位方向;③ 大力出奇迹,**但撞壁反弹会乱**;④ 颜色对号入座,**错舱不算分**;⑤ 箱子少了会补,**手上别停**!

**结算:**入舱数、本局得分、历史最高分、已玩局数。
