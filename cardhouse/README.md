# 纸牌叠屋 (🃏 纸牌叠屋 · 手稳楼高)

> 分类:**解压休闲** · 入口:/cardhouse/ · 免费在线 · 手机即点即玩

**目标:**时机搭楼:**绿区放牌叠层**,塌层重来;限时计分。

| 元素 | 效果 |
|---|---|
| 🃏 放牌 | 点屏即放 |
| 🟩 绿区 | 稳度回升 |
| 🏠 一层 | 三张成层 |
| 💥 塌层 | 歪过头了 |
| 🏆 结算 | 楼层折分 |

**操作:**指针进绿区**点屏放牌**。

> 💡 **打法:**① **绿区很宽**,别被晃得不敢点;② **连着两次歪牌**必塌,第三次前稳一手;③ 楼高**指针变快**,呼吸放慢;④ 塌一层**不心疼**,楼还在就能追;⑤ 最后一秒**那张牌最值钱**,手别抖!

**结算:**叠楼层高、用牌数、本局得分、历史最高分、已玩局数。
