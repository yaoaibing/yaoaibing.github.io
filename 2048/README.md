# 2048 (🔢 2048 · 数字合并)

> 分类:**烧脑益智** · 入口:/2048/ · 免费在线 · 手机即点即玩

**目标:**在 4x4 棋盘上**滑动数字块**,相同数字相撞即合并翻倍,每滑一步随机出现一个新块。合出 **2048** 即达成经典目标,棋盘满且无路可走时结束,总分是每次合并的数字之和。

| 元素 | 效果 |
|---|---|
| 🔢 滑动 | 手指上下左右滑,或用键盘方向键 |
| ➕ 合并 | 两个相同数字相撞合并成一个翻倍块 |
| ✨ 新块 | 每步随机出现 2(90%)或 4(10%) |
| ↶ 撤销 | 可以撤销一步,每局限 3 次 |
| 🏁 结束 | 棋盘填满且相邻无相同数字,按总分结算 |

**操作:**在棋盘区域**滑动**即可(键盘用方向键);**撤销**退回上一步,**新局**重开。每次合并都会加分,合并出大数字还有额外奖励分。

> 💡 **打法:**① 大数字永远压在一个角,比如全程只往左下滑;② 不要追着小数字乱滑,先把一列填满像阶梯一样递增;③ 合并出 128 之前别让第二行乱长;④ 撤销留给手滑的那一步,平时少用;⑤ 想冲高分,最后关头留一排空格来回腾挪。

**结算:**分数(合并数字累加,合出 128+ 额外奖励)、最大数字块、步数、撤销剩余次数、历史最高分、已玩局数。
