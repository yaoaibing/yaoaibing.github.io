# 夜行回声 (🦇 夜行回声 · 声呐探路)

> 分类:**街机动作** · 入口:/echo/ · 免费在线 · 手机即点即玩

**目标:**蝙蝠在漆黑洞穴里下潜:**点屏幕喊一嗓子**,声呐波纹扩开的瞬间才看得见两侧石壁;按住左右半屏平移转向,撞一次墙少一条命,光球补氧气;氧气耗尽或命用完即结束,深度计分。

| 元素 | 效果 |
|---|---|
| 📣 声呐 | 点屏幕喊话,波纹经过处显形墙 |
| 💨 氧气 | 持续下降,每次喊话再扣 4% |
| ⬅️ 转向 | 按住左/右半屏平移,松手停 |
| ✨ 光球 | 吃到补 12% 氧气并加分 |
| 🏁 结束 | 氧气耗尽或三次撞墙 |

**操作:****点屏幕**喊话照路,按住左右半屏转向;**重潜**立刻重开。别乱喊,每一嗓子都在烧氧气!

> 💡 **打法:**① 记住<b>波纹刚扫过</b>的走向,走廊短期内不会急转;② 贴着中心线走,两侧余量最大;③ 氧气低于 40% 就少喊多走,优先找光球;④ 看不清时<b>轻点一下</b>比长按更省氧;⑤ 撞墙不慌,还有两次命,回到中间再来!

**结算:**下潜深度、光球数、剩余生命、本局得分(深度 + 光球 x50)、历史最高分、已玩局数。
