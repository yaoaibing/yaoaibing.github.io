# 三信标寻宝 (📡 三信标寻宝 · 圈圈相交)

> 分类:**寻宝推理** · 入口:/triangulate/ · 免费在线 · 手机即点即玩

**目标:**三角定位:信标数字即**曼哈顿距离**,画出菱形圈找**三圈交点**挖宝;挖错给冷热提示并扣分,6 铲不中换图,4 图结算。

| 元素 | 效果 |
|---|---|
| 📡 信标 | 数字=距宝藏步数 |
| ⬡ 菱形圈 | 同数字格子连成的轨迹 |
| 🎯 交点 | 三圈共同覆盖处 |
| ⛏ 挖掘 | 越少铲分越高 |
| 🔥 冷热 | 挖错提示距离 |

**操作:****点格子**开挖。

> 💡 **打法:**① 先看**最小的数字**,圈最小最好画;② 两个圈相交**最多两点**,第三圈二选一;③ 圈画在**格子中心**,数格子别数斜线;④ 挖错看冷热:**热就贴着挖**,冷就往对角走;⑤ 心里没底就**挖两圈交点先**,八成在这!

**结算:**完成图数、挖掘次数、本局得分、历史最高分、已玩局数。
