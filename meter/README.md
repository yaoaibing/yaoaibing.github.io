# 拍号听辨 (🥁 拍号听辨 · 重音寻拍)

> 分类:**音乐节奏** · 入口:/meter/ · 免费在线 · 手机即点即玩

**目标:**拍号测验:播放两小节鼓点,**低音重音标记小节开头**,判断 2/3/4 拍子;连对每题 +100 + 连对 x10,答错断连。

| 元素 | 效果 |
|---|---|
| 🔊 低音 | 小节第一拍,听它定头 |
| 🥁 嘀嗒 | 高音均匀铺满每拍 |
| 🔢 三选 | 2 拍/3 拍/4 拍 |
| 🔥 连对 | 每题 100 + 连对 x10 |
| 🏆 评级 | 连对 6 次节奏侦探 |

**操作:****点选项**(键盘 **1-3**)作答。

> 💡 **打法:**① 先抓**最低沉那声**,它是小节的「1」;② 数到下次重音前有几声嘀,**几声就是几拍**;③ 圆舞曲的摇感=三拍,进行曲的顿感=两拍;④ 犹豫时**哼唱出来**,身体比耳朵诚实;⑤ 连对是复利,**稳比快值钱**!

**结算:**连对、本局得分、历史最高分、已玩局数。
