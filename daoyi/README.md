# 捣衣砧声 (🌕 捣衣砧声 · 一杵一练)

> 分类:**音乐节奏** · 入口:/daoyi/ · 免费在线 · 手机即点即玩

**目标:**交替节奏:**双杵轮捣**,三段连环。

| 元素 | 效果 |
|---|---|
| 🌕 月下 | 秋夜正长 |
| 👆 双杵 | 左右半屏 |
| 🌀 连拍 | 捣得越连越厚 |
| ⚠️ 起棱 | 错边布伤 |
| 🏆 结算 | 捣衣折分 |

**操作:**点**亮圈那侧半屏**。

> 💡 **打法:**① **左边圈缩点左边**,右边点右边,手别乱;② 圈**缩到杵心**最响,抢拍只有半分;③ 连拍**越连越厚**,错一边就断;④ 段段**速度递增**,月下也要稳;⑤ 三段练平,**寒衣赶得及寄出**!

**结算:**练布段号、连拍数、本局得分、历史最高分、已玩局数。
