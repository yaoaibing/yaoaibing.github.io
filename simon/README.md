# 记忆节拍 (🎛️ 记忆节拍 · 跟我念)

> 分类:**解压休闲** · 入口:/simon/ · 免费在线 · 手机即点即玩

**目标:**四色音垫每回合**演示一段序列**(逐格亮起配音高),玩家**照原顺序按回**;每回合序列加长一格,按错即结束,坚持的回合数就是成绩。

| 元素 | 效果 |
|---|---|
| 🎛️ 演示 | 电脑逐格闪亮播放,注意顺序 |
| 👆 复现 | 轮到你按,按对继续,按错结束 |
| ➕ 加长 | 每回合多 1 个音,无上限 |
| 🎵 音高 | 四垫四音,耳朵能救命 |
| 🏁 结束 | 按错即结束,回合数计分 |

**操作:****点色垫**复现序列;**新局**重开。键盘 1/2/3/4 对应四垫。演示阶段点了不算数,等提示再动手。

> 💡 **打法:**① 把颜色换成<b>声音</b>记,音高比颜色好记;② 序列超过 5 个就分段记:前 3 后 3;③ 演示时手指悬停在下一次可能的垫上,复现快一倍;④ 别被加长吓到,其实只多记 1 个新音;⑤ 深呼吸,手抖按错最冤。

**结算:**坚持回合数、最长序列、本局得分(回合 x100)、历史最高分、已玩局数。
