# 节拍回声 (🥁 节拍回声 · 节奏记忆)

> 分类:**音乐节奏** · 入口:/echobeat/ · 免费在线 · 手机即点即玩

**目标:**听一段鼓点节奏(3→8 连音),在鼓面上**照原样复敲**;间隔时值也是判定的一部分,三条命,十轮节奏记忆训练。

| 元素 | 效果 |
|---|---|
| 🥁 听 | 自动播放节奏两遍可重听 |
| 🥁 复敲 | 点鼓面,时值也要一致 |
| 📏 长度 | 3 连音起步,8 连音封顶 |
| ❤️ 容错 | 三条命,敲错重听本组 |
| 🎵 判定 | 间隔误差 ±40%+60ms |

**操作:****点鼓面**复敲节奏(空格同效);先听整体感觉再敲。

> 💡 **打法:**① 把节奏<b>哼成歌词的断句</b>记,比数毫秒快;② 长间隔是关键记忆点,**先记最长的那拍**;③ 复敲时心里跟着上次的声音走;④ 错了重听,**只关注错的那一段**;⑤ 三条命省着用,前四轮节奏短,稳拿!

**结算:**完成轮数、剩余心数、本局得分(100 + 音数 x20)、历史最高分、已玩局数。
