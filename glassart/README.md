# 染色玻璃 (🎨 染色玻璃 · 对称拼色)

> 分类:**创意涂鸦** · 入口:/glassart/ · 免费在线 · 手机即点即玩

**目标:**对称创作:12x12 玻璃格,涂抹自动**四重对称**(上下左右镜像)展开;八色可选,画完按上色格数结算,纯创作零失败。

| 元素 | 效果 |
|---|---|
| 🎨 四重对称 | 上下左右镜像展开 |
| 🌈 八色 | 暖冷+黑白,调色丰富 |
| 🔷 高光 | 有色格子自带玻璃高光 |
| 🗺 覆盖 | 铺满 100% 是极致挑战 |
| ✅ 结算 | 上色格数 x4 + 100 |

**操作:****按住涂抹**上色;**点色盘**换色。怎么画都好看!

> 💡 **打法:**① **从中心向外画**,四重对称自动生成图案;② 先用深色打底再亮色提亮,层次感强;③ 中心对称<b>画一个圆就出花</b>,试试看;④ 铺满 100% 不容易,<b>四角是对称的死角</b>;⑤ 完成分不重要,图案才是留念!

**结算:**上色格数、覆盖率、创作分、历史最高分、已玩局数。
