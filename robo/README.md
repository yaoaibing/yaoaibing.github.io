# 机器人编程 (🤖 机器人总动员 · 编程闯关)

> 分类:**烧脑益智** · 入口:/robo/ · 免费在线 · 手机即点即玩

**目标:**在指令队列里**排好上下左右**,一键运行让机器人执行:撞墙停在原地,踩坑损毁重来,吃齐路上宝石并到达绿色基站即过关。**用的指令越少分越高**,共 12 关。

| 元素 | 效果 |
|---|---|
| 🤖 指令 | 点方向键加入队列,回厂重排可清空 |
| ▶ 运行 | 逐步执行,执行中可随时重置 |
| 🕳️ 坑 | 踩到就损毁,本关自动重来 |
| 💎 宝石 | 不强制,但全吃有额外分 |
| 🏁 基站 | 到达即过关,指令数决定得分 |

**操作:**点底部方向按钮或键盘方向键**排指令**,点**运行**执行;**清空**重排,**重置**关卡复位。 执行时按钮自动锁定。

> 💡 **打法:**① 先在脑子里走一遍完整路线再排指令,别走一步看一步;② 撞墙不损毁,可以拿墙当<b>定位器</b>省指令;③ 宝石顺路的才吃,专门绕路的宝石多数不划算;④ 队列上限 24 条,超长说明路线该优化了;⑤ 后期关卡先找<b>窄道口</b>,过了道口再铺直线。

**结算:**过关数、总指令数、宝石收集率、本关得分(基础 200 - 指令数 x5 + 宝石 x40)、历史最高分、已玩局数。
