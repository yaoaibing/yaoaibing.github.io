**目标:**统筹扫掠:**三道行列扫定额**,三区递进。

| 元素 | 效果 |
|---|---|
| 🌌 尘格 | 数字即分量 |
| ⬍ 行列 | 点标扫掠 |
| 📊 定额 | 过半为准 |
