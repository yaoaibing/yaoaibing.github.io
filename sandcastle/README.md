# 沙堡与潮 (🏖️ 沙堡与潮 · 退潮抢建)

> 分类:**建造物理** · 入口:/sandcastle/ · 免费在线 · 手机即点即玩

**目标:**潮汐建造:8×4 沙格自下而上堆沙块;每 10 秒潮位+1 冲掉当前最底层;60 秒后按存块与最高层计分。

| 元素 | 效果 |
|---|---|
| 🧱 堆块 | 必须贴地或贴块 |
| 🌊 涨潮 | 每 10 秒冲掉底层 |
| 🏰 高度 | 每层额外 +40 |
| ⏱ 节奏 | 60 秒 60 块 |
| 🏆 评级 | 四层存堡海堡大师 |

**操作:****点沙格**放沙块。

> 💡 **打法:**① **先铺满最底层**,地基宽塔才稳;② 潮位提示还有几秒,**冲前一层前别堆那层**;③ 中层收窄,**沙块省着用**;④ 沙块用完立即结算,**别留闲块**;⑤ 最后一波潮前,**能堆多高堆多高**!

**结算:**存堡沙块、最高层数、本局得分、历史最高分、已玩局数。
