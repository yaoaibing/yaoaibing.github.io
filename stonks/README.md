# 股神时刻 (📈 股神时刻 · 低买高卖)

> 分类:**解压休闲** · 入口:/stonks/ · 免费在线 · 手机即点即玩

**目标:**60 秒模拟炒股:股价随机游走,「买入」用全部现金换股、「卖出」全部换回现金,每次交易收 2 手续费;收盘时**总资产**(现金+持股 x 价格)即成绩。

| 元素 | 效果 |
|---|---|
| 📈 价格 | 随机游走,0.5 秒一跳 |
| 💰 买入 | 全部现金换股(收 2 手续费) |
| 💵 卖出 | 全部持股换现金(收 2 手续费) |
| 📊 资产 | 现金 + 持股 x 当前价 |
| 🏁 结束 | 60 秒收盘结算 |

**操作:****买入/卖出**两个按钮(键盘 B/S);**重新开盘**重开。别频繁交易,手续费会吃掉利润!

> 💡 **打法:**① 只在<b>明显低点</b>买:连跌三跳后的反弹概率高;② 手续费 2 块,来回一趟 4 块,差价不到 8% 就别动;③ 满仓后安心持有,等一波像样的拉升;④ 股价翻倍后回撤 10% 就果断落袋;⑤ 别看别人,你的对手是手续费!

**结算:**最终资产、交易次数、最大回撤、本局得分(最终资产)、历史最高分、已玩局数。
