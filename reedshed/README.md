# 芦苇搭棚 (🛖 芦苇搭棚 · 一经一纬)

> 分类:**建造物理** · 入口:/reedshed/ · 免费在线 · 手机即点即玩

**目标:**经纬编织:**照示顺编**,三棚递进。

| 元素 | 效果 |
|---|---|
| 🛖 苇棚 | 一面一棚 |
| 👆 压篾 | 顺次点格 |
| 📖 格示 | 上或下 |
| ⚠️ 串行 | 折十分 |
| 🏆 结算 | 搭棚折分 |

**操作:**按**顺序点格压篾**。

> 💡 **打法:**① **格中提示上或下**,照着下手;② **串行折十分**,别抢快;③ 棚号越深**格越密**,节奏别乱;④ 编满**整棚有赏**,一口气到底;⑤ 三面棚成,**梅雨季的渔船都来搭伙**!
