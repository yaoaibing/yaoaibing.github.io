**目标:**飞盘投掷:从任意点**向后拖拽**瞄准,松手掷出;飞盘带随机侧旋弯曲,入筐 +150 起按轮次递增,擦筐 +50;五投结算。

| 元素 | 效果 |
|---|---|
| 🥏 拖拽 | 方向+长度决定初速 |
| 🌀 弧线 | 侧旋逐帧弯曲航向 |
| 🧺 目标 | 虚线圈内 34px 入筐 |
