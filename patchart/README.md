# 布贴画 (🧵 布贴画 · 碎布成图)

> 分类:**创意涂鸦** · 入口:/patchart/ · 免费在线 · 手机即点即玩

**目标:**色彩拼贴:**选布对色贴图**,三幅递进。

| 元素 | 效果 |
|---|---|
| 🧵 碎布 | 下方选色 |
| 🎯 区域 | 虚线圈位 |
| 🎨 底色 | 淡显提示 |
| ⚠️ 贴错 | 扣分布回 |
| 🏆 结算 | 三幅折分 |

**操作:**点**碎布**选色,点**区域**贴合。

> 💡 **打法:**① **先看区域的淡色**,心里有底再选布;② 选布**只点一次**,别来回换;③ 贴对一幅**自动换下一幅**,节奏自己带;④ 贴错**布不损耗**,色对就还能救;⑤ 三幅全对,**碎布头也有春天**!

**结算:**贴画进度、贴对数、本局得分、历史最高分、已玩局数。
