# 点灯谜题 (💡 点灯谜题 · 灯阵翻转)

> 分类:**烧脑益智** · 入口:/lightsout/ · 免费在线 · 手机即点即玩

**目标:**每点一格,它自己和**上下左右**相邻格一起翻转。把所有灯点亮即通关,每局由程序生成,保证有解。

| 元素 | 效果 |
|---|---|
| 💡 翻转 | 点一格,自己和上下左右四格一起亮灭 |
| 🎯 目标 | 全部灯亮着即通关 |
| 🧠 参考步数 | 当前局面的最短解,越接近分越高 |
| 💡 提示 | 每局 3 次,自动点亮一个应该点的格子 |
| 🎚 难度 | 4x4 入门、5x5 经典、6x6 进阶 |

**操作:**点灯格翻转;**提示**点亮正确一步,**难度**切换并开新局,**新局**重开。键盘 <kbd>H</kbd> 提示,<kbd>R</kbd> 新局。

> 💡 **打法:**① 点灯**顺序不影响结果**,同一格点两次等于没点;② 从上往下推:上一行有暗的,就点它正下方那格;③ 第一行先点成整行全亮,再逐行往下推;④ 步数快接近参考值时,每一步都要想清楚;⑤ 卡住就用提示,提示只点真正该点的格子。

**结算:**步数、参考步数、提示剩余、本局得分(500 + 步数奖励 - 提示扣分,最低 120)、历史最高分、已玩局数。
