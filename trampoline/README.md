# 蹦床翻转 (🤸 蹦床翻转 · 空中体操)

> 分类:**街机动作** · 入口:/trampoline/ · 免费在线 · 手机即点即玩

**目标:**选手被蹦床弹起后**按住屏幕转体**,接近完整一圈(330°-390°)时**松手**,落地即评分:完美 +100、勉强 +40、翻转过度或不足判失误;3 次失误比赛结束,连击有倍率。

| 元素 | 效果 |
|---|---|
| 🤸 转体 | 按住屏幕旋转,角度实时显示 |
| ✅ 完美 | 330°-390° 之间松手,+100 x连击 |
| ⚠️ 勉强 | 300°-330° 或 390°-420°,+40 |
| ❌ 失误 | 其他角度松手,失误 +1 |
| 🏁 结束 | 3 次失误结算,连击最高 x5 |

**操作:****按住屏幕**转体,**松手**落地;**重来**重赛。转体速度会越来越快,后期拼预判!

> 💡 **打法:**① 心里默数<b>一圈节奏</b>,按住时长固定下来就稳;② 连击倍率是大分,宁可求稳完美也别贪多转;③ 转速上升后,提前 30° 松手;④ 失误一次别慌,还有两次机会;⑤ 屏幕上的角度环是你的眼睛,多看环少看人。

**结算:**完美次数、最高连击、失误次数、本局得分(完美 x100 x连击)、历史最高分、已玩局数。
