**目标:**堆叠平衡:**观偏落泥**,三梁递进。

| 元素 | 效果 |
|---|---|
| 🐦 春燕 | 横飞衔泥 |
| 👆 落泥 | 点屏即下 |
| 🧱 巢身 | 十泥一梁 |
| ⚠️ 坍泥 | 歪过即塌 |

**操作:**点屏**落泥**。
