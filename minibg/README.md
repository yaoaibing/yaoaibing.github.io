# 乌龟双陆 (🐢 乌龟双陆 · 掷骰竞速)

> 分类:**对战棋牌** · 入口:/minibg/ · 免费在线 · 手机即点即玩

**目标:**骰子竞速:12 格赛道,双方各 3 子;掷双骰各走一步,**落在对方单子上将其踢回**;三子到家胜。

| 元素 | 效果 |
|---|---|
| 🎲 双骰 | 每骰各走一个子 |
| 💥 踢子 | 目标恰有对方单子即踢回 |
| 🏁 到家 | 三子全部出线获胜 |
| 🐇 AI | 贪心前进+抢踢 |
| 🏆 计分 | 胜 380 连胜滚 |

**操作:**点「**🎲 掷骰**」(空格),**点蓝圈龟**走子(键盘 1-3)。

> 💡 **打法:**① 对手**落单的子就是靶子**,踩上去血赚;② 两子同格**不会被踢**,抱团保平安;③ 落后时**集中走一只**,先到一只回血;④ 骰运没法控,**选择比运气重要**;⑤ 差一步到家也**可能被踹**,到家前都要小心!

**结算:**对局比分、本局得分、历史最高分、已玩局数。
