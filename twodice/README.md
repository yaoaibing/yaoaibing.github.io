# 点数追逐 (🎯 点数追逐 · 双骰过关)

> 分类:**骰子冒险** · 入口:/twodice/ · 免费在线 · 手机即点即玩

**目标:**双骰 Craps:押注→首掷(7/11 赢,2/3/12 输,其余立点)→追点阶段(中点赢,7 输);筹码制结算。

| 元素 | 效果 |
|---|---|
| 🎲 首掷 | 7/11 天然赢,2/3/12 输 |
| 🎯 立点 | 之后中点赢、7 输 |
| 💰 押注 | 每次 +25,1:1 赔付 |
| 📊 路纸 | 最近 6 局胜负 |
| 🏆 结算 | 剩多少筹码多少分 |

**操作:**「**💰 押注**」下注,「**🎲 开骰**」掷(B 键 / 空格)。

> 💡 **打法:**① 立点后 **7 出现概率 6/36 最高**,追点阶段心要冷;② 6/8 是最容易追到的点,**立到它们偷着乐**;③ 连输两把别加倍,**Craps 没有热手**;④ 押注 25 起步,**翻倍到 800 就收**;⑤ 概率上庄家占 1.4%,**当娱乐模拟玩**!

**结算:**剩余筹码、当前点数、押注额、本局得分、历史最高分、已玩局数。
