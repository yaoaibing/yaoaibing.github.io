# 投石机攻城 (🏰 投石机攻城 · 一石当千)

> 分类:**街机动作** · 入口:/catapult/ · 免费在线 · 手机即点即玩

**目标:**抛石攻城:两段锁定(角度扫动→力度翻动)掷出巨石;普通砖 +20、铁石需两击、城头敌兵 +50;清空一城 +100,共 3 城每城 4 发。

| 元素 | 效果 |
|---|---|
| 🎯 角度 | 22°-68° 来回扫 |
| 💪 力度 | 15-100 往复 |
| 🧱 铁石 | 两击才碎,先 +8 再碎 |
| 🗡️ 敌兵 | 城头一个 +50 |
| 🏆 评级 | 三城全破攻城大师 |

**操作:****点屏幕/空格**:一次锁角度,一次锁力度。

> 💡 **打法:**① 角度 **45° 左右射程最远**,贴墙就压低;② 铁石先削一下,**第二发对准同格**;③ 城头敌兵最值钱,**弧线顶正好扫到**;④ 力度条中段偏上**最常命中**;⑤ 一城 4 发,**先轰兵再清墙**!

**结算:**破墙数、斩将数、本局得分、历史最高分、已玩局数。
