# 挤棋 (🔹 挤棋 · 三连出局)

> 分类:**对战棋牌** · 入口:/squeeze/ · 免费在线 · 手机即点即玩

**目标:**对弈挤子:**凑连出局**,杀至剩一。

| 元素 | 效果 |
|---|---|
| 🔹 四子 | 各守一行 |
| 🧱 三连 | 横竖斜皆可 |
| 💥 挤出 | 线端敌子出局 |
| ⚠️ 反挤 | 对方也来 |
| 🏆 结算 | 挤子折分 |

**操作:**点**己子**看绿圈,**点落点**行棋。

> 💡 **打法:**① **挤一次四十**,见连就连;② **斜线也算**,四十五度最阴;③ 对方**凑连前一手**,先拆了再说;④ 己子**别挤成一堆**,留活动余地;⑤ 挤到对方剩一子,**这一盘够吹半年**!

**结算:**对弈回合、挤出数、本局得分、历史最高分、已玩局数。
