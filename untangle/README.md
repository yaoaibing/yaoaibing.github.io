# 解绳结 (🧶 解绳结 · 拉直不交叉)

> 分类:**解压休闲** · 入口:/untangle/ · 免费在线 · 手机即点即玩

**目标:**平面性消除(Planarity 玩法):木桩是节点、绳子是边,开局把桩随机打乱,绳子上到处是交叉。拖动任意木桩到盘面任何位置,**目标是让任意两条边不再相交**。每关的图都是先在一个矩形里做随机三角剖分、再随机剪边并保持连通生成的,因此一定存在零交叉摆法;关卡只在打乱后确有交叉时才发出。八个结,交叉清零自动进下一关,单结超时即结束。

| 元素 | 效果 |
|---|---|
| 🧶 木桩 | 可拖到盘内任意位置,绳子实时重画 |
| 🔴 交叉点 | 实时标出正在相交的位置 |
| 🔢 边数 | 随关卡从 5 个桩一路涨到 12 个桩 |
| 💡 亮线 | 点亮一根打结的绳子(扣 6 分) |
| 🏁 过关 | 交叉归零自动进下一结 |

**操作:****按住木桩拖动**,松手落定;减少一处交叉就记一次解扣。💡 亮线点出问题绳,**↻ 重打结**把本结重新打乱。键盘 H 亮线、S 重打结、R 重开。

> 💡 **打法:**① 先把<b>外圈三根桩</b>拉成一个大三角形,给里面留地方;② 数一数每根桩连了几条线,<b>线多的桩放中间、线少的贴边</b>;③ 别死磕一个红点,先挪<b>牵涉最多交叉</b>的那根桩;④ 交叉只剩一两处时,沿外围空位整体旋一圈最见效;⑤ 亮线是省眼力的,别硬撑,超时更亏。

**结算:**解开的结数、本局得分(每结基础分 + 剩余秒数 - 拖动与提示扣分)、历史最高分、已玩局数。
