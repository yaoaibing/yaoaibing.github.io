# 小行星穿越 (☄️ 小行星穿越 · 陨石航线)

> 分类:**太空导航** · 入口:/asteroidx/ · 免费在线 · 手机即点即玩

**目标:**生存躲避:**拖动飞船**躲陨石,陨石密度随时间飙升;三层护盾被撞 -1 层,归零解体;活满 45 秒穿越成功,生存时间即分数。

| 元素 | 效果 |
|---|---|
| ☄️ 陨石 | 大小/速度随机,密度递增 |
| 🛸 飞船 | 左右拖动,无惯性 |
| 🛡 护盾 | 三层,撞击 -1 |
| ⏱ 时长 | 45 秒 |
| 📈 提速 | 陨石速度随时间 +2/秒 |

**操作:****拖动飞船**左右移动(方向键同效);**护盾耗尽即结束**!

> 💡 **打法:**① 飞船<b>贴屏边</b>活率更高:陨石均匀分布,边缘可躲面积大;② 别追着空隙跑,<b>找陨石间的大缝隙停住</b>;③ 连续陨石群来袭时,**宁可吃一格也要穿过去**;④ 护盾三层是容错,<b>第三层掉后就当没有盾玩</b>;⑤ 45 秒后半段密度最高,<b>前面省下的护盾是最后的命</b>!

**结算:**生存秒数、护盾余量、本局得分、历史最高分、已玩局数。
