# 节拍稳压器 (🥁 节拍稳压器 · 稳如节拍器)

> 分类:**音乐节奏** · 入口:/tempo/ · 免费在线 · 手机即点即玩

**目标:**节奏跟拍:圆环指针转一圈=一拍,**拍点处按下**判误差(70ms 完美/150ms 合格),bpm 逐段提升;30 秒按平均误差结算。

| 元素 | 效果 |
|---|---|
| 🥁 圆环 | 指针扫满=一拍 |
| 👆 跟拍 | 拍点 ±70ms 完美 |
| 📈 提速 | 每 8 拍 bpm 提升 |
| 🎯 结算 | 平均误差越小分越高 |
| 🏆 评级 | 误差 <45ms 人形节拍器 |

**操作:**点「**🥁 跟拍**」(空格/回车同效)。

> 💡 **打法:**① **先听四拍再进**,别上来就按;② 看圆环不如**数拍子**,1-2-3-4 心里默念;③ 提速后**提前一点点**按下,人的反应总有延迟;④ 抢拍比拖拍更伤,**宁稳勿抢**;⑤ 身体跟着晃,**肌肉比耳朵准**!

**结算:**连击、平均误差、本局得分、历史最高分、已玩局数。
