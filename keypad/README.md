# 键位密电 (🔢 键位密电 · 九宫译码)

> 分类:**密码破译** · 入口:/keypad/ · 免费在线 · 手机即点即玩

**目标:**键位密码破译:单词用**手机九宫键位**加密为数字串(如 DARK=3275),对照**九宫键位表**(2=ABC/3=DEF…)推理原词,四选一作答;三条命十组题。

| 元素 | 效果 |
|---|---|
| 🔢 密电 | 数字串,每数字一键 |
| 📖 键位表 | 底部常驻 2-9 键字母对照 |
| 🔤 四选一 | 正确 + 干扰项 3 个 |
| ❤️ 信号灯 | 三条命,选错扣一换题 |
| 📈 词库 | 10 个 4 字母单词 |

**操作:****看数字串 → 对照键位表 → 点单词**(键盘 **1-4**);一数字可对应键上多个字母,需组合推理!

> 💡 **打法:**① 每个数字键有 3-4 个字母,**同键不同字母=不同单词**;② 先数按键次数:同键连续两下=该键第 2 个字母(老式手机打法);③ 破译首字母就能排除 2 个选项;④ 常见组合:7=PQRS 4=GHI,**G+O+L+D 拼 GOLD** 这类联想最快;⑤ 词库只有 10 个,**玩两轮就背下来**,之后变成速答挑战!

**结算:**破译组数、剩余信号灯、本局得分、历史最高分、已玩局数。
