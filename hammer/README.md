# 掷链球 (🔄 掷链球 · 旋转出手)

> 分类:**体育竞技** · 入口:/hammer/ · 免费在线 · 手机即点即玩

**目标:**蓄力投掷:按住**转速攀升(峰值 4.6 后衰减)**,松手按当前转速×45° 出手;转速过低脱手失败;三投取最佳。

| 元素 | 效果 |
|---|---|
| 🔄 蓄力 | 按住转快,峰值后衰减 |
| ⚡ 绿区 | 转速 5.6+ 出手理想 |
| 📐 出手 | 固定 45° 弹道 |
| 💧 失误 | 转速 <1.5 脱手失败 |
| 🏆 评级 | 60 米链球之王 |

**操作:****按住「🔄 旋转」**蓄力,**松手**出手(空格同效)。

> 💡 **打法:**① 转速表**冲顶前半拍松手**,吃满上升期;② 蓄过头开始衰减,**衰减中也够用别慌**;③ 转速太低松手=**脱手失误**,白丢一投;④ 三投策略:**第一投试探,后两投冲顶**;⑤ 听风声,**嗡嗡声越尖转得越快**!

**结算:**最佳距离、投掷轮次、本局得分、历史最高分、已玩局数。
