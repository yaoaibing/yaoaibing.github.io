# 热气球逃亡 (🎈 热气球逃亡 · 飞越沙海)

> 分类:**生存挑战** · 入口:/balloonrun/ · 免费在线 · 手机即点即玩

**目标:**热气球生存:漏气下坠 + 喷火升空的垂直管理,石柱上下错落需找**缝隙穿行**;燃料耗尽坠落即败,飞满 1000 里抵达绿洲胜利。

| 元素 | 效果 |
|---|---|
| 🎈 物理键 | 漏气 -46/s,喷火 +64/s |
| 🔥 喷火 | 按住持续升,耗燃料 |
| 🎒 沙袋 | 瞬时 +150 升力,5 个 |
| 🏗️ 石柱 | 缝隙随时间变窄 |
| 🏆 结算 | 航程 + 余燃料 + 绿洲奖 |

**操作:****按住「🔥 喷火」**升空,点「**🎒 沙袋**」急升(空格喷火/↓沙袋)。

> 💡 **打法:**① **中空层最省燃料**,高不成低不就最危险;② 石柱缝隙**提前半屏对线**,别到跟前才修;③ 沙袋留给**窄缝**,平时靠喷火微调;④ 燃料低于 30 就该**贴地飞**,绿洲在低处也够得着;⑤ 坠地不死,**擦着沙丘飞**是高手的浪漫!

**结算:**航程、剩余燃料、沙袋数、本局得分、历史最高分、已玩局数。
