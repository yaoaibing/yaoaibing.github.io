# 悬崖采药 (🌿 悬崖采药 · 荡索攀崖)

> 分类:**街机动作** · 入口:/herbcliff/ · 免费在线 · 手机即点即玩

**目标:**摆荡跳跃:**松手飞抓岩钉**,顺采药草;三命限时。

| 元素 | 效果 |
|---|---|
| 🌿 药绳 | 自动摆荡 |
| 👆 松手 | 点屏起跳 |
| 🪝 岩钉 | 越上越远 |
| 🌿 药草 | 株株+15 |
| 🏆 结算 | 采药加攀高 |

**操作:****点屏**松手,飞抓下一个岩钉。

> 💡 **打法:**① **摆到最高点松手**,出手才有高度;② **上方岩钉先看准**,再决定飞不飞;③ 药草**顺路薅**,别专程扑空;④ 摔落**不丢进度**,岩钉还在;⑤ 时间过半**冲顶部**,高处一株顶三株!

**结算:**采药株数、攀爬高度、本局得分、历史最高分、已玩局数。
