> 分类:**密码破译** · 入口:/drumcode/ · 免费在线 · 手机即点即玩

**目标:**听鼓译令:**两击定令四旗**,八轮提速。

| 元素 | 效果 |
|---|---|
| 🥁 四击 | 鼓点序列 |
| 🔑 前两击 | 定令之钥 |
| 💨 烟幕 | 后两干扰 |
| 🚩 令旗 | 四选一点 |
| 🏆 结算 | 轮次折分 |

**操作:**听完鼓点**点令旗**应令。
