**目标:**追逐博弈:**跳啖脱围**,一局定胜负。

| 元素 | 效果 |
|---|---|
| 🦌 独鹿 | 你执之 |
| 🐺 六犬 | 步步为营 |
| 🔴 跳啖 | 隔一吃一 |
| 🏳️ 胜负 | 犬尽或鹿困 |
