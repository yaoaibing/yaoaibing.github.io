# 成语接龙 (🐉 成语接龙 · 一字千金)

> 分类:**烧脑益智** · 入口:/idiomchain/ · 免费在线 · 手机即点即玩

**目标:**看当前成语的**最后一个字**,从 4 个选项里选出以这个字开头的成语,一条龙接到底。每题限时 20 秒,3 条命。

| 元素 | 效果 |
|---|---|
| 🐉 接龙 | 选项第一个字 = 当前成语最后一个字 |
| ⏱️ 限时 | 每题 20 秒,剩余时间越多分越高 |
| 🔥 连击 | 每连对一次,下一题额外 +20,连击不断叠加 |
| ❤️ 生命 | 答错或超时扣 1 条,3 条扣完结束 |
| 🔁 换链 | 当前成语接不下去时自动换新链,并 +30 分 |

**操作:**点选项作答;**新局**重新开始。键盘 <kbd>1</kbd>-<kbd>4</kbd> 选择对应选项。

> 💡 **打法:**① 只盯**最后一个字**,别被成语意思带跑;② 干扰项里常混着「尾字相同」的成语,看清第一个字;③ 快速作答有额外时间分,别犹豫太久;④ 连击每层 +20,保住连击比抢时间更值;⑤ 生僻成语接不下去也别慌,系统会换链,接稳下一题更实在。

**结算:**得分(基础 80 + 剩余秒数 x4 + 连击 x20)、接对数量、最高连击、称号、历史最高分、已玩局数。
