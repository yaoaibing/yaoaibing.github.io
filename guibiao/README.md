**目标:**历法推算:**以影定节**,八题连环。

| 元素 | 效果 |
|---|---|
| 🌞 圭表 | 八尺表杆 |
| 📏 影长 | 一尺半到一丈三 |
| 📅 定节 | 四选一点击 |
| ✅ 连对 | 正确加成 |
| 🏆 结算 | 测影折分 |

**操作:**点**节气选项**定案。

> 💡 **打法:**① **背两个锚点**:冬至十三尺、夏至一尺半;② 影越短**日越接近头顶**,往夏至那边猜;③ 中间影长**看靠哪头**,分不清就取春秋分;④ 错一题**连对清零**,别贪快;⑤ 八题全中,**钦天监的日历你来定**!

**结算:**测影题号、连对数、本局得分、历史最高分、已玩局数。
