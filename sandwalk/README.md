# 沙暴夜行 (🏜️ 沙暴夜行 · 绿洲在望)

> 分类:**生存挑战** · 入口:/sandwalk/ · 免费在线 · 手机即点即玩

**目标:**双资源生存:**每夜水-1、荫-1**;水尽或荫尽(概率)倒下;第六天抵达绿洲。

| 元素 | 效果 |
|---|---|
| 🥤 计水 | 水 +2 |
| ⛺ 歇晌 | 荫 +2,少走一天路 |
| 🚶 夜行 | 路程 +2,水荫各 -1 |
| 🦴 探河床 | 风险与惊喜并存 |
| 🏆 撤离 | 撑满六天即抵达 |

**操作:****点行动卡**(键盘 **1-3**)过夜。

> 💡 **打法:**① **水是最脆的线**,计水两天一补;② 荫掉光不是必死,**但赌不起**;③ 夜行两格路,**前松后紧**的走法;④ 河床**水囊空了再赌**;⑤ 最后一天**只管活到日落**!

**结算:**坚持天数、水、历史最高分、已玩局数。
