# 假山叠石 (⛰️ 假山叠石 · 一石一景)

> 分类:**建造物理** · 入口:/rockpile/ · 免费在线 · 手机即点即玩

**目标:**堆叠平衡:**落石成山**,三山递进。

| 元素 | 效果 |
|---|---|
| ⛰️ 假山 | 十二石封顶 |
| 👆 落石 | 线上点屏 |
| 📐 歪斜 | 山身渐倾 |
| ❌ 山塌 | 偏出即塌 |
| 🏆 结算 | 叠山折分 |

**操作:**点屏**落石**。

> 💡 **打法:**① 石头**左右来回**,看准虚线再点;② 压正**加十五**,一块顶三块;③ 山身**越叠越歪**,早往回压;④ 十二石**封顶结算**,贪高必塌;⑤ 三山叠成,**园主都要请你掌墨**!

**结算:**叠山座号、落石块数、本局得分、历史最高分、已玩局数。
