# 汉诺塔 (🗼 汉诺塔)

> 分类:**烧脑益智** · 入口:/hanoi/ · 免费在线 · 手机即点即玩

**目标:**把左塔的 **N 层圆盘整体搬到右塔**。规则只有两条:**一次动一盘**、**大盘不能压小盘**。步数越接近理论最少分越高。
| 层数 | 最少步数(2ⁿ-1) | 分数系数 |
|---|---|---|
| 3 层 | 7 步 | ×1 |
| 4 层 | 15 步 | ×1.3 |
| 5 层 | 31 步 | ×1.65 |
| 6~8 层 | 63 / 127 / 255 步 | ×2.1 ~ ×3.4 |

**操作:**点一根柱**拿起顶盘**(顶盘悬空),再点目标柱**放下**;点原柱收回。非法移动(大盘压小盘)会被拒绝并震动提示。拿起后**目标柱显示金色虚线圈**帮你瞄准。键盘 `←→` 选柱,`空格` 拿/放,`1``2``3` 直达。

> 💡 **拿分要点:**① **递归口诀**:想搬 n 层,先把上面 n-1 层搬到**缓冲柱**,把最大盘落底,再把 n-1 层搬到它上面;② 奇数层塔**第一盘先去目标柱**,偶数层塔先去缓冲柱,照这个口诀走就不会绕路;③ 超步每多 1 步扣 18 分、每秒扣 3 分,**6 层以上别硬冲**,先把 3~5 层刷到满星;④ 拿起后看清金圈再落子,**手快放错柱要多走好几步**。

**结算:**使用步数(对比最少步数)、用时、星级、本局得分、历史最高分。
