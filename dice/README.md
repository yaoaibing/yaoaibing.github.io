# 骰子地牢 (🎲 骰子地牢 · 十层试炼)

> 分类:**骰子冒险** · 入口:/dice/ · 免费在线 · 手机即点即玩

**目标:**骰子构建冒险:每轮**掷 3 骰**,把总和分配为**攻击/防御/休息**(防御=全额减伤,休息=回血一半但挨全伤);怪物有大爪预警轮;击败怪物得宝石并下潜,10 层通关。

| 元素 | 效果 |
|---|---|
| 🎲 掷骰 | 3 颗骰子,每轮一次 |
| ⚔️ 攻击 | 总和 = 伤害,但挨怪物反击 |
| 🛡 防御 | 总和 = 减伤,预警轮必防 |
| ❤️ 休息 | 回复总和一半,挨全伤 |
| 💎 奖励 | 击败怪物 +1~2 宝石,概率回血 |

**操作:****🎲掷骰**后点 **⚔️/🛡/❤️**(键盘 1/2/3)分配,空格=掷骰或快速攻击。算术简单,决策不简单!

> 💡 **打法:**① 怪物<b>⚠️大爪预警轮必防御</b>,3+3 的骰子正好全免;② 怪物剩 6 血以内<b>果断攻击</b>斩杀,防御是留给打不动时的;③ 休息亏一轮伤害,<b>血量 40% 以下再歇</b>;④ 骰子期望 10.5,<b>攻击期望收益永远最高</b>,防御只在预警和残血时值钱;⑤ 每层怪物攻高血厚不同,前 3 层激进攒宝石,7 层后保血为上!

**结算:**到达层数、宝石数、剩余生命、本局得分(层数 x45 或 600 + 宝石 x60)、历史最高分、已玩局数。
