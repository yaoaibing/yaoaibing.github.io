# 街拍时刻 (📷 街拍时刻 · 定格大师)

> 分类:**摄影抓拍** · 入口:/photo/ · 免费在线 · 手机即点即玩

**目标:**摄影时机游戏:路人穿行街头,目标进入**取景框**且**对焦圈接近转满**时按快门;普通人 120 分起、罕见明星 300 分起,按对焦质量加成;12 张胶卷用完结算。

| 元素 | 效果 |
|---|---|
| 🚶 路人 | 4 人在场,速度方向随机 |
| ⭐ 明星 | 12% 概率出现,分值 2.5 倍 |
| 🖼️ 取景框 | 屏幕中央的白色四角框 |
| 🎯 对焦圈 | 0-100% 来回摆动,越满越准 |
| 🎞️ 胶卷 | 12 张,快门间隔 0.7 秒 |

**操作:****点屏幕/空格**按快门。构图靠站位(框不动人动),时机看对焦圈!

> 💡 **打法:**① 对焦圈是<b>匀速往返</b>的,掐准它到顶的半拍提前按;② 明星⭐走得慢,<b>优先等它进框</b>,一张顶三张;③ 取景框中央最稳:目标贴边时容易裁半身;④ 连拍加成靠不断片,<b>宁拍普通不空镜头</b>;⑤ 12 张拍完就结算,<b>最后 3 张别省</b>,看到框里有人就按!

**结算:**胶卷使用数、总分、历史最高分、已玩局数。
