# 混色调漆 (🖌️ 混色调漆 · 补色工坊)

> 分类:**解压休闲** · 入口:/colormix/ · 免费在线 · 手机即点即玩

**目标:**给定目标色,用茜红/藤黄/群青/铅白<b>逐滴混合</b>(RGB 取平均)调出尽可能接近的颜色;相似度进入容差即通过,滴数越少得分越高,倒掉重来记一笔浪费,共 8 张色单。

| 元素 | 效果 |
|---|---|
| 💧 滴料 | 每点一次加一滴,颜色按平均值混合 |
| 📏 相似 | 与目标色的欧氏色差换算成百分比 |
| 🎯 容差 | 越到后面容差越严(34% 递减到 13%) |
| 🗑 倒掉 | 清空本桶,记录一次浪费 |
| 🏁 通关 | 8 张色单全部调中 |

**操作:**底部**点颜色滴料**,「倒掉」清空本桶;**重调**从头再来。白色是最强调节杆,善用!

> 💡 **打法:**① 目标偏暗就<b>少加白</b>,白色一旦多了很难拉回来;② 红+黄=橙,蓝+黄=绿,先定色系再调明度;③ 相似度到 90% 上下就停手,多一滴可能就偏了;④ 后期容差小,先用大量定方向再用一滴微调;⑤ 倒掉不扣分但费时间,心里有数再点!

**结算:**调中色单数、滴料总数、倒掉次数、本局得分(每张 100 + 省下的滴数 x12)、历史最高分、已玩局数。
