# 空气曲棍球 (🏒 空气曲棍球 · 桌面冰球)

> 分类:**街机动作** · 入口:/airhockey/ · 免费在线 · 手机即点即玩

**目标:**拖动球拍撞击冰球,把球送进对方球门。**先到 7 分**的一方获胜,球拍只能停留在自己半场。

| 元素 | 效果 |
|---|---|
| 🏒 球拍 | 按住自己半场拖动,松手球拍停在原地 |
| 💨 力度 | 拖动越快撞击越重,轻碰可以改角度 |
| 🥅 球门 | 球门在两端中间,进球即得 1 分 |
| 🛡️ 半场 | 球拍不能越过中线,回防要及时 |
| 🎚 难度 | 简单/普通/困难,电脑速度和压迫感递增 |

**操作:**按住下半场拖动球拍撞球;底部切换**难度**,**新局**重开。鼠标拖拽同样有效。

> 💡 **打法:**① 别一直追着球跑,**守在中线前**等球回来;② 撞球瞬间快速划动,球速最快;③ 球贴边时用球拍侧面轻碰,角度更刁;④ 对方球门空了再发力,别在自家门前大力抽射;⑤ 落后时先稳住防守,对方压上就会露出空门。

**结算:**比分、胜负、难度、本局得分(胜利 1000 + 净胜球 x100 + 难度 0/100/200)、历史最高分、已玩局数。
