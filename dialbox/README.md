# 机关盒 (🎛️ 机关盒 · 三转盘锁)

> 分类:**组装拼装** · 入口:/dialbox/ · 免费在线 · 手机即点即玩

**目标:**逻辑推理锁:每盒一个 **0-9 三位密码**,三条线索(三盘之和/两盘之差/单盘范围)唯一确定答案;拨对三个转盘点开盒,五盒递进。

| 元素 | 效果 |
|---|---|
| 🎛️ 转盘 | 三盘 0-9,◀▶ 拨动 |
| 📜 线索 | 和/差/范围三类随机组合 |
| ✅ 开盒 | 三盘全对即开 |
| 🧩 组合 | 每盒线索不同 |
| 🏆 计分 | 每盒 200 |

**操作:****◀▶**(QE/AD/ZC)拨对应转盘;**空格**开盒。

> 💡 **打法:**① 「三盘之和」+「某盘范围」几乎可以<b>直接算出答案</b>;② 差值线索是负数也正常,<b>先假设再验算</b>;③ 拨转盘零成本,<b>边拨边对照三条线索</b>;④ 开错盒没有惩罚,<b>大胆试</b>;⑤ 最后一盒线索最刁钻,<b>把三条线索联立成方程</b>一次解出!

**结算:**开启盒数、本局得分(每盒 200)、历史最高分、已玩局数。
