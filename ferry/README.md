# 渡口摆渡 (🛳️ 渡口摆渡 · 逆流靠岸)

> 分类:**街机动作** · 入口:/ferry/ · 免费在线 · 手机即点即玩

**目标:**俯视角摆渡:**点屏幕解缆开船**,船自动往对岸走,水流按位置把你推向下游(河心最急);按住左右半屏打舵修正航线,必须停进对岸的黄色码头才算送客成功,擦到泥岸或直接撞上游石滩都要扣船体。漂浮木顺流漂来、礁石钉在河心,撞到一样伤船。船体 3 格用完或天光归零即停航,每送一位客人加分并续一点天光。

| 元素 | 效果 |
|---|---|
| 🚢 解缆 | 点屏幕开船,船自动冲向对岸 |
| 🌊 暗流 | 河心推得狠,靠岸水缓,方向永远往下游 |
| ⬅️ 打舵 | 按住左/右半屏横移,松手被水推 |
| 🚩 码头 | 对岸黄色泊位,停进去才结算 |
| 🪵 障碍 | 漂浮木与礁石,撞上扣船体 |

**操作:****点屏幕**解缆,按住<b>左/右半屏</b>打舵,也可用 ◀ ▶ 按钮;**↻ 重开**重来。看虚线航向标判断该往哪边顶。

> 💡 **打法:**① 别直直对着码头开,<b>斜着上游一点</b>,让水流把你推进泊位;② 河心段推力最大,提前两秒就开始打舵;③ 靠岸前减速不了,<b>宁可擦岸也别撞石</b>;④ 天光是钱,每次成功靠岸都会续,别省着不开船;⑤ 空船回航时水一样急,回港也要修正。

**结算:**送出乘客数、成功靠岸次数、坚持天数、剩余船体、本局得分(乘客 x100 + 靠岸 x20)、历史最高分、已玩局数。
