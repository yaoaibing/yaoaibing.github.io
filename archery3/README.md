# 射箭比赛 (🏹 射箭比赛 · 百步穿杨)

> 分类:**体育竞技** · 入口:/archery3/ · 免费在线 · 手机即点即玩

**目标:**抛物线射箭:两段式锁定,**按距离靶心给环数**;8 箭累计总环数。

| 元素 | 效果 |
|---|---|
| 🎯 靶心 | 距离越小环数越高 |
| 📐 角度 | 10-80° 自动扫 |
| 💪 力度 | 15-100 自动扫 |
| 🏁 八箭 | 累计环数 |
| 🏆 评级 | 总环 60 神射手 |

**操作:**点屏**锁角度** → 再点**锁力度**发射(空格)。

> 💡 **打法:**① **角度 45° 射最远**,但要看靶位远近;② **力度适中**最稳,满力容易过头;③ 靶心在**正中偏上**,瞄准那里;④ 一箭一计,**别上头连射**;⑤ 60 环以上,**就是神射手**!

**结算:**总环数、本局得分、历史最高分、已玩局数。
