**目标:**方向反应:箭头闪现**点同向按钮**摇铃;连摇滚分,反方向扣心。

| 元素 | 效果 |
|---|---|
| 🔔 摇铃 | 点侧屏对应方向 |
| ←→ 方向 | 随机闪现 |
| 🔥 连摇 | 每连一次 +2 |
| ❤️ 容错 | 三颗心 |
| 🏆 评级 | 连摇 20 铃铛达人 |
