# 击剑大师 (🤺 击剑大师 · 一剑制胜)

> 分类:**街机动作** · 入口:/fencing/ · 免费在线 · 手机即点即玩

**目标:**与电脑击剑对决:**前进/后退**控制距离,近身时「刺!」命中得分,对手出剑瞬间「格挡」可反制。先得 **5 分**者胜,三档 AI 强度。

| 元素 | 效果 |
|---|---|
| ⬅ 前进 | 缩短距离,进入攻击范围 |
| ➡ 后退 | 拉开距离,躲开攻势 |
| 🗡 刺! | 近身时命中 +1 分 |
| 🛡 格挡 | 对手出剑 0.4 秒内按下则反制 |
| 🏁 胜负 | 先得 5 分者胜 |

**操作:**底部四个按钮:前进/刺!/后退/格挡(键盘 ← → 空格 格挡 S)。距离条在顶部,变红就是出剑良机!

> 💡 **打法:**① 距离条<b>变红</b>的瞬间出剑最稳,别在远距空刺;② 电脑出剑前有 0.3 秒预备动作,看到就按格挡;③ 格挡成功后接一剑,几乎必中;④ 别一直后退,被逼到剑道尽头就躲不开了;⑤ 高手局拼节奏:前进-停-刺,打乱它的预判。

**结算:**双方得分、格挡次数、命中率先、难度、本局得分(胜 500 + 剩余分差 x60)、历史最高分、已玩局数。
