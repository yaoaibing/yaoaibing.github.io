# 数字华容道 (🧩 数字华容道)

> 分类:**烧脑益智** · 入口:/fifteen/ · 免费在线 · 手机即点即玩

**目标:**滑动方块,把数字排成 1→15 的顺序、空格留在右下角即通关。
| 操作 | 键位 |
|---|---|
| 移动 | 在棋盘上**朝空格方向滑动**,或点空格旁边的块;电脑用 `↑``↓``←``→`
| 尺寸 | 3×3 入门 / 4×4 标准 / 5×5 进阶 |
辅助 | 撤销、重置、提示(高亮下一步最优走法) |

**打乱保证有解**——是从拼好状态倒着走出来的,不存在无解局。

> 💡 **还原思路:**① **一行一行来**:先排好第一行,再第二行,锁死不再动;② 排最后两行时用「旋转法」:把目标块转到它该去的位置再整体转回来;③ 3×3 先练手,别一上来就 5×5;④ 提示是真求解器算的,卡住就点一下看思路。
