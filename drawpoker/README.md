# 五张抽牌 (🃏 五张抽牌 · 一次换牌)

> 分类:**卡牌构筑** · 入口:/drawpoker/ · 免费在线 · 手机即点即玩

**目标:**抽牌扑克:发 5 张**留牌换牌**一次,按牌型赔率派彩(两对 2 倍→同花顺 50 倍);押注自调,筹码耗尽结算。

| 元素 | 效果 |
|---|---|
| 👑 同花顺 | 50 倍 |
| 🎯 四条/葫芦 | 25/9 倍 |
| 💠 同花/顺子 | 6/4 倍 |
| ✌️ 大对子 | J 以上 1 倍 |
| 💰 押注 | 10-50 循环 |

**操作:****点牌**保留/取消,「**🃏 换牌**」开抽(空格),「**💰 押注+10**」调注(b)。

> 💡 **打法:**① **低对全换**:J 以下对子期望不如搏两对;② 四张同花/四张顺子**必留一张赌成**;③ 押注策略:牌顺加注,**牌背减注回血**;④ 别恋战散牌,**一次换牌就是全部机会**;⑤ 200 筹码起步,**翻倍即走是美德**!

**结算:**剩余筹码、当前押注、本局得分、历史最高分、已玩局数。
