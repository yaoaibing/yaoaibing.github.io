# 对称补全 (🪞 对称补全 · 镜像点阵)

> 分类:**烧脑益智** · 入口:/symgrid/ · 免费在线 · 手机即点即玩

**目标:**对称谜题:虚线轴一侧锁定,另一侧**点格补成镜像**;全图对称即过关 +60+格数分,连对滚分,过关 +6 秒,网格 6→8 递增。

| 元素 | 效果 |
|---|---|
| 🔵 蓝区 | 原稿,不可编辑 |
| 🟡 黄区 | 镜像侧,点格补全 |
| ⚖️ 轴线 | 垂直/水平交替 |
| ⏱ 续命 | 每关 +6 秒 |
| 🏆 评级 | 连对 8 张对称大师 |

**操作:****点黄区暗格**点亮,点错再点熄灭。

> 💡 **打法:**① **按行扫**:每行只看蓝区亮了几格;② 蓝 3 黄 2,**缺的就是那一格**;③ 轴线会换方向,**看清虚线再动手**;④ 多余的亮格也要熄掉,**对称是双向的**;⑤ 连对不断,**分是滚雪球的**!

**结算:**补全张数、连对、本局得分、历史最高分、已玩局数。
