# 秋千架 (🌿 秋千架 · 越荡越高)

> 分类:**街机动作** · 入口:/swingset/ · 免费在线 · 手机即点即玩

**目标:**节奏摆荡:**接近最高摆角时点击送劲**;连送滚分;荡过 88 度翻越清零。

| 元素 | 效果 |
|---|---|
| 🌿 摆角 | -88° 到 88° |
| 💨 送劲 | 最高点 ±38° 内 |
| 📈 增幅 | 每次送劲 +4% |
| ⚠️ 失手 | 劲泄连击断 |
| 🏆 评级 | 荡到 80% 秋千王 |

**操作:**摆到最高点附近**点屏幕/空格**。

> 💡 **打法:**① **心里数拍**:到头一送,节奏最要紧;② 连送滚分,**断了就重新找拍**;③ 70 度以后**小幅度微调**,别贪;④ 荡过头会翻,**88 度封顶**;⑤ 看角度标尺,**比看感觉靠谱**!

**结算:**最高摆幅、连送、本局得分、历史最高分、已玩局数。
