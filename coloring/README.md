# 填色小画家 (🎨 填色小画家 · 涂色减压)

> 分类:**解压休闲** · 入口:/coloring/ · 免费在线 · 手机即点即玩

**目标:**6 幅线稿(花朵/小屋/金鱼/蝴蝶/蛋糕/火箭)随你涂色,点区域上色,涂满一幅触发庆祝。纯解压玩具,没有失败。

**操作:**底部调色盘 12 色任选,点画里的**封闭区域**涂色;点屏幕两侧 `◀``▶` 换画;🧽清空重涂本幅。**每幅画的配色自动保存**,随时回来继续。

**计分:**完成一幅画作数 +1,历史最高=累计完成幅数(重复涂同一幅只记一次,清空后可再刷)。

> 💡 **涂色灵感:**① 先铺**大面积底色**再点小区域,视觉上更快"像回事";② 花瓣用相邻色系(粉→紫)、屋顶深墙浅,对比出来最好看;③ 金鱼的气泡留白反而灵动,不必涂满;④ 白色可以当"橡皮"把涂错的改回来;⑤ 完成度到 100% 才算完成,差最后一块时用"完成"提示检查哪里还是灰色。

**结算:**完成画作数、当前完成度、历史最高。
