# 沙滩排球 (🏐 沙滩排球 · 人机对战)

> 分类:**街机动作** · 入口:/volleyball/ · 免费在线 · 手机即点即玩

**目标:**左右移动球员接球,把球打过网落到对方半场得分。**先到 7 分**获胜,球落在自己半场则对方得分。跳起接球可以打出更快的扣杀。

| 元素 | 效果 |
|---|---|
| 🏐 移动 | 左右拖动或按方向键,球员只在自己半场 |
| ⬆ 起跳 | 点屏幕、起跳键或空格,跳起接球变成扣杀 |
| 💥 接球 | 球靠近球员自动击回,站得越正球越稳 |
| 🥅 得分 | 球落在哪边,哪边丢分,先到 7 分获胜 |
| 🎚 难度 | 简单/普通/困难,电脑速度与预判递增 |

**操作:**左右拖动球场移动球员,点屏幕或**起跳**键跳跃;底部切换难度和**新局**。键盘方向键移动,<kbd>空格</kbd> 起跳。

> 💡 **打法:**① 站到球的**落点正下方**再起跳,扣杀角度最刁;② 别一直贴网,后撤半步才能接高球;③ 球很高时先移动到落点,别提前跳;④ 电脑站位靠前时往底线打;⑤ 领先时求稳,别每球都扣。

**结算:**比分、胜负、难度、本局得分(胜利 1000 + 净胜分 x100 + 难度 0/100/200)、历史最高分、已玩局数。
