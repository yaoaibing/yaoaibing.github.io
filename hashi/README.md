# 数桥连岛 (🌉 数桥连岛 · 海上航线)

> 分类:**烧脑益智** · 入口:/hashi/ · 免费在线 · 手机即点即玩

**目标:**数桥(Hashi)谜题:岛上标的数字就是它需要连出的桥数。**点两座岛架桥**,只能横竖、不能穿岛不能交叉、两岛间最多双桥;所有岛桥数满足且连成一片即解开,共 6 盘,提示 3 次。

| 元素 | 效果 |
|---|---|
| 🌉 数字 | 该岛需要的桥数(单桥计 1,双桥计 2) |
| 👆 架桥 | 点岛再点岛,方向必须横竖对齐 |
| 🚫 限制 | 不可穿岛、不可与其他桥交叉 |
| 🔗 连通 | 全部岛必须连成同一块 |
| 💡 提示 | 放下一座正确的桥,每局 3 次 |

**操作:****点岛—点岛**架桥,点已架的桥可加第二座或拆掉;「撤销」「清空」「提示」都在底部。先处理 4 以上的数字岛!

> 💡 **打法:**① <b>四角和边</b>上的岛最多连 2 或 3 座,数字大的先安排;② 数字=桥数一半时通常上下左右各一座;③ 用「缺口」计数判断还剩多少;④ 桥把图切成两半时一定有误,回头拆;⑤ 最后检查<b>所有岛连成一片</b>,数字对了也不算完!

**结算:**解开盘数、错架次数、提示使用、本局得分(每盘 300 - 错架 x25 - 提示 x60)、历史最高分、已玩局数。
