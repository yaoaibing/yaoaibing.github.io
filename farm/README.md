# 开心农场 (🌾 开心农场 · 四季收成)

> 分类:**解压休闲** · 入口:/farm/ · 免费在线 · 手机即点即玩

**目标:**在 3x3 田地里播种,等作物成熟后点田块收成换金币。**60 秒一季**,收成总额就是最终得分。

| 元素 | 效果 |
|---|---|
| 🌱 播种 | 选种子点空地,扣除种子费 |
| ⏳ 生长 | 萝卜 4 秒、玉米 9 秒、草莓 16 秒 |
| 🧺 收成 | 作物发亮后点田块收获,卖价高于种子费 |
| 💰 金币 | 初始 20 币,收成后才有钱买更贵的种子 |
| ⏱️ 一季 | 60 秒结束,收成总额即得分 |

**操作:**底部选种子,点空地播种,点成熟作物收成;**新局**重开。键盘 <kbd>1</kbd>-<kbd>3</kbd> 选种子,<kbd>R</kbd> 新局。

> 💡 **打法:**① 开局只有 20 币,先种**两茬萝卜**滚本金;② 金币过 30 再上玉米,过 60 再种草莓;③ 九块地别全种同一种,错开成熟时间才不会空等;④ 收成前先点种子,收完立刻补种;⑤ 最后 20 秒只种能收的,萝卜最保险。

**结算:**收成总额、金币余额、种植次数、称号、历史最高分、已玩局数。
