# 墨梅吹画 (🎋 墨梅吹画 · 一纸风骨)

> 分类:**创意涂鸦** · 入口:/inkblow/ · 免费在线 · 手机即点即玩

**目标:**水墨生成:「吹气」让墨滴分叉生长成枝;**点纸面点梅**,凑满目标朵数成画换新纸。

| 元素 | 效果 |
|---|---|
| 🌬 吹气 | 末端分叉,枝越吹越繁 |
| 🌸 点梅 | 随手一点红梅 +10 |
| 🖼️ 成画 | 凑满朵数 +120 |
| 🎋 风骨 | 枝形随机,永不重样 |
| 🏆 评级 | 三幅梅册小画师 |

**操作:**点「**🌬 吹气**」(空格)长枝,**点纸面**点梅。

> 💡 **打法:**① **多吹几口气**,枝繁才有梅可点;② 梅点**落在枝头附近**最像画;③ 成画重开一纸,**手感会延续**;④ 别追求对称,**歪枝才见风骨**;⑤ 红梅数量看着凑,**差一朵别急吹**!

**结算:**成画数、点梅数、本局得分、历史最高分、已玩局数。
