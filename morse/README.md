# 电波密语 (📻 电波密语 · 摩斯解码)

> 分类:**密码破译** · 入口:/morse/ · 免费在线 · 手机即点即玩

**目标:**摩斯电码破译:屏幕显示密语摩斯码并**自动播放嘀嗒音**,对照底部**密码表**逐字母解码,四选一选出正确单词;选错扣一颗信号灯并可重听,三灯用尽任务失败。

| 元素 | 效果 |
|---|---|
| 📻 摩斯码 | 字母间以 / 分隔,自动播放两遍可重听 |
| 📖 密码表 | 底部常驻 A-Z 对照,随时查 |
| 🔤 四选一 | 干扰项长度相近,纯读码定胜负 |
| 💡 信号灯 | 三条命,选错扣一并重听 |
| 📈 难度 | 3 字母起步,后期 5 字母长词 |

**操作:**听完看码,**点单词**(键盘 **1-4**)作答;**R** 或「重听」再放一遍声音。建议先数 `/` 的个数锁定长度!

> 💡 **打法:**① 最快的破译顺序:<b>数字母个数 → 对每个字母的码 → 排除法选词</b>;② 短码最常用:E(一嘀)T(一划)A(点划)——看到一嘀开头八成是 E 开头的词;③ 长词别慌,**先破译首字母**就能排除两个选项;④ 听声音比看码快:嘀短嗒长,<b>节奏感</b>是字幕员的核心技能;⑤ 错一次只扣灯不重置进度,**同一组可以慢慢磨**,但别连错三下!

**结算:**破译组数、剩余信号灯、本局得分(100 + 时限分 + 词长分)、历史最高分、已玩局数。
