# 雨伞接雨 (☂️ 雨伞接雨 · 清雨计划)

> 分类:**街机动作** · 入口:/raincatch/ · 免费在线 · 手机即点即玩

**目标:**拖动雨伞**接住净水**、躲开脏雨:净水 +10 起步、连击加成,接到脏雨 -1 生命并清空连击;雨速与密度随时间上升,3 命用完结算。

| 元素 | 效果 |
|---|---|
| 💧 净水 | 接住 +10,连击每层 +2 |
| ☠️ 脏雨 | 接到 -1 命、清连击 |
| ☂️ 雨伞 | 拖动/方向键左右移动 |
| 📈 难度 | 雨速与密度随时间上升 |
| 🏆 评级 | 60 滴清雨大师 |

**操作:****拖动**屏幕左右移动雨伞(方向键同效)。

> 💡 **打法:**① **盯天不看伞**,水滴落点比伞重要;② 脏雨密度前低后高,**开局多囤连击**;③ 横向移动要提前,伞的接雨范围比看起来小;④ 接到脏雨别慌,**先回中位**再找下一滴;⑤ 后期雨太密时**守一侧**比全场追轻松!

**结算:**接住净水滴数、剩余生命、本局得分、历史最高分、已玩局数。
