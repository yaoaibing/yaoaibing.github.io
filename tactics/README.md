# 兵团推演 (⚔️ 兵团推演 · 三路攻防)

> 分类:**策略战棋** · 入口:/tactics/ · 免费在线 · 手机即点即玩

**目标:**三路攻防战棋:**骑兵克弓手、弓手克盾兵、盾兵克骑兵**(克制 2 倍伤害,被克 0.5);部署阶段选兵种点路放兵,倒计时或手动出击;单位冲到对方基地扣 2 点,守住 5 波获胜。

| 元素 | 效果 |
|---|---|
| 🛡 盾兵 | 4 费 · 血 30 · 克骑兵,肉盾顶前排 |
| 🏹 弓手 | 3 费 · 血 16 · 克盾兵,后排输出 |
| 🐎 骑兵 | 5 费 · 血 22 · 克弓手,速度快冲锋 |
| 🏰 基地 | 各 20 点,被单位冲到 -2 |
| 📈 波次 | 5 波,双方兵力逐波增加 |

**操作:**部署阶段**点下方选兵种**、**点三路任意位置放兵**;点 **⚔️出击**(空格)开战;战斗全自动,你只管下一波的排兵!

> 💡 **打法:**① 克制是 2 倍伤害、被克只有 0.5 倍,<b>差出四倍</b>,对位比堆数量重要;② 看上波 AI 出什么,<b>这波摆克制它的</b>(它弓多你就堆骑兵);③ 三路都要有人,空路等于白送基地血;④ 骑兵 42 速度最快,<b>空路放一匹骑兵</b>偷基地血极赚;⑤ 部署点数别攒,全花出去,场面上多一个兵就多一分赢面!

**结算:**守住波数、剩余基地血、击破数、本局得分(每波 200 + 基地 x8 + 击破 x12)、历史最高分、已玩局数。
