> 分类:**学习教育** · 入口:/weathervane/ · 免费在线 · 手机即点即玩

**目标:**观风猜天:风向标**转到实际方向**,四选一猜明日;8 天竞猜,5 中过关。

| 元素 | 效果 |
|---|---|
| 🌬️ 四向 | 东南西北随机 |
| 👁️ 观察 | 标转=真实方向 |
| 👉 猜测 | 四选一 |
| ❤️ 容错 | 三颗心 |
| 🏆 评级 | 猜中 5 天气象通 |

**操作:****点选项**(键盘 **1-4**)猜明日风向。

> 💡 **打法:**① **风向标指东=东风**,风从东来;② 前几天风向**有规律**,连续东风后常变;③ 猜错**扣一颗心**,三心用完结束;④ **没有规律时选直觉**,反正五五开;⑤ 猜中五天,**全村的种菜都靠你**!

**结算:**猜中天数、本局得分、历史最高分、已玩局数。
