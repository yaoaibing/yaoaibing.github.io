# 扎染工坊 (🎨 扎染工坊 · 折出花样)

> 分类:**创意涂鸦** · 入口:/tiedye/ · 免费在线 · 手机即点即玩

**目标:**对称滴染创作:点**调色盘选色**、点**布面滴染**,每一滴按 2/4/8 重对称复制;「漂洗」结算覆盖率与配色丰富度,零失败创作。

| 元素 | 效果 |
|---|---|
| 🎨 四色盘 | 蓝/粉/黄/绿随时切换 |
| 💧 滴染 | 不规则晕染边缘 |
| ✖️ 对折 | 2 重/4 重/8 重万花筒 |
| 🫧 漂洗 | 结算并清布,可反复 |
| 🏆 计分 | 覆盖 x6 + 配色 x60 |

**操作:**点**色盘**选色,点**布面**滴染;「对折」「漂洗」在下方。

> 💡 **打法:**① **中心滴一大滴**,四周补小滴,构图立刻稳;② 8 重对称**一点成花**,别滴太密;③ 相邻色滴叠着滴,**晕染层次最好看**;④ 漂洗不限次,**多出几幅挑最满意的**;⑤ 分数不重要,**截图分享你的花纹**才是正经事!

**结算:**滴染点数、覆盖率、成品得分、历史最高分、已做作品数。
