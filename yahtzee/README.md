# 快艇骰子 (🎲 快艇骰子 · 十三轮)

> 分类:**对战棋牌** · 入口:/yahtzee/ · 免费在线 · 手机即点即玩

**目标:**13 轮定胜负。每轮最多掷 3 次骰子,锁定想保留的点数,最后在 13 个计分格中各选一格记分,**总分越高越好**。

| 元素 | 效果 |
|---|---|
| 🎲 掷骰 | 每轮最多 3 次,第一次必掷满 5 颗 |
| 🔒 锁定 | 点骰子锁定想保留的点数,再点一次取消 |
| 🃏 计分表 | 上区 6 格按点数求和,下区 7 格按牌型计分 |
| 🏆 上区奖励 | 1-6 点合计 ≥63,额外 +35 |
| 🚢 牌型 | 三条/四条按总点数,葫芦 25,小顺 30,大顺 40,快艇 50 |

**操作:**点骰子锁定,**掷骰**按钮扔剩下的骰子;掷完后点计分表任意空格结算(选了不能反悔)。键盘 <kbd>空格</kbd> 掷骰,<kbd>1</kbd>-<kbd>5</kbd> 锁定对应骰子。

> 💡 **打法:**① **上区先凑 63**——每格平均 3.5 点就够,拿到 +35 比什么都实在;② 一点、二点这种低分格,越早填越不心疼;③ 快艇、大顺这类高难牌型留到最后一轮博一把;④ 四条和三条看总点数,点数低时不如填「机会」;⑤ 葫芦固定 25 分,凑不出来时别硬追。

**结算:**总分、上区/63(已拿奖励或还差多少)、下区得分、称号、历史最高分、已玩局数。
