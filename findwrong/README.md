# 挑错题 (🔍 挑错题 · 火眼金睛)

> 分类:**学习教育** · 入口:/findwrong/ · 免费在线 · 手机即点即玩

**目标:**找错训练:四个算式有一个**计算结果错误**,点出错的那道;加减乘混合,连对加分,10 题逐级升档,火眼金睛非你莫属。

| 元素 | 效果 |
|---|---|
| 🧮 四题 | 加减乘混合,一题有错 |
| 🎯 找错 | 点出错题编号(1-4) |
| 🔥 连对 | 每题 100 + 连对 x10 |
| 📈 升档 | 每 4 题加法→减法→乘法 |
| 🏆 评级 | 连对 8 次火眼金睛 |

**操作:****点错题**(键盘 **1-4**);心算检查每题。

> 💡 **打法:**① 加法看<b>个位数</b>是否对;② 减法验证<b>差+减数=被减数</b>;③ 乘法用**九九口诀**快速扫描;④ 不确定的题<b>先跳过检查下一题</b>,用排除法;⑤ 连对分是复利,<b>前三题稳拿</b>建立优势,后面再冲!

**结算:**最长连对、本局得分、历史最高分、已玩局数。
