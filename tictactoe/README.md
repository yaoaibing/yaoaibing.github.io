# 井字棋 (⭕ 井字棋 · 天人大战)

> 分类:**对战棋牌** · 入口:/tictactoe/ · 免费在线 · 手机即点即玩

**目标:**你执 **X 先手**,电脑执 O,在 3×3 棋盘上横、竖、斜**任一方向三连**即胜;棋盘下满无人三连为平局。得分跨局累计,历史最高分自动保存。
| 难度 | AI 水平 | 分数系数 |
|---|---|---|
| 萌新 | 三成棋步不走最优,会犯明显错误 | ×1 |
| 日常 | 七成半走最优,偶尔漏防 | ×1.4 |
| 地狱 | **极小极大全搜索,永不失误** | ×2 |

**操作:**手机**直接点格子**落子;键盘 `↑↓←→` 移动光标、`空格`/`回车` 落子。赢一局 **+100 起**,之后**每连胜一局额外 +25**;平局拿小分;输了不扣分但**连胜清零**。

> 💡 **拿分要点:**① **抢中心**——首手占天元(正中)是先手最大优势;② **双活二**——摆出两条两连线让电脑只能堵一条;③ 地狱档 AI 无法被击败,**逼和也是本事**,想刷分靠连胜滚分,别上头;④ 日常档 AI 有 25% 概率犯错,**钓它双重威胁**是稳定赢法。

**结算:**胜负结果、累计胜平负战绩、当前连胜、累计得分、历史最高分。
