# 独立钻石 (🔴 独立钻石 · 孔明棋)

> 分类:**烧脑益智** · 入口:/peg/ · 免费在线 · 手机即点即玩

**目标:**孔明棋:选中棋子**隔一子直跳**,被跳过的子移除;剩 1 子且在中心为完美通关;无步可走即结算,支持撤销。

| 元素 | 效果 |
|---|---|
| ⏭ 跳吃 | 直线隔一子跳,被跳子移除 |
| 🎯 中心 | 剩 1 子落中心 +800 |
| ↩ 撤销 | 随时悔棋,扣 30 分 |
| 📉 结算 | 剩子越少分越高 |
| 🏆 评级 | 剩 1 子且居中=完美 |

**操作:**点红子选中,再点<b>绿圈位置</b>落子;「↩ 撤销」悔棋。

> 💡 **打法:**① **角落的子最先死**,别急着往角落跳;② 优先保持棋子**成片**,孤子必死;③ 经典解法第一步常从上方或侧翼开局,**别动中心四邻**;④ 剩 5 子时就该规划最终中心路线;⑤ 悔棋不丢人,**这游戏人类平均要练几十局**!

**结算:**剩余棋子数、行走步数、本局得分、历史最高分、已玩局数。
