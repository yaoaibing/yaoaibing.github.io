# 造桥大师II (🌁 造桥大师 II · 峡谷狂风)

> 分类:**建造物理** · 入口:/bridge2/ · 免费在线 · 手机即点即玩

**目标:**进阶物理造桥:**中央石柱**成为第三锚点,**正弦侧风**持续横推所有自由节点;两次点击连梁(≤230px),试车时卡车与风载同时作用,应变 >9% 崩断;三桥全通获胜。

| 元素 | 效果 |
|---|---|
| 🪨 石柱 | 桥中央水下岩石,第三个固定锚点 |
| 🌬️ 侧风 | 正弦+阵风双重叠加,推力随时间波动 |
| 📐 连梁 | 任意锚点/节点两两相连,≤230px |
| 🔴 断裂 | 应变 >9% 崩断,断梁不承重 |
| 💰 预算 | 920→1160,剩余折半计分 |

**操作:****点锚点→点落点**连梁;**试车**(空格)验收;**重搭**清空本关。先造静定结构,再补抗风斜撑!

> 💡 **打法:**① 风从侧面来,<b>斜撑要逆风多搭一档</b>,顺风侧省料;② 中央石柱是免费的黄金锚点,<b>所有桥都先连石柱</b>;③ 长跨 500 必须把桥面分成 3 段以上,单段超 230 连不上;④ 试车看红梁位置,<b>风大时应变是波动的</b>,绿梁也可能在风峰变红;⑤ 预算比上作宽裕但跨度更长,<b>每一段都要三角化</b>再进下一关!

**结算:**通过工程数、剩余钢材、本局得分(每桥 350 + 剩余预算一半)、历史最高分、已玩局数。
