# 酒席猜枚 (🤞 酒席猜枚 · 一握一猜)

> 分类:**骰子冒险** · 入口:/caimei/ · 免费在线 · 手机即点即玩

**目标:**概率押注:**单双稳妥**,冷门搏大。

| 元素 | 效果 |
|---|---|
| 🤞 攥拳 | 莲子在手 |
| 👆 单双 | 稳中二倍 |
| 🎲 三五千 | 中则五倍 |
| ✅ 连胜 | 越连越厚 |
| 🏆 结算 | 猜枚折分 |

**操作:**点**押单/押双/博三五千**。

> 💡 **打法:**① **单双稳如老狗**,连胜加成才是大头;② 三五千**偶尔搏一次**,十把一碰;③ 输一局**罚酒别上头**,下局重新算;④ 看他**攥拳的手势**,说不定有破绽;⑤ 八局连中,**满桌都喊你枚仙**!

**结算:**猜枚局数、连胜局数、本局得分、历史最高分、已玩局数。
