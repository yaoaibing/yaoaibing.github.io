# 竞价手牌 (🏷️ 竞价手牌 · 十张定输赢)

> 分类:**拍卖竞价** · 入口:/pricecard/ · 免费在线 · 手机即点即玩

**目标:**手牌竞价(Goofspiel):每轮拍品有隐藏行价,双方各出一张暗牌,**高价得品并计入行价**;十轮比总资产。

| 元素 | 效果 |
|---|---|
| 🃏 手牌 | 1-10 各一张 |
| 🖼️ 拍品 | 每件行价 20-90 |
| ⚖️ 规则 | 高价得品,平价流拍 |
| 🧠 博弈 | 对手也在算计 |
| 🏆 评级 | 总资产领先金牌买手 |

**操作:****点价签**(键盘 **1-9**)出价。

> 💡 **打法:**① **大牌配大货**,1 号牌白送小货;② 行价是公开的,**等值出牌最稳**;③ 对手大牌用掉后,**剩下的货用中牌撬**;④ 平局流拍**谁都不亏**,别乱抬;⑤ 最后一两件**算清差额再出**!

**结算:**拍得总值、场次、本局得分、历史最高分、已玩局数。
