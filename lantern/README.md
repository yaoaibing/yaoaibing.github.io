# 放河灯 (🏮 放河灯 · 心愿漂流)

> 分类:**解压休闲** · 入口:/lantern/ · 免费在线 · 手机即点即玩

**目标:**点亮莲花灯**顺流而下**:左右拖动引方向,灯芯随时间烧尽;接**烛火**补灯芯(+28)计一盏河灯,撞**石头**灯芯 -22 被弹开;灯灭漂流结束,距离与河灯数结算。

| 元素 | 效果 |
|---|---|
| 🏮 河灯 | 自动顺流,你只管左右轻引 |
| 🕯️ 烛火 | 接到 +28 灯芯,河灯数 +1 |
| 🪨 石头 | 撞上 -22 灯芯并被弹开 |
| 📉 灯芯 | 每秒 -2.5%,烧尽即结束 |
| 🌊 水流 | 越漂越快,需要更早预判 |

**操作:****左右拖动**或**方向键**引灯;没有失败惩罚只有灯灭,节奏舒缓。适合睡前单手玩!

> 💡 **打法:**① 灯芯 2.5%/秒,平均 40 秒一局,**每 6-7 秒必须接到一盏烛火**才守得住;② 石头被撞开的方向固定往另一侧,**借力变向**反而能省操作;③ 别贴边走:两岸芦苇带不出烛火;④ 水流会越来越快,**提前半屏预判**比现场补救轻松;⑤ 这是解压局,听水声看灯影,别急!

**结算:**漂流距离、收集河灯数、本局得分(距离 + 河灯 x15)、历史最高分、已玩局数。
