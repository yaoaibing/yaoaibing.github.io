# 点格棋 (🔲 点格棋 · 圈地大战)

> 分类:**对战棋牌** · 入口:/dotsbox/ · 免费在线 · 手机即点即玩

**目标:**轮流在相邻点之间**画一条边**,谁补上某格的第 4 条边就占领该格并**额外再画一次**。全部格子占完后格子多者胜。核心博弈:既要自己抢格,又不能画出"第三条边"把格子白送。

| 元素 | 效果 |
|---|---|
| 🔲 画线 | 点两点之间即画一条边,横竖都行 |
| 📦 占格 | 一格四边齐了归当前玩家,且继续行动 |
| ⚠️ 让格 | 主动画第三条边是大忌,除非吃到整条链 |
| 🔗 长链 | 后期会出现长链,谁先开口谁吃整条 |
| 🏁 胜负 | 16 格(或 25 格)占完,格子多者赢 |

**操作:**点两个相邻点之间画线;**难度**切换 4x4/5x5/6x6 棋盘并重开,**新局**重开。电脑吃到格子会连续行动。

> 💡 **打法:**① 中盘只画**安全边**:画之前看这格是不是第 3 条边;② 双方都只剩危险边时,故意送**最短的链**给自己减少损失;③ 长链到手要懂得**最后留双格**(把 2x1 留给对方),控制总数奇偶;④ 先数格子:安全边耗尽前算清谁能吃首链;⑤ 大棋盘先抢中心格的边。

**结算:**双方格子数、链长统计、难度、本局得分(净胜格 x60 + 棋盘规模分)、历史最高分、已玩局数。
