# 堵门棋 (🧱 堵门棋 · 断你生路)

> 分类:**对战棋牌** · 入口:/quoridor/ · 免费在线 · 手机即点即玩

**目标:**攻防棋:**走子或砌墙**,先抵达对岸胜;墙不得封死双方;三局定比分。

| 元素 | 效果 |
|---|---|
| 🔵 走子 | 点相邻空位移动 |
| 🧱 砌墙 | 点两格缝隙落墙 |
| 🚫 规则 | 双方都得留活路 |
| 🔺 对手 | 会堵你的最短路 |
| 🏆 赛制 | 三局两胜 |

**操作:****点相邻格**走子,**点格间缝**砌墙。

> 💡 **打法:**① **自己的路先算好**,再堵别人;② 墙砌在对方**必经窄道**才值;③ **别把墙花光**,残局没墙只能干追;④ 对手快到时,**砌墙不如堵位**;⑤ 三局两胜,**输一局别乱**!

**结算:**比分、本局得分、历史最高分、已玩局数。
