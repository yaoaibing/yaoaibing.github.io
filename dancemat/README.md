# 舞力全开 (💃 舞力全开 · 箭头节拍)

> 分类:**音乐节奏** · 入口:/dancemat/ · 免费在线 · 手机即点即玩

**目标:**四轨下落音舞:**箭头压到判定圈**时按对应方向键或点击轨道;PERFECT ±60ms 三倍分/GOOD ±140ms;BPM 95 递增 135;连击加成,40 秒后按准确率结算。

| 元素 | 效果 |
|---|---|
| 💃 四轨 | ←↓↑→ 四方向 |
| ✨ 判定 | Perfect ±60ms / Good ±140ms |
| 🔥 连击 | 每 6 连加成一档 |
| 📈 BPM | 95→135 渐快 |
| ⏱ 曲长 | 40 秒 |

**操作:****按对应方向键**或**点对应轨道**;空格随机轨。**跟上节奏别盲按**!

> 💡 **打法:**① 音舞铁律:<b>看判定圈不听歌</b>,箭头到圈上才按;② 连击加成每 6 连一档,<b>断了别崩</b>,下一箭头稳住;③ 双手操作:<b>左手←↓右手↑→</b>,分工比单手快;④ BPM 135 时拍距 0.44 秒,<b>箭头间距视觉压缩</b>,相信余光;⑤ 准确率 ≥93% 就是舞王,<b>宁要 GOOD 不要 MISS</b>!

**结算:**准确率、Perfect/Good/Miss 计数、最大连击、本局得分、历史最高分、已玩局数。
