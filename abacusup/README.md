| 元素 | 效果 |
|---|---|
| 🪵 算盘框 | 规矩第一步 |
| ➖ 横梁 | 分上下珠 |

| 🔴 珠 | 上二下五归位 |
| 🏆 评级 | 两盘全成算盘刘 |

**操作:****点部件**再**点槽位**(键盘 **1-5** 直装)。
