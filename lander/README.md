# 登月着陆 (🌙 登月着陆 · 太空驾驶员)

> 分类:**街机动作** · 入口:/lander/ · 免费在线 · 手机即点即玩

**目标:**驾驶登月舱从空中开始下降:**点火**反推对抗重力,**左右转**控制姿态,最终以垂直速度 < 25、水平速度 < 15、机身不倒的姿态降落在发光平台上。燃料有限,落点偏出平台算坠毁,关卡越深燃料越少风越大。

| 元素 | 效果 |
|---|---|
| 🔥 主发 | 按住点火,向上反推,消耗燃料 |
| ↺ ↻ 姿态 | 左右旋转舱体,推力方向跟着转 |
| ⏱ 计时 | 高度/速度实时显示,红色预警要立刻减速 |
| 🎯 平台 | 只有落在发光平台区才算成功 |
| 💨 侧风 | 第 3 关起有随机侧风,注意水平速度 |

**操作:**底部按钮:**左转/主发/右转**按住生效(键盘 ← ↑ → 同理)。落稳一关自动进下一关,燃料不满补给,坠毁即结算。

> 💡 **打法:**① 一开始就**倾斜加速**横移,别垂直下坠到跟前才急刹;② 记住"燃料烧在半路":最后 200 米只要微调;③ 水平速度靠反向姿态喷气修正,别只顾上下;④ 落点看准平台**边缘内侧**,中心不一定安全;⑤ 每关燃料有限,动作越柔和越省,狂喷必炸。

**结算:**成功关数、着陆垂直/水平速度、剩余燃料、任务得分(每关 200 + 剩燃料 x3 + 软着陆奖励)、历史最高分、已玩局数。
