# 捡宝石 (💎 捡宝石 · 曼卡拉)

> 分类:**对战棋牌** · 入口:/mancala/ · 免费在线 · 手机即点即玩

**目标:**非洲播棋(曼卡拉)对 AI:点自己一坑取光宝石,<b>逆时针逐坑撒下</b>(跳过对手仓库);最后一颗进自己仓库可<b>再走一次</b>,落在自己原本空的坑则吞走<b>对面那坑</b>;任一侧清空后各自收干净,仓库宝石多者胜。

| 元素 | 效果 |
|---|---|
| 💎 开局 | 12 个小坑各 4 颗,共 48 颗 |
| 🔄 撒种 | 逆时针一颗一坑,跳过对方仓库 |
| 🎁 免费手 | 最后一颗进自己仓库,再走一次 |
| 🎯 吞子 | 最后一颗落在自己空坑,拿走对面 |
| 🏁 终局 | 一边空了清场,仓库多者胜 |

**操作:****点自己排的坑**撒种(键盘 1-6 对应左到右);「重新开局」重来。先数准最后一颗落点再伸手!

> 💡 **打法:**① 起手先算<b>4 步</b>:坑里几颗就往后数几格;② 造一个<b>空坑</b>等最后一颗落进去就能吞对面;③ 进自己仓库的那步等于白送一次,优先做;④ 对手也要吞子,别把大坑留在他数得着的距离;⑤ 残局一边空了就立刻收干净,别送分!

**结算:**双方仓库数、撒种次数、胜负、本局得分(仓库 x10 + 胜 300 / 平 100)、历史最高分、已玩局数。
