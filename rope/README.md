# 跳绳挑战 (🪢 跳绳挑战 · 甩绳达人)

> 分类:**街机动作** · 入口:/rope/ · 免费在线 · 手机即点即玩

**目标:**绳子绕着人转圈,扫到**脚底**的一瞬起跳,跳早跳晚都会绊倒。每跳过一个绳速加快一档,看看你能连跳多少个。

**操作:**点屏幕任意处或 `空格` 起跳。判定窗口较宽:绳过脚底时你在空中(起跳后 0.12~0.88 秒内)都算过。初始绳速 1.0x,每 10 个左右提一档,上限 2.4x。

> 💡 **拿分要点:**① **听"唰"声起跳**比看画面更稳,声音永远和绳底同步;② 起跳有约 0.12 秒的起手,**绳声一响立刻点**,别等画面;③ 绳速 1.8x 以上时提前半拍点,靠节奏而不是反应;④ 每跳一个都有音调递进的提示音,把它当节拍器;⑤ 30 连是及格线,60 连可称宗师。

**结算:**连跳个数、最终绳速、历史最高分。
