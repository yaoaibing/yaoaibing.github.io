**目标:**对位精度挑战:方向键移动游层与虚影重合,**按偏移像素分档计分**;五张结算。

| 元素 | 效果 |
|---|---|
| 🌓 虚影 | 半透明=目标位 |
| 🌗 游层 | 实体=可移动层 |
| ✚ 十字 | 虚影中心参考线 |
| 📸 合成 | ≤6px 满分 150 |
| 🏆 计分 | 五张总分 |

**操作:****◀▲▼▶** 挪层(方向键),「**📸 合成**」出片(回车)。
