# 信鸽竞翔 (🕊️ 信鸽竞翔 · 千里归巢)

> 分类:**竞速赛车** · 入口:/pigeonrace/ · 免费在线 · 手机即点即玩

**目标:**气象博弈:每站看风向**选高度层**;高度与风向匹配飞得远;先满 15 里胜。

| 元素 | 效果 |
|---|---|
| 🕊️ 三层 | 低空/中空/高空 |
| 💨 风向 | 逆/横/顺随机 |
| 🏁 赛点 | 先满 15 里 |
| 📈 八站 | 累计里程定输赢 |
| 🏆 评级 | 四站头名养鸽人 |

**操作:****点高度带**(键盘 **1-3**)放飞。

> 💡 **打法:**① **逆风天选低空**,三倍效率白送;② **顺风天冲高空**,风推着飞;③ 对手也在猜,**用常识压它**;④ 领先时**求稳选匹配**,别赌;⑤ 里程差一里,**结局都翻盘**!

**结算:**航程、胜站、本局得分、历史最高分、已玩局数。
