**目标:**成语连线:按顺序**点亮字格**组成成语;5 关通关,60 秒时限。

| 元素 | 效果 |
|---|---|
| 🔤 四字 | 16 格藏 4 字成语 |
| ✅ 连对 | 按序点亮 +15 |
| ✅ 成语 | 连完 +80 |
| 📈 五关 | 成语逐关换新 |
| 🏆 评级 | 五关全通出口成章 |

**操作:****点字格**按成语顺序点亮。

> 💡 **打法:**① **先想好成语**,再在格子里找字;② 已连的**亮绿色**,不会忘;③ 点错会提示,**但不扣分**;④ 五个成语**都是常用语**,别想太偏;⑤ 60 秒够,**别慌**!
