# 花牌采月 (🎴 花牌采月 · 同月成对)

> 分类:**卡牌构筑** · 入口:/hanafuda/ · 免费在线 · 手机即点即玩

**目标:**配对采集:**手牌配同月场牌**,单收 10 双收 30;无配上场,六回合比花分。

| 元素 | 效果 |
|---|---|
| 🎴 六月 | 松梅樱藤枫菊各四张 |
| 🌸 配对 | 同月收 +10 |
| ✌️ 双收 | 场上同月两张 +30 |
| 🤖 对手 | 贪心配对 |
| 🏆 赛制 | 六回合总分 |

**操作:****点一张手牌**打出。

> 💡 **打法:**① **场上有单张的月份**,你的对牌打了就收;② **双张别贪早**,等对手无牌可配再收;③ 没配的牌**挑对手难配的月份**上;④ 记牌**四张同月**,收了两张对手还有俩;⑥ 六回合花魁,**再来一局何妨**!
