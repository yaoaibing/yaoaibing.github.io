# 声呐探测 (📡 声呐探测 · 深海寻物)

> 分类:**寻宝推理** · 入口:/sonar2/ · 免费在线 · 手机即点即玩

**目标:**距离推理寻物:7x7 海域藏一艘沉船,每**点一格发一声呐**,回波显示到沉船的切比雪夫步距;声呐次数越少分越高,4 张海域逐图推理。

| 元素 | 效果 |
|---|---|
| 📡 声呐 | 点击格子获得回波数字 |
| 🔢 步距 | 切比雪夫距离,1=紧邻 |
| 🟢 扫描线 | 装饰性旋转,不影响判定 |
| 🚢 沉船 | 挖中即过关 |
| 📈 计分 | 每图 400 - 声呐 x30 |

**操作:****点格子**发声呐;**回波 1** 时宝藏必在紧邻 8 格!

> 💡 **打法:**① 首点<b>中心</b>,回波数字直接画出方框包围圈;② 沿对角线再点,**两圆交点**大幅缩小范围;③ 回波 1 = <b>八格必有一个</b>,螺旋试;④ 每张图独立,声呐次数不跨图,<b>大胆点</b>;⑤ 扫描线只是氛围,**数字才是真相**!

**结算:**寻获海域数、声呐次数、本局得分、历史最高分、已玩局数。
