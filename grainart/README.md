# 五谷粮食画 (🍚 五谷粮食画 · 一粒一色)

> 分类:**创意涂鸦** · 入口:/grainart/ · 免费在线 · 手机即点即玩

**目标:**色彩拼贴:**选谷撒画**,三幅递进。

| 元素 | 效果 |
|---|---|
| 🍚 谷色 | 四谷选一 |
| 🎯 区域 | 虚圈定位 |
| 🎨 贴对 | 一幅一景 |
| ⚠️ 撒错 | 谷粒混色 |
| 🏆 结算 | 粮食画折分 |

**操作:**点**谷色**再点**区域**。

> 💡 **打法:**① **先扫一遍淡影**,心里分好四色;② 红豆热、绿豆鲜,配色**看图案气质**;③ 撒错**不损谷粒**,色对就贴;④ 二三幅**区域更多**,眼要更尖;⑤ 三幅装框,**粮食店都来订门面画**!

**结算:**画作进度、撒对数、本局得分、历史最高分、已玩局数。
