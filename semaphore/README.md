| 元素 | 效果 |
|---|---|
| 🚩 双旗 | 左旗定组,右旗定字母 |
| 📖 小抄 | 本词字母对照提示 |
| 🔤 单词 | SUN/MAP/KEY 等常用词 |
| ❤️ 容错 | 三颗心,扣完为止 |

**操作:****点选项**(键盘 **1-4**)作答。
