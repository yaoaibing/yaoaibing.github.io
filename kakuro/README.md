# 数和迷阵 (🔢 数和迷阵 · 行列求和)

> 分类:**密码破译** · 入口:/kakuro/ · 免费在线 · 手机即点即玩

**目标:**数和逻辑:3x3 迷阵,从 1-9 **不重复选 3 个数**填入,使**行和与列和都等于目标值**;六阵递进,确认后判定。

| 元素 | 效果 |
|---|---|
| 🔢 数字池 | 1-9 各一个,选 3 个 |
| ➡️ 行目标 | 右侧显示每行目标和 |
| ⬇️ 列目标 | 底部显示每列目标和 |
| ✅ 确认 | 行列全对破阵 |
| 📈 计分 | 每阵 350 - 尝试 x50 |

**操作:****点数字池**选数填入,**点格子撤销**;选满后**确认**(空格)。

> 💡 **打法:**① 先看<b>和最大的行</b>,配最大的数字组合;② 行目标和列目标<b>必须同时满足</b>,交叉验证;③ 每个数只能用一次,<b>总和 45 恒定</b>,核算是否吻合;④ 三盘组合只有有限种,**穷举也行**;⑤ 尝试次数扣分,<b>心算确认再提交</b>!

**结算:**破阵阵数、尝试次数、本局得分、历史最高分、已玩局数。
