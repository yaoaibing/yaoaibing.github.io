# 打马格棋 (♟️ 打马格棋 · 一骰一骑)

> 分类:**对战棋牌** · 入口:/dama/ · 免费在线 · 手机即点即玩

**目标:**掷点行棋:**择马分点**,三骑争先。

| 元素 | 效果 |
|---|---|
| ♟️ 棋盘 | 六十格跑道 |
| 🎲 掷骰 | 一点到六点 |
| 🐎 三骑 | 派点行进 |
| ⚔️ 对手 | 三骑同样跑 |
| 🏆 结算 | 打马折分 |

**操作:**点屏**掷骰**,再**点马**行进。

> 💡 **打法:**① **点数派给谁**是全部学问,均衡还是突前要想清;② 对手**快过线就拼一人**,田忌赛马的思路;③ 每步**都加十分**,走得稳分也厚;④ 落后别慌,**骰子面前人人平等**;⑤ 三骑先至,**易安居士都赞你懂打马**!

**结算:**行棋回合、领先格数、本局得分、历史最高分、已玩局数。
