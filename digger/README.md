# 地心探险 (🚜 地心探险 · 挖挖挖)

> 分类:**街机动作** · 入口:/digger/ · 免费在线 · 手机即点即玩

**目标:**驾驶钻地车在网格地层里**挖土移动**,收集金矿/宝石/能量块;岩石不可挖,毒气扣能量。点**回地表**瞬移回地面并自动卖掉载货换分与能量;能量归零结束,已卖矿总价就是成绩。越深矿越值钱!

| 元素 | 效果 |
|---|---|
| 🚜 挖掘 | 点画面方向或键盘方向键,挖土前进 |
| 💎 矿物 | 金矿 30,宝石 80,能量块 +25 能量 |
| 🪨 岩石 | 不可挖,只能绕行 |
| ☠️ 毒气 | 碰到 -15 能量,深层数量变多 |
| ⏫ 回地表 | 卖掉载货,能量补满,再来一趟 |

**操作:**点画面**四个方向**或键盘方向键挖掘;**回地表**卖矿补给;**新局**重开。能量随移动缓慢消耗,规划好路线再深挖!

> 💡 **打法:**① 开局先垂直往下挖,浅层矿少但胜在安全;② 能量<b>剩 30</b> 就要考虑回程,别贪最后一颗;③ 宝石只在深层出,看到必拿;④ 毒气颜色发绿,隔一格挖过去就安全;⑤ 回地表是免费的"传送",回程路线不用规划,放心往深了走。

**结算:**最大深度、卖矿总收入、本局得分(总收入)、往返趟数、历史最高分、已玩局数。
