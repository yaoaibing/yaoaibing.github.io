**目标:**序列连招:**看谱跟招四式**,五套递增。

| 元素 | 效果 |
|---|---|
| 🗡 四式 | 刺撩挂云 |
| 👀 演示 | 逐式高亮 |
| ✌️ 跟招 | 按序点按 |
| ⚡ 断招 | 重来 |
