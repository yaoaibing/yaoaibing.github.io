# 洗车房 (🚗 洗车房 · 泡泡解压)

> 分类:**解压休闲** · 入口:/washcar/ · 免费在线 · 手机即点即玩

**目标:**按住拖动用海绵**擦掉车身泥点**,洁净度到 **93%** 自动交车;越快加分越多(100 + 速度奖励),连洗 5 辆不同配色的车,无失败机制。

| 元素 | 效果 |
|---|---|
| 🧽 海绵 | 按住出现,拖到哪擦到哪 |
| 🟤 泥点 | 擦过即消失,带起小泡泡 |
| ✨ 交车线 | 洁净 93% 触发星光结算 |
| ⚡ 速度分 | 每提前 1 秒 +4,上限 120 |
| 🚙 五连洗 | 5 辆车配色不同,泥点布局随机 |

**操作:****按住拖动**擦车即可,松手休息随时继续;擦完一辆自动进入下一辆。适合单手躺玩!

> 💡 **打法:**① <b>打大圈</b>比来回蹭覆盖率高,先大圈后补漏;② 泥点分布随机,先擦车身<b>下半部分</b>再补车顶;③ 泡泡是擦洗的痕迹反馈,跟着新泡泡走就不会漏;④ 洁净度显示在车底,90% 出头时找<b>漏网小泥点</b>;⑤ 无失败无计时压力,当白噪音玩,别赶!

**结算:**完成辆数、本局得分(每辆 100 + 速度奖励)、历史最高分、已玩局数。
