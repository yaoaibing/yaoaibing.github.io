# 峡谷摆荡 (🧗 峡谷摆荡 · 荡绳飞人)

> 分类:**街机动作** · 入口:/swing/ · 免费在线 · 手机即点即玩

**目标:**抓着绳索像**钟摆**一样荡,在合适的时机松手飞出去,越过一道道峡谷。落地自动抓住下一个锚点,能荡多远荡多远(50 单位=1 米)。

**操作:**点屏幕 / `空格`**松手**(只有这一个操作!)。飞行途中靠近金锚点会**自动抓住**开始下一荡;落进峡谷缝隙或坠出屏幕即结束。

> 💡 **物理要点:**① 钟摆在**最低点速度最大**——在荡向前方的最低点附近松手,飞得最远;② 过早松手(还在上升段)飞不高,过晚(已开始回摆)会往回飞;**感觉身体开始下沉时**松手就对了;③ 荡的幅度每荡一轮会积累一点,第一次荡不高很正常,先用小荡找手感;④ 落地别慌,自动抓锚后有 0.5 秒缓冲再起荡;⑤ 50 米内是热身,100 米算上手,200 米+是Timing大师。

**结算:**荡出的距离(米)、历史最远。
