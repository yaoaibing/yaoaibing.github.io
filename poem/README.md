# 诗词填空 (🎋 诗词填空 · 诗意人生)

> 分类:**烧脑益智** · 入口:/poem/ · 免费在线 · 手机即点即玩

**目标:**给出名句**上句**,从四个选项里选出正确的下句。题库 45 组课本级名篇(李白/杜甫/王维/苏轼/陆游…)。3 颗心容错,每题 12 秒。

**操作:**点选项或按 `1``2``3``4`。答对 +100 起连对滚分;答错/超时 -1 心 -30 分。选项是**别的诗的下句**,最容易背串。

> 💡 **对诗要点:**① 先判断上句的**尾字平仄和意境**,下句通常对仗(明月对清风、千山对万水);② 名句的"接续感"很強——读上句时心里默念下句,顺口的就是答案;③ 排除法:明显**意境不符**的先划掉(写春天的诗接不出大漠孤烟);④ 李白/杜甫的句子最常考,先把课本名篇过一遍;⑤ 三星线:一局对上 30 句。

**结算:**答对句数、最大连对、总得分、历史最高分。
