# 排箫叠韵 (🎶 排箫叠韵 · 一管一音)

> 分类:**音乐节奏** · 入口:/paixiao/ · 免费在线 · 手机即点即玩

**目标:**按谱点管:**圈亮即吹**,三曲连环。

| 元素 | 效果 |
|---|---|
| 🎶 排箫 | 长短五管 |
| 👆 点管 | 照谱吹音 |
| 🌀 连吹 | 越连越厚 |
| ⚠️ 吹岔 | 该音重来 |
| 🏆 结算 | 吹箫折分 |

**操作:**点**金圈指定的管**。

> 💡 **打法:**① 金圈**亮哪根吹哪根**,别抢拍;② 连吹**越连越厚**,错一音清零;③ 曲子**越吹越长**,第九管别看花眼;④ 吹岔**该音重来**,不丢进度;⑤ 三曲吹罢,**山风都跟着你的调子走**!

**结算:**吹箫乐句、连吹数、本局得分、历史最高分、已玩局数。
