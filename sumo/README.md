# 相扑推挤 (🤼 相扑推挤 · 土俵之战)

> 分类:**街机动作** · 入口:/sumo/ · 免费在线 · 手机即点即玩

**目标:**圆形土俵上一人对多人的物理推挤:**拖动屏幕瞄准松手冲刺**,或用「冲撞」短爆把对手顶出圈外;自己滑出圈线少一条命并回到中心,清空一圈进入下一回合(对手增至 5 人),推出计分。

| 元素 | 效果 |
|---|---|
| 🤼 质量 | 体型越大撞得越远,小心被反顶 |
| 💥 冲撞 | 1.5 秒冷却的爆发推 |
| 🎯 瞄准 | 按住拖动定方向,松手出发 |
| ⭕ 出圈 | 对手出圈 +100,自己出圈扣命 |
| 🏁 结束 | 三次踩出圈即止步 |

**操作:****拖动瞄准松手**冲刺,「冲撞」短爆;**重来**重开。别在圈边对撞,借对手的身体把他顶出去!

> 💡 **打法:**① 站<b>圆心</b>等对手靠近,别追出去;② 两个对手贴在一起时,撞外侧那个,内侧会被一起带飞;③ 冷却期靠走位躲,别硬碰;④ 高回合先<b>把大的引到圈边</b>再推;⑤ 自己贴线时,反向轻推一步回中心!

**结算:**推出人数、撑到回合、本局得分(推出 x100 + 回合 x250)、历史最高分、已玩局数。
