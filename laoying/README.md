**目标:**方向格挡:**鹰扑左挡左扑右挡右**,漏挡丢鸡;45 秒守护。

| 元素 | 效果 |
|---|---|
| 🦅 盘旋 | 随机起扑 |
| 👈 预兆 | 半秒方向提示 |

| 🏆 结算 | 保鸡越多越强 |
