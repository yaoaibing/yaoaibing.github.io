# 攀岩高手 (🧗 攀岩高手 · 绝壁向上)

> 分类:**解压休闲** · 入口:/climb/ · 免费在线 · 手机即点即玩

**目标:**交替伸手上抓:**点下一个岩点**让空闲的手抓过去,距离越远耗体力越多;红色是休息点回复体力;体力耗尽或抓空即坠落,高度就是分数。

| 元素 | 效果 |
|---|---|
| 🧗 抓点 | 空闲的手点哪个岩点就抓哪个 |
| ⚡ 体力 | 按距离消耗,休息点回满 |
| 🔴 休息点 | 红色岩点,战略资源 |
| 💀 坠落 | 体力空/抓空即结束 |
| 🏁 计分 | 爬升高度 x10 |

**操作:****点岩点**抓握;**重爬**立刻重开。规划路线:远处的好点未必现在够得着!

> 💡 **打法:**① 优先走<b>休息点</b>连成的路线;② 别 always 扑最远的点,距离越远体费越高;③ 体力低于 30 时下一个点必须是红的;④ 左右交替上爬比竖直冲刺省力;⑤ 手别抖,点错岩点直接摔!

**结算:**高度、抓点次数、休息次数、本局得分(高度 x10)、历史最高分、已玩局数。
