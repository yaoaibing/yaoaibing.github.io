# 快递柜员 (📪 快递柜员 · 格子管理)

> 分类:**模拟经营** · 入口:/locker/ · 免费在线 · 手机即点即玩

**目标:**柜格管理:客户单据给 **字母+数字坐标**,在 4x5 柜机里**点对格子**入柜;放错 -20、超时 -30,已占用柜格不能放,60 秒结算。

| 元素 | 效果 |
|---|---|
| 📪 柜机 | 4 列 x 5 行 = 20 格 |
| 🏷️ 单据 | 字母行 + 数字列,如 C4 |
| ⏳ 耐心 | 6.5 秒超时投诉 -30 |
| 📦 占用 | 满格放件会弹回 |
| 🔄 取件 | 已占格会随机被取走腾空 |

**操作:****点对应柜格**;**字母找行、数字找列**。

> 💡 **打法:**① 先横后纵:找字母行,再数数字列;② **连对是复利**,稳比快值钱;③ 放错也占格——<b>相当于给自己加障碍</b>;④ 取件会随机腾格,<b>被占的柜随时可能解放</b>;⑤ 最后 10 秒节奏最紧,**提前扫下一张单据**!

**结算:**入柜件数、放错次数、本局得分、历史最高分、已玩局数。
