# 团购定价 (🛒 团购定价 · 一价定乾坤)

> 分类:**拍卖竞价** · 入口:/groupbuy/ · 免费在线 · 手机即点即玩

**目标:**定价博弈:每团随机成本,**调价看需求曲线**,开团结算(价-成本)x 销量;六团累计利润竞赛。

| 元素 | 效果 |
|---|---|
| 💰 成本 | 每团随机 10-35 |
| 📈 需求 | 价格越高人越少 |
| 📣 开团 | 销量带 ±7 随机 |
| 💎 定价 | 5-99 连续可调 |
| 🏆 结算 | 累计利润即分数 |

**操作:****◀ ▶** 调价(方向键),「**📣 开团**」结算(回车)。

> 💡 **打法:**① 先找曲线中段:**利润=价x人**,两头都是悬崖;② 成本 30+ 的团,**别恋战薄利**;③ 随机波动 ±7 人,**期望利润比单团运气重要**;④ 连亏两团说明**参考系错了**,回曲线中段重找;⑤ 最后一团**按峰值利润定价**,没有后顾之忧!

**结算:**定价、累计利润、本局得分、历史最高分、已玩局数。
