# 运河船闸 (🚢 运河船闸 · 闸门之间)

> 分类:**策略战棋** · 入口:/canallock/ · 免费在线 · 手机即点即玩

**目标:**分流调度:**点闸门放船**(每闸限 3),双闸并行有奖励;八闸次结算过闸量。

| 元素 | 效果 |
|---|---|
| 🚢 四船 | 小帆中船大船随机 |
| ⚖️ 限载 | 每闸最多 3 艘 |
| 💧 双闸 | 两闸都用 +15 |
| 🏁 结算 | 每艘 +20 |
| 🏆 评级 | 过闸 20 艘调度长 |

**操作:****点闸门**放船(键盘 **1/2**),点「**🌊 提闸**」开闸。

> 💡 **打法:**① **小船先派**,大船留着配对;② **两闸都非空**才有并行奖,别堆一闸;③ 大船挤一闸**照样放行**,但浪费了另一闸;④ 提闸前**数一数有没有漏船**;⑤ 八闸次,**过闸数就是硬指标**!

**结算:**过闸数、本局得分、历史最高分、已玩局数。
