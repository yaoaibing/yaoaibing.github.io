# 灯笼速递 (🏮 灯笼速递 · 一路红灯)

> 分类:**竞速赛车** · 入口:/lanternrow/ · 免费在线 · 手机即点即玩

**目标:**三道夜跑:自动加速,**切道**躲风口和柱子;灯笼三盏定胜负。

| 元素 | 效果 |
|---|---|
| 🏮 三道 | 左右点切或键盘 |
| 💨 风口 | 碰上灯灭 |
| ⚠️ 柱子 | 撞上灯灭 |
| 🏁 计分 | 距离+分 |
| 🏆 评级 | 300 米提灯人 |

**操作:****点巷道**切道(键盘 ← →)。

> 💡 **打法:**① **风口有烟雾提示**,提前变道;② **柱子是实体**,撞了就灭;③ 提灯**忽明忽暗**是常态,别慌;④ 三盏灯,**最后一盏别浪**;⑤ 距离就是分,**跑得越远越好**!

**结算:**滑行距离、本局得分、历史最高分、已玩局数。
