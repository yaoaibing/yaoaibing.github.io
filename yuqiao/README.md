**目标:**听音复奏:**渔问樵应**,六问递进。

| 元素 | 效果 |
|---|---|
| 🎣 渔歌 | 发问五音 |
| 👆 樵歌 | 照样应五音 |
| 🎶 问答 | 一长一长 |
