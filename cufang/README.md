# 酿醋晒醅 (🍶 酿醋晒醅 · 一缸一香)

> 分类:**模拟经营** · 入口:/cufang/ · 免费在线 · 手机即点即玩

**目标:**发酵节律:**翻晒相济**,四缸递进。

| 元素 | 效果 |
|---|---|
| 🍶 大缸 | 一缸一批 |
| 👆 翻晒 | 两钮任点 |
| ⏳ 日头 | 日落即验 |
| ⚠️ 欠火 | 酸度不满 |
| 🏆 结算 | 酿醋折分 |

**操作:****点翻醅攒香**,香足**点伏晒增酸**。

> 💡 **打法:**① **先翻两遍再晒**,闷醅晒不出酸;② 香气**别攒过九成五**,沤了就糟;③ 日头**倒计时盯着**,晒不完就白忙;④ 缸号越深**日头越短**,手要麻利;⑤ 四缸醋成,**打醋的队伍排到街尾**!
