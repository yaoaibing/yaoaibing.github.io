# 拉格朗日驻留 (🛰️ 拉格朗日驻留 · 引力天平)

> 分类:**太空导航** · 入口:/lagrange/ · 免费在线 · 手机即点即玩

**目标:**引力弹道:双体引力实时作用,**停在平衡区 2.2 秒**过关;撞星/漂出损一发探测。

| 元素 | 效果 |
|---|---|
| 🌍 双体 | 蓝星引力 2.6 倍 |
| ⚖️ 驻留区 | 虚线圈稳 2.2s |
| 🚀 三发 | 撞/漂即耗一发 |
| 📈 三站 | 平衡点逐站偏离 |
