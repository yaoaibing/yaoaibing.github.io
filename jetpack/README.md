# 火箭背包 (🚀 火箭背包 · 峡谷穿越)

> 分类:**街机动作** · 入口:/jetpack/ · 免费在线 · 手机即点即玩

**目标:**按住屏幕**喷火上升**,松手自然下坠,在收窄的峡谷中穿行;躲避岩柱与激光门,收集能量币(+30 并补燃料);撞上即坠毁,距离计分。

| 元素 | 效果 |
|---|---|
| 🚀 飞行 | 按住=上升推力,松手=重力下坠 |
| 🪨 岩柱 | 上下伸出的石柱,缝隙越来越窄 |
| ⚡ 激光门 | 第 500 米起出现,定期开关 |
| 🪙 能量币 | +30 分并回复燃料 |
| 🏁 结束 | 撞岩柱/激光/出界即坠毁 |

**操作:****按住屏幕**喷火,**松手**下坠(键盘空格同);**重飞**重开。手感是「点一下微调」而不是死按!

> 💡 **打法:**① 用<b>短点按</b>维持高度,长按必撞天花板;② 入门后先背板:岩柱缝隙的位置有规律;③ 激关门开合有节奏,等它变色的瞬间冲;④ 能量币多在险处,燃料充足时才去捡;⑤ 心态放平,这游戏死于手抖不死于难!

**结算:**距离、金币数、最高波次、本局得分(距离 x2 + 金币 x30)、历史最高分、已玩局数。
