# 滑索飞车 (🛒 滑索飞车 · 山谷快递)

> 分类:**街机动作** · 入口:/trolley/ · 免费在线 · 手机即点即玩

**目标:**滑索竞速:松闸俯冲加速、按住刹车减速;飞鸟随机出没撞上重创速度;四段滑索按速度与到站奖励结算。

| 元素 | 效果 |
|---|---|
| 🛑 刹车 | 按住减速,松开俯冲 |
| 🦅 飞鸟 | 撞上速度腰斩 -60 |
| 🏁 到站 | 速度越快奖励越高 |
| 📈 段位 | 四段逐渐更长 |
| ⚠ 结算 | 撞鸟 3 次出局 |

**操作:****按住「🛑 刹车」**减速,松手俯冲(空格同效)。

> 💡 **打法:**① 全速冲分高,但**鸟群前必须松闸**;② 鸟从上游来,**看到就提前半屏减速**;③ 到站前**不用收**,过站自动结算;④ 撞鸟后别急,**恢复到中速再冲刺**;⑤ 记住:**分是速度给的,命是刹车给的**!

**结算:**完成路段、撞鸟次数、本局得分、历史最高分、已玩局数。
