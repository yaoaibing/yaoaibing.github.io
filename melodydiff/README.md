# 旋律找错 (🎶 旋律找错 · 变了哪个音)

> 分类:**音乐节奏** · 入口:/melodydiff/ · 免费在线 · 手机即点即玩

**目标:**听辨记忆:四音旋律播放两遍,**第二遍有且只有一个音变化**,选出变化位置;音高在五声内级进,8 轮计分。

| 元素 | 效果 |
|---|---|
| 🎵 旋律 | 四音级进,似曾相识 |
| 🔁 重听 | 两遍随时重放 |
| 👉 定位 | 四选一指出变音 |
| 🔥 连对 | 每题 100 + 连对 x10 |
| 🏆 评级 | 连对 6 次金耳朵 |

**操作:****点选项**(键盘 **1-4**);「**🔁 重听**」重放两遍。

> 💡 **打法:**① **跟着第一遍哼出来**,第二遍跑调处自然别扭;② 重点听**旋律轮廓**:升了还是降了;③ 拿不准时对比**相邻两个音**,变化处最突兀;④ 重听不扣分,**听三遍是常规操作**;⑤ 别用眼睛盯着选项,**闭上眼更准**!

**结算:**连对、本局得分、历史最高分、已玩局数。
