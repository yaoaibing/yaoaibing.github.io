# 绕桩计时 (🏎️ 绕桩计时 · 卡丁车过桩)

> 分类:**竞速赛车** · 入口:/cone/ · 免费在线 · 手机即点即玩

**目标:**绕桩竞速:拖动卡丁车**在桩阵中穿行**;从两桩之间(62px 内)穿过 +50,撞桩记失误;桩阵逐渐密集,30 秒结算。

| 元素 | 效果 |
|---|---|
| 🔴 桩阵 | 从上往下滚动,间距随机 |
| 🏎️ 卡丁车 | 拖动走位,响应灵敏 |
| ✅ 过桩 | 距离桩 <62px 穿过得分 |
| 💥 撞桩 | 距离 <20px 碰撞 |
| 📈 密度 | 逐渐增加 |

**操作:****左右拖动**转向(方向键同效);靠近桩但**别碰**。

> 💡 **打法:**① **提前看桩位**别低头看车;② 桩间距大时<b>从正中过</b>,间距小时靠边;③ 撞桩后别慌,<b>回正再找下一个</b>;④ 漏桩不可怕,撞了才亏分;⑤ 最后 10 秒桩最密,**匀速直线**有时比乱转好!

**结算:**过桩数、漏桩数、撞桩数、本局得分、历史最高分、已玩局数。
