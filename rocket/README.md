# 水火箭 (🚀 水火箭 · 配比与压强)

> 分类:**建造物理** · 入口:/rocket/ · 免费在线 · 手机即点即玩

**目标:**双参数发射:每发有随机**水量甜点**与**压强甜点**,点滑条调水、按住充气松手升空;高度按双偏差结算,五发累计计分。

| 元素 | 效果 |
|---|---|
| 💧 水量 | 甜点 35-60%,偏差重罚 |
| ⛽ 压强 | 甜点 72-90,爆压减半 |
| 📐 高度 | 甜点越高基础越猛 |
| 🎯 记忆 | 上一发偏差是下一发线索 |
| 🏆 评级 | 420m 水箭工程师 |

**操作:****点水量滑条**(◀▶微调),**按住「发射」**充气,**松手**升空。

> 💡 **打法:**① 上一发**记下高度与偏差**,下一发反向修;② 水量**一次调到位**,别微调浪费时间;③ 压强**宁高勿低**,90 上下最甜;④ 连续翻车就**回归中位 50%** 重新找感觉;⑤ 最后一发放手搏,**甜点猜对血赚**!

**结算:**最佳高度、发射次数、本局得分、历史最高分、已玩局数。
