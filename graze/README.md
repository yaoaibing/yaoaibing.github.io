# 弹幕地狱 (🌀 弹幕地狱 · 极限擦弹)

> 分类:**街机动作** · 入口:/graze/ · 免费在线 · 手机即点即玩

**目标:**按住屏幕**拖动小白点**,在越来越密的弹幕中求生:每秒 +10 分,子弹贴身擦过 +5 分,被击中一次即结束。时间是朋友也是敌人,弹幕永不停歇!

| 元素 | 效果 |
|---|---|
| 🌀 移动 | 按住任意处拖动,小白点跟随手指 |
| ✨ 擦弹 | 子弹进入贴身圈 +5 分,不碰到才算 |
| 💥 击中 | 碰到任何子弹即结束 |
| 📈 波次 | 每 10 秒弹幕量+波速上一个台阶 |
| 🏁 结束 | 被击中即结算,时间+擦弹=总分 |

**操作:****按住拖动**移动小白点(全屏跟手);**重来**立刻重开。手指按在点的下方一点,视野更清楚!

> 💡 **打法:**① 别贪擦弹,擦弹圈比碰撞圈大<b>一点点</b>,手要稳;② 弹幕从上方和两侧来,贴<b>下边缘</b>走位最安全;③ 预判弹幕的缝隙,提前移动比临时躲快;④ 每 10 秒一波更猛,听到提示音就往空区靠;⑤ 手指出汗前垫张纸巾,这不是玩笑。

**结算:**生存时间、擦弹次数、最大同屏弹幕、本局得分(时间 x10 + 擦弹 x5)、历史最高分、已玩局数。
