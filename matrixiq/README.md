# 图形推理 (🧩 图形推理 · 九宫问号)

> 分类:**烧脑益智** · 入口:/matrixiq/ · 免费在线 · 手机即点即玩

**目标:**矩阵推理:3×3 图形按**形状/数量/填充**三条规则渐变;选出问号处图形;错三次结束。

| 元素 | 效果 |
|---|---|
| ⭕ 形状 | 圆/三角/方横变 |
| 🔢 数量 | 1-4 个竖变 |
| ◐ 填充 | 实/空/半循环 |
| ❤️ 容错 | 三颗心 |
| 🏆 评级 | 八题全对推理达人 |

**操作:****点选项**(键盘 **1-4**)作答。

> 💡 **打法:**① **先横着比一行**:形状怎么换的;② **再竖着比一列**:数量加了几;③ 填充实/空/半,**按循环猜下一位**;④ 两个选项都像?**挑只破坏一条规律的**;⑤ 卡住就**从第一行重新看**,别钻牛角尖!

**结算:**连对、本局得分、历史最高分、已玩局数。
