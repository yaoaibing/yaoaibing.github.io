# 国际跳棋 (♟️ 国际跳棋)

> 分类:**对战棋牌** · 入口:/checkers/ · 免费在线 · 手机即点即玩

**目标:**把对方的子吃光,或者让对方无子可动。8×8 棋盘,双方各 12 枚,只有深色格能走。
| 动作 | 规则 |
|---|---|
| 走子 | 兵只能**斜向前**走一格到空格
吃子 | 跳过相邻敌子落到其后的空格,**只能斜向前**吃 |
| 连吃 | 吃完还能继续吃就**必须继续**,一回合内连跳到底
升王 | 兵走到对方底线变**王**,王可以斜向四个方向走和吃 |

**强制吃子:**只要存在能吃子的走法,你就**必须吃**,不能走别的——这是国际跳棋的核心规则,也是新手最容易忽略的一条。

> 💡 **下法要点:**① 吃子前先数**"吃完会不会被反吃"**,送子比不吃更亏;② 连吃路线要算到底,有时候吃三颗不如吃一颗保住阵型;③ 尽量把子**成对贴着走**,单子容易被连吃;④ 早升王基本等于赢,底线要守住;⑤ 被强制吃子逼着走的时候,选那条吃最少但位置最好的。
