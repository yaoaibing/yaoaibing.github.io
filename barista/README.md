# 拉花咖啡 (☕ 拉花咖啡 · 描线艺术)

> 分类:**模拟经营** · 入口:/barista/ · 免费在线 · 手机即点即玩

**目标:**描线精度游戏:奶泡上有**虚线目标路径**(心形/叶形/波浪),从起点**按住描到终点**;平均偏差越小得分越高,中途松手即结算,五杯一轮。

| 元素 | 效果 |
|---|---|
| ☕ 五杯 | 心形/叶形/波浪三样图轮流 |
| ✍️ 描线 | 偏差计入,贴线走分高 |
| 📏 判定 | 沿线 ±22% 内算描过 |
| 🚫 松手 | 中途松手按已描部分结算 |
| 🏆 计分 | 500 - 平均偏差 x8 |

**操作:****从起点按住描到终点**,中途别松手;**手抖**是唯一的敌人!

> 💡 **打法:**① 描线<b>分段呼吸法</b>:描两秒松口气再来?不行——<b>松手即结算</b>,所以下手前稳住呼吸;② 心形要<b>两个圆弧一尖角</b>,转折处放慢;③ 叶形是二倍频曲线,<b>摆动节奏均匀</b>才对称;④ 波浪匀速横移+正弦纵移,<b>斜握姿势更稳</b>;⑤ 平均偏差 20 内就是 500 满分段,心形最难,放最后一杯攒手感!

**结算:**完成杯数、平均偏差、本局得分(500 - 偏差 x8)、历史最高分、已玩局数。
