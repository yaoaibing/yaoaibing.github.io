# 八音盒 (🎶 八音盒 · 发条上的旋律)

> 分类:**音乐节奏** · 入口:/musicbox/ · 免费在线 · 手机即点即玩

**目标:**匀速演奏:每转发条一圈拨响一音,**转速偏离理想值即跑调**;整段均准 70% 过关。

| 元素 | 效果 |
|---|---|
| 🎶 梳齿 | 一圈拨一音 |
| 🔄 发条 | 按住转动 |
| 🎯 音准 | 转速表指针看齐 |
| ❤️ 容错 | 整段跑调 -1♥ |
| 🏆 评级 | 八段全奏调音师 |

**操作:****按住「🔄 按住转」**(空格)转动发条。

> 💡 **打法:**① **先听样曲**,心里有个速度;② 转速表**指针贴住中线**,快了松一点;③ 跑调一两音不慌,**整段均准 70% 就行**;④ 曲越长越难,**匀速比手速重要**;⑤ 闭眼转,**耳朵会带着手**!

**结算:**奏完曲数、音准、本局得分、历史最高分、已玩局数。
