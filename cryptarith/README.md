> 分类:**烧脑益智** · 入口:/cryptarith/ · 免费在线 · 手机即点即玩

**目标:**数字推理:**填洞验算**,四题连环。

| 元素 | 效果 |
|---|---|
| 🧩 虫洞 | 每题三个 |
| 🔢 数键 | 零到九 |
| ➕ 竖式 | 右对齐进位 |
| ✅ 提交 | 算平才给分 |
| 🏆 结算 | 解算折分 |

**操作:**点**数字键**填洞,再点**提交验算**。

> 💡 **打法:**① **先填个位**,进位倒着往上推;② 一处填错**满盘算不平**,提交前扫一遍;③ 连对**有加成**,稳一题是一题;④ 首位洞**不会是零**,排除一个数;⑤ 四题全平,**钱庄把算盘珠子送你一串**!

**结算:**解题题号、已填虫洞、本局得分、历史最高分、已玩局数。
