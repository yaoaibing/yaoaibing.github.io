# 图形计算 (📐 图形计算 · 边边角角)

> 分类:**学习教育** · 入口:/geocalc/ · 免费在线 · 手机即点即玩

**目标:**几何速答:长方形/三角形/圆**四选一**;连对滚分,45 秒结算。

| 元素 | 效果 |
|---|---|
| ▭ 长方形 | 面积=长×宽 |
| 🔺 三角形 | 面积=底×高÷2 |
| ⭕ 圆 | 面积=πr²(π=3.14) |
| 🔥 连对 | 每题 +30+连对×6 |
| 🏆 评级 | 连对 12 几何小能手 |

**操作:****点选项**(键盘 **1-4**)作答。

> 💡 **打法:**① 长方形**先背长×宽**,周长是两倍长宽和;② 三角形**乘完除 2**,别忘;③ 圆先算 **r×r** 再乘 3.14;④ 选项差距大时**估算锁定范围**;⑤ 答错想公式,**下一题赚回来**!

**结算:**连对、本局得分、历史最高分、已玩局数。
