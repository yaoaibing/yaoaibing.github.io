# 冒险跳跳 (🍄 冒险跳跳 · 旗杆之巅)

> 分类:**街机动作** · 入口:/jumpman/ · 免费在线 · 手机即点即玩

**目标:**横版平台闯关:底部按钮**左右移动与跳跃**,踩扁敌人、收集金币、躲开尖刺,摸到旗杆过关。4 个手工关卡,3 条命。

| 元素 | 效果 |
|---|---|
| 🍄 移动 | ◀▶ 按钮,↑ 跳跃 |
| 👾 敌人 | 来回巡逻的蘑菇怪,踩扁得分 |
| 💰 金币 | 收集 +20 分 |
| ⚠️ 危险 | 尖刺/敌人侧面碰撞 -1 命 |
| 🚩 过关 | 摸到旗杆进入下一关 |

**操作:**底部 **◀ ▲ ▶** 三键(键盘 ←↑→ 同理);**重开**回到第 1 关。掉出屏幕也会 -1 命!

> 💡 **打法:**① 敌人<b>背对</b>你时再靠近,踩它个正着;② 金币都放在「顺路但有点险」的位置,量力而行;③ 尖刺关跳之前先看清落点;④ 掉坑比敌人更危险,离边缘远一点;⑤ 第 4 关的旗杆前有一排连续刺,助跑跳要满力!

**结算:**到达关卡、金币总数、剩余生命、本局得分(金币 x20 + 关卡 x300)、历史最高分、已玩局数。
