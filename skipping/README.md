# 打水漂 (🪨 打水漂 · 石上七漂)

> 分类:**体育竞技** · 入口:/skipping/ · 免费在线 · 手机即点即玩

**目标:**两段投掷:锁角度(20°-32° 黄金区)+锁力度,石子触水按**剩余动能概率弹跳**,速度衰减直至沉底;四投取最佳。

| 元素 | 效果 |
|---|---|
| 📐 角度 | 绿区 20°-32° 弹得远 |
| 💪 力度 | 越高初速越快 |
| 🌊 弹跳 | 每次跳消耗动能 |
| 💧 沉底 | 力度或角度不足 |
| 🏆 评级 | 7 连漂水上漂! |

**操作:**点「**🪨 出手**」或**空格**:一次锁角度,一次锁力度。

> 💡 **打法:**① **低角度+满力度**最容易连漂;② 石头越飘越慢,**沉底很正常别灰心**;③ 角度扫动快,**在绿区中间出手**;④ 每投独立,**前三投试出手感**;⑤ 传说 7 漂是极限,**打出来截图炫耀**!

**结算:**最佳连漂数、总漂数、本局得分、历史最高分、已玩局数。
