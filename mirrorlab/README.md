# 镜屋激光 (🪞 镜屋激光 · 一束定局)

> 分类:**寻宝推理** · 入口:/mirrorlab/ · 免费在线 · 手机即点即玩

**目标:**光学谜题:6×6 镜屋,点击循环空/⟍/⟋ 镜子,**发射追踪光路**;命中右侧目标行过关,四关递进。

| 元素 | 效果 |
|---|---|
| 🪞 镜子 | 空 → ⟍ → ⟋ 循环 |
| 🔴 发射 | 实时画出光路 |
| 🎯 目标 | 右侧亮条所在行 |
| 🌫️ 出界 | 光路作废可重来 |
| 🏆 计分 | 每关 200 + 关卡奖励 |

**操作:****点格子**换镜,「**🔴 发射**」(空格)。

> 💡 **打法:**① 口诀:**⟍ 把光转右下,⟋ 转右上**(迎面看);② 先摆**倒数第一面镜**:它决定光往哪个方向出右墙;③ 入口行是起点,**从左往右倒推**最容易;④ 光路图是免费情报,**多发几次探地形**;⑤ 镜子放在目标行同列,**最后一跳必是垂直**!

**结算:**通过关卡数、镜子数、本局得分、历史最高分、已玩局数。
