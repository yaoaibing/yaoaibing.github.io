# 炮王争霸 (💥 炮王争霸 · 抛物线对决)

> 分类:**街机动作** · 入口:/cannon/ · 免费在线 · 手机即点即玩

**目标:**回合制炮术对决:从己方炮台**往后拖拽**瞄准(方向决定角度,拖距决定力度),松手开炮。炮弹受**重力与随机侧风**影响,落点越近伤害越高。先把对方血量打到 0 的一方获胜,共三档 AI。

| 元素 | 效果 |
|---|---|
| 💥 拉弹 | 按住炮台向后拖,虚影显示预估弹道 |
| 🌬️ 风 | 每回合随机侧风,HUD 显示风力箭头 |
| 🎯 伤害 | 直接命中 40,近爆 20,远爆 10 |
| 🤖 AI | 新手手抖,高手几乎百发百中 |
| 🏁 胜负 | 敌方血量先归零者胜,剩血越多分越高 |

**操作:**按住屏幕**向后拖**瞄准,松手发射;**难度**三档,**新局**重开。电脑回合自动开炮。

> 💡 **打法:**① 逆风要<b>抬高角度</b>,顺风可以压平直射;② 记住上一炮的落点,只微调不要每次都大改;③ 直接命中伤害是近爆的两倍,值得多试两炮;④ 高抛弹道(约 60 度)在强风天更稳;⑤ 新手 AI 会瞄你的旧位置,别连续站在同一个地方挨打。

**结算:**胜负、剩余血量、发射炮数、命中率、难度、本局得分(胜 500 + 剩血 x4)、历史最高分、已玩局数。
