# 数列推理 (🔢 数列推理 · 下一个数)

> 分类:**烧脑益智** · 入口:/sequence/ · 免费在线 · 手机即点即玩

**目标:**60 秒限时答题:屏幕给出一串数字,**从 4 个选项中选出下一个数**;答对 +100 连对加成,答错 -30。题型覆盖等差/等比/平方/斐波那契/交替双序列,越往后越难。

| 元素 | 效果 |
|---|---|
| 🔢 题面 | 5-6 个数字,问号处待填 |
| 👉 选项 | 4 选 1,点选即判 |
| ✅ 得分 | 对 +100 x连击,错 -30 |
| 🧠 题型 | 等差/等比/平方/斐波那契/交替 |
| ⏱ 限时 | 60 秒,答对微量加时 |

**操作:****点选项**作答;**重开**重开一轮。做错不扣命,只扣分,大胆试!

> 💡 **打法:**① 先算<b>相邻差值</b>,差值恒定是等差;② 差值也等差,就是平方或二阶等差;③ 后项=前两项之和,斐波那契实锤;④ 一升一降交替,是双序列隔项看;⑤ 选项里有 0 或负数多半是干扰,相信正数规律!

**结算:**答对题数、最大连对、最高题型、本局得分、历史最高分、已玩局数。
