# 转盘对色 (💠 转盘对色 · 同心归位)

> 分类:**烧脑益智** · 入口:/rings/ · 免费在线 · 手机即点即玩

**目标:**三层同心圆环各含一组颜色序列:点环**旋转一格**,让每条辐射线上三层颜色一致即过关;步数越少分越高,10 关环数与颜色数递增。

| 元素 | 效果 |
|---|---|
| 💠 旋转 | 点某个环,该环顺时针转一格 |
| 🎨 对齐 | 每条辐条上三层同色即成 |
| 🔁 计步 | 每次旋转计 1 步 |
| 🧠 参考 | 显示打乱步数(可反推) |
| 🏁 过关 | 全部对齐自动下一关 |

**操作:****点圆环**旋转;**重乱**重新打乱,**新一关**跳关重抽。先看哪个环打乱得最少,先定住它!

> 💡 **打法:**① 从<b>外环</b>开始:它的扇区大最好认;② 记住每个环的颜色序列,旋转是循环的;③ 中环转的时候会打乱已对齐的外环?不会!环是独立的,放心转;④ 打乱步数=最少还原步数(逆向操作);⑤ 全对齐前最后一步最容易手滑,深呼吸!

**结算:**通关数、总步数、各关成绩、本局得分(每关 300 - 超额步 x15)、历史最高分、已玩局数。
