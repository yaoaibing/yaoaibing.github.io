# 牵引回收 (🛸 牵引回收 · 光束捞陨石)

> 分类:**太空导航** · 入口:/tractor/ · 免费在线 · 手机即点即玩

**目标:**光束回收:点击陨石发射牵引波,**自动拉向最近舱口**入舱 +50;未牵引陨石撞船 -1 护盾,3 盾耗尽结算;60 秒时限。

| 元素 | 效果 |
|---|---|
| ☄️ 陨石 | 三向漂入,速度渐快 |
| 🔵 光束 | 点中即锁定,自动导航 |
| 🛸 舱口 | 左右两个,就近入舱 |
| 💥 撞船 | -1 护盾、-40 分 |
| 🏆 评级 | 回收 18 块回收站之王 |

**操作:****点陨石**牵引。

> 💡 **打法:**① **离船近的先拉**,远的让它漂;② 光束会持续拉,**点过就别再点**;③ 两个舱口**自动选近的**,不用操心路线;④ 护盾剩 1 时**只拉大块头**,小石头让它飞;⑤ 最后 10 秒陨石最密,**守住船前扇区**!
