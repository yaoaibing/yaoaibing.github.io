# 骰子金字塔 (🧊 骰子金字塔 · 越摞越险)

> 分类:**骰子冒险** · 入口:/dicepyramid/ · 免费在线 · 手机即点即玩

**目标:**推运叠塔:掷骰**逐层向上摞**(上层 ≥ 下层),压错全塌;可花 5 分重掷;七层封顶大奖,70 秒结算。

| 元素 | 效果 |
|---|---|
| 🧊 摞上 | 上层 ≥ 下层才稳 |
| 🎲 重掷 | -5 分换当前骰 |
| 💥 塌塔 | 压错清零重来 |
| 🏆 封顶 | 7 层 +300 |
| 🏆 评级 | 7 层金字塔法老 |

**操作:**点「**🧊 摞上**」或「**🎲 重掷**」(空格/r)。

> 💡 **打法:**① **1-3 点直接重掷**,别心疼 5 分;② 6 点是**万能顶层**,留到关键时刻;③ 高层压低层是铁律,**塔越高容错越低**;④ 塌了不慌,**重头再来时间还够**;⑤ 最后 10 秒,**能摞就摞别保守**!

**结算:**当前层数、最佳层数、本局得分、历史最高分、已玩局数。
