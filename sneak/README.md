# 潜行大盗 (🥷 潜行大盗 · 灯下黑手)

> 分类:**街机动作** · 入口:/sneak/ · 免费在线 · 手机即点即玩

**目标:**按住**拖动小偷**移动,避开守卫来回扫动的**视线锥**,摸到宝箱过关;被发现记 1 次警报,3 次警报行动失败。10 关守卫越来越多。

| 元素 | 效果 |
|---|---|
| 🥷 移动 | 按住拖动,小偷跟手 |
| 👁️ 视线锥 | 扇形区域,进入即被发现 |
| 📦 宝箱 | 碰到即过关 |
| 🚨 警报 | 被发现 +1,3 次失败 |
| 🏁 通关 | 10 关全部得手 |

**操作:****按住拖动**移动(键盘方向也行);**重来**复位本关。守卫转身时有盲区,那就是你的窗口!

> 💡 **打法:**① 守卫<b>背对</b>的瞬间加速通过,别贪慢走;② 视线锥有边界,贴着边界外走最安全;③ 先观察两轮巡逻节奏再动身;④ 被发现后守卫会加速,重开本关更稳;⑤ 最后关的宝箱往往在最深处,耐心第一!

**结算:**通关数、警报次数、总用时、本局得分(过关 x150 - 警报 x50)、历史最高分、已玩局数。
