# 陀螺对战 (🌀 陀螺对战 · 竞技场争锋)

> 分类:**街机动作** · 入口:/spintop/ · 免费在线 · 手机即点即玩

**目标:**竞技场内两陀螺对决:**拖动**控制己方陀螺,撞击消耗对手旋转值,把它**撞出圆环**直接获胜;双方旋转值持续衰减,先归零者输。三档 AI。

| 元素 | 效果 |
|---|---|
| 🌀 移动 | 按住拖动,陀螺跟手 |
| ⚔️ 撞击 | 撞击双方都掉旋转,速度越快掉越多 |
| 💥 出界 | 对手被撞出圆环直接获胜 |
| 📉 衰减 | 旋转值每秒自然下降 |
| 🏁 胜负 | 对方归零/出界即胜 |

**操作:****按住屏幕拖动**移动(键盘方向也行);**难度**三档,**新局**重开。撞击后双方弹开,借力打力!

> 💡 **打法:**① 别追着撞,绕到对手<b>身后</b>再发力撞;② 自己快归零时贴边绕圈,拖时间等它先停;③ 把对手往<b>圈边</b>压,出场判负最爽;④ 撞击是双刃剑,高速对撞前先看自己旋转值;⑤ 学徒局随便撞,宗师局要预判走位!

**结算:**胜负、剩余旋转值、撞击次数、难度、本局得分(胜 500 + 剩余旋转 x4)、历史最高分、已玩局数。
