# 骰子贪心 (🐖 骰子贪心 · 先到一百)

> 分类:**骰子冒险** · 入口:/pigdice/ · 免费在线 · 手机即点即玩

**目标:**Pig 博弈:掷骰累积本轮池,**停**则入账换人,**1** 则清池换人;先到 100 分胜,AI 在 19-24 区间收手。

| 元素 | 效果 |
|---|---|
| 🎲 掷骰 | 2-6 入池,1 清池 |
| ✋ 停 | 池子入总分,换人 |
| 💥 风险 | 1 的概率 1/6 |
| 🤖 AI | 池到 19-24 就收 |
| 🏆 计分 | 胜 300 + 余分 |

**操作:**点「**掷骰**」或按**空格**;「**停**」入账(回车)。

> 💡 **打法:**① 池子到 **20 上下就收**,期望值开始倒挂;② 落后时**该贪就贪**,保守追不上;③ AI 收手区间 19-24,**你压到 18 靠频率赢**;④ 连续 3 把没 1,**下一把更可能出 1**(心理战别信邪);⑤ 终局前算分:**停可以赢,掷 1 必输**!

**结算:**双方总分、对局比分、本局得分、历史最高分、已玩局数。
