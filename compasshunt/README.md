# 罗盘寻宝 (🧭 罗盘寻宝 · 方位猎手)

> 分类:**寻宝推理** · 入口:/compasshunt/ · 免费在线 · 手机即点即玩

**目标:**方位推理:测向返回**曼哈顿距离与大致方位**;次数内挖中升级,关卡递增次数。

| 元素 | 效果 |
|---|---|
| 🧭 测向 | 方向+步数双信息 |
| 🎯 定位 | 两三点交出宝位 |
| 🦴 挖中 | +120+剩余×30 |
| 🗺️ 换图 | 每关宝箱换位 |
| 🏆 评级 | 三关全清领航员 |

**操作:****点格子**测向,推准后点格挖掘。

> 💡 **打法:**① **先点四角**,一次测向砍掉半张图;② 步数小的地方**直接圈十字**;③ 方向是「扇形」不精确,**用两测交点**;④ 记住测过的格子,**别重复浪费**;⑤ 关卡越高次数越多,**宝箱也更远**!

**结算:**寻宝数、关卡、本局得分、历史最高分、已玩局数。
