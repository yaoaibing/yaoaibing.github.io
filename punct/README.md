# 标点填空 (✒️ 标点填空 · 文从字顺)

> 分类:**学习教育** · 入口:/punct/ · 免费在线 · 手机即点即玩

**目标:**标点测验:句子填空处**四选一填标点**;陈述/疑问/并列/转折等 12 组句库,连对计分。

| 元素 | 效果 |
|---|---|
| 📝 句库 | 陈述/疑问/感叹/列举等 |
| ✒️ 标点 | 。,?!、:……—— 8 种 |
| 🔥 连对 | 每题 100 + 连对 x10 |
| ❌ 答错 | 断连 -15 |
| 🏆 评级 | 连对 8 次文从字顺 |

**操作:****点选项**(键盘 **1-4**)作答。

> 💡 **打法:**① **读出声**:语调上扬是问号,戛然而止是句号;② **话没说完**用逗号,省略号是欲言又止;③ 并列词语用**顿号(、)**,别和逗号混;④ 提示下文用**冒号**,解释说明用破折号;⑤ 拿不准就**默念全句**,标点是呼吸的节奏!

**结算:**连对、本局得分、历史最高分、已玩局数。
