# 调音师 (🎵 调音师 · 金耳朵)

> 分类:**音乐节奏** · 入口:/tuner/ · 免费在线 · 手机即点即玩

**目标:**听一遍目标音后,**拖动滑杆**用实时音找回到相同音高,松手提交;按**音分**计差距,容差从 60 音分逐轮收窄到 18,10 轮后按最准成绩评级。

| 元素 | 效果 |
|---|---|
| 🎧 听音 | 每轮先播放 1 秒目标音 |
| 🎚 对音 | 滑杆实时发声,边听边调 |
| ✋ 提交 | 松手锁定,金线(目标)紫线(你)对比 |
| 📐 音分 | 1200 音分=一个八度,越小越准 |
| 🏆 评级 | ≤12 金耳朵 / ≤30 银 / ≤60 铜 |

**操作:****拖动滑杆**对音,松手提交(空格也可);戴耳机效果最佳。全程只靠耳朵,不看任何提示!

> 💡 **打法:**① 先记住目标音的「高度感」再拖,**边拖边微调**比大范围扫准;② 拖过头时音会明显发亮发紧,退半格往往就对了;③ 容差前松后紧,**前 4 轮快速稳拿**建立分数;④ 八度错觉:调到很接近但听感发飘,可能高了整八度的邻音;⑤ 手机外放会削低频,**低音区更信滑杆位置**不如多听一遍原音!

**结算:**回合数、最准音分差、本局得分(命中 100 + 余量分)、金耳朵评级、历史最高分、已玩局数。
