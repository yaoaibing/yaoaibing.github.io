# 音感测试 (🎼 音感测试 · 绝对耳力)

> 分类:**烧脑益智** · 入口:/tonepin/ · 免费在线 · 手机即点即玩

**目标:**每题先后播放**两个音**,判断哪个更高,共 10 题。两音差距一题比一题小(从 14% 缩到 1.2%),后期纯靠耳朵。每题 10 秒,可无限重听。

**操作:**自动播放两音 → 点"第一个更高/第二个更高"(键盘 `1`/`2`)→ 点"🔁重听"不限次数。

> 💡 **听音要点:**① 别用"猜"——**在心里哼一遍**两个音,哼到第二个时感觉是"往上够"还是"往下落";② 两个音间隔 0.75 秒,第一遍听不全就果断重听,**重听不扣分**;③ 后期差距 1%~3%,普通人靠猜是 50%,专心听能到 70%+;④ 安静环境+耳机是刚需,外放会出现"方向错觉";⑤ 9/10 以上就是货真价实的金耳朵。

**结算:**10 题答对数、历史最佳。
