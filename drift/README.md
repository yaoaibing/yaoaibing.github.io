# 极速漂移 (🏁 极速漂移 · 弯道之王)

> 分类:**竞速赛车** · 入口:/drift/ · 免费在线 · 手机即点即玩

**目标:**弯道漂移计分:道路无限延伸且**越开越快**,左右拖动转向;在弯道中**贴近路肩但不压草**持续累积漂移分,压草减速;60 秒后里程 + 漂移分结算。

| 元素 | 效果 |
|---|---|
| ↔️ 转向 | 拖动/方向键,车身随转向倾斜 |
| ↗️ 弯向预告 | 上方箭头提前提示下一个弯 |
| 🔥 漂移分 | 弯中贴边,分 = 速度 x 弯度 |
| 🌿 草地 | 速度减半,漂移分停止 |
| 📈 提速 | 距离越远速度越高,260→460 |

**操作:****左右拖动**转向(方向键同效),全程一个动作;箭头是弯向预告,提前半秒切线!

> 💡 **打法:**① 弯道里**贴外侧入弯、切内侧出弯**,漂移分不中断;② 数字大就说明路直,<b>抓紧回正攒速度</b>,直道没有漂移分但有里程分;③ 压一次草掉一半速度,<b>回正要拖 2 秒</b>,宁欠勿过;④ 弯向箭头出现后**半秒内**就要动,等看到弯心已经晚了;⑤ 高速段方向盘变沉(响应变慢),**提前量再加大**!

**结算:**行驶里程、漂移分、本局得分(里程 + 漂移)、历史最高分、已玩局数。
