# 雪橇闪避 (🛷 雪橇闪避 · 林海飞驰)

> 分类:**街机动作** · 入口:/sleighrun/ · 免费在线 · 手机即点即玩

**目标:**三道下坡:自动加速,**切道躲树桩**;撞上 -1 雪橇;三条雪橇滑到黑。

| 元素 | 效果 |
|---|---|
| 🛷 三道 | 左右点切或键盘 |
| 🪵 树桩 | 撞上 -1 且减速 |
| ⚡ 提速 | 每秒 +3 |
| 🏁 计分 | 滑行距离+得分 |
| 🏆 评级 | 滑行 500 米林海飞人 |

**操作:****点雪道**切道(键盘 ← →)。

> 💡 **打法:**① **中道视野最好**,没把握别乱切;② 树桩**提前三秒就能看到**,从容变道;③ 提速后**反应窗口变窄**,少切为妙;④ 撞一下掉速,**正好缓一缓**;⑤ 尾段极速,**靠背单词的专注**!

**结算:**滑行距离、本局得分、历史最高分、已玩局数。
