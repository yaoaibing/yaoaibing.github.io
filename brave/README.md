# 勇者登塔 (🗡️ 勇者登塔 · 见好就收)

> 分类:**解压休闲** · 入口:/brave/ · 免费在线 · 手机即点即玩

**目标:**press-your-luck 博弈:**上楼**奖励翻倍,每层随机是宝藏(+层 x10)或怪物(本层清零);随时「携款撤退」保住金币。贪心还是理智?纪录就是答案!

| 元素 | 效果 |
|---|---|
| 🗡️ 上楼 | 奖励翻倍,但怪物概率逐层升高 |
| 🎁 宝藏层 | +层数 x10 金币 |
| 👾 怪物层 | 本层金币清零,强制结算 |
| 💰 撤退 | 随时带走全部金币 |
| 🏦 纪录 | 历史最大一笔撤退金额 |

**操作:****点「上楼」**继续,**点「携款撤退」**保本(键盘 ↑/↓);**重进**重开。10 层以上怪物概率飙升!

> 💡 **打法:**① 前 5 层怪物概率低,大胆上;② 7 层之后每层都问自己:<b>这口气值不值</b>;③ 带着双倍金额撤退,再进塔重新算;④ 连续两层宝藏后,下一层是怪的概率变大(错觉但别慌);⑤ 见好就收四个字,就是这个游戏的全部!

**结算:**到达层数、撤退金额、历史纪录、本局得分(撤退金额)、已玩局数。
