# 打尜尜 (🏏 打尜尜 · 一棒一飞)

> 分类:**解压休闲** · 入口:/gagaplay/ · 免费在线 · 手机即点即玩

**目标:**两段挥击:**削尜打飞**,三局比远。

| 元素 | 效果 |
|---|---|
| 🏏 木尜 | 两头尖中间胖 |
| 🔪 削尖 | 准线判定 |
| 💪 挥棒 | 八成劲最优 |
| 📏 计步 | 飞距定输赢 |
| 🏆 结算 | 打尜折分 |

**操作:****点屏两下**:一削尖,二挥棒。

> 💡 **打法:**① 削尖**正中线**,尜才立得稳;② 挥棒**八成劲最远**,满了反而飘;③ 对手**每局重掷**,别用上局的远近;④ 输一局**下一棒找补**,三局两胜的路数;⑤ 三棒打完,**整条巷子都在喊再来**!

**结算:**对局数、飞出步数、本局得分、历史最高分、已玩局数。
