# 五格拼板 (🧩 五格拼板 · 方寸乾坤)

> 分类:**烧脑益智** · 入口:/pentfill/ · 免费在线 · 手机即点即玩

**目标:**拼板填充:随机五格块**旋转+平移**放入 5×5 框;每块 +25,拼满 +150 进下一板。

| 元素 | 效果 |
|---|---|
| 🧩 拼块 | 八种五格随机抽取 |
| 🔄 旋转 | 按钮转向自由试 |
| ⬇️ 放置 | 绿框=可放 |
| ✅ 拼满 | 整板 +150 |
| 🏆 评级 | 四板全通拼图宗师 |

**操作:****点棋盘格**移动拼块,点「**🔄 转向**」「**⬇️ 放置**」落下。

> 💡 **打法:**① **先放角上的怪块**,直条最好补空;② 绿框亮了才放得进,**白框不用试**;③ 旋转是免费的,**多转几圈看顺眼**;④ 中间 3×3 最难填,**留给十字块**;⑤ 卡住就重摆思路,**先空后补**!
