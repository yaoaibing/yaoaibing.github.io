# 谁是卧底 (🕵️ 谁是卧底 · 派对推理)

> 分类:**对战棋牌** · 入口:/spy/ · 免费在线 · 手机即点即玩

**目标:**一部手机 4-8 人开玩的经典派对游戏。平民拿**同一个词**,卧底拿**相近词**(如「可乐」vs「雪碧」),描述-投票-放逐,**揪出卧底平民胜,卧底活到最后 2 人卧底胜**。

**流程:**① 选人数开局;② 按提示**轮流交手机**,点「查看我的词」偷看,点「隐藏」交给下一位;③ 全部看完进入**自由讨论**,每人一句话描述自己的词(不许说出词本身);④ 点「开始投票」,点选玩家头像→**二次确认放逐**;⑤ 放逐错人继续下一轮,直到分出胜负。

> 💡 **场下技巧:**① 平民描述要**具体但不暴露词**,说功能、说场景最稳;② 卧底开局少说、贴着别人的描述"跟风加一点",暴露是大忌;③ 票型也是信息:**被集中投票的往往是话最多或最含糊的**;④ 词库 30 对全是生活词,新手友好;⑤ 卧底胜也能拿分,但平民胜 +150 更肥。

**结算:**胜负阵营、两个词、卧底是谁、轮数、本局得分、历史最高分。
