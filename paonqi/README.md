# 炮棋 (🔵 炮棋 · 隔子打子)

> 分类:**对战棋牌** · 入口:/paonqi/ · 免费在线 · 手机即点即玩

**目标:**民间炮棋:5×5 棋盘,每回合**移动一步**或**隔一子直线开炮**吃子;吃光对方获胜,AI 贪吃但直线思维。

| 元素 | 效果 |
|---|---|
| 🔵 你执蓝 | 下两排+中路一子 |
| ⬆ 走一步 | 上下左右空位 |
| 💥 开炮 | 直线隔一子打远处 |
| 🤖 AI | 贪吃型,直线炮为主 |
| 🏆 计分 | 胜 400 起 + 存子奖励 |

**操作:****点棋子**选中,**点圈**走/开炮。

> 💡 **打法:**① **让 AI 先冲**:它吃你一子时,往往露出炮口;② 双子连排=**移动炮架**,随时开火;③ 中路那一子**别乱动**,是全盘炮眼;④ 对方一子换你一子**不亏**,亏在没吃到;⑤ 残局**数炮线**:能开炮的线多者胜!

**结算:**对局兵力、比分、本局得分、历史最高分、已玩局数。
