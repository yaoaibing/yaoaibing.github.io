# 斗地主 (👑 斗地主 · 欢乐对战)

> 分类:**对战棋牌** · 入口:/ddz/ · 免费在线 · 手机即点即玩

**目标:**一副 54 张牌三家同玩:**叫分**最高的当地主拿 3 张底牌,另外两家自动结成农民。地主先出牌,牌型必须相同且更大才能压,两家都不要则重新领出。**先出完手牌**的一方获胜,炸弹和王炸让倍数翻倍。

| 元素 | 效果 |
|---|---|
| 💰 叫分 | 1/2/3 分,叫 3 分直接当地主,全不叫重新发牌 |
| 👑 地主 | 拿底牌共 20 张,一人对抗两家农民 |
| 🧨 牌型 | 单/对/三/三带一/三带二/顺子/连对/四带二/炸弹/王炸 |
| ⏭ 不要 | 压不起或不想压都可以过,连续两家过则重新领出 |
| 🏁 胜负 | 地主先出完地主赢,任一农民出完农民赢 |

**操作:**点牌**选牌**(再点取消),**出牌**打出所选,**提示**自动帮你找能压的最小牌,**不要**过牌。叫分阶段按钮变成叫 1/叫 2/叫 3/不叫。

> 💡 **打法:**① 手牌散就**不叫**,两王四个二再叫 3 分;② 农民要配合:队友放的大牌别乱压,让地主多过牌;③ 顺子先拆最长的出,连对留着收尾;④ 炸弹留给关键时刻,比如地主剩 2 张牌时炸开;⑤ 下家报单(剩 1 张)时,顶牌出对子或大单拖节奏。

**结算:**胜负、身份、底分 x 倍数结算积分(炸弹王炸每个翻倍,春天再翻倍)、累计积分、本局得分、历史最高分、已玩局数。
