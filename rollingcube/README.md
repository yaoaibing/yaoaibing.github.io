# 滚动方块 (📦 滚动方块 · 立体谜题)

> 分类:**烧脑益智** · 入口:/rollingcube/ · 免费在线 · 手机即点即玩

**目标:**控制 2x1x1 长方块在棋盘上翻滚,**竖直立在目标格**即过关;不能掉出边缘,不能压碎裂纹格。10 关由简到繁。

| 元素 | 效果 |
|---|---|
| 📦 移动 | 方向键翻滚,方块重心改变 |
| 🎯 目标 | 竖直(1x1 底面)立在目标格 |
| ⚠️ 边缘 | 翻滚出棋盘即失败重来 |
| 🔨 裂纹 | 裂纹格只能承受竖直状态 |
| 🏁 过关 | 正确姿态到达目标格 |

**操作:**底部方向按钮或**键盘方向键**翻滚;**撤销**退一步,**重来**复位。键盘 ↑↓←→ 更顺手!

> 💡 **打法:**① 竖直状态占 1 格,横躺占 2 格,<b>先想清楚每种朝向占哪些格</b>;② 目标格通常在最远处,沿边缘走更安全;③ 裂纹格是陷阱,靠近前确认自己是什么姿态;④ 撤销功能不限次数,大胆试错;⑤ 先在心里模拟 3-4 步,看清走向再出手!

**结算:**通过关卡数、总步数、各关成绩、本局得分(每关 300 - 超额步 x20)、历史最高分、已玩局数。
