**目标:**约束填数:**行列不重复 + 不等号方向**,点格循环换数,检查通过进下一局。

| 元素 | 效果 |
|---|---|
| 🔢 行列 | 每行每列 1-N 不重 |
| 🔺 不等号 | 尖角指向小数 |
| ✅ 检查 | 冲突标红,违例扣分 |
| 📈 递进 | 第 3 局起升五路 |
| 🏆 评级 | 连破五局逻辑通 |

**操作:****点格子**循环换数,点**检查**验证。
