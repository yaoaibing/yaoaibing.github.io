# 坦克大战 (🪖 坦克大战 · 保卫基地)

> 分类:**街机动作** · 入口:/tanks/ · 免费在线 · 手机即点即玩

**目标:**驾驶坦克守住底部的**老鹰基地**,击毁一波波来袭的敌方坦克。砖墙可以被炮弹打穿,钢墙不能。基地被毁或 3 条命用完就结束。

| 元素 | 效果 |
|---|---|
| 🕹️ 移动 | 左下摇杆拖动,坦克朝摇杆方向开 |
| 🔫 开火 | 按住右下开火键连射,炮弹可打穿砖墙 |
| 🧱 地形 | 砖墙能打穿,钢墙不可破坏 |
| 🦅 基地 | 底部老鹰,被敌方炮弹击中立即失败 |
| 💥 波次 | 共 12 辆敌方坦克,同时最多 3 辆 |

**操作:**左下摇杆拖动移动,右下开火键按住连射;**新局**重开。键盘方向键/<kbd>WASD</kbd> 移动,<kbd>空格</kbd> 开火。

> 💡 **打法:**① 开局先打掉基地正上方的砖墙,留出射击通道;② 别贴着钢墙走,炮弹会被弹掉;③ 敌方坦克成排时先打最后面的,避免被包抄;④ 老家被围时回防,宁可少拿分也别丢基地;⑤ 开火有冷却,点射比乱按更准。

**结算:**击毁数、得分、存活时间、本局得分(击毁 100/辆 + 胜利 500)、历史最高分、已玩局数。
