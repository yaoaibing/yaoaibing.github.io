# 笙簧合鸣 (🎼 笙簧合鸣 · 一笙一和)

> 分类:**音乐节奏** · 入口:/shenghuang/ · 免费在线 · 手机即点即玩

**目标:**和音配对:**看求按双**,四曲递进。

| 元素 | 效果 |
|---|---|
| 🎼 笙管 | 五音五管 |
| 👆 按管 | 两管成一和 |
| 🎵 求 | 头顶写着 |
| ⚠️ 跑调 | 折十二分 |
| 🏆 结算 | 笙簧折分 |

**操作:****先点一管,再点另一管**成和音。

> 💡 **打法:**① **看清求的和**:宫+角、商+徵;② 先按**低音管**再按高音,顺手;③ 按岔**只折十二分**,重按就是;④ 曲越深**和越多**,手指排个序;⑤ 四曲合鸣,**凤凰都落你院里听**!

**结算:**曲数、和数、本局得分、历史最高分、已玩局数。
