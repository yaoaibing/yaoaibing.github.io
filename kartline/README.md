# 卡丁弯道 (🏎️ 卡丁弯道 · 走线大师)

> 分类:**竞速赛车** · 入口:/kartline/ · 免费在线 · 手机即点即玩

**目标:**两段走线:**刹车指针进绿区**踩刹车,弯心出现**果断给油**出弯;走线损失累积计分,四圈指针渐快。

| 元素 | 效果 |
|---|---|
| 🛑 刹车 | 绿区 ±7% 完美 |
| ⛽ 油门 | 弯心 0.55s 内出弯 |
| ⚠ 推头 | 没到弯心给油=损线 |
| 📈 难度 | 每圈指针提速 |
| 🏆 计分 | 完美刹车 60 + 出弯 40 |

**操作:**「**🛑 刹车**」「**⛽ 油门**」(空格=刹车/↑=油门)。

> 💡 **打法:**① 口诀:**慢进快出**,刹车宁早勿晚;② 盯指针**别盯弯道**,绿区前一拍手指就位;③ 出弯窗口很宽,**过了弯心立刻给油**就行;④ 推头比刹早更亏,**拿不准就先刹**;⑤ 最后一圈指针最快,**稳住呼吸**!

**结算:**完成圈数、走线得分、本局得分、历史最高分、已玩局数。
