# 迷你爬塔 (🃏 迷你爬塔 · 三层卡塔)

> 分类:**卡牌构筑** · 入口:/minideck/ · 免费在线 · 手机即点即玩

**目标:**卡牌爬塔:每回合 3 能量,打出手牌攻击/格挡/抽牌,**结束回合**挨打换新;通关三选一强化牌组,HP 跨层继承,三层登顶。

| 元素 | 效果 |
|---|---|
| ⚔️ 攻击 | 基础攻击 6 伤 |
| 🛡 格挡 | 当回合吸收伤害 |
| 🔍 洞悉 | 立即抽 2 张 |
| 👹 意图 | 魔像每 3 回合放大招 |
| 🏆 计分 | 生命 x20 + 登顶奖励 |

**操作:****点手牌**打出,「**🛡 结束回合**」换新(键盘建议全鼠标)。

> 💡 **打法:**① **先看敌人意图再出牌**,大攻击回合优先盾;② 洞悉别开局就打,**关键回合抽牌找解**;③ 奖励选吸血,**续航胜过爆发**;④ 史莱姆 24 血是送分题,**两刀一盾稳过**;⑤ 魔像大招前必叠盾,**8+6=14 伤不是闹着玩的**!

**结算:**当前层数、剩余生命、登顶状态、本局得分、历史最高分、已玩局数。
