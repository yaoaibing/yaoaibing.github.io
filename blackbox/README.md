# 黑箱探秘 (⚛️ 黑箱探秘 · 射线定影)

> 分类:**寻宝推理** · 入口:/blackbox/ · 免费在线 · 手机即点即玩

**目标:**射线推理:边缘发射射线探测**4 颗隐藏原子**,✖命中/↺反射/数字对穿;在格内标记原子位置,标满 4 个验证;每箱射线越少分越高。

| 元素 | 效果 |
|---|---|
| ✖ 命中 | 正前方有原子 |
| ↺ 反射 | 双斜侧夹击原路返回 |
| 🔢 对穿 | 数字=进口配出口 |
| 📍 标记 | 点格子放置/取消 |
| 🏆 计分 | 400 - 射线数 x10 |

**操作:**点**小孔**发射射线,点**格子**标记原子,「🔍 验证」判卷。

> 💡 **打法:**① 先打四角和中点,**八条基线铺满全局**;② 对穿数字相同的两孔连线,**线上必无原子**;③ 反射说明原子紧贴入口,**斜角试一发便知方向**;④ 偏转成对出现,**两个出口配对夹出原子**;⑤ 别急着验证,**推满证据再落子**,错一次 -60!

**结算:**破解箱数、使用射线数、本局得分、历史最高分、已玩局数。
