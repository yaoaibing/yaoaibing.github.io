# 数独 (🔢 数独 · 九宫格)

> 分类:**烧脑益智** · 入口:/sudoku/ · 免费在线 · 手机即点即玩

**目标:**在 9x9 盘面上填数,让**每行、每列、每个 3x3 宫**都恰好包含 1 到 9 各一次。每局由程序生成,保证**唯一解**。

| 元素 | 效果 |
|---|---|
| 🕳️ 挖空 | 入门 36 格,普通 44 格,进阶 50 格 |
| 🖊️ 填数 | 点格子后点下方数字键,填错会标红 |
| 💡 提示 | 每局 3 次,自动补一个正确数字 |
| ⏱️ 计时 | 用时越短,时间奖励越高 |
| ❌ 填错 | 每次扣 25 分,可以擦掉重填 |

**操作:**点格子选中,再点下方 1-9 数字键填数,点最后的 ⌫ 擦除;**提示**补一格,**难度**切换档位并开新局。键盘方向键移动,<kbd>1</kbd>-<kbd>9</kbd> 填数,<kbd>退格</kbd> 擦除。

> 💡 **打法:**① 先扫一遍,把**候选只剩一个**的格子全部填掉;② 用行、列、宫互相锁死:某数字在一行里只剩一个位置,就一定是它;③ 填错会标红,不确定时先空着,别浪费提示;④ 时间奖励最高 1500 分,每秒扣 5 分,想清楚再落笔;⑤ 提示优先用在卡了最久的格子上。

**结算:**用时、难度、提示次数、填错次数、本局得分(基础分 600/900/1200 + 时间奖励 - 填错 x25)、历史最高分、已玩局数。
