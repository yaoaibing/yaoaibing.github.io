# 引力弹弓 (🪐 引力弹弓 · 借力飞行)

> 分类:**太空导航** · 入口:/gravshot/ · 免费在线 · 手机即点即玩

**目标:**引力轨迹:拖动瞄准发射探测器,**行星引力实时弯折轨迹**;命中目标蓝星过关(4 次尝试),撞星或出界重试;五关引力递增。

| 元素 | 效果 |
|---|---|
| 🪐 引力 | 距离越近弯折越狠 |
| 🎯 蓝星 | 虚线圈=目标 |
| ☄️ 探针 | 拖得越长初速越大 |
| 🌀 险区 | 贴星 14px 内坠毁 |
| 🏆 计分 | 命中 150 + 剩尝试 x40 |

**操作:**从**卫星拖线**瞄准,松手发射。

> 💡 **打法:**① 别瞄着目标,**瞄着行星侧面**让引力送你一程;② 拖太长速度太快,**引力来不及弯**,中速最灵活;③ 双行星关卡,**绕外侧大圈**比穿中间稳;④ 失败轨迹都是情报,**复刻上次路线微调**;⑤ 蓝星有虚线圈,**蹭圈边也算中**!

**结算:**通过关卡数、剩余尝试、本局得分、历史最高分、已玩局数。
