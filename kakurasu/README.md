# 数和拼行 (➕ 数和拼行 · 加法迷盘)

> 分类:**烧脑益智** · 入口:/kakurasu/ · 免费在线 · 手机即点即玩

**目标:**加法拼图:行内格子权值=列号、列内权值=行号;**行列权和同时达标**即过关;6 关递进。

| 元素 | 效果 |
|---|---|
| ➕ 行和 | 行内格子按列号求和 |
| 📐 列和 | 列内格子按行号求和 |
| 🎯 目标 | 右侧/下侧数字 |
| 🟢 已达 | 满足的行列标绿 |
| 🏆 评级 | 6 关全通逻辑控 |

**操作:****点格子**点亮/熄灭。

> 💡 **打法:**① **先攻目标最大的行**:大数拆法少;② 权值 5 格是行内的「大杀器」,**有 5 想 5**;③ 列目标和行目标**互相制约**,卡住就换行列;④ 目标是 10 = **5+4+1** 或 **5+3+2**,拆法枚举;⑤ 小于 3 的目标基本白送,**先锁这些**!

**结算:**破解关数、本局得分、历史最高分、已玩局数。
