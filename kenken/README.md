# 算独 (🧮 算独 · 笼中算术)

> 分类:**烧脑益智** · 入口:/kenken/ · 免费在线 · 手机即点即玩

**目标:**算独(Calcudoku):行列不重复 + 每个粗线笼内数字**满足加/减/乘/除算式**;6 关递进,填满即自动校验。

| 元素 | 效果 |
|---|---|
| 🧮 笼 | 粗线圈起,左上角写目标 |
| ➕ 算式 | + − × ÷ 随机组合 |
| 🔢 规则 | 行列数字不重复 |
| ⌫ 清除 | 删掉当前格 |
| 🏆 评级 | 6 关全通算独高手 |

**操作:**点**格子**选中,点下方 **1-5** 填数(键盘 **1-5**/退格)。

> 💡 **打法:**① 先扫**单格笼**,白送的直接填;② 两格笼看减除,**差和商限制最多**;③ 5×5 别急着猜,**行列排除法**永远够用;④ 大笼(3格)多为加乘,**先算总和/总积**;⑤ 卡住就换个笼,**换脑子比硬磕快**!

**结算:**破解关数、本局得分、历史最高分、已玩局数。
