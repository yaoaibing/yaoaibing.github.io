# 木琴敲敲 (🎹 木琴敲敲 · 听音回奏)

> 分类:**音乐节奏** · 入口:/xylophone/ · 免费在线 · 手机即点即玩

**目标:**旋律记忆:样例播放后在 8 音木琴上**原样复奏**;全对通关,曲长随关卡增加。

| 元素 | 效果 |
|---|---|
| 🎹 八音 | 红橙黄绿蓝靛紫彩色键 |
| 🔊 试听 | 可反复重听样例 |
| 📈 曲长 | 3 音起步逐关加长 |
| ❤️ 容错 | 三颗心 |
| 🏆 评级 | 八曲全通顺风耳 |

**操作:****点木琴键**(键盘 **1-8**),可点「**🔁 重听**」。

> 💡 **打法:**① **三个音一组记**,像记电话号码;② 记**高低走向**,别死记编号;③ 拿不准就重听,**重听不扣分**;④ 敲错别慌,**下一曲换好听的**;⑤ 哼出声来,**嘴是最好的存谱器**!

**结算:**通过曲数、连过、本局得分、历史最高分、已玩局数。
