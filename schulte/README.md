# 舒尔特方格 (🔟 舒尔特方格 · 注意力训练)

> 分类:**烧脑益智** · 入口:/schulte/ · 免费在线 · 手机即点即玩

**目标:**5×5 方格内是**打乱的 1~25**,按顺序从 1 点到 25,越快分越高(25 秒内完成可得满分)。点错 +2 秒罚时。飞行员、学霸都在用的经典专注力训练。

**操作:**按 1→25 的顺序依次点数字,点对变绿,点错 +2 秒并震动。

> 💡 **训练要点:**① **眼睛盯住方格中心**,用余光找数字——这是舒尔特表的核心训练法,比逐个扫快一倍;② 找到下一个数字前**先记住它的位置**,手指提前移动;③ 点错 +2 秒很伤,**不确定就慢半拍**,稳定比冒险划算;④ 成年人平均 25~40 秒,20 秒内是优秀,15 秒内是飞行员水平;⑤ 每天练 3 轮,一周后阅读速度和专注时长都会有体感提升。

**结算:**完成用时(含罚时)、总得分、历史最高分。
