# 木鹊扑翼 (🐦 木鹊扑翼 · 一飞三丈)

> 分类:**组装拼装** · 入口:/woodbird/ · 免费在线 · 手机即点即玩

**目标:**配平试飞:**调翼配坠**,三鹊连飞。

| 元素 | 效果 |
|---|---|
| 🐦 翼角 | 三档可调 |
| ⚖️ 配重 | 三档可调 |
| 🚀 试飞 | 一次定距 |
| 📏 计程 | 米数折分 |
| 🏆 结算 | 试飞折分 |

**操作:**点**翼角/配重**钮,自动试飞。

> 💡 **打法:**① **先翼后坠**,两钮都动才叫调;② 翼越陡**升得越急栽得越快**,平翼借风最稳;③ 配重**跟着翼走**,陡配轻、平配中;④ 三鹊**一鹊比一鹊难调**,越往后越细;⑤ 三丈开外,**鲁班看了都得再削一只**!

**结算:**试飞架数、飞行距离、本局得分、历史最高分、已玩局数。
