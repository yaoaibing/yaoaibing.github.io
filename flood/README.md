# 洪水逃生 (🌊 洪水逃生 · 屋顶七日)

> 分类:**生存挑战** · 入口:/flood/ · 免费在线 · 手机即点即玩

**目标:**洪水生存:水位**每天 +20%**(漫顶即败),每天 3 点行动力分配:搜物资/凑绳索(6 段垂降逃生)/舀水(-10 压水位);夜晚断粮 -16、绳索可能被浪卷走;7 天内水位不漫顶即获救。

| 元素 | 效果 |
|---|---|
| 🌊 水位 | 每天 +20%,舀水 -10 压制 |
| 🍖 搜物资 | +2~3 食物 |
| 🪢 凑绳索 | +1~2 段,6 段达成垂降 |
| 🌧 随机 | 雨夜失温/绳索被浪卷走 |
| 🚣 获救 | 撑到第 7 天即胜 |

**操作:**点 **搜物资/凑绳索/舀水**(键盘 **1-3**);行动力用尽自动入夜。

> 💡 **打法:**① 水位是<b>不可逆的主时钟</b>:舀水只争取时间,不改变结局;② 绳索 6 段是硬指标,**每天至少 1 次凑绳索**;③ 雨夜会卷走绳索,<b>绳索 5 段时留 1 次行动补</b>;④ 食物断一晚 -16,<b>搜物资和水都在屋顶不用冒险</b>,安全但要快;⑤ 第 5 天水位 80% 时,**舀水 2 次 + 凑绳索 1 次**是最稳终盘!

**结算:**存活天数、绳索段数、水位余量、本局得分(胜 500 + 剩余天数 x60 + 生命 x3)、历史最高分、已玩局数。
