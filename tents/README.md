# 帐篷营地 (⛺ 帐篷营地 · 一树一帐)

> 分类:**烧脑益智** · 入口:/tents/ · 免费在线 · 手机即点即玩

**目标:**经典 Tents and Trees(帐篷与树):6x6 草地上散布 8 棵树,**每棵树的上/下/左/右四邻里要恰好搭 1 顶帐篷,一顶帐篷也只认一棵树;帐篷八方向不许相碰**;盘面右侧与下侧的数字给出该行、该列应有几顶。点草地循环切换 空地 / 帐篷 / 打叉记号。十块营地由生成器随树随帐布好后,用独立回溯求解器逐块复核,确认唯一解才收进关卡。违规落帐会扣机会,扣光或本关超时即收摊。

| 元素 | 效果 |
|---|---|
| 🌲 树 | 位置固定,四邻之一必须搭帐 |
| ⛺ 帐篷 | 点草地放置,只服务正旁边那棵树 |
| ❌ 记号 | 再点一下打叉,标记这里不可能有帐 |
| 🔢 数字 | 每行每列的帐篷数量约束 |
| 💡 提示 | 替你搭一顶正确帐篷,扣分 |

**操作:****点草地**:空地 → 帐篷 → 打叉 → 空地;**💡 提示**搭一顶正确帐篷(每关 2 次,扣 50 分);**↻ 清空**重来本关。违规落帐(压树、不挨树、贴别帐、行列超数)扣 1 次机会。键盘 H 提示、C 清空、R 重开。

> 💡 **打法:**① 先盯 <b>0</b>:那一整行都不许搭,直接全打叉;② 再看 <b>3</b> 这类大数,一格之内的帐篷位置基本被锁死;③ 一棵树只有两个可用邻格时,把两格各打一半标记,另一行的数字会替你解开;④ 帐篷相碰是隐形杀手,<b>落一顶就把八个方向扫一遍</b>;⑤ 机会比时间值钱,拿不准先打叉别硬搭。

**结算:**通过营地数、本局得分(每块基础分 + 剩余秒数 - 提示扣分)、历史最高分、已玩局数。
