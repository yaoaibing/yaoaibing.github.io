# 骰子角斗士 (⚔️ 骰子角斗士 · 攻防对决)

> 分类:**骰子冒险** · 入口:/dicearena/ · 免费在线 · 手机即点即玩

**目标:**骰子对战:双方各掷 4 骰,自己方 **≥4 计剑、≤3 计盾**,伤害=对方剑-我方盾;先打空对方 20 血赢局,五局定胜负。

| 元素 | 效果 |
|---|---|
| 🗡 剑 | 掷出 4/5/6 各算一把 |
| 🛡 盾 | 掷出 1/2/3 各算一面 |
| 💥 伤害 | 对方剑数-我方盾数 |
| ❤️ 血量 | 20 血,清零败北 |
| 🏆 计分 | 每胜局 180 |

**操作:**点「**⚔️ 掷骰对决**」(空格同效)。

> 💡 **打法:**① 期望各 2 剑 2 盾,**互零互伤是常态**;② 血线领先时**安心对耗**,方差会帮你;③ 血量落后**别怂**,骰运不看排面;④ 连续空过别上头,**20 血很长慢慢磨**;⑤ 第五局定胜负,**掷前深呼吸**!

**结算:**对局比分、双方血量、本局得分、历史最高分、已玩局数。
