# 跳跳球 (🟢 跳跳球 · 冲上云霄)

> 分类:**街机动作** · 入口:/doodle/ · 免费在线 · 手机即点即玩

**目标:**小球落地**自动弹起**,你只负责左右移动踩平台,跳得越高分越高(每 50 像素=1 米)。掉回屏幕底部就结束。
| 平台 | 效果 |
|---|---|
| 🟩 普通 | 稳定弹跳
🟦 移动 | 左右巡航,**落点要预判** |
| 🟫 易碎 | 踩一次就碎,只送你一程
🌀 弹簧 | **弹力接近双倍**,快速爬升通道 |

**操作:**手机**按住左/右半屏**即可持续转向,也可拖动;键盘 `←``→`/`A``D`。屏幕左右**穿边瞬移**到另一侧。

> 💡 **拿分要点:**① 落点要**踩平台中段**,边缘容易弹空;② 上升时**提前把手指移到下一平台的横向位置**,下落中调整最灵活;③ 易碎平台只能踩一次,**别把它当休息点**,弹完立刻找下一块;④ 弹簧平台弹得极高,是拉开分差的关键,但落点失控风险大,**确认上方有空位再踩**;⑤ 高处平台间隔更大、易碎更多,移动要更早更小步。

**结算:**高度(米)、历史最高、已玩局数。
