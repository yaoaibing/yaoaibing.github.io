# 滑沙竞速 (🏜️ 滑沙竞速 · 一坡一泻)

> 分类:**竞速赛车** · 入口:/sandslide/ · 免费在线 · 手机即点即玩

**目标:**速降竞速:**压板避石**,三坡连下。

| 元素 | 效果 |
|---|---|
| 🏜️ 沙坡 | 一坡比一坡陡 |
| ↔ 压板 | 短点转向 |
| 🪨 顽石 | 撞之即翻 |
| 🏁 冲线 | 过线满分 |
| 🏆 结算 | 滑沙折分 |

**操作:**按住**左/右半屏**压板。

> 💡 **打法:**① 沙地**转向有延迟**,看见石头再动已经晚了;② **速度只增不减**,靠走位不靠刹;③ 翻车**分数照给**,下一坡找回场子;④ 二三坡**石更密**,走中线最省心;⑤ 三坡冲线,**鸣沙山的回声都是你的板音**!

**结算:**滑坡赛段、行程米数、本局得分、历史最高分、已玩局数。
