# 极限跳伞 (🦸 极限跳伞 · 穿环挑战)

> 分类:**街机动作** · 入口:/skydive/ · 免费在线 · 手机即点即玩

**目标:**从 4000 米跳下:**按住拖动**控制水平位置,穿过彩色圆环得分(连击有加成),撞到热气球或飞鸟扣 1 格护盾并眩晕;高度归零自动开伞,护盾 3 格,穿环越多分越高。

| 元素 | 效果 |
|---|---|
| ⭕ 得分环 | 金环 100,蓝环 60,连击 x2 |
| 🎈 障碍 | 热气球静止漂浮,飞鸟横穿 |
| 🛡️ 护盾 | 3 格,撞障碍扣 1 格并眩晕 0.6 秒 |
| ⏱ 高度 | 4000 米匀速下降约 55 秒 |
| 🏁 着陆 | 高度归零结算,穿环总分就是成绩 |

**操作:****按住屏幕左右拖动**控制位置(键盘 ←→ 也行);**重跳**立刻重跳。眩晕时不受控,提前规划路线!

> 💡 **打法:**① 看到环<b>提前 1 秒</b>开始横移,别贴脸急转;② 金环通常和障碍同排,先掂量护盾值不值;③ 连击是分数大头,断在环边上最亏;④ 被眩晕时松手漂一下,比乱拉方向强;⑤ 最后 500 米障碍变密,稳住手别贪环。

**结算:**穿环数、最高连击、撞障碍次数、着陆剩余高度、本局得分(金环 x100 + 蓝环 x60,连击加成)、历史最高分、已玩局数。
