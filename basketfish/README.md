> 分类:**寻宝推理** · 入口:/basketfish/ · 免费在线 · 手机即点即玩

**目标:**视差判断:**以影定鱼**,六罩连环。

| 元素 | 效果 |
|---|---|
| 🧺 鱼罩 | 口阔一尺 |
| 🌊 浑水 | 只见斜影 |
| 👉 偏移 | 风向标提示 |
| ⚠️ 罩空 | 惊鱼变向 |
| 🏆 结算 | 罩鱼折分 |

**操作:**点屏**下罩**。
