> 分类:**体育竞技** · 入口:/rubjump/ · 免费在线 · 手机即点即玩

**目标:**花样节奏:**口令选步法**,五档升筋。

| 元素 | 效果 |
|---|---|
| 🎀 皮筋 | 五档高度 |
| ⭕ 节奏环 | 绿区按钮 |
| 🦶 勾 | 勾筋而过 |
| 👣 踩 | 压筋一踩 |
| 🌀 绕 | 绕筋翻花 |
