# 连线不交叉 (🚇 连线不交叉)

> 分类:**烧脑益智** · 入口:/flow/ · 免费在线 · 手机即点即玩

**目标:**把每一对同色圆点用线连起来,线不能交叉、不能共用格子,而且**要把整个棋盘填满**才算过关。**共 48 关**,从 5×5 到 9×9,颜色 3 到 8 种。
| 操作 | 键位 |
|---|---|
| 连线 | 按住圆点**拖动**到同色另一端
改线 | 点已连好的线可清除重画;拖回自己线上可回退 |

> 💡 **解题套路:**① 先连**贴着边、只有一条路**的颜色,边角最受限制;② 长线先走,它需要更多空间;③ 遇到死路往回拖一格再拐弯,不用重新开始;④ 全部连上但没填满,说明有颜色绕了远路——找那条最绕的拉直;⑤ 卡住就撤销一步换方向,这游戏的多解往往只差一个拐弯。
