# 灯塔守望 (🗼 灯塔守望 · 夜海巡逻)

> 分类:**街机动作** · 入口:/lighthouse/ · 免费在线 · 手机即点即玩

**目标:**拖动旋转灯塔光柱照亮黑暗海面,标记所有过往船只;船只撞上暗礁则损失一条命,3 艘失事结束。每夜船只与暗礁增多。

| 元素 | 效果 |
|---|---|
| 🗼 光柱 | 按住拖动旋转,照亮扇形区域 |
| 🚢 船只 | 从边缘驶入,光照到即标记 |
| 🪨 暗礁 | 固定位置,船撞上即失事 |
| ⬛ 黑暗 | 只有光柱扫过时可见 |
| 🏁 过关 | 标记所有船只进入下一夜 |

**操作:****按住拖动**旋转光柱;**重来**重守本夜。光柱转速要稳,别忽快忽慢!

> 💡 **打法:**① 先扫<b>内圈</b>,近处的船最先撞礁;② 记住暗礁位置,下次光扫到时快速确认安全;③ 船只标记后有光晕,不会忘;④ 后期船多,沿一个方向匀速扫比来回乱扫效率高;⑤ 别忘了听音效,船靠近暗礁有提示音!

**结算:**照亮船只数、失事数、通过夜数、本局得分(照亮 x80)、历史最高分、已玩局数。
