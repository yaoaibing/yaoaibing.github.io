# 单位换算 (📏 单位换算 · 换算快手)

> 分类:**学习教育** · 入口:/units/ · 免费在线 · 手机即点即玩

**目标:**单位换算速答:长度/质量/货币/时间 12 组进率,**四选一**快答;连对计分,40 秒结算。

| 元素 | 效果 |
|---|---|
| 📏 长度 | 千米/米/厘米/分米 |
| ⚖️ 质量 | 吨/千克/克 |
| 💰 货币 | 元/角 |
| ⏰ 时间 | 时/分/秒 |

**操作:****点选项**(键盘 **1-4**)作答。

> 💡 **打法:**① 口诀:**大化小乘进率,小化大除进率**;② 千米→米 **加 3 个 0**,米→厘米加 2 个;③ 元角分:**1 元 = 10 角**,别和百分搞混;④ 时间:**1 时 = 60 分**,半小时 = 0.5 时;⑤ 错一个马上想进率,**下一题就赚回来**!

**结算:**连对、本局得分、历史最高分、已玩局数。
