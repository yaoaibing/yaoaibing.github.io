# 雪橇竞速 (🛷 雪橇竞速 · 雪原冲刺)

> 分类:**竞速赛车** · 入口:/sledrace/ · 免费在线 · 手机即点即玩

**目标:**四道竞速:**切道**躲雪堆踩加速带;撞雪堆扣雪橇;三条雪橇结算。

| 元素 | 效果 |
|---|---|
| 🛷 四道 | 左右点切或键盘 |
| ⚡ 加速带 | 踩上短暂加速 |
| ⛄ 雪堆 | 撞上 -1 雪橇 |
| 🏁 计分 | 滑行距离+分 |
| 🏆 评级 | 500 米雪原飞人 |

**操作:****点雪道**切道(键盘 ← →)。

> 💡 **打法:**① **蓝色加速带**是加分利器,不撞白不踩;② 雪堆**提前三秒看到**,从容变道;③ 加速中**更难控制**,提前想好道;④ 三只雪橇,**最后一只求稳**;⑤ 计分跟着速度走,**快就是分**!

**结算:**滑行距离、本局得分、历史最高分、已玩局数。
