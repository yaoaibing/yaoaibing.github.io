# 跨栏高手 (🚧 跨栏高手 · 百米冲刺)

> 分类:**街机动作** · 入口:/hurdle/ · 免费在线 · 手机即点即玩

**目标:**自动加速的百米跨栏:**点屏幕起跳**跨过跨栏,撞栏会大幅减速并消耗体力,体力耗尽即退赛;距离就是分数,越远越快,完美越过(不碰栏)有奖励分。

| 元素 | 效果 |
|---|---|
| 🚧 跨栏 | 单栏和双连栏混合出现,栏距随机 |
| 👆 起跳 | 点屏幕跳,空中再点无效 |
| 💥 撞栏 | 速度掉三成 + 体力大扣,攒满三次退赛 |
| ⚡ 完美 | 越过栏顶不碰边缘,奖励分 +50 |
| 🏁 结束 | 撞栏 3 次退赛,按距离结算 |

**操作:****点屏幕**起跳(键盘空格也行);**重跑**立刻重开。速度随距离上涨,后期靠预判不靠反应。

> 💡 **打法:**① 起跳点在栏前<b>一臂距离</b>最稳,别贴脸才跳;② 双连栏第二栏要轻点,跳太高落点会撞第二栏;③ 撞栏后别急,先恢复节奏再追速度;④ 速度破 12 之后看<b>地面阴影</b>预判,别盯栏本身;⑤ 完美跳是分数大头,宁可跳早半拍也别蹭栏。

**结算:**距离(米)、最高速度、完美跳次数、撞栏次数、本局得分(距离 x6 + 完美跳 x50)、历史最高分、已玩局数。
