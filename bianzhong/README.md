> 分类:**音乐节奏** · 入口:/bianzhong/ · 免费在线 · 手机即点即玩

**目标:**旋律记忆:样曲播放后在 9 音编钟上**原样复奏**;全对通关,曲长随关卡增加。

| 元素 | 效果 |
|---|---|
| 🔔 九钟 | 大小相间的双音编钟 |
| 🔊 试听 | 可反复重听样曲 |
| 📈 曲长 | 3 音起步逐关加长 |
| ❤️ 容错 | 三颗心 |
| 🏆 评级 | 八曲全通钟乐师 |

**操作:****点编钟**(键盘 **1-9**),可点「**🔁 重听**」。

> 💡 **打法:**① **三个音一组记**,像背电话号码;② 大钟音低小钟音高,**用高低走向记**;③ 拿不准就重听,**重听不扣分**;④ 敲错别慌,**下一曲重新来**;⑤ 哼出声来,**嘴比脑子快**!
