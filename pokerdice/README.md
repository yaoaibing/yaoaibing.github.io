# 扑克骰子 (🎲 扑克骰子 · 五骰定夺)

> 分类:**骰子冒险** · 入口:/pokerdice/ · 免费在线 · 手机即点即玩

**目标:**骰子牌型:5 骰 3 掷,锁骰重掷凑牌型;牌型大小与 AI 暗比,**赢者得底注**;8 轮结算筹码。

| 元素 | 效果 |
|---|---|
| 🎲 三掷 | 每局最多掷三次 |
| 🔒 锁骰 | 点骰子保留不掷 |
| 🏆 牌型 | 五连/四条/葫芦/顺子 |
| 💰 底注 | 10 筹码一局 |
| 🏆 评级 | 收手 200 筹码骰王 |

**操作:****点骰子**锁定,点「**🎲 再掷**」(空格)重摇,点「**✋ 开牌**」比牌。

> 💡 **打法:**① **散牌别犹豫,三次全掷完**;② 对子以上**先锁再补**,别贪三连;③ 顺子差一颗时,**锁四颗赌一颗**;④ 庄家牌型概率和你一样,**别被吓住**;⑤ 筹码见底就**保守押**,苟到最后一局!

**结算:**轮次、最终筹码、历史最高分、已玩局数。
