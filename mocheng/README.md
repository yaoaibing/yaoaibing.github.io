# 滩头摸蛏 (🦐 滩头摸蛏 · 一蛏一筐)

> 分类:**寻宝推理** · 入口:/mocheng/ · 免费在线 · 手机即点即玩

**目标:**滩涂采集:**识包下摸**,限时速猎。

| 元素 | 效果 |
|---|---|
| 🦐 蛏子 | 泥下藏身 |
| 👆 摸 | 点包下手 |
| 🦐 十五只 | 一潮的量 |
| ⚠️ 空手 | 折分 |
| 🏆 结算 | 摸蛏折分 |

**操作:**点**鼓包摸蛏**。

> 💡 **打法:**① **新鼓包**出蛏多,老包多半空;② 空手**折五分**,别乱摸;③ 潮限**三十八息**,抓紧;④ 三潮**摸满四十五只**;⑤ 三潮摸罢,**蛏子炒韭菜鲜掉眉**!

**结算:**潮数、摸蛏数、本局得分、历史最高分、已玩局数。
