**目标:**藏头解密:四句诗的**首字纵向组成四字词**;四选一猜出藏词;8 轮计分。

| 元素 | 效果 |
|---|---|
| 📜 诗行 | 唐诗名句拼接 |
| ⬇️ 首字 | 竖读即藏词 |
