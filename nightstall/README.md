# 夜市摊 (🏮 夜市摊 · 六夜风光)

> 分类:**模拟经营** · 入口:/nightstall/ · 免费在线 · 手机即点即玩

**目标:**夜市经营:每晚**选品进货→三档定价→按天气客流结算**;毛利与销量此消彼长,六夜滚动。

| 元素 | 效果 |
|---|---|
| 🍢 货品 | 烤串/酸梅汤/手工糖/煎饺 |
| 🌙 天气 | 晴夜 1x / 小雨 0.7x / 庙会 1.6x |
| 🏷 定价 | 低价走量 · 高价高风险 |
| 💰 现金 | 进货花销+销售收入 |
| 🏆 结算 | 六夜后现金即分数 |

**操作:**点**货品按钮**进货,**出摊**后点**低/中/高价**开卖。

> 💡 **打法:**① **庙会夜全仓压货**,晴夜正常,雨夜只进便宜货;② 高价宰客有上限,**低价走量更稳**;③ 煎饺单价高但成本高,**现金少时先串汤后饺子**;④ 留 30 现金过夜,**别把身家全压一晚**;⑤ 最后一夜**清仓式进货**,反正不用留后路!

**结算:**夜数、现金、本局得分、历史最高分、已玩局数。
