# 宠物投喂 (🐾 宠物投喂 · 饥饿食堂)

> 分类:**模拟经营** · 入口:/petfeed/ · 免费在线 · 手机即点即玩

**目标:**宠物食堂:宠物随机出现,**头顶图标=想吃的食物**;**点宠物选中**(金圈)再**点对应食物**投喂;耐心 7 秒走完跑单 -30,投错 -20,60 秒结算。

| 元素 | 效果 |
|---|---|
| 🐶 三种宠物 | 小狗🍖/小猫🐟/兔子🥕 |
| ⏳ 耐心 | 7 秒倒计时,最后 3 秒变红 |
| ✅ 投喂 | 选中+对食物 = 100 + 连对 x10 |
| ❌ 投错 | -20 并断连击 |
| ⏱ 时长 | 60 秒 |

**操作:****点宠物**选中 → **点食物**(键盘 **1-3** 同效)投喂。

> 💡 **打法:**① 宠物头顶图标是唯一真相,<b>别凭颜色猜</b>;② 选中金圈会一直亮,**先选中再从容选食物**;③ 耐心最后 3 秒变红,<b>红条宠物优先</b>;④ 投错不弹出,<b>再点对的食物就补救</b>(选中状态不变);⑤ 连对是复利,<b>喂 3 只后节奏自然形成</b>!
