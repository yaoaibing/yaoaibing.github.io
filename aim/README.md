# 幽灵猎人 (👻 幽灵猎人 · 神枪手)

> 分类:**街机动作** · 入口:/aim/ · 免费在线 · 手机即点即玩

**目标:**45 秒限时,夜森林里**幽灵四处飘**,点它就是一枪。小幽灵飘得快分高,**🎃 南瓜是友军**打到 -80 并断连击,打空 -20。

**操作:**点哪打哪;电脑有鼠标十字瞄准线。连中滚分(每连击 +10/发)。

> 💡 **枪法要点:**① **优先打慢的大幽灵**保命中率,连击滚分比单发更肥;② 南瓜位置固定不动,别手快扫到它;**南瓜和小幽灵挨着时先打远的**;③ 手机玩家用指腹点,灵敏度比指尖高;④ 飘得快的幽灵**提前一个身位预判**;⑤ 命中率 70%+ 就算神枪手,100% 手感党奖励自己一杯奶茶。

**结算:**总得分、命中/出手/命中率、最高连击、历史最高分。
