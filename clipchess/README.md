# 夹子棋 (🥪 夹子棋 · 两头一夹)

> 分类:**对战棋牌** · 入口:/clipchess/ · 免费在线 · 手机即点即玩

**目标:**夹击对弈:6×6 盘**正交走一格**;己子把敌子**夹在中间**即吃;吃光对方获胜。

| 元素 | 效果 |
|---|---|
| 🥪 夹击 | 敌子在己双子之间 |
| 📐 四向 | 上下左右皆可夹 |
| 🏁 胜负 | 吃光对方 |
| 🤖 AI | 会算夹也会躲 |
| 🏆 计分 | 胜 380 连胜滚 |

**操作:****点蓝子**选中,**点绿框**走一格。

> 💡 **打法:**① **先摆两枚桩子**,夹击才有支点;② 送子入虎口前,**看它能不能反夹**;③ AI 会躲,**用两个方向同时威胁**;④ 边角好夹,**把敌人往边线赶**;⑤ 数子:**多两子就稳住换**!

**结算:**比分、俘获数、本局得分、历史最高分、已玩局数。
