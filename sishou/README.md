**目标:**双手分谱:**左右半屏分司两手**,同拍齐弹;四段递进。

| 元素 | 效果 |
|---|---|
| 🎹 左手 | 左半屏两根弦 |
| 🖐 右手 | 右半屏两根弦 |
| 📖 双谱 | 上下两行提示 |
| 📈 乐段 | 音数递增 |
| 🏆 评级 | 四段全合双料王 |

**操作:****点左右半屏**(ASJK 键)分手弹。

> 💡 **打法:**① **先读谱**:左右各几号弦,心里过一遍;② **两只手指各管半屏**,别窜位;③ 弹错**只扣小分**,节奏别乱;④ 段长**三音一组**,左右分开记;⑤ 四段全合,**琴房都让你三分**!
