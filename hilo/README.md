# 大小通吃 (🂡 大小通吃 · 翻牌连击)

> 分类:**卡牌构筑** · 入口:/hilo/ · 免费在线 · 手机即点即玩

**目标:**Hi-Lo 翻牌:猜下一张 **>7 或 <7**(相同半对半错),赢按连击加成派彩;牌堆翻尽重洗;筹码耗尽结算。

| 元素 | 效果 |
|---|---|
| ▲ 大 | 下一张 > 7 |
| ▼ 小 | 下一张 < 7 |
| 🔥 连击 | 每连胜 +10% 赔率 |
| 🂡 A/K | A 最小,K 最大 |
| 💰 押注 | 每轮固定 10 起 |

**操作:**点「**▲ / ▼**」(键盘 **↑ ↓**)。

> 💡 **打法:**① 当前是 7,**最难猜,期望五五开**;② 当前是 2,**无脑压大**;③ 连击加成很高,**连胜时保持节奏别浪**;④ 记牌:**大牌出多了,后面小牌密度高**;⑤ 筹码 200 起步,**翻倍就收是美德**!

**结算:**剩余筹码、连击数、本局得分、历史最高分、已玩局数。
