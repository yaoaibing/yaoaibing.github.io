# 湿滑漂移 (🌧️ 湿滑漂移 · 雨夜赛道)

> 分类:**竞速赛车** · 入口:/skid/ · 免费在线 · 手机即点即玩

**目标:**漂移进阶:雨夜路面**转向响应减慢**(lerp 4 而非 7),弯道中**随机打滑**;左右拖动转向,弯道贴边攒漂移分,55 秒结算。

| 元素 | 效果 |
|---|---|
| 🌧️ 雨夜 | 路面湿滑,转向 lerp 减半 |
| 💧 打滑 | 弯道贴边时随机侧滑 ±26px |
| ↔️ 转向 | 拖动/方向键,提前量加大 |
| 🔥 漂移分 | 弯中贴边,分 = 速度 x 弯度 |
| ⏱ 时长 | 55 秒 |

**操作:****左右拖动**转向(方向键同效);**箭头预告**弯向,提前切线!

> 💡 **打法:**① 雨路转向 lerp 是 4 而非 7,**所有操作提前一秒**;② 随机打滑只发生在弯中贴边时,<b>稳住别慌</b>它会回正;③ 打滑方向随机,**往反方向预拉一点点**可以抵消;④ 雨丝是装饰,<b>真正影响的是路边反光的湿润感</b>;⑤ 最后 10 秒速度最高,**贴边策略不变**但手上轻一点!

**结算:**行驶里程、漂移分、本局得分、历史最高分、已玩局数。
