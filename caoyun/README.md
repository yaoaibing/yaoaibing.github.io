# 漕运调度 (⛵ 漕运调度 · 开闸放船)

> 分类:**策略战棋** · 入口:/caoyun/ · 免费在线 · 手机即点即玩

**目标:**回合调度:**切闸门控制航路**,每天三次闸牌;十天内送五船到港。

| 元素 | 效果 |
|---|---|
| ⛵ 粮船 | 每天顺流一格 |
| 🚦 闸门 | 红=拦停,绿=放行 |
| 🪨 浅滩 | 此路不通,提前变道 |
| 🎟 闸牌 | 每天限切三次 |
| 🏆 评级 | 五船全到漕运总办 |

**操作:****点闸门**切换,点**过一天**行船。

> 💡 **打法:**① **闸是堵不是导**,船不会拐弯,只会停;② 一道闸停一船,**后面全堵死**,算好先后;③ 浅滩位置**开局先看清**,占道的闸少动;④ **船挤一条道**不如分道走;⑤ 十天五船,**你就是漕运总办**!

**结算:**到港船数、天数、历史最高分、已玩局数。
