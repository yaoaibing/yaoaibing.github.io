# 雪球滚滚 (⛄ 雪球滚滚 · 越滚越大)

> 分类:**街机动作** · 入口:/snowroll/ · 免费在线 · 手机即点即玩

**目标:**体积成长:**滚大避石**,里程滚分。

| 元素 | 效果 |
|---|---|
| ⛄ 转向 | 半屏点按 |
| 📈 变大 | 惯性变钝 |
| 🌲 小树 | 四号可压 |
| 🪨 石头 | 一撞即碎 |
| 🏆 结算 | 滚程折分 |

**结算:**雪球直径、滚程、本局得分、历史最高分、已玩局数。
