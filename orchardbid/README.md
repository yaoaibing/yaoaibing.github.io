# 果园认购 (🍊 果园认购 · 一季押一树)

> 分类:**拍卖竞价** · 入口:/orchardbid/ · 免费在线 · 手机即点即玩

**目标:**风险认购:每季一棵果树,**买入后按风险随机决定收成**;六季结算银钱。

| 元素 | 效果 |
|---|---|
| 🍑 六树 | 桃梨杏苹樱桃柿 |
| 📊 行情 | 丰收区间公示 |
| 🐛 虫害 | 风险率 5%-45% |
| 💰 结算 | 收成-认购价=净利 |
| 🏆 评级 | 结余 200 果行东家 |

**操作:**点「**🍊 认购**」或「**🙏 观望**」。

**结算:**结余银钱、季次、历史最高分、已玩局数。
