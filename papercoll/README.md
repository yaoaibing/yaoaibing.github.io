# 剪影拼贴 (🖼️ 剪影拼贴 · 纸屑成画)

> 分类:**创意涂鸦** · 入口:/papercoll/ · 免费在线 · 手机即点即玩

**目标:**剪纸拼贴:取色后**点剪影格粘贴**;覆盖 95% 成画换新稿,90 秒连拼。

| 元素 | 效果 |
|---|---|
| 🎨 五色 | 红蓝黄绿白纸屑 |
| 🖼️ 底稿 | 发亮区是待贴 |
| ✅ 成画 | 95% 以上装框 |
| 🚫 出界 | 剪影外不用贴 |
| 🏆 评级 | 三画装框拼贴手 |

**操作:****点色盘**取纸屑(键盘 **1-5**),**点剪影格**粘贴。

> 💡 **打法:**① **从中间往四周贴**,大块优先;② 贴错色没关系,**覆盖就行**;③ 剩 10% 时**沿边扫一遍**;④ 出界提示别在意,**点到就是**;⑤ 换新稿配色重开,**节奏别断**!

**结算:**成画数、覆盖率、本局得分、历史最高分、已玩局数。
