# 极速滑雪 (⛷️ 极速滑雪 · 雪岭穿越)

> 分类:**街机动作** · 入口:/slalom/ · 免费在线 · 手机即点即玩

**目标:**从雪坡疾驰而下(自动加速),**左右移动**躲开树木岩石,穿过旗门 +50 分。速度随距离越来越快,撞到即摔。

**操作:**手机按住左/右半屏或拖动;键盘 `←``→`/`A``D`。距离每 50 单位=1 米。

> 💡 **滑雪要点:**① 视线放**半屏之外**,提前规划路线,盯脚下滑不过来;② **贴旗门中间过**+50 分,为旗门冒险前先确认两侧没树;③ 速度 300 后反应时间不到半秒,**小幅移动**比大幅横跳安全;④ 树和岩石的判定是圆形,擦边不算撞,**贴边走**能救命;⑤ 旗门数和距离都计入成绩,300 米+5 门是熟手线。

**结算:**滑行距离(米)、旗门数、历史最远。
