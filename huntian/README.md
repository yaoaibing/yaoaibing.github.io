**目标:**序装校轴:**依口诀装环**,校轴验手。

| 元素 | 效果 |
|---|---|
| 🪐 环圈 | 四环四道 |
| 👆 装环 | 依序点取 |
| 🧭 校轴 | 望筒过带 |
| ⚠️ 错序 | 环磕折稳 |
| 🏆 结算 | 装环折分 |
