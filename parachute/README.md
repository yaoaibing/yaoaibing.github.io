# 跳伞精准 (🪂 跳伞精准 · 定点着陆)

> 分类:**街机动作** · 入口:/parachute/ · 免费在线 · 手机即点即玩

**目标:**从高空跳下,**按住拖动**控制降落伞水平移动,落在靶心得分最高;风力影响水平偏移,10 跳后按总分排名。

| 元素 | 效果 |
|---|---|
| 🪂 移动 | 按住拖动控制水平位置 |
| 🎯 靶心 | 靶心 100/内圈 70/外圈 40/地面 10 |
| 💨 风 | 每跳随机,影响水平偏移 |
| ⏱ 高度 | 高度越低操控越难 |
| 🏁 结束 | 10 跳后结算 |

**操作:****按住左右拖动**移动(键盘 ←→);**重跳**重开。低空时移动变慢,提前对准!

> 💡 **打法:**① 前半段<b>大调</b>,后半段<b>微调</b>;② 风标指左,你就要偏右出发;③ 别等快落地才改,低空移动变慢;④ 看阴影位置比看降落伞更准;⑤ 连续跳同一风向时,记住上次偏了多少!

**结算:**总分、靶心次数、最好一跳、本局得分(总分)、历史最高分、已玩局数。
