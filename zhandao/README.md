# 栈道架梁 (🪵 栈道架梁 · 凿孔铺梁)

> 分类:**建造物理** · 入口:/zhandao/ · 免费在线 · 手机即点即玩

**目标:**两步施工:**凿孔定深,配梁定距**,两次晃动折心;十段成道。

| 元素 | 效果 |
|---|---|
| 🪚 凿孔 | 针到绿区孔深 |
| 📐 选梁 | 短中长配孔距 |
| ⚠️ 晃动 | 两次折一心 |
| 📈 计分 | 孔深加成 |
| 🏆 结局 | 十段通或心尽 |

**操作:****点屏**凿孔,点**梁按钮**配梁。

> 💡 **打法:**① **针到绿区中央**再点,孔深梁稳;② **孔距念两遍**再选梁,短中长别手滑;③ 晃一次**下段更小心**,两次就折心;④ 后几段**针速加快**,预判提前;⑤ 十段全通,**古道上留着你凿的孔**!

**结算:**架设段数、本局得分、历史最高分、已玩局数。
