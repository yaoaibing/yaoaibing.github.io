# 符阵连携 (🔯 符阵连携 · 三符成阵)

> 分类:**卡牌构筑** · 入口:/runecombo/ · 免费在线 · 手机即点即玩

**目标:**组合谜题:每阵一条**组合规则**(连号/同符/和值/对子),点亮手牌凑齐即得分。

| 元素 | 效果 |
|---|---|
| 🔯 阵纹 | 四类规则随机出现 |
| 🃏 符牌 | 六符 × 数值 1-6 |
| ✨ 成阵 | 验证成功得赏 |
| ❌ 散阵 | 失败 -15 |
| 🏆 评级 | 八阵 400 分符阵师 |

**操作:****点符牌**点亮(键盘 **1-5**),点「**✨ 成阵**」(空格)验证。

> 💡 **打法:**① **先读懂阵纹**,别急着点牌;② 连号阵**先找同色**,再看数值挨没挨着;③ 和值 15 的组合就几组,**6+5+4 最顺手**;④ 双对阵要**四张同色**,亮牌别超过四张也能过;⑤ 失败扣分,**三张试错也好过乱点**!

**结算:**成阵得分、阵次、本局得分、历史最高分、已玩局数。
