# 商队手牌 (🐫 商队手牌 · 丝路行商)

> 分类:**卡牌构筑** · 入口:/tradehand/ · 免费在线 · 手机即点即玩

**目标:**契约凑集:每程两张契约(货物组合),**手牌凑齐即可交货领金**;每程一次换牌,八程结算。

| 元素 | 效果 |
|---|---|
| 🍵 四货 | 茶2/丝4/瓷6/盐1 价值 |
| 📜 契约 | 凑齐组合即成 |
| 🔄 换牌 | 每程一次重抽 |
| 💰 赏金 | 按货物价值×2 |
| 🏆 评级 | 50 金丝路富商 |

**操作:****点契约**交货,点「**🔄 换新牌**」重抽,点「**🐫 启程**」下一程。

> 💡 **打法:**① **先读契约再打牌**,缺啥补啥;② 瓷器契约赏金最高,**优先凑它**;③ 两契约都不够时,**果断换牌**;④ 茶盐数量多,**天然是拼图 filler**;⑤ 启程前**看清有没有白跑**!

**结算:**金币、行程、本局得分、历史最高分、已玩局数。
