# 激流漂流 (🛶 激流漂流 · 险滩过闸)

> 分类:**竞速赛车** · 入口:/rafting/ · 免费在线 · 手机即点即玩

**目标:**急流下行:木筏自动前进,**拖动控制横向**;礁石撞击扣船体,穿旗门加分加时;航程计入总分。

| 元素 | 效果 |
|---|---|
| 🪨 礁石 | 撞上 -1 船体 -30 分 |
| 🚩 旗门 | 两旗之间穿过有奖 |
| 🌊 水流 | 定期左右偏移推船 |
| ⏱ 加时 | 每过门 +3 秒 |
| 🏆 评级 | 500 米漂流健将 |

**操作:****拖动屏幕**左右移动木筏(键盘 ← →)。

> 💡 **打法:**① **盯远处提前变道**,近了躲不开;② 旗门**走正中间**,两旗碰不得;③ 水流提示出现,**预判漂移方向**;④ 三条船体是三条命,**贪门不如保船**;⑤ 越漂越快,**手要一直搭在屏幕上**!

**结算:**航程、过门数、本局得分、历史最高分、已玩局数。
