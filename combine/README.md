# 合字成词 (🀄 合字成词 · 拼字大师)

> 分类:**烧脑益智** · 入口:/combine/ · 免费在线 · 手机即点即玩

**目标:**每题给两个汉字部件:**从 4 个候选字中选出两者能拼成的那个字**(如木+目=相);40 题由易到难,答对 +100 连对加成,答错 -20。

| 元素 | 效果 |
|---|---|
| 🀄 部件 | 两个部件显示在题面上方 |
| 👉 选项 | 4 个候选字,点选作答 |
| ✅ 计分 | 对 +100 连对加成,错 -20 |
| 🧠 难度 | 前 20 题常见字,后 20 题进阶 |
| 🏁 结束 | 40 题答完结算 |

**操作:****点候选字**作答;**重开**重开一轮。把部件在脑子里上下左右摆一摆,答案自然浮现!

> 💡 **打法:**① 先看部件是<b>左右结构</b>还是上下结构;② 「氵」相关的字大多和水有关,联想字义;③ 后 20 题有冷僻组合,排除法最有效;④ 连对加成可观,前面简单题稳稳拿分;⑤ 答错的字记下来,汉字量就是这样涨的!

**结算:**答对题数、连对最高、本局得分、历史最高分、已玩局数。
