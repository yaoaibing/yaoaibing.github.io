# 彗尾采样 (☄️ 彗尾采样 · 追星之旅)

> 分类:**太空导航** · 入口:/cometsip/ · 免费在线 · 手机即点即玩

**目标:**采集飞行:**上下拖动**探测器;亮蓝尘埃 +1,碎岩 -1 船体;60 秒或三体尽毁结算。

| 元素 | 效果 |
|---|---|
| ☄️ 彗核 | 在左侧吐出尾流 |
| 🔵 尘埃 | 每粒 +1 样本 |
| 🪨 碎岩 | 撞上 -1 船体 |
| 🛰 船体 | 三格,撞完即止 |
| 🏆 评级 | 采样 40 追星者 |

**操作:****拖动屏幕**上下移动探测器(键盘 ↑ ↓)。

> 💡 **打法:**① **探测器停在尘埃最密的高度带**,小幅微调;② 碎岩比尘埃大,**提前半屏预判**;③ 贴核收益高但石头也多,**贴而不撞**;④ 尾流有波浪,**跟着波走**;⑤ 船体是命,**别为两粒尘送一条命**!

**结算:**采样数、船体、本局得分、历史最高分、已玩局数。
