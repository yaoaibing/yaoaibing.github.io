# 书法描红 (✍️ 书法描红 · 一笔一画)

> 分类:**创意涂鸦** · 入口:/calligraphy2/ · 免费在线 · 手机即点即玩

**目标:**笔顺描红:按规则**点选笔画顺序**;四字通关。

| 元素 | 效果 |
|---|---|
| ✍️ 四字 | 永/心/飞/乃 |
| 📜 笔顺 | 先横后竖先撇后捺 |
| 👆 点选 | 下方笔画按钮 |
| ❤️ 容错 | 三颗心 |
| 🏆 评级 | 四字全对小小书法家家 |

**操作:****点下方笔画按钮**(键盘 **1-5**)按笔顺书写。

> 💡 **打法:**① **永字八法**最难也最值,练好永字百字通;② **心的卧钩**是第三笔,别写成竖弯钩;③ 点错会提示,**记住正确顺序**;④ 描红就是**跟着写**,不用自己想;⑤ 四字写完,**书法入门了**!

**结算:**写对字数、连对、本局得分、历史最高分、已玩局数。
