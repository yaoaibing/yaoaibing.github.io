# 五音作曲 (🎼 五音作曲 · 宫商角徵羽)

> 分类:**音乐节奏** · 入口:/penta/ · 免费在线 · 手机即点即玩

**目标:**五声创作:点击宫商角徵羽五音砖**谱 8 音内旋律**,试听回放;按音多样性、级进流畅度、结尾落音(宫/徵)评分,零失败。

| 元素 | 效果 |
|---|---|
| 🏮 五音 | 宫商角徵羽 = 1 2 3 5 6 |
| 🎵 谱曲 | 最多 8 个音 |
| ▶ 试听 | 随时回放你的旋律 |
| ⭐ 评分 | 多样 x40 + 级进 x30 + 落音 80 |
| 🏆 评级 | 320 分仙乐级 |

**操作:**点**音砖**(键盘 **1-5**)谱曲,「**▶ 试听**」回放,「**🎵 成曲**」结算(回车)。

> 💡 **打法:**① **怎么敲都不跑调**——五声音阶的魔法;② 落音很值钱:**结尾落宫或徵 +80**;③ 相邻音级进(差 1-2)流畅分高,**大跳慎用**;④ 五个音都用上,**多样性拉满**;⑤ 谱完先试听,**耳朵满意再成曲**!

**结算:**成曲数量、本局得分、历史最高分、已作乐曲数。
