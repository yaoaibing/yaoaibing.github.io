# 拔根儿较劲 (🌿 拔根儿较劲 · 一根一局)

> 分类:**街机动作** · 入口:/bageng/ · 免费在线 · 手机即点即玩

**目标:**角力争锋:**挑梗角力**,五局定魁。

| 元素 | 效果 |
|---|---|
| 🌿 叶梗 | 三种韧度 |
| 👆 较劲 | 号响连点 |
| ⚡ 号令 | 倒数完再拔 |
| ⚠️ 自断 | 梗不撑劲 |
| 🏆 结算 | 拔根折分 |

**操作:****先挑梗**,号响**连点较劲**。

> 💡 **打法:**① **看对手的梗**再挑,杨梗对藤梗就是送;② 倒数**没完别拽**,抢跑泄力;③ 连点**节奏匀**,一股一股地较;④ 梗快断**发颤的那下**,再加把劲;⑤ 五局拔罢,**孩子王的位置就是你的**!

**结算:**局数、较劲度、本局得分、历史最高分、已玩局数。
