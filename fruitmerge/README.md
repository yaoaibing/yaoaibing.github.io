# 水果合成 (🍓 水果合成 · 大果冻)

> 分类:**解压休闲** · 入口:/fruitmerge/ · 免费在线 · 手机即点即玩

**目标:**把水果丢进箱子,两颗**同级水果相撞合成更大一级**,一路从樱桃合成大西瓜。果子堆过顶线并停住 1.8 秒就结束。

| 元素 | 效果 |
|---|---|
| 🍒 合成 | 同种水果相撞升一级,得分按新水果计算 |
| 🍉 西瓜 | 最高级,两个西瓜相撞直接爆掉 +160 |
| 👀 预览 | 顶部显示下一颗水果,提前规划落点 |
| 📏 顶线 | 果子停在红线以上超过 1.8 秒就结束 |
| 🧱 物理 | 水果会滚动、挤压,落点不只看瞄准线 |

**操作:**左右拖动瞄准,松手落果;**重置**开新局。键盘 <kbd>←</kbd><kbd>→</kbd> 移动,<kbd>空格</kbd> 落果。

> 💡 **打法:**① **小果靠边合,大果留中间**——中间空间最值钱;② 同类果尽量贴着落,别把同种分散到两边;③ 水果会滚,瞄准线只作参考,落点留一点余量;④ 有一列快顶到线了,优先把它合掉;⑤ 两个西瓜别急着合,清出的大片空间能救急。

**结算:**得分、合成次数、称号、历史最高分、已玩局数。
