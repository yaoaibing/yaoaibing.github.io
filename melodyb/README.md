# 补全音阶 (🎵 补全音阶 · 缺音听辨)

> 分类:**音乐节奏** · 入口:/melodyb/ · 免费在线 · 手机即点即玩

**目标:**旋律缺音听辨:四音旋律**缺一个音**(问号标示),听完后从三个琴键**点出缺的音**;旋律走向级进,答案在相邻音中,10 轮随机。

| 元素 | 效果 |
|---|---|
| 🎵 出题 | 四音级进旋律,1-2 号位缺音 |
| 🎹 三键 | 正确音+两个相邻干扰 |
| 📈 递进 | 缺口位置随机 |
| 🔥 连对 | 每题 120 + 连对 x12 |
| 🏆 毕业 | 10 轮全对 |

**操作:**听完**点琴键**(键盘 **1-3**)作答;**R** 键重听。

> 💡 **打法:**① 旋律是级进(相邻音)走向,<b>缺口前后音差半个到一个全音</b>;② 缺口画问号的位置就是答案位,**别多想**;③ 不确定时唱一遍旋律,<b>唱到卡壳的音就是它</b>;④ 连对分是复利,不确定选<b>听感更顺的那个</b>;⑤ 每天十分钟,一周后旋律耳朵明显变好!

**结算:**完成轮数、连对数、本局得分(120 + 连对 x12)、历史最高分、已玩局数。
