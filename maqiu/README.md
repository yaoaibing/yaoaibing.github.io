> 分类:**体育竞技** · 入口:/maqiu/ · 免费在线 · 手机即点即玩

**目标:**骑行击球:**追球蓄力挥杖**,向指定球门击出;五次进攻。

| 元素 | 效果 |
|---|---|
| 🏇 追球 | 拖动骑手 |
| 💪 蓄力 | 低打左高打右 |
| 🎯 破门 | 正中 60 擦柱 30 |
| ⚠️ 落空 | 离太远挥空杖 |
| 🏆 结算 | 五击定胜负 |

**操作:****拖动**追球,**按住蓄力松手**挥杖(空格)。

> 💡 **打法:**① **先看门在哪边**,蓄力方向别搞反;② **贴近再挥**,远着呢就白抡;③ 鞠球**来回滚**,预判它的折返;④ 连续破门**分差才拉开**;⑤ 五击四中,**球场边上都在喊你名号**!

**结算:**进攻次数、本局得分、历史最高分、已玩局数。
