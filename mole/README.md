# 打地鼠 (🔨 打地鼠)

> 分类:**街机动作** · 入口:/mole/ · 免费在线 · 手机即点即玩

**目标:**60 秒内抡锤敲冒头的地鼠,分数越高越好。
| 目标 | 分值 | 说明 |
|---|---|---|
| 🐹 普通地鼠 | +10 | 冒头就敲 |
| 💰 金鼠 | +50 | **探头时间最短**,身上会闪光 |
| 💣 炸弹鼠 | -20 | **别碰**,还会清零连击 |
| 👑 地鼠王 | 每锤 +15 / 打死 +120 | 每 18 秒来一次,**要敲 3 下** |

**连击:**5 连 ×1.5 / 10 连 ×2 / 20 连 ×3,空手或挨炸即清零。

**操作:**手机直接点土洞;键盘 `↑↓←→` 移光标 + `空格` 挥锤,`P` 暂停。

> 💡 **冲分打法:**① **连击是主要分数来源**,宁可少敲一只也别空手 —— 空手一次,20 连的 ×3 直接归零;② 金鼠分值 5 倍但探头最短,**盯着闪光的那几个洞**;③ 炸弹鼠和金鼠长得像,区别在于**炸弹是深色的、不闪光**,手快之前先看一眼;④ 地鼠王 18 秒一次、要敲 3 下,血最厚,**它一出现就停手专攻它**,120 分顶 12 只普通鼠;⑤ 多指并用,两只手一起点能明显提高命中率。

**结算:**总分、命中次数、最高连击、空手次数、被炸次数、地鼠王数。
