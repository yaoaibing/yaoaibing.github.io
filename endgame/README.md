# 象棋残局 (♔ 象棋残局 · 一子定音)

> 分类:**对战棋牌** · 入口:/endgame/ · 免费在线 · 手机即点即玩

**目标:**10 个经典象棋残局:每局展示盘面,三个走法中**只有一步能立即取胜**(将死/绝杀无解),点选正确答案过关,连对有加成。

| 元素 | 效果 |
|---|---|
| ♔ 盘面 | 每局独立残局,红方先行 |
| 👉 三选一 | 点正确走法,答错可重选 |
| 🧠 套路 | 马后炮/闷宫/双车错/铁门栓… |
| ✅ 连对 | 连续答对有分数加成 |
| 🏁 通关 | 破完 10 局即胜利 |

**操作:****点走法选项**作答;**回第1局**重头玩。先找黑将的位置,再想哪个子能一步置它死地!

> 💡 **打法:**① 先看<b>黑将在哪</b>,它的活动点越少越好杀;② 车走直线将杀最常见,看它和将是否同行同列;③ 马后炮=马作炮架,炮在将正后方;④ 有士象防守时,先看这些点是否被挡;⑤ 不确定就用排除法:两个明显送吃的先划掉!

**结算:**答对残局数、连对最高、本局得分(答对 x150 x连击)、历史最高分、已玩局数。
