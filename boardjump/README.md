# 跳浪登船 (⚓ 跳浪登船 · 浪头一跃)

> 分类:**街机动作** · 入口:/boardjump/ · 免费在线 · 手机即点即玩

**目标:**时机跳跃:**浪顶抓舷**,三船递进。

| 元素 | 效果 |
|---|---|
| ⚓ 小船 | 随浪起伏 |
| 🟩 绿条 | 浪顶提示 |
| 👆 起跳 | 点屏一跃 |
| 🌊 落水 | 耗一体力 |
| 🏆 结算 | 登船折分 |

**操作:**绿条亮时**点屏**起跳。

> 💡 **打法:**① **浪有节奏**,心里数一二三;② 绿条**亮起只一小会**,眼到手上;③ 落水**不冤**,下次提前半拍;④ 第二艘**浪更急**,节奏跟着变;⑤ 三船齐登,**船老大都收你入伙**!

**结算:**登船进度、剩余体力、本局得分、历史最高分、已玩局数。
