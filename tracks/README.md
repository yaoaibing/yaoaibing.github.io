# 足迹追踪 (🐾 足迹追踪 · 沙地侦探)

> 分类:**寻宝推理** · 入口:/tracks/ · 免费在线 · 手机即点即玩

**目标:**踪迹推理:沙地足迹可视化 + 两条特征线索,**四选一判断动物**;马鹿/赤狐/野猪/野兔/野鸭/山猫特征各异。

| 元素 | 效果 |
|---|---|
| 🦌 马鹿 | 步距长且直,蹄印双瓣 |
| 🦊 赤狐 | 飘忽梅花印,尾迹扫地 |
| 🐗 野猪 | 横冲直撞,蹄印深圆 |
| 🐇 野兔 | 前短后长双联印 |
| 🏆 评级 | 连对 5 题山野侦探 |

**操作:****点选项**(键盘 **1-4**)作答。

> 💡 **打法:**① **先看步距节奏**:直线的、飘忽的、乱撞的,先分三类;② 野兔**双联印**最好认,前短后长;③ 野鸭**三趾蹼**+左右摇摆;④ 猫科**圆印无爪痕**,犬科有爪痕;⑤ 记住:**形状细节比直觉靠谱**!

**结算:**连对、本局得分、历史最高分、已玩局数。
