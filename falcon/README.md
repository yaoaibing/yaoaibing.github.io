# 鹰猎寻踪 (🦅 鹰猎寻踪 · 放鹰召回)

> 分类:**寻宝推理** · 入口:/falcon/ · 免费在线 · 手机即点即玩

**目标:**召回时机:**低盘扑得准**,久盘必惊飞;八猎结算。

| 元素 | 效果 |
|---|---|
| 🦅 放鹰 | 点屏出鹰 |
| 🌀 盘旋 | 半径渐大 |
| 👇 召回 | 再点俯冲 |
| ⏰ 惊飞 | 盘旋过久 |
| 🏆 结算 | 低盘高分 |

**操作:**点屏**放鹰**,再点屏**召回**。

> 💡 **打法:**① **放鹰就盯紧**,别东张西望;② 盘旋**一两秒果断召回**,越低分越高;③ 盘过三圈**猎物必跑**,宁可放空;④ 每猎**草丛位置会换**,先找再放;⑤ 八猎全中,**驯鹰人都来讨教**!

**结算:**出猎次数、猎获数、本局得分、历史最高分、已玩局数。
