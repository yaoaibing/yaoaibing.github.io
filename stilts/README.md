# 踩高跷 (🤹 踩高跷 · 平衡之路)

> 分类:**街机动作** · 入口:/stilts/ · 免费在线 · 手机即点即玩

**目标:**平衡行走:重心摆倒时**点反方向**修正(倒地即败),阵风随机干扰;平衡越稳前进越快,60 秒按行进距离结算。

| 元素 | 效果 |
|---|---|
| ⚖️ 重心表 | 倒到头即摔 |
| ◀▶ 反打 | 点对方向才有用 |
| 💨 阵风 | 随机侧向推力 |
| 📏 计分 | 行进米数 x10 |
| 🏆 评级 | 200 米高跷高手 |

**操作:**点「**◀ 左撑 / 右撑 ▶**」(键盘 **← →**)。

> 💡 **打法:**① **小步高频**反打,大幅修正必摔;② 重心过中线再打,**提前打会荡过头**;③ 阵风来袭**连点两下**同向;④ 平衡区里**少动比多动稳**;⑤ 后程手酸,**节奏放慢比乱按远**!

**结算:**行进距离、平衡率、本局得分、历史最高分、已玩局数。
