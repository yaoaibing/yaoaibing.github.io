> 分类:**策略战棋** · 入口:/wisdom/ · 免费在线 · 手机即点即玩

**目标:**多线谋划:**每夜酒戏各-1**,踩点满 3 处即可动手;下药高风险高回报。

| 元素 | 效果 |
|---|---|
| 🍶 备酒 | 酒 +2 |
| 🕶️ 扮枣贩 | 戏 +2 |
| 🗺️ 踩点 | 点 +1(耗酒) |
| 🍹 下药 | 点 +1,高风险 |
| 🏆 得手 | 踩点≥3 即成 |

**操作:****点行动卡**(键盘 **1-3**)谋划。
