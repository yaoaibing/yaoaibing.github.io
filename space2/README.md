# 月球着陆 (🌕 月球着陆 · 反推落地)

> 分类:**太空导航** · 入口:/space2/ · 免费在线 · 手机即点即玩

**目标:**经典着陆模拟:月面重力持续下拉,**点火沿机头反推**(耗燃料),**↺↻ 调整姿态**;落灯牌条件:垂直速度 <52、横速 <36、姿态 ±0.3 内;重力与灯牌宽度逐次收紧,共 4 次。

| 元素 | 效果 |
|---|---|
| 🌕 重力 | 190→250 逐次增强 |
| 🔥 点火 | 沿机头 430 推力,耗油 16%/秒 |
| ↺↻ 姿态 | ±0.7 弧度,点火方向随姿态 |
| 🟢 灯牌 | 56→110px 逐次变窄 |
| 📊 仪表 | 垂速/横速超限即变红 |

**操作:**按住 **🔥点火**(空格/↑)反推,**↺↻**(←→/AD)调姿态;看仪表开车,别看风景!

> 💡 **打法:**① **高度 150 米是决胜点**:此时垂速必须已压进绿区,来不及了才叫自由落体;② 反推会让横移加速——<b>机头略向横速反方向倾</b>,一石二鸟;③ 燃料低于 25% 就放弃完美,<b>活着落上灯牌</b>哪怕歪一点;④ 灯牌位置每局随机,开场先横移对齐再下降;⑤ 着陆判定有 0.3 弧度容差,<b>轻微倾斜摔不死</b>,但横速 36 是死线!

**结算:**完成着陆次数、剩余燃料、本局得分(胜 400 + 燃料 x3 + 关卡 x80)、历史最高分、已玩局数。
