# 藏宝图 (🗺️ 藏宝图 · 三步寻踪)

> 分类:**寻宝推理** · 入口:/treasuremap/ · 免费在线 · 手机即点即玩

**目标:**寻宝推理:8×8 海岛图,三步**方向+步数**线索链从地标指向宝藏;挖对 +250,挖错扣分耗铲;4 张图结算。

| 元素 | 效果 |
|---|---|
| 🗼 地标 | 灯塔/棕榈/礁石/山峰/旧屋 |
| 🧭 线索 | 北南东西 + 步数,链式指向 |
| ⛏ 挖掘 | 5 把铲,错挖 -20 |
| 💰 宝藏 | 挖中 +250 + 剩铲奖励 |
| 🏆 评级 | 全中寻宝图大师 |

**操作:****点格子**挖掘。

> 💡 **打法:**① 先在图上**找到线索起点地标**;② 用手指**比划方向步数**,画十字定点;③ 链式线索**一步一步走**,别跳步;④ 铲子 5 把,**推理到八成才动铲**;⑤ 挖错也别慌,**排除法下一铲更准**!

**结算:**挖到宝藏数、剩余铲子、本局得分、历史最高分、已玩局数。
