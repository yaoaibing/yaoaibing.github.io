# 跳水表演 (🤿 跳水表演 · 十米台)

> 分类:**街机动作** · 入口:/dive/ · 免费在线 · 手机即点即玩

**目标:**点屏幕起跳,**按住翻腾**累计转体角度,松手停止旋转直坠入水。入水角度越接近竖直(0°)水花越小分越高,翻腾整圈有难度加分。共三跳。

**计分:**基础 600×(1-偏差比例)+每整圈 80;压水花(偏差<30°)满档;炸鱼(横着入水)也有底分 50。

> 💡 **跳水要点:**① 按住约 **0.55 秒=一整圈**,心里默数节拍;② 新手先练「一圈压水花」:起跳→按 0.55 秒→松手,等它转正入水;③ **两周转体**要按 1.1 秒,但入水偏差更难控,分数不一定更高;④ 松手后身体还有残余转速,**提前一点点松**;⑤ 三跳总分制,稳一跳比博一跳划算。

**结算:**三跳总分、每跳评价、历史最高分。
