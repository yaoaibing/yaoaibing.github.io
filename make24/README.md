# 24点 (🃏 24点 · 算术大师)

> 分类:**烧脑益智** · 入口:/make24/ · 免费在线 · 手机即点即玩

**目标:**每题发 **4 张牌**(A=1 … K=13),用 **+ − × ÷** 把它们算成 **24**。点两张牌再点运算符合并成新牌,合并顺序天然就是括号,每张牌只能用一次。

**操作:**点**第一张牌**(金框亮起)→ 点**运算符** → 点**第二张牌**,自动合并。除法可以出小数,最终牌面等于 24 即过关。↩撤销=整题重发;🔄换一题免费但本题不计分;练习模式不限时。

**计分:**限时模式 90 秒,答对 **+100 起、连对每题再 +20**;结算分=题数×120+最大连对×15。

> 💡 **速算要点:**① 先找 **3×8、4×6、2×12、12+12** 这些"标准分解",把四张牌往这些组合上凑;② 有 **3、4、6、8** 的题大概率是乘法题;③ 大牌(K/Q/J)先想办法**减掉或除掉**变成小数字;④ 分数解法别怕,游戏支持小数显示,比如 8÷(3−8÷3)=24 这种经典难题;⑤ 越到后面越依赖练出来的"数字敏感度",每天 90 秒很够用。

**结算:**题数、最大连对、本局得分、历史最高分。
