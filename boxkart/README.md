# 纸箱赛车 (📦 纸箱赛车 · 下坡漂移)

> 分类:**竞速赛车** · 入口:/boxkart/ · 免费在线 · 手机即点即玩

**目标:**下坡过门:按住左右**摆头转向**,穿旗门加速、撞筒掉速;车速渐增、门渐窄,3 次撞击结算。

| 元素 | 效果 |
|---|---|
| 🚩 旗门 | 过门 +25 并提速 |
| 🚧 雪糕筒 | 撞击掉速 50 |
| 📦 摆头 | 按住持续转向 |
| 📈 车速 | 240→380 km/h |
| 💥 结算 | 3 撞散架 |

**操作:****按住 ◀ / ▶** 摆头(键盘 ← →)。

> 💡 **打法:**① 入弯**提前摆头**,弯中稳住;② 旗门比筒重要,**门中一次顶三次过门分**;③ 车速 300 后**小修小补**,别大幅横移;④ 连续门看向**下一个门位**,别盯眼前;⑤ 三条命,**命在距离在**!

**结算:**滑降距离、车速、撞击次数、本局得分、历史最高分、已玩局数。
