# 汉堡现做 (🍔 汉堡现做 · 现做现卖)

> 分类:**模拟经营** · 入口:/burger/ · 免费在线 · 手机即点即玩

**目标:**快餐模拟:看订单**自下而上**叠汉堡(面包→配料→面包);放错 -20 重做,客人超时 -30 跑单;连对出餐分递增,75 秒内出最多。

| 元素 | 效果 |
|---|---|
| 🍔 叠层 | 按订单顺序从下往上 |
| 📋 订单 | 左侧票据,自下而上读 |
| ⏳ 耐心 | 14+层数秒,进度条变红 |
| 🔥 连对 | 出餐 100 + 连对 x10 |
| 🚫 重做 | 放错 -20 清空重叠 |

**操作:**点 **底部食材按钮**(键盘 **1-5**)按订单叠;放错自动清空。

> 💡 **打法:**① 底层面包**永远第一个**,别搞反;② 自下而上读订单,**先想好再按**;③ 连对是复利,<b>宁可慢一拍也别放错</b>;④ 客人耐心条变红时<b>优先出餐</b>别纠结;⑤ 配料虽随机但种类 ≤4,**排除法找相同**!

**结算:**出餐份数、做错次数、本局得分、历史最高分、已玩局数。
