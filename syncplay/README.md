**目标:**听音辨人:**齐奏找偏**,八轮指认。

| 元素 | 效果 |
|---|---|
| 🥁 四师 | 鼓锣钹笙 |
| 👂 细听 | 三秒听辨 |
| 👆 指认 | 四选一 |

| 🏆 结算 | 听辨折分 |

**操作:**听完**点乐师**指认。
