# 骰子天梯 (🪜 骰子天梯 · 和与积)

> 分类:**骰子冒险** · 入口:/tianti/ · 免费在线 · 手机即点即玩

**目标:**运算博弈:**二骰选和或积**,避雷登顶;与 AI 竞速。

| 元素 | 效果 |
|---|---|
| 🎲 双骰 | 每轮掷一次 |
| ➕ 取和 | 稳,2-12 步 |
| ✖️ 取积 | 险,1-36 步 |
| ⚠️ 雷 | 踩中退 3 |
| 🏆 赛制 | 先到 30 级胜 |

**操作:**点**掷骰**,再点**取和/取积**。

> 💡 **打法:**① **两骰乘积过 12 才值**,不然老老实实取和;② **雷就在前方**,差一级也别贪;③ AI **随机选**,你算着来就有优势;④ 落后时**必须赌积**,求稳输定;⑤ 先登顶,**天梯刻你的名字**!

**结算:**爬梯级数、本局得分、历史最高分、已玩局数。
