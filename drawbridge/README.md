**目标:**承重规划:**选垂度铺板**,货车验收。

| 元素 | 效果 |
|---|---|
| 🌉 主索 | 三档垂度 |
| 🪵 桥板 | 至多八块 |
| 🚚 验收 | 货车过桥 |
| ⚠️ 塌桥 | 承不住损命 |
| 🏆 结算 | 三段折分 |

**操作:**点**垂度钮**定索,**点屏**铺板。
