# 烟花秀 (🎆 烟花秀 · 夜空绽放)

> 分类:**解压休闲** · 入口:/fireworks/ · 免费在线 · 手机即点即玩

**目标:**没有输赢的治愈玩具。点夜空任意位置放一朵烟花,**按住拖动=连发扫射**;不点也有自动烟花秀。粒子带重力下坠消散,配"咻——砰!"音效。

**操作:**单击单发;按住不放+拖动可以画出一片烟花带。放了多少发**永久累计**。

> 💡 **玩法建议:**① 按**住画圆圈**,烟花会沿着你手指的轨迹炸成一圈,非常好看;② 高度拉满的烟花散开最大,贴近地面的闷响更带感;③ 音效开起来,每次"砰"的音高都不同;④ 想截图当壁纸的话,连发几发后趁粒子没散截图;⑤ 放完点"🌙谢幕结算"看累计数据。

**结算:**本次烟花数、历史累计。
