# 搭戏台 (🎭 搭戏台 · 对称立柱)

> 分类:**建造物理** · 入口:/stagebuild/ · 免费在线 · 手机即点即玩

**目标:**对称搭建:**立柱成对上梁**,层层递进;五层成台。

| 元素 | 效果 |
|---|---|
| 🎭 立柱 | 自动配对 |
| 🪵 横梁 | 压柱 +25 |
| ⚠️ 单柱 | 不能单拆 |
| 📐 递进 | 五层到顶 |
| 🏆 结算 | 五层开锣 |

**操作:****点格子**立柱,成对自动上梁。

> 💡 **打法:**① **先点一对柱**,梁就自动落;② **中柱单立**也能承梁,关键位;③ 上层柱**必须踩在下层梁上**;④ 搭歪了**成对才能拆**,别硬点;⑤ 五层台成,**开锣那一嗓子最亮**!

**结算:**搭设层数、立柱数、本局得分、历史最高分、已玩局数。
