# 盾反格挡 (🛡️ 盾反格挡 · 弹反之刃)

> 分类:**街机动作** · 入口:/parry/ · 免费在线 · 手机即点即玩

**目标:**时机格挡:飞刀连续袭来,**贴身瞬间举盾**触发弹反(+120 起、连击加成),提前举盾只算普通格挡,没举就中刀 -1 命;速度渐快,3 命结算。

| 元素 | 效果 |
|---|---|
| 🗡️ 飞刀 | 绿圈亮起=弹反窗口 |
| 🛡 举盾 | 举盾 0.22 秒有效 |
| ⚡ 弹反 | 贴身 +120,连击 x20 |
| 🟡 格挡 | 稍早 +40,断连击 |
| 💥 中刀 | -1 命、清连击 |

**操作:**点「**🛡 格挡**」或按**空格**举盾。

> 💡 **打法:**① **看刀的提示圈**,缩到贴身那帧才是按点;② 心里默念「来—来—按」,节奏比反应稳;③ 普通格挡也 +40,**拿不准就早一点**;④ 连击是弹反复利,**稳住前 5 把**;⑤ 后期刀速飞快,**盯刀尖别盯屏幕中央**!

**结算:**挡刀次数、弹反次数、本局得分、历史最高分、已玩局数。
