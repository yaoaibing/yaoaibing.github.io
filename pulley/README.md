# 滑轮组 (🪃 滑轮组 · 四两拨千斤)

> 分类:**建造物理** · 入口:/pulley/ · 免费在线 · 手机即点即玩

**目标:**滑轮物理:选择滑轮数(1-4)决定**拉程与指针速度**的取舍,指针进绿区拉动、绳程累积 120cm 完成吊装;3 块巨石结算。

| 元素 | 效果 |
|---|---|
| 🔀 滑轮 | 1-4 个,x4 省 4 倍拉程 |
| 🪢 拉 | 指针 ±22% 内有效 |
| ⚠ 回弹 | 拉偏绳程 -1 环 |
| ⚖️ 取舍 | 滑轮多指针飞快 |
| 🏆 计分 | 每拉 50 起步 x 滑轮系数 |

**操作:**点「**🔀 换滑轮**」选配置,「**🪢 拉**」在绿区出手(空格拉)。

> 💡 **打法:**① 滑轮 x1 慢针好对,**稳扎稳打流**;② 滑轮 x4 指针飞快,**预判党专用**;③ 拉偏回弹一环,**连续失手果断换滑轮**;④ 绿区正中收益一样,**不必贪中心点**;⑤ 石头越到后面越要**省拉程**,合理分配手感!

**结算:**吊装石块数、滑轮配置、本局得分、历史最高分、已玩局数。
