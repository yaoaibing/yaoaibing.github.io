# 滚球撞柱 (🎳 滚球撞柱 · 地滚保龄)

> 分类:**街机动作** · 入口:/bowlhit/ · 免费在线 · 手机即点即玩

**目标:**弹射撞柱:**拖放弹射**石球撞木柱;全倒 +100;六球四局结算。

| 元素 | 效果 |
|---|---|
| 🎳 五柱 | 两排三角站位 |
| 💥 撞倒 | 每柱 +30 |
| 🎯 全中 | 一球全倒 +100 |
| 🔢 六球 | 球尽或局满结算 |
| 🏆 评级 | 撞倒 12 柱地滚王 |

**操作:****从球往后拖**再松手(方向=拖的反向)。

> 💡 **打法:**① **拖的方向就是反方向**,想正打就往后拉;② **对准第一排中间**,撞倒连带后面;③ 擦边只倒一颗,**正中才是全倒**;④ 全倒奖励 100,**一球顶三球**;⑤ 六球打完,**分数落袋**!

**结算:**撞倒数、本局得分、历史最高分、已玩局数。
