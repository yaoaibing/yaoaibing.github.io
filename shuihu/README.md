> 分类:**卡牌构筑** · 入口:/shuihu/ · 免费在线 · 手机即点即玩

**目标:**比点出牌:**将牌对垒**,六轮智斗。

| 元素 | 效果 |
|---|---|
| 🃏 牌堆 | 十二将瓜分 |
| ⚔️ 对垒 | 星位定胜负 |
| ✅ 赢轮 | 大牌多加分 |
| 🧠 记牌 | 对手剩谁 |
| 🏆 结算 | 叶子戏折分 |

**操作:**点**手牌**出将。

> 💡 **打法:**① **星位即牌点**,宋江一出谁也压不住;② 大牌**捏到关键轮**,首轮就梭是新手;③ 对手**出大牌你让**,省下火力;④ 记住**对门亮过的牌**,算他手里还剩谁;⑤ 六轮赢四,**牌桌上的老大都被你叫来陪练**!
