# 骰子竞速 (🎲 骰子竞速 · 终点冲刺)

> 分类:**对战棋牌** · 入口:/dicerace/ · 免费在线 · 手机即点即玩

**目标:**24 格赛道双方竞速:轮到谁就**掷骰子**前进,踩到事件格触发顺风/陷阱/再掷一次;**落在对方格上把对方撞退 2 格**;先到终点者胜。

| 元素 | 效果 |
|---|---|
| 🎲 掷骰 | 点掷骰按钮,1-6 点随机 |
| 🍀 事件 | 顺风+3 / 陷阱-3 / 再掷一次 |
| ⚔️ 撞人 | 同格碰撞,对方退 2 格 |
| 🤖 电脑 | 自动掷骰,公平竞争 |
| 🏁 胜负 | 先到第 24 格者胜 |

**操作:****点掷骰子**按钮(键盘空格);**新局**重开。纯运气游戏,但事件格的博弈让你欲罢不能!

> 💡 **打法:**① 纯随机游戏,<b>心态</b>就是技术;② 事件格是翻盘点,落后别灰心;③ 撞人格是双刃剑,领先时别去踩;④ 「再来一次」格最爽,连掷两轮能反超;⑤ 电脑没有 secretly 加权,放心大胆掷!

**结算:**胜负、总点数、触发事件数、本局得分(胜 500 + 剩余距离差 x20)、历史最高分、已玩局数。
