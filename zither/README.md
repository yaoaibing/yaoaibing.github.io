# 古筝拨弦 (🎶 古筝拨弦 · 二十一弦)

> 分类:**音乐节奏** · 入口:/zither/ · 免费在线 · 手机即点即玩

**目标:**旋律记忆:听样曲后在 7 弦古筝上**原样复奏**;全对通关,曲长随关卡增加。

| 元素 | 效果 |
|---|---|
| 🎶 七弦 | 音阶从低到高 |
| 🔊 试听 | 可反复重听样曲 |
| 📈 曲长 | 3 音起步逐关加长 |
| ❤️ 容错 | 三颗心 |
| 🏆 评级 | 八曲全通筝乐师 |

**操作:****点筝弦**(键盘 **1-7**),可点「**🔁 重听**」。

> 💡 **打法:**① **三个音一组记**,像背电话号码;② 记**高低走向**,粗弦低细弦高;③ 拿不准就重听,**重听不扣分**;④ 拨错别慌,**下一曲重新来**;⑤ 哼出声来,**嘴是最好的记谱器**!

**结算:**弹奏曲数、连过、本局得分、历史最高分、已玩局数。
