# 填字风云 (📝 填字风云 · 成语盘)

> 分类:**烧脑益智** · 入口:/crossword/ · 免费在线 · 手机即点即玩

**目标:**每盘棋面上横竖交错排着成语,部分字被挖空:**点空格选字**填入,依据上下成语推断;全部填对即破盘,共 8 盘由易到难,提示 3 次。

| 元素 | 效果 |
|---|---|
| 📝 成语盘 | 横竖成语互相咬合,共享关键字 |
| 👆 填字 | 点空格再点候选字,可换可改 |
| ✅ 判定 | 填错只是不亮,无惩罚 |
| 💡 提示 | 直接填对一个空,每局 3 次 |
| 🏁 破盘 | 全部空格填对进入下一盘 |

**操作:****点空格**选中,**点候选字**填入;**提示**救急,**下一盘**跳盘。先把有把握的成语填完,共享字自然浮出!

> 💡 **打法:**① 先填<b>两个成语都用到</b>的交叉字,它对全局影响最大;② 想成语时把候选字一个个套进去念;③ 一横一竖两个成语,先做长度短的;④ 实在没头绪用提示,答案会点亮你的思路;⑤ 填完复查:成语念得通才算对!

**结算:**破盘数、用时、提示使用数、本局得分(破盘 x200 - 提示 x50)、历史最高分、已玩局数。
