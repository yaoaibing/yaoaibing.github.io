# 骰渡黄河 (⛵ 骰渡黄河 · 浪里行舟)

> 分类:**骰子冒险** · 入口:/ferrycross/ · 免费在线 · 手机即点即玩

**目标:**骰运博弈:**选舟载货掷骰**,浪头过险线翻船;三趟结算渡货。

| 元素 | 效果 |
|---|---|
| 🛶 小舟 | 2 箱,险线 7 |
| ⛴ 中舟 | 4 箱,险线 9 |
| 🚢 大舟 | 6 箱,险线 11 |
| 🌊 翻船 | 整舟货没,记一次 |
| 🏆 结算 | 渡货越多分越高 |

**操作:**点底部**舟型按钮**开渡。

> 💡 **打法:**① **头趟押大舟**,赌赢了占大便宜;② 翻过船**第二趟转稳**,小舟保底;③ **浪头骰全随机**,别信手气玄学;④ 货剩二箱**果断小舟**,稳稳带走;⑤ 五箱以上过河,**你就是黄河老艄公**!

**结算:**渡货箱数、本局得分、历史最高分、已玩局数。
