# 五子棋 (⚫ 五子棋 · 人机对战)

> 分类:**对战棋牌** · 入口:/gomoku/ · 免费在线 · 手机即点即玩

**目标:**横、竖、斜任意方向连成 **5 颗**即胜。你执**黑先手**,电脑执白。
| 操作 | 键位 |
|---|---|
| 落子 | 点/摸棋盘交叉点(自动吸附到最近点,落子前有半透明预览)
| 难度 | 简单(会漏防) · 普通(算 2 步) · 困难(算 4 步) |
悔棋 / 认输 / 重开 | 点对应按钮,悔棋一次退两手(你 + 电脑) |

> 💡 **下棋要点:**① 优先做**活三**(两头都能成四),对手只能堵一头;② 对手活三必须堵,别只顾自己连;③ **冲四**是硬棋,对手必须应,可以拿来抢先手;④ 双三、四三是经典杀法,困难难度电脑也会这么打你;⑤ 输给困难不丢人,先拿普通练手。
