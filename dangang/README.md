**目标:**交替蓄力:**左右交替攒摆幅**,满值回环;掉零脱手。

| 元素 | 效果 |
|---|---|
| 🤾 交替 | 左右半屏 A/D |
| 🔄 摆幅 | 满 100 过顶 |
| ⚠️ 同手 | -18 摆幅 |
| 📉 衰减 | 每秒掉 6.5 |
| 🏆 结算 | 回环越多越强 |
