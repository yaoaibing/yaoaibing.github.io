# 舞狮采青 (🦁 舞狮采青 · 桩上生风)

> 分类:**街机动作** · 入口:/liondance/ · 免费在线 · 手机即点即玩

**目标:**桩上跳跃:**点屏起跳**,鼓劲值决定跳高;踩桩前进,采到高处的青菜得大分,落地即结束。

| 元素 | 效果 |
|---|---|
| 🥁 鼓劲 | 跳跃自动攒,随时间泄 |
| 🦶 梅桩 | 高低错落向前延伸 |
| 🥬 采青 | 高桩青菜单笔 80 |
| ⚠️ 落地 | 踩空立即收场 |
| 🏆 评级 | 连桩 20 步采青王 |

**操作:****点屏幕/空格**起跳。

> 💡 **打法:**① **鼓劲满格再跳**,跳得高才够得着高桩;② **桩距看准**,起跳点离桩沿半步最稳;③ 采青在**桩顶上方**,跳到桩上就够到;④ 越跳越快,**手别快过眼**;⑤ 采一次青鼓劲回满,**节奏就顺了**!
