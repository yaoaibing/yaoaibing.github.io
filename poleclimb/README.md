# 爬杆夺旗 (🚩 爬杆夺旗 · 左右手)

> 分类:**街机动作** · 入口:/poleclimb/ · 免费在线 · 手机即点即玩

**目标:**交替节奏:**左右交替点击爬杆**,同手滑落;15 秒内登顶。

| 元素 | 效果 |
|---|---|
| 🧗 交替 | 左-右-左-右 |
| ⚠️ 同手 | 滑落 1 米 |
| 📈 步幅 | 一步 0.8 米 |
| ⏱ 限时 | 15 秒 |
| 🏆 结算 | 登顶 +200,按高度计分 |

**操作:**点**左右半屏**(A/D 键)交替爬。

> 💡 **打法:**① **心里打拍子**:左—右—左—右;② **同手滑落最伤**,宁可慢半拍;③ 最后两米**最想抢**,也是最易滑;④ 手指**悬在屏上别抬**,快半拍;⑤ 顶上红旗,**就是你的**!

**结算:**爬升高度、本局得分、历史最高分、已玩局数。
