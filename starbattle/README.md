# 星域布防 (⭐ 星域布防 · 一星一格)

> 分类:**烧脑益智** · 入口:/starbattle/ · 免费在线 · 手机即点即玩

**目标:**6x6 星战棋(Small Star Battle):盘面被分成 6 块连通的彩色星域,**每行、每列、每块星域都必须恰好放 1 颗星,且任意两颗星不能相邻(含斜角)**。点格子落子或取消,冲突的星描红。十张盘面由生成器枚举全部合法星位后反向生长分区,并用独立校验器复核规则,摆出任何一组合法星位即过关。限时到达分越高,提示会替你钉死一颗正确的星。

| 元素 | 效果 |
|---|---|
| ⭐ 落星 | 点格子放星,再点取消 |
| 📏 行列 | 每行每列各 1 颗,超了就描红 |
| 🎨 星域 | 6 块连通颜色域,每域 1 颗 |
| 🚫 相邻 | 米字邻格内不许有第二颗 |
| 💡 提示 | 替你钉一颗合法星,扣分 |

**操作:****点格子**放星 / 再点取消;**💡 提示**钉一颗合法星(每关 2 次,各扣 45 分);**↻ 清空**重摆本关。键盘 H 提示、C 清空、R 重开。

> 💡 **打法:**① 先找<b>只有一种落法的行</b>:某行的可用格被颜色域卡死时先钉它;② 一整块域贴着边界时,那一域只能落在唯一的角落;③ 星一落就把它的<b>米字九格</b>划掉,行列顺势收窄;④ 卡住就 ↻ 清空重看,别在错的第一手上硬撑;⑤ 提示留到最后一格再用,一分能顶两关。

**结算:**通过关卡数、本局得分(每关基础分 + 剩余秒数 - 提示扣分)、历史最高分、已玩局数。
