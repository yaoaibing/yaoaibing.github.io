# 九子棋 (⭕ 九子棋 · 成三吃子)

> 分类:**对战棋牌** · 入口:/morris/ · 免费在线 · 手机即点即玩

**目标:**双方各 9 子,先在 24 个点上轮流**布子**,三子成线就能吃掉对方一子。布完后沿连线走子,把对手吃到**只剩 2 子**或堵死即获胜。

| 元素 | 效果 |
|---|---|
| ⭕ 布子 | 前 18 手轮流落子,每次一颗 |
| 🎯 成三 | 三颗同色子在同一条线上即成一三,立即吃对方一子 |
| 🛡️ 保护 | 优先吃不在成三里的子,对方全在成三里才能拆线 |
| 🚶 走子 | 布完后每次沿连线走一格,走到能成三的点 |
| 🏁 胜负 | 对方少于 3 子或无合法走法即获胜 |

**操作:**布子阶段点空点落子,走子阶段先点自己的子再点相邻空点;成三后点对方棋子吃掉。**悔棋**退回你的上一手,底部切换难度。

> 💡 **打法:**① 布子先抢占**十字路口**和连线多的点;② 别急着成三,先做出**双三威胁**让对手顾不过来;③ 自己的子尽量连成两线互相保护;④ 走子阶段先堵对方的活动点,再考虑自己成三;⑤ 对手只剩 3 子时,封死它的所有相邻点就能赢。

**结算:**胜负、双方剩余子数、成三次数、难度、本局得分(胜利 900 + 吃子数 x80 + 难度 0/100/200)、历史最高分、已玩局数。
