# 行列寻踪 (🧭 藏宝图 II · 行列寻踪)

> 分类:**寻宝推理** · 入口:/gridhunt/ · 免费在线 · 手机即点即玩

**目标:**行列数谜寻宝:羊皮纸边缘标注**每行/每列的宝藏数量**,交叉比对行列数字推出宝藏坐标;误挖空坑 -20 分并留记号;每图挖齐全部宝藏过关,5 图宝藏 2→4 件。

| 元素 | 效果 |
|---|---|
| 🔢 行数字 | 左侧数字 = 该行埋的宝藏件数 |
| 🔢 列数字 | 顶部数字 = 该列埋的宝藏件数 |
| ✖️ 误挖 | 空坑 -20 分,但留下排除记号 |
| 💎 过关 | 挖齐当图全部宝藏 |
| 📈 递进 | 宝藏 2/3/3/4/4 件 |

**操作:****点击格子**挖掘即可;心里划掉已确认的行列,纸面推理一键完成!

> 💡 **打法:**① 数字为 0 的行/列<b>整行整列划掉</b>,排除面最大;② 行数字=1 且列数字=1 的交叉点<b>必是宝藏</b>;③ 某行数字 2,而未挖格子只剩 2 个,<b>直接全挖</b>;④ 误挖留记号是资产:排除信息越挖越多,<b>后期反而更准</b>;⑤ 最后一图 4 件宝藏,先数总和核对行列数字之和是否相等(必相等)再动手!

**结算:**寻获图数、误挖次数、本局得分(每图 300 - 误挖 x20)、历史最高分、已玩局数。
