# 跳远冠军 (🏅 跳远冠军 · 腾空一跳)

> 分类:**体育竞技** · 入口:/longjump/ · 免费在线 · 手机即点即玩

**目标:**三跳定胜负:**按住**加速助跑,在黄色起跳板区间内**松手**起跳(越贴中线越好),**再点一下**锁定角度;距离 = 物理抛物线公式,冲过板即踩线犯规;与 AI 各三跳比最远。

| 元素 | 效果 |
|---|---|
| 🏃 助跑 | 按住加速,满速 10.5m/s |
| 🟨 起跳板 | 区间内松手有效,贴中线加成最高 |
| 📐 角度 | 摆动条再点锁定,45° 理论最远 |
| 🚫 犯规 | 越过板尾松手 = 踩线,成绩作废 |
| 🏅 胜负 | 三次取最远与 AI 比较 |

**操作:****按住**起跑,**松手**起跳,**再点**锁角度(空格同样三连);**重赛**重开三跳。

> 💡 **打法:**① 助跑一定要<b>拉满速</b>,速度是平方进距离的;② 起跳点贴住黄色中线,成色加成直接进公式;③ 角度条摆到 <b>45° 附近</b>再锁,60° 看着高其实近;④ 最后一条领先时求稳:宁可 44° 也别等 45° 错过板;⑤ AI 单跳 5.4-8 米,你满速贴板 45 度能到 7 米+,稳赢!

**结算:**三跳成绩、最远距离、胜负、本局得分(最远 x100 + 胜 300)、历史最高分、已玩局数。
