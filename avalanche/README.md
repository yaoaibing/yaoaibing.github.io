# 雪崩逃生 (🏔️ 雪崩逃生 · 向下挖掘)

> 分类:**生存挑战** · 入口:/avalanche/ · 免费在线 · 手机即点即玩

**目标:**向下生存:雪崩追近、氧气消耗;**挖=深入甩开雪崩**,**氧袋=续命**,**探=捷径或塌方**;挖到 60 米或氧尽/被埋/重伤结束。

| 元素 | 效果 |
|---|---|
| ⛏ 挖 | +8~15 米,同时拉开雪崩距离 |
| 🫁 氧袋 | +25~45 氧气 |
| 🧭 探 | 50% 捷径 / 30% 塌方 / 20% 氧气 |
| ❄ 雪崩 | 每回合追 6~11 米 |
| 🫁 氧气 | 回合 -12,归零窒息 |

**操作:**点 **挖/氧袋/探**(键盘 **1/2/3**);行动力 3 点用完自动休整。

> 💡 **打法:**① **氧气过半再挖**:氧气是硬通货币,挖的收益是距离;② 雪崩追到距离 ≤0 直接被埋,<b>挖的优先级永远最高</b>;③ 探是赌博:50% 捷径 30% 塌方,<b>血量低于 40 别探</b>;④ 氧袋加 25-45,<b>氧低于 40 必须补</b>;⑤ 挖和探都能拉开雪崩距离,**两手抓两手硬**!

**结算:**挖掘深度、雪崩距离、氧气/生命终值、本局得分、历史最高分、已玩局数。
