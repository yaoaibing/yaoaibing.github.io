# 暴风雪夜 (❄️ 暴风雪夜 · 撑到天亮)

> 分类:**生存挑战** · 入口:/blizzard/ · 免费在线 · 手机即点即玩

**目标:**资源生存:8 小时内**砍柴/补棚/添火**三选一,每回合暴风雪侵蚀体温/火堆/棚子;棚破加倍掉温,体温归零失败,天亮按余量结算。

| 元素 | 效果 |
|---|---|
| ❄️ 暴风雪 | 每小时三项全掉 |
| 🪓 砍柴 | 柴 +14~30,体温 -6 |
| ⛺ 补棚 | 棚 +15~30,体温 -4 |
| 🔥 添火 | 耗柴回暖,火堆大补 |
| 🏆 结算 | 余温 x8 + 资源奖励 |

**操作:**点「**砍柴/补棚/添火**」推进一小时。

> 💡 **打法:**① **柴是命根子**,前 3 小时先囤柴;② 棚低于 25% 失温加倍,**破棚比缺火更危险**;③ 火堆低于 20 该添了,**别等体温红条**;④ 砍柴也掉体温,**取暖砍柴要轮着来**;⑤ 最后两小时猛添火,**活着比什么分都重要**!

**结算:**剩余体温、火堆量、撑过小时数、本局得分、历史最高分、已玩局数。
