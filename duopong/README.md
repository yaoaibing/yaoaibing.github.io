# 双人乒乓 (🏓 双人乒乓 · 同屏对战)

> 分类:**对战棋牌** · 入口:/duopong/ · 免费在线 · 手机即点即玩

**目标:**一部手机**两个人打**!一人守上方球拍、一人守下方,球漏过谁谁丢分,**先到 7 分**赢下比赛。

**操作:**各自**按住自己那半屏**左右拖动移动球拍(支持双指同时)。键盘:下方玩家 `A``D`,上方玩家 `←``→`。回合越长球越快、反弹角度越刁。

> 💡 **对战心得:**① 球拍**边缘击球**会把球打得很偏——用拍边打角度是进攻,留拍心是防守;② 回合越长球速越快,**先稳后凶**;③ 上方玩家视角是"倒着看"的,开局先适应半分钟;④ 一个人也能玩:左右手各控一边自练;⑤ 聚会规则建议:输家下局先发球,三局两胜。

**结算:**双方比分、总回合数、完赛局数。
