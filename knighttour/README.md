# 马踏棋盘 (🐎 马踏棋盘 · 走日全巡)

> 分类:**对战棋牌** · 入口:/knighttour/ · 免费在线 · 手机即点即玩

**目标:**路径规划:**马步巡游**,二十五格。

| 元素 | 效果 |
|---|---|
| 🐎 马步 | 走日八向 |
| 🟢 绿点 | 当前可落 |
| 🔢 序号 | 踏格计数 |
| ⚠️ 死局 | 无路即止 |
| 🏆 结算 | 踏格折分 |

**操作:**点**绿点**行马。

> 💡 **打法:**① **起手选边角**,回路多不容易封死;② **少进死角**,四周绿点少于两个的格子最后再踏;③ **盯着绿点数走**,一步一步留后路;④ 死局**也按格计分**,三十格外多走多扣;⑤ 二十五格全遍,**棋盘上留下一整圈马蹄印**!

**结算:**踏格数、全巡目标、本局得分、历史最高分、已玩局数。
