# 俄罗斯方块 (🧱 俄罗斯方块)

> 分类:**烧脑益智** · 入口:/tetris/ · 免费在线 · 手机即点即玩

**目标:**标准 10×20 场地,7 种方块(I/O/T/S/Z/J/L),消行得分、堆满即结束。
| 操作 | 手机 | 键盘 |
|---|---|---|
| 挪列 | **左右拖动**,按格吸附 | `←``→` |
| 旋转 | 上滑 / 单击 / ↻ | `↑` 或 `X` |
| 软降 | 下滑(攒下落分) | `↓` |
| 硬降 | 滑到底 | `空格` |
| 暂存 Hold | 🎒 按钮 | `C`(每块限一次) |
| 暂停 | — | `P` |

**计分:**一次消 1/2/3/4 行 = **100/300/500/800 × 等级**;连续 Tetris(四连消)**B2B 再 ×1.5**;每 10 行升 1 级,重力一路飙到 15 级。

> 💡 **打法:**① **永远留一个 I 的坑**——四连消 800×等级,是普通消行的 8 倍,别把 I 随手填了;② **贴墙旋转会自动踢墙**,夹住也能翻,所以窄缝里别怕转;③ **Hold 是救命键**,来了一块没地方放的就先存起来,等下一块;④ 软降每格 +1 分,硬降每格 +2 分,**想刷分就硬降**,想稳就软降微调;⑤ 连击(连续消行)有额外加成,**宁可攒着一起消,别消一行就走**;⑥ 等级越高下落越快,**前期慢的时候把地形铺平**,后面才扛得住。

**结算:**总分、消行数、四连消次数、最高连击、落块数、到达等级、用时。
