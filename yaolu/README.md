# 摇橹顺流 (🚣 摇橹顺流 · 一橹一湾)

> 分类:**竞速赛车** · 入口:/yaolu/ · 免费在线 · 手机即点即玩

**目标:**左右交替:**换橹正舵**,三湾顺水。

| 元素 | 效果 |
|---|---|
| 🚣 木橹 | 一摇一扳 |
| 👆 换边 | 左右轮着点 |
| 🌊 水势 | 湾湾不同向 |
| ⚠️ 打转 | 连摇一边 |
| 🏆 结算 | 摇橹折分 |

**操作:****左右交替点**摇橹。

> 💡 **打法:**① **盯船头度数**,偏三度就换边;② 交替**越匀越快**,顺水推舟;③ 湾越深**水越拧**,手要更勤;④ 船头**太偏行船慢**,先正舵再赶路;⑤ 三湾进港,**梢公都问你要不要搭伙**!

**结算:**湾数、船头向、本局得分、历史最高分、已玩局数。
