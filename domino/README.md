# 多米诺 (⚄ 多米诺接龙 · 对战)

> 分类:**对战棋牌** · 入口:/domino/ · 免费在线 · 手机即点即玩

**目标:**28 张双六骨牌每人发 7 张,轮流把骨牌**接到链条两端**(点数必须匹配),接不上就摸牌。**先出完手牌**获胜;双方都卡住时,剩余点数少的一方赢。

| 元素 | 效果 |
|---|---|
| ⚄ 骨牌 | 双六牌组 28 张,每张两端有点数 |
| 🔗 接龙 | 新牌的一端点数要与链条端点一致 |
| 🂠 摸牌 | 手牌接不上就摸,直到摸到能出的或摸空 |
| 🚫 卡局 | 双方都无法行动且牌堆空,比剩余点数 |
| 🏁 胜负 | 先清空手牌获胜,卡局点少者胜 |

**操作:**点手牌选牌,再点链条**左端/右端**放下;接不上时点**摸牌**。**新局**重开。首局电脑先出会自动摆好。

> 💡 **打法:**① 尽早甩掉**大点数牌**,卡局时剩点少才赢;② 手里留一张**双牌**(如 6|6)当保险,任何时刻都能应急;③ 盯着链条两端出牌,让两端都变成电脑没有的点数;④ 牌堆快空时先算:电脑摸不到牌就只能过;⑤ 电脑连续摸牌就是它接不上,趁机把链条两头都堵死。

**结算:**胜负、剩余牌数与点数、摸牌次数、本局得分(胜利 600 + 对手剩点 x10)、历史最高分、已玩局数。
