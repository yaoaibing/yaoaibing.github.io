# 迷雾列车II (🚉 迷雾列车 II · 返程)

> 分类:**互动剧情** · 入口:/story2/ · 免费在线 · 手机即点即玩

**目标:**续篇剧情:一年后主动返程,**信赖/从容/行囊**三属性随选择增减;收集**怀表、地图、孩子**三件信物可达成真圆满,共 4 个结局。

| 元素 | 效果 |
|---|---|
| 🚉 返程 | 始发站印着你的名字,主动赴约 |
| 🕰️ 旧物 | 车厢里是你上次留下的三件遗物 |
| 👁️ 去年 | 「去年」站台上站着一年前的你 |
| 🪧 两块牌 | 终点抉择:雾散,或继续前行 |
| 🎞 结局 | 圆满/自由/徘徊/遗憾 |

**操作:****点选项**推进(键盘 **1/2/3**);一周目随意体验,二周目按信物清单规划!

> 💡 **打法:**① 真圆满公式:<b>帮孩子(收鞋)→收怀表→用地图说服乘客</b>,三信物缺一不可;② 「给新票」是好选择但耗行囊,<b>先攒再给</b>;③ 从容线(闭眼/守行李)通向自由结局,喜欢留白就选它;④ 属性不足真结局门槛会在终章自动降级,<b>别硬闯</b>;⑤ 两个篇章连玩,剧情细节会互相呼应!

**结算:**达成结局(4 种)、信赖/从容/行囊终值、本局得分(结局分 + 属性 x12)、历史最高分、已玩局数。
