# 疯狂堆塔 (🏗️ 疯狂堆塔 · 精准落块)

> 分类:**解压休闲** · 入口:/stack/ · 免费在线 · 手机即点即玩

**目标:**滑动的方块**点屏幕放下**:与下层重叠的部分保留,悬空部分被切掉,塔越来越窄;完全对齐触发「完美」回涨塔宽。塔宽归零或三次大偏差即结束,层数越高分越高。

| 元素 | 效果 |
|---|---|
| 🏗️ 放块 | 点屏幕任意处放下滑块 |
| ✂️ 切割 | 重叠部分保留,悬空部分掉落 |
| ✨ 完美 | 误差 < 4px 回涨塔宽 +10% |
| 📉 变窄 | 每块都比下层小一点 |
| 🏁 结束 | 完全没搭上即结束 |

**操作:****点屏幕**放块;**重堆**重新开始。速度和方向都会变化,专注看当前滑块与塔顶的相对位置!

> 💡 **打法:**① 盯着<b>滑块和塔顶的重合段</b>,不看别的;② 完美回涨塔宽,是续命的关键;③ 前几层宁慢勿快,把节奏稳住;④ 滑块到塔顶正上方时提前半格点,有落体延迟;⑤ 连续完美后速度暴涨,做好心理准备!

**结算:**层数、完美次数、最终塔宽、本局得分(层 x50 + 完美 x80)、历史最高分、已玩局数。
