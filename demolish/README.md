# 定向拆除 (🧱 定向拆除 · 拆楼专家)

> 分类:**烧脑益智** · 入口:/demolish/ · 免费在线 · 手机即点即玩

**目标:**点柱子拆除支撑,建筑在重力下倒塌;废墟必须落在**目标区域**内才算成功,精度决定得分。10 栋楼由矮到高。

| 元素 | 效果 |
|---|---|
| 🧱 柱子 | 点一下拆除,建筑失去支撑 |
| 🎯 目标区 | 地面上标出的范围 |
| 📐 物理 | 重心偏了会往偏的方向倒 |
| 📊 精度 | 废墟在目标区内的比例 |
| 🏁 过关 | 精度 ≥ 60% 过关 |

**操作:****点柱子**拆除;全部拆完后自动倒塌判定;**重来**复位本关。先拆一侧的柱子让楼往目标区倒!

> 💡 **打法:**① 先拆<b>远离目标区</b>那侧的柱子,楼往有支撑的方向倒;② 高楼比矮楼好控制方向;③ 不是拆得越多越好,有时候只拆一根就够了;④ 观察哪些柱子是承重的,拆非承重的没效果;⑤ 精度 60% 就过关,先过关再追求高分!

**结算:**通关数、平均精度、总拆除柱数、本局得分(精度 x5)、历史最高分、已玩局数。
