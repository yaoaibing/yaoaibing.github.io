**目标:**顺序装配:**按缺补件**,三箱递进。

| 元素 | 效果 |
|---|---|
| 🪗 风箱 | 拉杆阀板毛边 |
| 👆 补件 | 三选一 |
| 🔥 试拉 | 装成见火 |
| ⚠️ 漏风 | 满百收摊 |

**操作:**点**缺的那件装上**。
