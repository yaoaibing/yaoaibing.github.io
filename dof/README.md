# 景深对焦 (📸 景深对焦 · 一档光圈)

> 分类:**摄影抓拍** · 入口:/dof/ · 免费在线 · 手机即点即玩

**目标:**参数匹配:**焦点加光圈贴题意**,快门定分;四张结算。

| 元素 | 效果 |
|---|---|
| 📸 焦点 | 前后四平面 |
| 🔆 光圈 | 四档可拧 |
| 🎯 题意 | 虚化或泛焦 |
| 📸 快门 | 调好再按 |
| 🏆 结算 | 贴合越高分 |

**操作:**点**近焦/远焦**、**光圈**,再点**快门**。

> 💡 **打法:**① **先读题**:要虚化就大光圈,要全清就 f/16;② 焦点**对准题面那个平面**,差一层就糊;③ **f/1.4 虚得最狠**,人像糖水片;④ 泛焦**忘了拧光圈**等于白拍;⑤ 四张全到位,**影展挂你这张**!

**结算:**拍摄张数、光圈档位、本局得分、历史最高分、已玩局数。
