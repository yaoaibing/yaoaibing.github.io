# 激光迷宫 (🔦 激光迷宫 · 光路解谜)

> 分类:**烧脑益智** · 入口:/laser/ · 免费在线 · 手机即点即玩

**目标:**发射器向下射出激光,**旋转斜面镜**让激光转弯,最终照到蓝色水晶。8 个手工关卡,步数越少分越高,顺路点亮星星有额外分。

**机制:**镜面 45°,**点一下切换 / 和 \\ 两种朝向**:右行激光打在 \\ 上转 DOWN,打在 / 上转 UP。深色墙挡光。选定所有镜面后光路自动连通即过关。

> 💡 **解谜要点:**① 从发射器出发**顺光路推一遍**,看它停在哪、离水晶差几个弯;② 记住口诀:**\\ 镜=右转下,/ 镜=右转上**;③ 星星在主路上就顺路拿,**偏路 2 步以上的星放弃**;④ 关卡 6 起有干扰镜,转错会把光引向死角,**复位按钮随时回到初始**;⑤ 激光实时可见,**边转边看光路变化**是最直接的解题方式。

**结算:**8 关通关、总得分(关卡+星星-步数)、历史最高分。
