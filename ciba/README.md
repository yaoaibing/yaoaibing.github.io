# 打糍粑 (🍚 打糍粑 · 一杵一香)

> 分类:**街机动作** · 入口:/ciba/ · 免费在线 · 手机即点即玩

**目标:**交替锤击:**换手舂糯**,四臼递进。

| 元素 | 效果 |
|---|---|
| 🍚 石臼 | 糯米热腾腾 |
| 👆 落杵 | 左右交替 |
| 💥 连击 | 细腻蹭蹭涨 |
| ⚠️ 粘杵 | 细腻倒扣 |
| 🏆 结算 | 打粑折分 |

**操作:****左右钮交替点**落杵。

> 💡 **打法:**① **口诀带节奏**,左杵右杵别打乱;② 连击**越不断越值钱**,细腻翻着涨;③ 粘杵**细腻倒扣**,手忙就乱;④ 臼号越深**糯越粘**,换手更快;⑤ 四臼起泡,**蘸豆面吃头一口**!

**结算:**臼号、细腻度、本局得分、历史最高分、已玩局数。
