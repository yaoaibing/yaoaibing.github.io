# 驼队竞速 (🐪 驼队竞速 · 鸣沙催驼)

> 分类:**竞速赛车** · 入口:/camelrace/ · 免费在线 · 手机即点即玩

**目标:**节奏竞速:**催驼绕丘**,六百里程。

| 元素 | 效果 |
|---|---|
| 🐪 催驼 | 绿区点屏 |
| 💨 沙丘 | 按箭头绕 |
| 💧 水袋 | 渴了点喂 |
| ⚠️ 疲劳 | 催过头 |
| 🏆 结算 | 里程折分 |

**操作:**绿区**点屏催驼**,沙丘**点提示侧**。

> 💡 **打法:**① **环进绿区才催**,红区催是打骆驼;② 沙丘**提前半屏绕**,顶着走最亏;③ 水袋**三只金贵**,渴到红条再喂;④ 疲劳**比慢更可怕**,匀速才是快;⑤ 头驼冲线,**驼铃一路响到家**!

**结算:**竞速里程、水袋数、本局得分、历史最高分、已玩局数。
