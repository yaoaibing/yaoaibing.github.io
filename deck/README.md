# 牌库远征 (🃏 牌库远征 · 卡牌构筑)

> 分类:**卡牌构筑** · 入口:/deck/ · 免费在线 · 手机即点即玩

**目标:**卡牌构筑 roguelite:**先选 8 张牌**(挥砍/重击/格挡/恢复/连击)组牌库;战斗中手牌三张、点牌即出并补牌;**格挡值自动抵消**怪物每 1.5 秒的撞击,连击牌强化下一击;五战全胜通关。

| 元素 | 效果 |
|---|---|
| ⚔️ 攻击 | 挥砍 3-6,重击 6-10 |
| 🛡️ 格挡 | 2-5 点护盾,抵消撞击后剩余保留 |
| 💚 恢复 | 回血 3-6,当轮不设防 |
| ⚡ 连击 | 下一张攻击伤害 +50% |
| 🐙 敌人 | 5 种,血量攻击逐战提升 |

**操作:**选牌阶段**点卡**收入牌库(1-3);战斗阶段**点手牌**(1-3)出牌。出牌节奏自己掌控,敌人撞击定时来!

> 💡 **打法:**① 构筑黄金比例:**4 攻 2 盾 1 治 1 连击**,攻守兼备;② ⚡连击牌<b>必配重击</b>,10 伤害变 15 最划算;③ 对手攻击是固定值,**算好格挡够一次就别多攒**,留出牌位输出;④ 怪物每 1.5 秒一撞,<b>两牌之间想清楚</b>,手忙脚乱就重开;⑤ 重击牌越多,"先⚡后🗡"的两回合爆发循环就是通关公式!

**结算:**推进战斗数、剩余生命、牌库构成、本局得分(胜 500 + 生命 x8)、历史最高分、已玩局数。
