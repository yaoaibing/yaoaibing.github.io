# 招标评审 (📋 招标评审 · 权重定标)

> 分类:**拍卖竞价** · 入口:/tender/ · 免费在线 · 手机即点即玩

**目标:**多目标决策:三家标书三维度,**自定权重**算综合分并定标;超预算折损得分;每轮预算与标书随机,六轮结算。

| 元素 | 效果 |
|---|---|
| 🏷 价格 | 低于预算越多分越高 |
| 💎 质量 | 0-100 直接入分 |
| ⏱ 工期 | 天数越短分越高 |
| 🎚 权重 | 三维 0-100 自定义 |
| ⚠ 超支 | 超预算得分的 40% |

**操作:**「**◀ ▶**」调权重,「**🔀 换维度**」切换(←→/Tab),「**✅ 定标**」确认(回车)。

> 💡 **打法:**① 先看三家**谁在哪个维度碾压**,再定权重;② 差距最大的维度**权重往低调**,避免一票定局;③ 全部超预算时,**选超得最少的质量优等生**;④ 预算紧时价格权重拉满;⑤ 现实评标也这么玩,**学完直接上岗**!

**结算:**定标项目数、评审得分、本局得分、历史最高分、已玩局数。
