# 天平找次珠 (⚖️ 天平找次珠 · 两称定案)

> 分类:**烧脑益智** · 入口:/scalefind/ · 免费在线 · 手机即点即玩

**目标:**逻辑推理:**称量排除**,四案连环。

| 元素 | 效果 |
|---|---|
| ⚖️ 天平 | 两次机会 |
| 🔵 八珠 | 一珠偏重 |
| 👆 上盘 | 左四右四 |
| 💡 定案 | 点中次珠 |
| 🏆 结算 | 称量折分 |

**操作:**点**珠上盘**,按**称**,再**点定案**。

> 💡 **打法:**① 第一次**四对四**,平了就查没上秤的;② 倾斜**记住沉的一盘**,再从中分组;③ 第二次**两对两**最划算,平则取余;④ 一称定案**五十封顶**,敢赌才高分;⑤ 四案全破,**掌柜的把账本都交你管**!

**结算:**找珠进度、称量次数、本局得分、历史最高分、已玩局数。
