# 逆光剪影 (🌆 逆光剪影 · 曝光拿捏)

> 分类:**摄影抓拍** · 入口:/backlit/ · 免费在线 · 手机即点即玩

**目标:**参数摄影:**调 EV 与补光**,按每张的光比要求打分;八张连拍。

| 元素 | 效果 |
|---|---|
| 🌆 EV | -3 到 +3 档 |
| 💡 补光 | 关/半/全三档 |
| 📷 快门 | 按区间评分 |
| 📊 直方图 | 实时预览明暗 |
| 🏆 评级 | 均分 90 海报手 |

**操作:**点**±EV / 补光 / 快门**按钮。

> 💡 **打法:**① **先看题面要求**:要剪影还是保细节,方向别反;② **天空过曝毁一切**,EV 宁可保守;③ **补光是提人脸的**,要剪影就全关;④ 直方图**堆在右边就是过曝**;⑤ 八张连拍,**每张都要按要求来**!

**结算:**拍摄张数、本局得分、历史最高分、已玩局数。
