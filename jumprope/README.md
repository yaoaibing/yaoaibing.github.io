# 跳绳 (🪢 跳绳 · 连跳不停)

> 分类:**体育竞技** · 入口:/jumprope/ · 免费在线 · 手机即点即玩

**目标:**节奏跳绳:点击/**空格起跳**,在绳子过脚前腾空;成功 +10 起步、连跳加成,绳速逐跳加快;绊到 3 次结算。

| 元素 | 效果 |
|---|---|
| 🪢 绳速 | 每跳加速,最低 0.55s/圈 |
| ⏱ 起跳 | 腾空约 0.45 秒窗口 |
| 🔥 连跳 | 每跳 10 + 连跳 x2 |
| ⚠ 失误 | 绊到 -20,3 次结算 |
| 🏆 评级 | 80 下绳王 |

**操作:**点击屏幕或按**空格**起跳。

> 💡 **打法:**① **听破风声**比盯绳子准,声音到脚边就是跳点;② 早期绳慢,**刻意练半拍提前量**;③ 连跳是复利,**稳 50 比冲 100 值钱**;④ 绊到别连点,**等绳子过去再起跳**;⑤ 手别抖,**节奏感是数出来的**:1-2-跳!

**结算:**跳过次数、最长连跳、失误次数、本局得分、历史最高分、已玩局数。
