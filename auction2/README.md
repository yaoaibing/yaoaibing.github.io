# 黑石拍卖 (🕯️ 黑石拍卖 · 夜场加映)

> 分类:**拍卖竞价** · 入口:/auction2/ · 免费在线 · 手机即点即玩

**目标:**拍卖进阶:每件拍品公开**底价**,落槌价低于底价即流拍;新增**一口价**=底价 2.2 倍,现金充足可跳过竞价直接买下;与三位新 AI 竞拍 6 件,转手按真实价值结算净利润。

| 元素 | 效果 |
|---|---|
| 🏷️ 底价 | 公开,低于它落槌 = 流拍 |
| 💎 一口价 | 底价 x2.2,即刻成交跳过竞价 |
| 🔨 加价 | +25 / +100 两档 |
| 🤖 新对手 | 夜枭/苍鹫/野猪公,估价浮动更野 |
| 💰 本金 | 1000 两,现金耗尽只能干看 |

**操作:**轮到你:**+25/+100**(键盘 1/2)出价、**💎一口价**(3)直购、**🚫弃权**(4/空格)。算好底价与真值的差,再决定抢还是等!

> 💡 **打法:**① 一口价 = 底价 x2.2,只有当<b>真值估计 > 一口价</b>时才值得按;② 底价是公开的利润下限参考:<b>真值大概率在底价 x1.2~1.6</b> 之间,低于底价的出价纯属烧钱;③ AI 估价浮动比上作野,前两件<b>观察它们放弃的价格带</b>;④ 流拍不亏钱,<b>但浪费机会</b>——六件里至少要吃下三件;⑤ 现金 1000 铺六件,平均 166 以内,<b>一口价是最后手段</b>,用了就别再后悔!

**结算:**拍得件数、总利润、现金余额、本局得分(利润 + 拍得 x30)、历史最高分、已玩局数。
