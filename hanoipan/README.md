# 叠盘归塔 (🛕 叠盘归塔 · 一移一梵)

> 分类:**烧脑益智** · 入口:/hanoipan/ · 免费在线 · 手机即点即玩

**目标:**梵塔移盘:**递归分步**,三塔递进。

| 元素 | 效果 |
|---|---|
| 🛕 梵塔 | 左起右归 |
| 👆 移盘 | 两段点塔 |
| 📿 最少手 | 二乘n减一 |
| ⚠️ 犯忌 | 大盘不落小 |
| 🏆 结算 | 移盘折分 |

**操作:****点塔提盘,再点塔落盘**。

> 💡 **打法:**① **口诀**:奇数层先去目标,偶数层先去中转;② 卡住了**退回重排**,手数才最要紧;③ 犯忌**只是不动**,多想一步;④ 塔号越深**盘越多**,一步一步来;⑤ 三塔归位,**老僧送你一串念珠**!

**结算:**塔号、手数、本局得分、历史最高分、已玩局数。
