# 笨鸟先飞 (🐤 笨鸟先飞 · 管道穿行)

> 分类:**街机动作** · 入口:/flappy/ · 免费在线 · 手机即点即玩

**目标:****点屏幕扑翅上升**,不点自然下坠;穿过管道缝隙得 1 分,碰到管道或落地即结束。缝隙位置随机,越往后越窄,过管数就是分数。

| 元素 | 效果 |
|---|---|
| 🐤 扑翅 | 点一下上浮一截,连点连升 |
| 🪈 管道 | 上下管道留缝,缝位随机 |
| ➕ 计分 | 每穿一根 +1 |
| 📈 难度 | 缝隙从 150px 收窄到 120px |
| 🏁 结束 | 碰管/落地即结束 |

**操作:****点屏幕**扑翅;**重飞**立刻重开。别连点太快,鸟会撞天花板!

> 💡 **打法:**① 永远让鸟处在缝隙<b>中线偏上</b>,下落有缓冲;② 点的节奏比点数重要,找自己的默数频率;③ 接近管道时<b>提前对准缝隙</b>,过了管再调整;④ 手别悬在屏幕上方乱晃,误触就是命;⑤ 连续失败时休息 10 秒,手感会回来。

**结算:**过管数、最佳纪录、本局得分(过管 x10)、历史最高分、已玩局数。
