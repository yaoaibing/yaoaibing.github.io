# 空拍律动 (🤫 空拍律动 · 该沉默时沉默)

> 分类:**音乐节奏** · 入口:/restrhythm/ · 免费在线 · 手机即点即玩

**目标:**节拍抑制训练:8 步循环 ● 击打 / ✕ 静默,漏拍或错拍断连,错 3 次结算;每圈提速并随机换型。

| 元素 | 效果 |
|---|---|
| ● 实拍 | 按「打」+10 起连击 |
| ✕ 空拍 | 碰了 -15 +1 错误 |
| ⏱ 提速 | 每圈 x0.96 |
| 🔀 换型 | 每圈随机重排 |
| 🏆 结算 | 错 3 次或 40 秒 |

**操作:**点「**🥁 打**」(空格)。

> 💡 **打法:**① **默数 1-8**,空拍位置提前半步绷住;② 别盯屏幕,**手指悬空找悬停感**;③ 漏拍只断连不错误,**不确定时宁可不按**;④ 提速后**重心从 8 步变 4 拍**记;⑤ 空拍连排最险,**用脚打实拍拍点**!

**结算:**连对、错误次数、本局得分、历史最高分、已玩局数。
