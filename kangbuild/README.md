> 分类:**建造物理** · 入口:/kangbuild/ · 免费在线 · 手机即点即玩

**目标:**结构搭建:**盘道抹泥**,两炕连做。

| 元素 | 效果 |
|---|---|
| 🛏️ 土炕 | 一铺通到头 |
| 🧱 烟道 | 三弯一回转 |
| 🔥 试火 | 烟顺即功成 |
