# 直线加速 (🏎️ 直线加速 · 千米冲锋)

> 分类:**竞速赛车** · 入口:/drag/ · 免费在线 · 手机即点即玩

**目标:**直线加速赛:起步后转速自动攀升,在**绿区(68-92%)点换挡**得完美加速(+14 速度),换早掉转、拖到红区断油扣速;六挡冲过千米线,与 AI 比冲线时间。

| 元素 | 效果 |
|---|---|
| ⚙️ 换挡 | 每次换挡挡位 +1,共 6 挡 |
| 🟢 绿区 | 68-92% 换挡 = 完美,速度 +14 |
| 🔴 红区 | 拖到 100% 断油,速度 -8 |
| 📉 早换 | 低于 68% 换挡,速度 -5 |
| 🏁 赛程 | 1000 米,先冲线者胜 |

**操作:**点 **⚙️换挡**(空格/↑同效)在绿区升挡;**难度**三档切换。听转速节奏比盯指针更稳!

> 💡 **打法:**① 每挡转速上升速度不同,**高挡升得慢**,别按老节奏换;② 绿区有 24% 宽,【进绿就换】比等到 90 稳;③ 完美换挡 +14 速度是<b>复利</b>,全程 6 个完美和 0 个差出近一个身位;④ 断油 -8 比早换 -5 更伤,拿不准时**宁早勿晚**;⑤ 最后两挡决定胜负,前面落 behind 别慌,后面反超很常见!

**结算:**冲线时间、完美换挡次数、胜负、本局得分(胜 600 + 时差分 + 完美 x50)、历史最高分、已玩局数。
