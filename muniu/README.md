# 木牛流马 (🦬 木牛流马 · 蜀道运粮)

> 分类:**竞速赛车** · 入口:/muniu/ · 免费在线 · 手机即点即玩

**目标:**档位竞速:**坡度配档位**,错档耗牛力;下坡疾行颠粮,千米到营。

| 元素 | 效果 |
|---|---|
| ⚙️ 一档 | 上坡专用,最省力 |
| ⚙️ 二档 | 平路均衡 |
| ⚙️ 三档 | 下坡快,易颠粮 |
| 📉 牛力 | 空了就地趴窝 |
| 🏆 结算 | 按里程余粮计分 |

**操作:**点底部**档位按钮**换档。

> 💡 **打法:**① **看「前方」提示**,提前半屏换档;② 上坡**别硬挂二三档**,牛力哗哗掉;③ 下坡**想快先看粮**,粮少再赌;④ 牛力**见红就挂一档缓缓**;⑤ 千米到营,**丞相的军功簿记你一笔**!

**结算:**运粮里程、余粮数、历史最高分、已玩局数。
