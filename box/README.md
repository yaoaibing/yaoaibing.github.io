# 推箱子 (📦 仓库番 · 推箱子)

> 分类:**烧脑益智** · 入口:/box/ · 免费在线 · 手机即点即玩

**目标:**把所有箱子推到圆点目标上就过关,共 12 关,越后面越绕。
| 操作 | 键位 |
|---|---|
| 走一步 | 在屏幕上**朝目标方向滑动**,或点底部**方向键**;电脑用 `↑``↓``←``→`
撤销 / 重来 | 点 `↶ 撤销`(可无限退) / `⟲ 重来` |

**注意:**箱子只能**推**不能拉,一次只能推一个,推不动就说明后面有墙或另一个箱子。

> 💡 **过关思路:**① 先看**目标点**反推箱子该走哪条路,再倒推人站哪;② **箱子推进墙角基本就死了**,看见要进角立刻撤销;③ 贴墙的箱子只能沿墙推,别指望把它拉出来;④ 卡住就大胆撤销重来,这游戏就是试错;⑤ 步数越少越漂亮,HUD 有参考步数可以追。
