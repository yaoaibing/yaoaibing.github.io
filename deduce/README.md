# 翻牌推理 (🃏 翻牌推理 · 逻辑侦探)

> 分类:**对战棋牌** · 入口:/deduce/ · 免费在线 · 手机即点即玩

**目标:**16 张卡各有 4 个属性(颜色/形状/数量/底纹),其中一张是目标:翻牌获得**属性相似度线索**,排除不可能候选,锁定目标卡。

| 元素 | 效果 |
|---|---|
| 🃏 翻牌 | 点任意卡翻开看线索 |
| 🟢 线索 | 每个属性匹配亮绿,不匹配亮灰 |
| 🧠 推理 | 根据线索排除候选卡 |
| 📌 标记 | 可以标记确定不是的卡 |
| 🏆 胜负 | 点中目标卡即胜,翻牌越少分越高 |

**操作:****点卡**翻开看线索,翻过的卡保持亮起供推理。确定目标后直接点它!

> 💡 **打法:**① 先翻一张看<b>哪个属性差异最大</b>,从最大差异入手;② 记住每个属性有几个选项(4 色 4 形 4 数 4 纹);③ 每翻一张都是 4 条线索,充分利用再翻下一张;④ 候选只剩 2 张时果断猜,概率 50%!;⑤ 翻 4-5 张就能锁定,超过 8 张说明推理有漏洞!

**结算:**翻牌次数、锁定准确率、本局得分(胜 400 - 翻牌 x30,最低 100)、历史最高分、已玩局数。
