# 摩天楼谜题 (🏢 摩天楼谜题 · 街边数独)

> 分类:**烧脑益智** · 入口:/skyscraper/ · 免费在线 · 手机即点即玩

**目标:**在 N x N 网格每行每列填入 **1-N 不重复**;四周数字表示该方向**能看到的楼数**(数字越大挡住越多矮楼)。10 关由 4x4 渐进到 6x6。

| 元素 | 效果 |
|---|---|
| 🏢 楼高 | 格子里的数字,1 最矮 N 最高 |
| 🔢 边缘线索 | 从该方向看过去能看见的楼数 |
| ⛔ 视线规则 | 遇到更高的楼,后面的全被挡住 |
| 🔴 冲突标红 | 同行同列重复即时提示 |
| 💡 提示 | 随机纠正一格,每次 -40 分 |

**操作:****点击格子**循环切换 1-N;**提示**自动纠正一格;**重来**清空本关。建议先填线索指向最强的行列!

> 💡 **打法:**① 边缘数字是 1 → 该位置必是 1(最低);是 N → 一路递增全可见;② **从最大的边缘线索入手**,能直接锁死整行;③ 某行/列只剩一个空格时立刻补上;④ 高楼位置先想清楚,矮楼是"填缝"的;⑤ 6x6 关卡先排除重复,再看"刚好递增/递减"的特殊行列!

**结算:**通过关卡、提示次数、冲突次数、本局得分(每关 N²x20 - 提示x40 - 冲突x10)、历史最高分、已玩局数。
