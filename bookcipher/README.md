| 元素 | 效果 |
|---|---|
| 🔢 密电 | 【】括号标记当前步 |
| 📖 密码本 | 4×4 格,角标是编号 |
| ✗ 容错 | 点错进度清零 -20 |
| ✅ 译文 | 实时拼出已解部分 |
| 🏆 评级 | 900 分译电尖兵 |

**操作:****点格子**(按密电数字顺序)。

> 💡 **打法:**① **先在心里数行**:编号 1-4 第一行、5-8 第二行;② 【】括号**只看当前一个**,别往后读;③ 电文有语义,**拼到一半能预判下一字**;④ 点错别慌,**前几个字往往没变**;⑤ 越到后段越慢,**稳比快值钱**!
