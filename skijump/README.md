# 跳台滑雪 (🎿 跳台滑雪 · 一跃百米)

> 分类:**体育竞技** · 入口:/skijump/ · 免费在线 · 手机即点即玩

**目标:**三段跳台:锁力度→锁角度→空中**平衡修正**,落地按距离+姿态计分;摔车按 30% 距离计;三跳结算。

| 元素 | 效果 |
|---|---|
| 💪 力度 | 决定初速 |
| 📐 角度 | 12°-34° 影响滞空 |
| 🪂 平衡 | 绿区居中=满分姿态 |
| 🏅 计分 | 距离 x6 + 姿态分 |
| 🏆 评级 | 90 米百米飞人 |

**操作:**「**💪 出手**」锁两段,**◀ 稳 / 稳 ▶**修姿态(空格+左右键)。

> 💡 **打法:**① 力度**尽量拉满**,角度 20° 左右最稳;② 空中**小点快点**,大幅修正必过冲;③ **姿态分上限 100**,翻车直接×0.3;④ 三跳策略:首跳求稳,**后两跳搏远**;⑤ 落地前**把指针带回绿区**,风格分白送!
