# 颜色陷阱 (🔷 颜色陷阱 · 脑内打架)

> 分类:**烧脑益智** · 入口:/stroop/ · 免费在线 · 手机即点即玩

**目标:**屏幕出现一个**彩色的字**(比如蓝色的"红"),两种题目随机切换:点「字的颜色」或点「字的意思」。经典斯特鲁普效应,大脑读字和认色两个系统打架。

**操作:**四色按钮四选一,键盘 `1`-`4`。答对 +100 起连对滚分;答错/超时 -1 心 -30 分,共 3 颗心,限时 45 秒。

> 💡 **抗干扰要点:**① 「点颜色」时**闭嘴默念颜色名**,能压制读字反射;② 「点意思」时直接读字,无视颜色——**先看题目要求再瞄字**;③ 连对滚分肥,平均 1.5 秒一题是高分线;④ 答错不慌,斯特鲁普对所有人都难,数据说话:45 秒答对 20+ 就是注意力高手。

**结算:**答对题数、最大连对、总得分、历史最高分。
