# 瞬间记忆 (👁️ 瞬间记忆 · 过目不忘)

> 分类:**烧脑益智** · 入口:/flash/ · 免费在线 · 手机即点即玩

**目标:**棋盘上若干格子**闪现一瞬就熄灭**,凭记忆原样点出全部亮格。关卡越深棋盘越大、亮格越多、闪现越短(3×3→5×5,1.1 秒→0.45 秒)。3 颗心容错。

**操作:**闪现结束点格子复现,再点一次可取消;全部点满自动判定。全对 +100 起每关 +10;点错/漏点 -1 心 -20 分。

> 💡 **记忆技巧:**① **别记格子,记形状**——把亮格看成字母、数字或折线,大脑对形状的记忆远强于散点;② 按**行扫描**复述一遍位置再下手;③ 点的时候**先点没把握的**,因为可以二次点击取消;④ 5×5 大盘时分组记(左上 2 个、右下 3 个);⑤ 一次闪现只给 0.45 秒的高关卡,看第一眼就跟着亮格顺序移动眼球,肌肉记忆也管用。

**结算:**闯过关卡数、总得分、历史最高分。
