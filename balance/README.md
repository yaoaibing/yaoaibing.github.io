# 钢丝平衡 (🎪 钢丝平衡 · 稳如泰山)

> 分类:**街机动作** · 入口:/balance/ · 免费在线 · 手机即点即玩

**目标:**人在钢丝上自动前进,**狂风随时把你吹歪**。点/按住左半屏往左压、右半屏往右压,把倾角稳在安全区。倾角超限就掉,走越远分越高(50 单位=1 米)。

**机制:**顶部的倾角表**红区=临界**,绿区=安全;距离越远风越大(风力倍率会涨)。键盘 `←``→` 同理。

> 💡 **平衡要点:**① **小幅高频微调**最稳,大按大放必翻车;② 倾角有惯性——指针还在往红区冲时就要反向压,**提前量是关键**;③ 风有方向性,一阵持续的风要顶住压而不是点一下;④ 走得越快不加分,分只看距离,**稳住就是赚**;⑤ 100 米是入门,200 米+风就很难顶了,真·走钢丝大师能上 300。

**结算:**行进距离(米)、历史最远。
