# 单牌接龙 (🃏 单牌接龙 · 先空手胜)

> 分类:**卡牌构筑** · 入口:/cardrun/ · 免费在线 · 手机即点即玩

**目标:**比牌轮出:**压大牌或跳过**,先空手胜;三局结算。

| 元素 | 效果 |
|---|---|
| 🃏 手牌 | 各十张 |
| 👉 压牌 | 要比桌面大 |
| ↩ 跳过 | 两家双跳清桌 |
| 🏁 空手 | 先出完即胜 |
| 🏆 结算 | 三局比分 |

**操作:**点**绿字手牌**出牌,点**跳过**让牌。

> 💡 **打法:**① **桌面空时甩最小**,别浪费大牌;② **压不过别硬憋**,跳过等清桌;③ 记着**AI 出过的牌**,算它剩什么;④ 尾局**大牌开路**,别被卡住;⑤ 三局全胜,**牌桌免检**!

**结算:**对局数、余牌数、本局得分、历史最高分、已玩局数。
