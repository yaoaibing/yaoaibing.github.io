# 凯撒密文 (🔐 凯撒密文 · 移位破译)

**目标:**凯撒密码:密文由明文整体移位而来,**调节移位数**观察预览,变成英文单词即可确认;每题 3 次机会,连对计分。

| 元素 | 效果 |
|---|---|
| 🅰 密文 | 26 字母循环移位 |
| ◀▶ 轮盘 | 移位 1-25 循环调节 |
| 👀 预览 | 实时解码结果 |
| 🔍 提示 | 揭示一位正确字母 -20 |
| 🏆 评级 | 900 分密码学家 |

**操作:**点 **◀ ▶** 或转轮盘调移位,「✅ 确认」提交(方向键+回车)。

> 💡 **打法:**① 先找 <b>E、T、A、O</b> 高频字母的位置;② 三字母孤词多半是 <b>THE</b>;③ 从 +1 试到 +25 也行,**但预览变单词会发光**;④ 确认错了 -10 且记一次尝试,**拿不准先转满一圈**;⑤ 提示留给最后一题,**保 streak 更划算**!
