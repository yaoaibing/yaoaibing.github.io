# 祖玛 (🔮 祖玛)

> 分类:**烧脑益智** · 入口:/zuma/ · 免费在线 · 手机即点即玩

**目标:**彩珠沿轨道向神殿推进,你要在它们**到达终点前**用同色珠把它们消掉。**共 12 关**,颜色从 4 种升到 6 种,轨道越来越险。
| 机制 | 规则 |
|---|---|
| 消除 | 彩珠插入队列,**同色连续 3 颗**立即爆裂
连锁 | 爆裂后两端同色接上会继续消,**得分逐级加倍** |
| 回退 | 爆裂越多,后面的珠子**倒退越远**,并短暂停止推进
换珠 | 当前珠与下一颗可预览,点**换珠**或双击切换 |

**操作:****点哪射哪**,拖动可微调瞄准虚线,松手发射。HUD 显示分数 / 剩余珠子 / 关卡。

> 💡 **打法:**① **别急着打 3 连就完事**——先把某一色在队列里堆到 4~5 颗再补一颗,爆裂后两端同色接上就能连锁,连锁才是分数大头;② **打队列靠后的同色段**更容易触发连锁,因为前面留下的珠子会自动补位接上;③ 珠子推进到接近终点时,**优先打最前面那段**,哪怕只得基础分——活下来才有下一关;④ 换珠键别舍不得用,手里两颗都是废色时果断换;⑤ 消除会让整条队列**倒退**,这是唯一的喘息窗口,退得越多你越安全。

**结算:**总分、到达关卡、最高连锁、消除总数、命中率。
