# 重力迷宫 (🧭 重力迷宫 · 滚球寻宝)

> 分类:**烧脑益智** · 入口:/maze/ · 免费在线 · 手机即点即玩

**目标:**朝一个方向滑动,**小球一路滑到撞墙才停**(重力式滑动)。收集星星(可选 +80/颗),滚到 🚩 出口过关。8 个手工关卡。

**机制:**🕳️ 黑洞会把球**吸回起点重滚**(不扣血);步数越少基础分越高(400-步数×12);一关星星全收再额外 +300。手机滑屏或点屏,键盘方向键/WASD。

> 💡 **解谜要点:**① 滑动是**一滑到底**,先想清楚球停在哪一格再动手;② 利用墙壁"刹车":贴着墙滑半格也是合法停点;③ 黑洞不扣分只重置,**大胆试错**摸清每关结构;④ 星星在主路上就顺路吃,偏离主路超过 2 步就放弃,步数罚分更贵;⑤ 卡关就点底部"↻重来本关",步数清零重新规划。

**结算:**8 关通关、总得分(含星星/步数)、历史最高分。
