# 太空对接 (🛰️ 太空对接 · 毫米之差)

> 分类:**太空导航** · 入口:/dock/ · 免费在线 · 手机即点即玩

**目标:**轨道对接:四向推进消除**相对速度**,以 <24px/s 潜入对接环**稳住 0.9 秒**;燃料耗尽判失败,三站难度递增。

| 元素 | 效果 |
|---|---|
| 🛰️ 漂移 | 空间站撞墙反弹 |
| 🚀 推进 | 每次脉冲耗 1.6 燃料 |
| 🎯 对接环 | 半径 30 的虚线圈 |
| ⚡ 相对速度 | 橙线箭头实时显示 |
| 🏆 计分 | 对接 200 + 余燃料 x2 |

**操作:**点 **◀▲▼▶** 推进(方向键按住持续喷)。

> 💡 **打法:**① **先追平速度再谈靠近**,橙线缩短是第一步;② 对接环在动,**提前量对准它的未来位置**;③ 靠近时把相对速度压到 <15,**留出修正余地**;④ 燃料就是分,**克制每一次脉冲**;⑤ 第三站漂得快,**贴着反弹边等它拐弯**更省油!

**结算:**成功对接数、剩余燃料、本局得分、历史最高分、已玩局数。
