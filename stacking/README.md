# 积木平衡 (🏗️ 积木平衡 · 稳如泰山)

> 分类:**烧脑益智** · 入口:/stacking/ · 免费在线 · 手机即点即玩

**目标:**拖动各种形状的积木放到塔顶,**保持重心平衡**不倒塌;搭得越高分越高,物理引擎实时模拟重心偏移。

| 元素 | 效果 |
|---|---|
| 🏗️ 放置 | 拖动积木到目标位置松手 |
| ⚖️ 重心 | 重心偏移会导致倾斜 |
| 📏 形状 | 长条/方块/三角,各有特点 |
| 📈 难度 | 越高越不稳,形状越怪 |
| 💥 结束 | 塔倒即结算 |

**操作:****按住拖动**放积木;**重来**重搭。大积木在下小积木在上,重心居中最稳!

> 💡 **打法:**① 每块积木的<b>中心</b>要对齐下面那块的中心;② 长条横放比竖放更稳;③ 不要一边倒,交替左右放;④ 三角形积木放顶端最好,底面大;⑤ 分数和高度成正比,但倒一次全没了,稳字当头!

**结算:**最大高度、积木数、倒塌原因、本局得分(高度 x10)、历史最高分、已玩局数。
