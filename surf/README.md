# 极限冲浪 (🏄 极限冲浪 · 浪壁狂飙)

> 分类:**街机动作** · 入口:/surf/ · 免费在线 · 手机即点即玩

**目标:**在浪壁上**左右拖动**躲避浮木与礁石,收集浮标得分(橙 30 蓝 10);速度随距离上涨,撞到障碍立即落水结束,距离与浮标合计为总分。

| 元素 | 效果 |
|---|---|
| 🏄 走位 | 按住拖动,冲浪板跟手 |
| 🟠 浮标 | 橙 30 / 蓝 10,成串出现 |
| 🪵 障碍 | 浮木横漂,礁石固定,撞上即落水 |
| 📈 加速 | 每 100 米提速一档 |
| 🏁 结束 | 撞障碍即落水结算 |

**操作:****按住屏幕左右拖动**(键盘 ←→ 也行);**重冲**立刻重开。看远不看近,提前半秒变线!

> 💡 **打法:**① 走<b>浪壁中带</b>,两边礁石多中间安全;② 浮标串往往跟着障碍缝,先找缝再收标;③ 高速期别为单颗蓝标绕大弯;④ 浮木会漂,盯它的<b>尾巴方向</b>预判;⑤ 手指放在屏幕下半,不挡视线。

**结算:**距离、浮标数、最高速度、本局得分(距离 x2 + 浮标分)、历史最高分、已玩局数。
