# 音符跳跃 (🎵 音符跳跃 · 五线谱)

> 分类:**街机动作** · 入口:/notes/ · 免费在线 · 手机即点即玩

**目标:**音符在五线谱上自动前进:**点屏幕上半跳上、下半跳下**,在线间移动收集加分道具躲开障碍;碰撞即结束,距离计分。

| 元素 | 效果 |
|---|---|
| 🎵 音符 | 自动前进,点屏幕上下跳 |
| ⬆️ 跳跃 | 上半屏=上跳,下半屏=下跳 |
| ♯✨ 道具 | 升号/降号 +30,碰到即得分 |
| 💥 障碍 | 降号符号和休止符,碰到结束 |
| 🏁 结束 | 碰撞即结束,距离计分 |

**操作:****点上半屏**向上跳,**点下半屏**向下跳;**重来**重跳。跟着节拍跳,节奏对了自然连击!

> 💡 **打法:**① 五线谱上<b>五条线四个间</b>,熟悉位置反应更快;② 障碍从右侧来,提前半秒变线;③ 连续收集升号有连击加成,别贪多;④ 节拍器声是你的节拍参考,跟上它!;⑤ 音乐素养越高玩得越好,玩完记得学乐理!

**结算:**距离、收集符号数、最高连击、本局得分(距离 x3 + 道具 x30)、历史最高分、已玩局数。
