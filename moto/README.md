# 飞车特技 (🏍️ 飞车特技 · 峡谷飞跃)

> 分类:**街机动作** · 入口:/moto/ · 免费在线 · 手机即点即玩

**目标:**按住屏幕=**油门**,加速冲上跳台飞越峡谷。速度不够摔进峡谷,落地太猛也会翻车。距离+飞跃次数就是荣耀。

**机制:**平地加速到 640 封顶;跳台末端起飞,抛物线落地;**落地角度过陡或速度过快会翻车**。每完成一次峡谷飞跃 +200 距离分。

> 💡 **飞车要点:**① **跳台前油门焊死**,速度不够就是峡谷来信;② 飞在空中不用操作,**落地点由起跳速度决定**;③ 落地在平地上角度正常,落在坡道上若角度差会翻——**瞄准平地落**;④ 连续峡谷会考验节奏:落地后立刻按油门续速度;⑤ 200 米+3 次飞跃是熟手线。

**结算:**飞 行距离(米)、峡谷飞跃次数、历史最远。
