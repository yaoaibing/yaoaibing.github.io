# 拍手背 (👋 拍手背 · 一掌一躲)

> 分类:**解压休闲** · 入口:/handslap/ · 免费在线 · 手机即点即玩

**目标:**反应对局:**辨攻守**,十回合对决。

| 元素 | 效果 |
|---|---|
| 👋 双手 | 一攻一守 |
| ⚡ 躲 | 他攻时点 |
| 🖐 拍 | 他守时点 |
| ⚠️ 挨拍 | 四记收场 |
| 🏆 结算 | 手速折分 |

**操作:**点屏**躲或拍**。

> 💡 **打法:**① **先看清是谁攻**,方向错直接挨拍;② 他翻掌**有一瞬预告**,盯手腕;③ 挨一记**别上头**,下一回合稳回来;④ 回合越后**假动作越多**,半拍再动;⑤ 十回合打完,**手心通红还喊着再来**!

**结算:**对局回合、挨拍数、本局得分、历史最高分、已玩局数。
