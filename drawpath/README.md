# 连线不交叉 (🌀 连线不交叉 · 智者一划)

> 分类:**烧脑益智** · 入口:/drawpath/ · 免费在线 · 手机即点即玩

**目标:**拓扑连线:同色点**两两相连不交叉**;三图递增,全连过关。

| 元素 | 效果 |
|---|---|
| 🔴 同色 | 两两配对 |
| 🚫 交叉 | 线不能相交 |
| 📈 三图 | 6点→6点→6点 |
| ✅ 全连 | 每图 +80 |
| 🏆 评级 | 三图全通一笔仙 |

**操作:****点同色两点**连线,不许交叉。

> 💡 **打法:**① **先连最短的一对**,给长线留空间;② **长线绕外圈**,贴边走不挡道;③ 交叉了**撤销重连**,点新的一对自动换;④ 三张图**规律相同**,第一张的解法能迁移;⑤ 全连加分,**一个不漏**!

**结算:**连线数、本局得分、历史最高分、已玩局数。
