# 数墙 (🧱 数墙 · 分岛成墙)

> 分类:**烧脑益智** · 入口:/nurikabe/ · 免费在线 · 手机即点即玩

**目标:**Nurikabe 数墙:按数字岛大小**涂黑其余格子**,黑墙必须连通、不得出现 2x2 黑块、各岛互不相邻;「检查」判卷,4 题累计计分。

| 元素 | 效果 |
|---|---|
| 🔢 数字格 | 所属岛的大小,永不当墙 |
| ⬛ 涂黑 | 点白格切换涂/擦 |
| 📜 连通 | 所有黑格连成一片 |
| 🚫 2x2 | 黑格禁憋 2x2 方块 |
| 🔍 检查 | 错一次 -20 |

**操作:****点格子**涂黑/恢复;「🔍 检查」判卷,「🧹 清除」重涂。

> 💡 **打法:**① 先把**确定的单格岛**周围全涂黑;② 两个数字岛之间**必隔一格墙**;③ 看到可能憋出 2x2 的角,**提前留白格**;④ 岛还没长够大时,**它相邻的白格不能黑**;⑤ 检查便宜,**涂一半就可以先查一次**!

**结算:**完成题数、错判次数、本局得分、历史最高分、已玩局数。
