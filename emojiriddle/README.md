# 表情猜谜 (🤔 表情猜谜 · 看图猜成语)

> 分类:**烧脑益智** · 入口:/emojiriddle/ · 免费在线 · 手机即点即玩

**目标:**屏幕给出 **2~3 个表情**,猜它们代表的成语,四选一。24 个经典图像谜题(🐴🐯=马马虎虎、🪵🐰=守株待兔、🐮🎸=对牛弹琴…)。3 颗心容错,每题 12 秒。

**操作:**点选项或按 `1`-`4`。答对 +100 起连对滚分;答错/超时 -1 心 -30 分。

> 💡 **脑洞要点:**① 表情就是**成语的字面画面**:🐮+🎸 就是"对牛弹琴"的字面演绎,顺着画面直译;② 动物成语占大半:🐴🐯、🦊🐯、🐯🐍、🐯🐲…看到两只动物先想"它们的关系";③ 🕳️🐸=井底之蛙、🪵🐰=守株待兔,场景类谜题想**寓言故事**;④ 别想太深——谜底都是最常见的成语;⑤ 答错的题多看一眼正确答案,题库会重复出现。

**结算:**答对题数/24、最大连对、总得分、历史最高分。
