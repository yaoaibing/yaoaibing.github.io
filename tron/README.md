# 光轨大战 (🏍️ 光轨大战 · 走位围杀)

> 分类:**街机动作** · 入口:/tron/ · 免费在线 · 手机即点即玩

**目标:**光标持续前进并留下光墙:用方向键转向,任何一方**撞到光墙/边界/对方光墙**即爆炸判负。五局三胜,考验走位与封路意识。

| 元素 | 效果 |
|---|---|
| 🏍️ 前进 | 每 0.12 秒前进一格,不可停下 |
| ⬅️ 转向 | 四方向按钮或键盘,不能 180° 掉头 |
| 🧱 光墙 | 自己与对手的墙都致命 |
| 🧠 AI | 会封路、会避墙,五局三胜 |
| 🏁 胜负 | 先爆炸者输 |

**操作:**底部四方向按钮或键盘方向键转向;**新局**清战绩。留空格给自己,把对手往边角逼!

> 💡 **打法:**① 沿<b>边线</b>走,少占中间空间;② 把自己围成「口袋」,等对手钻进来;③ 对手贴你很近时,突然 90° 急转,它反应不及;④ 别追着对手尾巴走,先保自己的活动空间;⑤ 五局三胜,第一局试探它的转向习惯!

**结算:**胜负、局数比分、最长生存、本局得分(胜 500 + 局数 x80)、历史最高分、已玩局数。
