# 画线救援 (✏️ 画线救援 · 智慧引导)

> 分类:**烧脑益智** · 入口:/drawn/ · 免费在线 · 手机即点即玩

**目标:**小球从天而降,**画一条线**(限长 320px)当斜坡/挡板,把所有小球引进杯子里。8 个关卡,障碍物和球数逐渐增加,真实重力+弹性碰撞。

**操作:**画线阶段**按住拖动**画出折线;点底部"▶开始"小球下落;"↻重画"清空重来。球进杯 +10/颗,球掉出屏幕要重画。

> 💡 **物理要点:**① 线是**可以两面挡**的:球从上面滚是斜坡,从下面顶是天花板;② **缓坡比陡坡好控**,太陡球会弹飞;③ 先画一段接住球的"托盘",再补一段导流的"滑道",两段式最稳;④ 杯口边缘会弹球,瞄准**杯中心正上方**做终点;⑤ 多球关卡用一条**主斜坡汇流**,让所有球滚向同一个出口;⑥ 卡关就想想:球被弹开的原因是线太竖还是太平?

**结算:**8 关全部救出、总得分(关卡×100+救援×10)、历史最高分。
