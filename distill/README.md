# 糟坊酒酿 (🍶 糟坊酒酿 · 一甑高粱)

> 分类:**模拟经营** · 入口:/distill/ · 免费在线 · 手机即点即玩

**目标:**链式工序:**四道工序依序开工**,全完成才能出酒;急单限时交货,90 秒结算。

| 元素 | 效果 |
|---|---|
| 💧 泡粮 | 2.5 息 |
| 🔥 蒸煮 | 3.5 息 |
| 🌬️ 摊晾 | 2 息 |
| 🏺 入窖 | 4 息 |
| 🏆 评级 | 收入 250 酿酒师 |

**操作:****按顺序点工序**(键盘 **1-4**),酒成点「**出酒**」(空格)。

> 💡 **打法:**① **顺序不能乱**,点灰色的工是白点;② 一道开工后**马上去准备下一道的心算**;③ 急单价高,**但要算好时辰接不接**;④ 退单扣钱,**空档期自由酿也不亏**;⑤ 出酒后工序重置,**流水线别停**!

**结算:**售出收入、历史最高分、已玩局数。
