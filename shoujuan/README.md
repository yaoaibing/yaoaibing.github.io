# 丢手绢 (🎀 丢手绢 · 圈上追风)

> 分类:**解压休闲** · 入口:/shoujuan/ · 免费在线 · 手机即点即玩

**目标:**环形时机:**手绢入背后弧再起身**,早扑空晚被贴;三心六十秒。

| 元素 | 效果 |
|---|---|
| 🎀 手绢 | 绕圈变速还停顿 |
| 🙌 追 | 入背后弧点屏 +50 |
| ⏱ 扑空 | 提前出手 -1 心 |
| 🧒 被贴 | 出手迟 -1 心 |
| 🏆 结算 | 逮住即分,心尽收场 |

**操作:****点屏**(空格)起身追。

> 💡 **打法:**① **圈上空档亮黄弧**就是信号,亮了就拍;② 手绢**会变速停顿**,别预判过头;③ 扑空一次**静两圈再动**,稳住;④ 三颗心**最后留给稳的窗口**;⑤ 逮住五六次,**整圈都在喊你名字**!

**结算:**逮住次数、本局得分、历史最高分、已玩局数。
