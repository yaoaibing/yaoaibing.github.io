# 顶水罐 (🏺 顶水罐 · 头上功夫)

> 分类:**街机动作** · 入口:/jarwalk/ · 免费在线 · 手机即点即玩

**目标:**平衡行进:**左右扶正保水位**,三程结算。

| 元素 | 效果 |
|---|---|
| 🏺 罐头 | 一路晃 |
| ⬅➡ 扶 | 回正指针 |
| 💧 洒水 | 出格-18 |
| 🚶 三程 | 越走越晃 |
| 🏆 结算 | 存水折分 |

**操作:**点**扶左/扶右**回正。

> 💡 **打法:**① **指针偏半格就扶**,别赌它能自己回来;② **晃动有节奏**,跟着节奏点最省手;③ 洒水**一次一口**,两三次罐就空;④ 后程**晃得凶**,手要更勤;⑤ 满罐到家,**全村都用你的水**!

**结算:**行进路程、存水量、本局得分、历史最高分、已玩局数。
