# 抢收麦浪 (🌾 抢收麦浪 · 一镰一行)

> 分类:**街机动作** · 入口:/wheatrun/ · 免费在线 · 手机即点即玩

**目标:**多线抢收:**择行挥镰**,风暴为限。

| 元素 | 效果 |
|---|---|
| 🌾 麦行 | 上中下三行 |
| 👆 挥镰 | 点行即割 |
| ⛈ 风暴 | 倒计时压顶 |
| ⚠️ 落空 | 折十分 |
| 🏆 结算 | 抢收折分 |

**操作:**点**进亮带的那一行**。

> 💡 **打法:**① **眼睛扫三行**,谁进亮带点谁;② 空挥**只折十分**,别因怕空而停手;③ 风暴**越近天越黑**,盯亮带别盯天;④ 每割一行**镰速微涨**,后程手要跟;⑤ 二十二行收满,**全村的麦垛数你的高**!

**结算:**风暴、已收行、本局得分、历史最高分、已玩局数。
