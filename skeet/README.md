# 飞碟打靶 (🎯 飞碟打靶 · 疾风快枪)

> 分类:**体育竞技** · 入口:/skeet/ · 免费在线 · 手机即点即玩

**目标:**定向飞碟:飞碟随机方向抛出并受重力下坠;**点中即碎**,得分按高度与距离结算;连击滚分。

| 元素 | 效果 |
|---|---|
| 🎯 命中 | 点飞碟 30px 内判中 |
| 📈 高分碟 | 飞得高远加倍分 |
| 🔥 连击 | 连中每发加成 8% |
| 💨 打空 | 连击清零 |
| 🏆 评级 | 50 中 45 快枪王 |

**操作:****点飞碟**开火(空格打准星处)。

> 💡 **打法:**① **打提前量**,瞄碟飞行前方一点;② 抛得高的碟**值钱两倍**,优先高碟;③ 连击是分差核心,**宁可放过不打空**;④ 两碟同屏,**先打近的那只**;⑤ 手指跟住抛物线,**别点松手慢半拍**!

**结算:**命中数、本局得分、历史最高分、已玩局数。
