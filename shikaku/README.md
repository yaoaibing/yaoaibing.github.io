# 矩形切分 (🔲 矩形切分 · 数格成框)

> 分类:**烧脑益智** · 入口:/shikaku/ · 免费在线 · 手机即点即玩

**目标:**面积切分:**矩形含一数且面积相等**,盖满全盘;三局递进。

| 元素 | 效果 |
|---|---|
| 🔢 数字 | 即矩形面积 |
| 🔲 画框 | 点两角成矩形 |
| 🚫 硬规则 | 一框一数,不重叠 |
| ✅ 盖满 | +100 过关 |
| 🏆 递进 | 三局全切分 |

**操作:****点两角**画矩形。

> 💡 **打法:**① **大数字先框**,占的地方大好定;② 贴边框**最省心**,先扫四边;③ 面积报错**说明大小不对**,横竖换一换;④ 剩下的**零散小格**,拼一拼总能齐;⑤ 三局全切,**方田之术属你最强**!
