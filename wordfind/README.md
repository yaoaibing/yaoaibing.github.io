# 词海寻宝 (🔡 词海寻宝 · 字里寻词)

> 分类:**烧脑益智** · 入口:/wordfind/ · 免费在线 · 手机即点即玩

**目标:**在 9x9 汉字方阵中找出藏着的 **8 个词语**,横竖斜方向均可。从词首字**按住划到尾字**松手即登记,找齐全部词过关,120 秒倒计时,剩时间越多分越高。

| 元素 | 效果 |
|---|---|
| 🔡 方阵 | 9x9 汉字格,8 个词横竖斜随机藏放 |
| 👆 划词 | 按住第一个字拖到词尾字,方向可以斜 |
| ✅ 登记 | 划中整词立即高亮并计入已找 |
| 💡 提示 | 圈出一个未找词的首字,每局 3 次 |
| ⏱ 倒计时 | 120 秒,找齐过关,超时按已找词结算 |

**操作:**在网格上**按住拖动**选词,方向横竖斜都行;**提示**圈词首,**新谜题**换一局。键盘 H 用提示。

> 💡 **打法:**① 先扫**3 字长词**,目标大最好找;② 同一个字出现两次时,看哪个方向能连出完整词;③ 从角落和对角线开始扫,斜词最爱藏这里;④ 找不到就提示首字,顺着首字往外瞄三个方向;⑤ 手别抖,划到一半松手就白划了。

**结算:**找到词数、用时、得分(每词 100 + 剩余秒数 x3)、提示剩余、历史最高分、已玩局数。
