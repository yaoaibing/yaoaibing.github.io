| 元素 | 效果 |
|---|---|
| 🪜 栏数 | 2/3/4 栅栏随机 |
| 👀 预览 | 实时复原结果 |
| 🈶 中文 | 全中文电文,读感判定 |
| ⚠ 机会 | 每题 3 次,超了揭晓 |
| 🏆 评级 | 850 分译电科长 |

**操作:**点 **◀ ▶** 调栏数,「**✅ 确认**」提交(方向键+回车)。
