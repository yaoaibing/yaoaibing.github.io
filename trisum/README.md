# 幻三角 (🔺 幻三角 · 三边同和)

> 分类:**烧脑益智** · 入口:/trisum/ · 免费在线 · 手机即点即玩

**目标:**幻三角填数:**每边三数之和相等**;固定数锁定,验错扣心;四阵通关。

| 元素 | 效果 |
|---|---|
| 🔺 六点 | 3 角 3 边中 |
| 🧮 同和 | 三边和相等 |
| 📌 固定 | 蓝字不可动 |
| ❤️ 容错 | 三颗心 |
| 🏆 评级 | 四阵全通三角宗师 |

**操作:****点数字**再**点圆点**摆放(空格验阵)。

> 💡 **打法:**① **口诀**:和 = (21+角和)÷3,角和必是 3 的倍数;② **小数放角上**更常见(1+2+3 或 1+2+6);③ 先摆**固定数的边**,推剩余;④ 验阵前**三条边口算一遍**;⑤ 卡住就**换角数组合**,组合就几种!

**结算:**通阵数、本局得分、历史最高分、已玩局数。
