# 古琴泛音 (🎼 古琴泛音 · 一按一拨)

> 分类:**音乐节奏** · 入口:/guqin/ · 免费在线 · 手机即点即玩

**目标:**下落接音:**认徽而按**,三曲连环。

| 元素 | 效果 |
|---|---|
| 🎼 七弦 | 五音各归位 |
| 👆 按徽 | 落弦即点 |
| 🎶 泛音 | 连按声愈清 |
| ⚠️ 音浊 | 差半寸即断 |
| 🏆 结算 | 抚琴折分 |

**操作:**点**音柱所指的徽位**。

> 💡 **打法:**① **先认五徽方位**:宫商角徵羽,左到右;② 音柱**压到弦上那一下**出手,看高不看低;③ 连按**泛音成串**,断了就从头攒;④ 曲号越高**音柱越急**,眼神要跟住;⑤ 三曲抚罢,**月下松风都是你的和声**!

**结算:**曲号、接音数、本局得分、历史最高分、已玩局数。
