# 藏宝图 (🗺️ 藏宝图 · 热度寻宝)

> 分类:**寻宝推理** · 入口:/hunt/ · 免费在线 · 手机即点即玩

**目标:**距离推理寻宝:8x8 网格埋 3 件宝藏,每挖一格显示**到最近宝藏的步距**(切比雪夫距离,1=紧挨);按热度画同心方框缩小包围圈,挖掘次数越少分越高,小心火药桶 -50。

| 元素 | 效果 |
|---|---|
| 🗺️ 网格 | 8x8,每图 3 件宝藏 |
| 🔢 步距 | 到最近宝藏的方框步数,1 最烫 |
| 🔥 热度色 | 红=1 橙=2 金=3 灰=远 |
| 💣 火药桶 | 挖到 -50 分,后期图才有 |
| 📈 计分 | 每图 300 - 挖掘 x15 |

**操作:****点击格子**挖掘即可,纯推理无操作门槛;记住已挖数字画圈排除!

> 💡 **打法:**① 首挖<b>正中</b>:数字几,宝藏就在以它为心的几格方框内;② 沿方框**对角线**再挖一格,两圆交点立刻锁定象限;③ 数字 1 时宝藏必在紧邻 8 格,**按螺旋顺序试**;④ 同一行的多个数字连起来看,梯度方向就是宝藏方向;⑤ 别恋战:30 次挖掘后每挖一格只值 0 分,及时收图保分!

**结算:**寻获图数、挖掘次数、本局得分(每图 300 - 挖掘 x15)、历史最高分、已玩局数。
