# 滑板少年 (🛹 滑板少年 · 场地之王)

> 分类:**体育竞技** · 入口:/skate/ · 免费在线 · 手机即点即玩

**目标:**碗池滑板:**点屏蓄力**在碗底加速,冲出碗沿自动腾空;空中**每点一下加转体 180°**,落板时角度转正(±45°内)得分 = 转体度数 x90 + 滞空分,摔板不扣分;45 秒比最高单招。

| 元素 | 效果 |
|---|---|
| 🛹 蓄力 | 碗底每点一下 +冲力,高度越高加成越小 |
| 🌀 转体 | 腾空后每点 +180°,指针实时显示 |
| ✅ 落板 | 角度 ±45° 内判干净落地 |
| 💥 摔板 | 半圈落地重来,零惩罚 |
| 🏅 计分 | 转体 x90 + 滞空 x120 |

**操作:****点屏幕**一个键走天下:碗底=蓄力,空中=转体(空格同效)。45 秒无限次起跳!

> 💡 **打法:**① 蓄力<b>连点两三下</b>再滑到碗沿,腾空时间才够转 360;② 转体是**自动匀速追目标**,点两下就是 360°,点四下 720° 别手滑多点;③ 落板看指针:快转正时就<b>别再点</b>,让指针自己走完;④ 高度不够就别强转,滞空 0.6 秒只够 180°;⑤ 摔板零惩罚,放手试 720°,时间就是拿来摔的!

**结算:**最高单招度数、总分、历史最高分、已玩局数。
