# 卡牌连锁 (🃏 卡牌连锁 · 速配出牌)

> 分类:**卡牌构筑** · 入口:/cardchain/ · 免费在线 · 手机即点即玩

**目标:**连锁出牌:手牌 3 张,**花色或点数匹配顶牌即可打出**;连锁越长分越高,不匹配断连 -20;12 张后比最大连锁。

| 元素 | 效果 |
|---|---|
| 🃏 顶牌 | 弃牌堆最上面的牌 |
| 🃏 手牌 | 3 张,出一张补一张 |
| 🔗 连锁 | 同花色或同点数均可 |
| ❌ 断连 | 不匹配 -20 并清零 |
| 🏆 计分 | 50 + 连锁 x20 |

**操作:****点手牌**(键盘 **1-3**)出牌。

> 💡 **打法:**① 同花色优先——<b>花色只有四种</b>,概率比点数高;② 连锁 x20 是复利,<b>宁可弃高分卡也要保连锁</b>;③ 点数匹配涵盖 1-10,<b>点数匹配概率 > 花色匹配</b>;④ 12 张很快打完,<b>别纠结</b>!

**结算:**最大连锁、本局得分、历史最高分、已玩局数。
