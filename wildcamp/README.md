# 荒野露营 (🏕️ 荒野露营 · 五夜求生)

> 分类:**生存挑战** · 入口:/wildcamp/ · 免费在线 · 手机即点即玩

**目标:**多资源生存:五夜求生,**每晚行动消耗体温与食物**,归零即败;三选一行动卡平衡资源,第五夜后按余量结算。

| 元素 | 效果 |
|---|---|
| 🔥 生火 | 体温 +3 |
| 🍖 觅食 | 食物 +3 |
| ⛺ 营地 | 防御 +2,夜耗减少 |
| 🌲 探索 | 食物+2 但体温-1 |
| 🐟 摸鱼 | 食物+2,50% 失温 |

**操作:****点行动卡**(键盘 **1-3**)过夜。

> 💡 **打法:**① 体温掉得比食物快,**火不能断**;② 防御升到 4+,**每晚省半口气**;③ 探索和摸鱼有代价,**体温富余才去**;④ 前两夜**攒资源**,后三夜**保底跳**;⑤ 结算看余量,**赢得漂亮不如活得剩得多**!

**结算:**生存天数、体温、食物、本局得分、历史最高分、已玩局数。
