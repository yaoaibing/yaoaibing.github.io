# 扎筏渡江 (🪵 扎筏渡江 · 一筏千钧)

> 分类:**建造物理** · 入口:/raftup/ · 免费在线 · 手机即点即玩

**目标:**结构承载:立竹+绑结造筏,**载荷÷竹数≤30** 才能渡江;每竹两道结是底线;省竹有奖。

| 元素 | 效果 |
|---|---|
| 🪵 立竹 | 1-6 根自选 |
| 🪢 打结 | 每竹上下各一道 |
| 🧮 承载 | 载重÷竹数≤30 |
| 🌊 试航 | 不合格散架 -30 |
| 🏆 评级 | 四江全渡筏子匠 |

**操作:**点格立竹打结,点「**🌊 试航**」(空格)验证。

> 💡 **打法:**① **先看载重再定竹数**:180 斤至少 6 根;② 竹多省力但费结,**绳结够用就好**;③ 每根竹**上下都绑**,少一道都不行;④ 载重轻时**少用竹**,剩余竹数是加分;⑤ 散架别慌,**补一根再试**!

**结算:**渡江数、绳结数、本局得分、历史最高分、已玩局数。
