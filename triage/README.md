# 急诊分诊 (🚑 急诊分诊 · 抢救室门口)

> 分类:**街机动作** · 入口:/triage/ · 免费在线 · 手机即点即玩

**目标:**一轮 18 位伤员依次到门口,读体征卡(心率、血氧、血压、意识)在倒计时内判级别:**两项以上危险为一级红,恰好一项为二级黄,全部平稳为三级绿**;判错或超时记一次事故,三起事故或全部处理完即结束。

| 元素 | 效果 |
|---|---|
| ❤️ 心率 | 过快 >130 或过慢 <50 记一项危险 |
| 🫁 血氧 | 低于 92% 记危险 |
| 🩸 血压 | 高压 <90 或 >180 记危险 |
| 🧠 意识 | 含糊或不清算危险 |
| 🏁 结束 | 18 人处理完或三起事故 |

**操作:**底部红黄绿三按钮定级(键盘 1/2/3);**重接**重开一班。越果断分越高,磨蹭会超时报废!

> 💡 **打法:**① 先扫<b>血氧</b>,它最难造假;② 数字都正常但意识模糊,至少二级;③ 老人基础病多,单项危险也别当没事;④ 倒计时到一半还没结论就先给红,宁可高判;⑤ 连着判对会有加分,稳住节奏别断!

**结算:**接诊人数、判对数、连续判对、本局得分(每人 100 + 手速 x60 + 连判 x10)、历史最高分、已玩局数。
