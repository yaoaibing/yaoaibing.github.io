# 饺子谜题 (🥟 饺子谜题 · 皮馅对对)

> 分类:**烧脑益智** · 入口:/dumpling3/ · 免费在线 · 手机即点即玩

**目标:**排列谜题:**交换位置**使同类相邻;三关递增,全部解出过关。

| 元素 | 效果 |
|---|---|
| 🥟 九宫 | 3×3 排列 |
| 🧩 三馅 | 菜/肉/虾 |
| 🔄 交换 | 点两个交换 |
| ✅ 相邻 | 同类都连在一起 |
| 🏆 评级 | 三关全通排列大师 |

**操作:****点两个饺子**交换位置。

> 💡 **打法:**① **先数清三种馅**各有几个;② **同类连成片**,十字或L形;③ 交换次数**越少分越高**,想好再换;④ 三关**盘子越来越大**,耐心点;⑤ 排列好了,**饺子下锅**!

**结算:**交换次数、本局得分、历史最高分、已玩局数。
