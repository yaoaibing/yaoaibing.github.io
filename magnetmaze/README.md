# 磁力迷宫 (🧲 磁力迷宫 · 极性导航)

> 分类:**烧脑益智** · 入口:/magnetmaze/ · 免费在线 · 手机即点即玩

**目标:**点击磁铁**切换吸引/排斥**极性,铁球在磁力作用下移动;把铁球引到终点圆圈即过关,墙壁阻挡磁力。10 关递增。

| 元素 | 效果 |
|---|---|
| 🧲 磁铁 | 点切换极性,吸引⬆/排斥⬇ |
| ⚽ 铁球 | 受多个磁力影响,合力决定方向 |
| 🧱 墙壁 | 阻挡磁力和球 |
| 🎯 终点 | 铁球停在圈内即过关 |
| 🏁 过关 | 进入下一关 |

**操作:****点磁铁**切换极性;**重来**复位本关。吸引力大排斥力小,善用排斥做精细调整!

> 💡 **打法:**① 吸引力让球加速飞向磁铁,别让球飞过头;② 排斥力可以做<b>精调</b>,轻推球到目标位置;③ 多个磁铁同时生效时,合力是向量叠加;④ 墙壁能挡磁力,利用墙壁做「磁力屏蔽」;⑤ 最后一关有移动磁铁,提前预判!

**结算:**通关数、总步数、各关成绩、本局得分(每关 200 - 超额步 x10)、历史最高分、已玩局数。
