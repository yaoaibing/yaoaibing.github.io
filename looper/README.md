# 四轨循环 (🎛️ 四轨循环 · 节奏复刻)

> 分类:**音乐节奏** · 入口:/looper/ · 免费在线 · 手机即点即玩

**目标:**节奏记忆:幽灵样例播放两圈后隐藏;在 4×16 步进格上**复刻目标节奏**;对比提交全对通关,错格扣一颗心。

| 元素 | 效果 |
|---|---|
| 🥁 四轨 | 鼓/贝斯/和弦/主旋 |
| 👣 幽灵 | 样例只播两圈 |
| ▶ 重听 | 随时再放样例 |
| ✅ 对比 | 多放漏放都算错 |
| 🏆 评级 | 连过 6 关节奏大脑 |

**操作:**点格子放置/取消音符,点「**▶ 听原曲**」重听,点「**✅ 对比提交**」验收。

> 💡 **打法:**① **按轨分组记**:先记鼓,再记贝斯;② 数拍子:**每 4 格一小节**,重心拍先记住;③ 拿不准就**重听一遍**,别急着提交;④ 高关卡**轨数变多**,先攻主旋律轨;⑤ 清空键是反悔神器,**推倒重来不可耻**!

**结算:**通过关数、连过、本局得分、历史最高分、已玩局数。
