# 打雪仗 (⛄ 打雪仗 · 雪地对决)

> 分类:**街机动作** · 入口:/snowball/ · 免费在线 · 手机即点即玩

**目标:**雪地 1v1 对轰:**拖动走位**躲球,**点击屏幕**朝指尖方向掷雪球,命中 +1;AI 挥臂蓄力是出球预兆;先得 5 分获胜,失手有 0.7 秒冷却。

| 元素 | 效果 |
|---|---|
| 👆 掷球 | 点屏幕,球飞向指尖方向 |
| 🏃 走位 | 左右拖动,出手后再换位更安全 |
| 👀 预兆 | AI 蓄力举手 0.3-0.7 秒后出球 |
| ❄️ 硬直 | 掷出后 0.7 秒不能连掷 |
| 🎚 难度 | 越高 AI 越准、越快、越会骗位 |

**操作:****拖动**走位,**点击屏幕**掷球(空格朝 AI 直掷);**重赛**重开,**难度**三档切换。

> 💡 **打法:**① 看<b>挥臂</b>躲球比看球快,举手就横移;② 掷出后立刻反向走位,最骗 AI 预判;③ 别站中线对轰,AI 困难档的误差只有 12 像素;④ AI 出手后有一小段<b>走位空窗</b>,那是还击最好的时机;⑤ 冷却 0.7 秒,与其乱掷不如一次掷向它移动方向的前面!

**结算:**比分、难度、本局得分(胜 600 + 难度 x100 + 净胜 x50,负 60 x 得分)、历史最高分、已玩局数。
