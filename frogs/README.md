# 青蛙过河 (🐸 青蛙过河 · 荷叶换位)

> 分类:**烧脑益智** · 入口:/frogs/ · 免费在线 · 手机即点即玩

**目标:**左岸绿蛙与右岸红蛙在荷叶上换位:青蛙只能**向前滑到相邻空位**或**向前跳过一只蛙**;两侧完全互换即胜利,步数越少分越高,6 关蛙数递增。

| 元素 | 效果 |
|---|---|
| 🐸 移动 | 点青蛙:滑 1 格或跳过 1 蛙 |
| ➡️ 方向 | 绿蛙只能向右,红蛙只能向左 |
| 🔁 目标 | 两种蛙完全互换位置 |
| 🧠 最优 | n+n 最少 n*n+2n 步 |
| 🏁 过关 | 换位成功自动下一关 |

**操作:****点青蛙**移动;**重来**复位本关。口诀:能跳就跳,不能跳就滑,让路优先!

> 💡 **打法:**① 口诀:<b>跳-滑-滑-跳-滑-滑-跳</b>,循环准没错;② 别让同色蛙堵成一排,中间留空位;③ 卡住时看哪只蛙的<b>前方是空位</b>,先动它;④ 关卡越大越要冷静,一步退棋全盘乱;⑤ 3+3 的 15 步解法背下来,6+6 就是扩展版!

**结算:**通关数、总步数、各关成绩、本局得分(每关 300 - 超额步 x20)、历史最高分、已玩局数。
