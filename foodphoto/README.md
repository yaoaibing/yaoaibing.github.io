# 美食摄影 (🍜 美食摄影 · 出片参数师)

> 分类:**摄影抓拍** · 入口:/foodphoto/ · 免费在线 · 手机即点即玩

**目标:**参数摄影:读菜品提示,**调节光位/景深/构图三滑杆**拍摄评分;每项与隐藏目标越接近分越高;六道菜结算。

| 元素 | 效果 |
|---|---|
| 💡 光位 | 顺光 0 / 侧逆 50 / 顶光 100 |
| 🎬 景深 | 实 0 → 虚 100 |
| 🖼 构图 | 全景 0 → 特写 100 |
| 📸 评分 | 每项 ±8 内满分 |
| 🏆 评级 | 1500 分美食摄影大拿 |

**操作:**「**◀ ▶**」调当前滑杆,「**🔀 换参数**」切换,「**📸 拍摄**」出片(方向键+Tab+回车)。

> 💡 **打法:**① 口诀:**甜品冷饮浅景深特写,热菜锅气顶光中景**;② 日料寿司=冷调顺光+特写;③ 滑杆 5 一档,**先粗调到附近再精调**;④ 提示里每个形容词都对应参数,**逐词拆解**;⑤ 先拍两道摸评分宽严,**后面越拍越准**!

**结算:**快门次数、本局得分、历史最高分、已玩局数。
