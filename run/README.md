# 星夜跑酷 (🏃 星夜跑酷(新并入))

> 分类:**街机动作** · 入口:/run/ · 免费在线 · 手机即点即玩

**目标:**小狐狸狂奔,距离=分数。跳/二段跳过箱子尖刺,滑铲钻横杆,金币满能量→无敌冲刺(速度已调慢)。
| 操作 | 键位 |
|---|---|
| 跳/二段跳 | `↑`/`Z`/点屏上半;空中再按一次
滑铲 | `↓`/点屏下半 |

> 💡 **技巧:**① 带 `!` 的紫横杆**必须滑铲**;② 双层高箱提前起跳;③ RUSH 期间无敌放心冲;④ 二段跳救命,长障碍先小跳再补。
