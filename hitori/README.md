# 孤数计 (🔢 孤数计 · 扣掉重复)

> 分类:**烧脑益智** · 入口:/hitori/ · 免费在线 · 手机即点即玩

**目标:**经典 Hitori(一人一计):5x5 数字盘,**扣掉一些格子,使得每个数字在它所在的行与列里只出现一次;被扣掉的格子不许上下左右相邻;所有没被扣的格子必须正交连通成一块**。点格子切换扣除,违规格实时描红。十道题由生成器随机填数后用回溯数解,只收唯一解盘面,并经行掩码 DP 与全枚举三方交叉复核;每关限时 90 秒,超时即结束。

| 元素 | 效果 |
|---|---|
| 🔢 数字格 | 点一下扣掉,再点还原 |
| 🚫 去重 | 每行每列同一数字只留一个 |
| ⬛ 不相连 | 扣除格不许上下左右贴在一起 |
| 🔗 保连通 | 留下的格子必须连成一整片 |
| 💡 提示 | 替你扣一个正确格子,扣分 |

**操作:****点格子**扣除 / 还原;**💡 提示**替你扣一个该扣的格(每关 2 次,扣 45 分);**↻ 重置**清盘重算这一关。违规时红框=行列重号、橙色虚线=扣除格相连、蓝色圆圈=留下的格被隔离在连通块外。键盘 H 提示、C 清盘、R 重开。

> 💡 **打法:**① 先找<b>同一格内出现三次</b>的数字,答案常常被锁死;② 挨着的两个重号必扣其一,把它记成候选,行列另一边会收敛;③ <b>扣除不能相连</b>最容易被忽略,扣一个就把它的四邻标成不能扣;④ 收尾一定检查连通,角落被切掉就是错;⑤ 提示留在最后一格,别开局就连用。

**结算:**解答题数、本局得分(每题基础分 + 剩余秒数 - 提示扣分)、历史最高分、已玩局数。
