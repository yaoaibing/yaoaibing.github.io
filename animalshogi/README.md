# 动物将棋 (🦁 动物将棋 · 森林对弈)

> 分类:**对战棋牌** · 入口:/animalshogi/ · 免费在线 · 手机即点即玩

**目标:**3×4 将棋:狮(八方)/长颈鹿(十字)/小象(斜四)/小鸡(前1,升变母鸡);吃子入手牌可打入;擒王获胜。

| 元素 | 效果 |
|---|---|
| 🦁 狮王 | 八方一步,被吃即输 |
| 🦒 长颈鹿 | 上下左右一步 |
| 🐘 小象 | 斜向四格 |
| 🐤 小鸡 | 前进一格,冲底线升母鸡(十字) |
| ♻️ 打入 | 手牌棋子落空格 |

**操作:****点己方棋子**再点目标格;点**手牌**再点空格打入。

> 💡 **打法:**① 小鸡升变是**翻倍战力**,冲线优先;② 狮王别乱出,**周边留护卫**;③ 吃子不只是赚子,**位置更值钱**;④ AI 贪吃,**用小鸡钓它再反打**;⑤ 手牌打入能**瞬间翻盘**,别攒着不用!

**结算:**对局比分、本局得分、历史最高分、已玩局数。
