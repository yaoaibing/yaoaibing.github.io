# 滚铁环 (⭕ 滚铁环 · 街头老手艺)

> 分类:**街机动作** · 入口:/hooproll/ · 免费在线 · 手机即点即玩

**目标:**平衡滚行:铁环持续前滚,**倾斜摆动需点两侧回正**;障碍点中屏跳过;翻倒三次结束。

| 元素 | 效果 |
|---|---|
| ⭕ 铁环 | 越滚越快 |
| 👈👉 扶环 | 点侧屏回正倾斜 |
| 🪨 跳跃 | 近障碍点中屏 |
| 📉 倾斜表 | 指针出格即翻倒 |
| 🏆 评级 | 滚 300 米街头老手 |

**操作:****点左右半屏**扶环,**点中屏**跳跃(键盘 ← → 空格)。

> 💡 **打法:**① **小歪快扶**,别等倾斜表见红;② 看到障碍**提前点中屏**,贴脸就迟了;③ 速度上来后**扶环手要轻**;④ 翻倒后环会慢下来,**趁机稳住节奏**;⑤ 心里哼个调子,**手就有谱了**!

**结算:**距离、翻倒次数、本局得分、历史最高分、已玩局数。
