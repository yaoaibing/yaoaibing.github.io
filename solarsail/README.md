# 太阳帆远航 (☀️ 太阳帆远航 · 追光者)

> 分类:**太空导航** · 入口:/solarsail/ · 免费在线 · 手机即点即玩

**目标:**光压航行:探测器受**日引力**与**帆角光压**共同作用;点左右转帆 15° 调整推力方向,**漂入目标星圈**过站;撞日/飞出界/超时即失败。

| 元素 | 效果 |
|---|---|
| ☀️ 引力 | 离日越近拉得越狠 |
| ⛵ 光压 | 贴日更强,帆角导向 |
| ↺↻ 转帆 | 每次 15° |
| 🪐 过站 | 进圈 +250+时间奖 |
| 🏆 三站 | 全达即深空老手 |

**操作:**点「**↺ 左转帆 / 右转帆 ↻**」(键盘 **← →**),点画面左右两侧也可转帆。

> 💡 **打法:**① **先贴日加速**,离太阳近光压翻倍;② 目标在上,**帆角打侧后方走螺旋**;③ 冲过头就**调转帆角**,慢慢往回蹭;④ 速度有上限,**别怕甩出去**;⑤ 后两站时间紧,**贴日蛇形走位**最稳!

**结算:**过站数、航速、本局得分、历史最高分、已玩局数。
