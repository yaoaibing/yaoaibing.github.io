# 密码破译 (🔐 密码破译 · 截获密电)

> 分类:**密码破译** · 入口:/cipher/ · 免费在线 · 手机即点即玩

**目标:**经典凯撒密码:密文由**字母移位**加密,用 **◀▶ 调偏移量**让解码预览还原成有效拼音,确认后再**四选一**挑出正确含义;每组 150 分起步,尝试与提示都扣分,共 8 组。

| 元素 | 效果 |
|---|---|
| 🔐 密文 | 每个字母按偏移量后移加密 |
| ◀▶ 偏移 | 0-25 共 26 种,预览实时解码 |
| ✅ 确认 | 解码为有效拼音才放行 |
| 🀄 语义 | 四选一挑正确汉字词 |
| 💡 情报 | 直接泄露偏移,本组 -50 分 |

**操作:****◀▶** 调偏移(**←→** 同效),**✅确认**(空格)锁定;含义用 **1-4** 选择;**💡情报**(H)应急。

> 💡 **打法:**① 已知首字母对照(如 G=L),<b>先算偏移再转动盘</b>,一步到位;② 偏移从 1 到 25,<b>对半试</b>比逐个翻快;③ 拼音韵母多为 i/ng/ao,<b>看解出的辅音结构</b>顺不顺口,顺就基本对了;④ 确认错了 -20,<b>预览像话再确认</b>;⑤ 情报 -50 但连错三次也是 -60,组内错两次就该用情报止损!

**结算:**破译进度、尝试次数、本局得分(每组 150 - 尝试 x30 - 提示 50)、历史最高分、已玩局数。
