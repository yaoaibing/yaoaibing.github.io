# 听声选器 (🎧 听声选器 · 音色辨识)

> 分类:**音乐节奏** · 入口:/timbre/ · 免费在线 · 手机即点即玩

**目标:**音色听辨:同旋律用**钢琴/吉他/铃铛**三种音色随机演奏,**点选正确乐器**;连对加分,12 轮测音色听感。

| 元素 | 效果 |
|---|---|
| 🎧 听音 | 旋律自动播放,含乐器特征泛音 |
| 🎹 三选一 | 点乐器卡作答(1-3) |
| 🔥 连对 | 每题 100 + 连对 x15 |
