# 夜摄猎人 (🦌 夜摄猎人 · 野生动物)

> 分类:**摄影抓拍** · 入口:/photo2/ · 免费在线 · 手机即点即玩

**目标:**夜间摄影:探照灯跟随指尖照亮黑暗,野兽在光圈**70px 内**即可快门;分值按稀有度递增,**害羞野兽会躲避灯光**;10 张底片用完结算,连拍有状态加成。

| 元素 | 效果 |
|---|---|
| 🔦 探照灯 | 跟随指尖,是唯一光源 |
| 🦌 猎物 | 鹿/枭/狼/熊,分值 150→350 |
| 🦄 白鹿 | 8% 概率惊现,600 分传说 |
| 🐰 怕光 | 部分野兽被照到会加速逃离 |
| 🎞️ 底片 | 10 张,间隔 0.8 秒 |

**操作:****移动指尖**探照,**光圈罩住野兽后点击**(空格)快门;方向键也可移动光圈。

> 💡 **打法:**① 把灯<b>留在屏幕中央偏右</b>:野兽多从右侧入场,提前守株待兔;② 害羞动物被照会跑,<b>从它前进方向的前方截拍</b>,别从背后追;③ 白鹿沿边角走,**听到提示就把灯扫向四角**;④ 快门有 0.8 秒间隔,<b>空按的代价是错过真目标</b>;⑤ 月熊 350 分但移动慢,新手拿它练手最稳,白鹿留给手热的时候!
