# 移车出巷 (🛒 移车出巷 · 一挪一让)

> 分类:**烧脑益智** · 入口:/cartout/ · 免费在线 · 手机即点即玩

**目标:**滑块解围:**点车定向**,三巷递进。

| 元素 | 效果 |
|---|---|
| 🛒 马车 | 红线主角 |
| 👆 挪移 | 点车点向 |
| 🧱 巷墙 | 撞上即停 |
| ⚠️ 堵死 | 换车让路 |
| 🏆 结算 | 挪车折分 |

**操作:****先点车,再点方向钮**。

> 💡 **打法:**① **先找挡在马车前的车**,让它挪开;② 车**撞墙会停**,放心大胆点;③ 一步到位**不存在的**,多挪几步不亏;④ 巷号越深**车越多**,倒着推最容易;⑤ 三巷挪通,**赶车的把式都来请教**!

**结算:**巷号、出口向、本局得分、历史最高分、已玩局数。
