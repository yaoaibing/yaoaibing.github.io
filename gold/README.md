# 黄金矿工 (🪙 黄金矿工 · 淘金达人)

> 分类:**街机动作** · 入口:/gold/ · 免费在线 · 手机即点即玩

**目标:**钩子左右摇摆,点屏幕**下钩**,抓住东西自动收回,60 秒内淘到越多金币越好。抓到的物品价值不同,**重量决定收杆速度**。
| 物品 | 价值 | 重量 |
|---|---|---|
| 🪙 小金块 | 50 | 轻,收得快 |
| 🪙 中金块 | 100 | 中 |
| 🪙 大金块 | 250 | 重,收得慢 |
| 💎 钻石 | **600** | 轻但罕见(约10%) |
| 🪨 石头 | 20 | **超重,收杆巨慢** |
| 🎁 神秘袋 | 随机 50~300 | 中 |

> 💡 **淘金要点:**① 钩子是**直上直下**的,等它摆到目标**正上方**再下钩;② 优先级:钻石 > 大金块 > 中金块,**石头永远最后考虑**;③ 石头被抓住会浪费好几秒,**下钩前确认路径上没石头挡道**;④ 神秘袋期望约 175,稳赚不亏;⑤ 60 秒大概能下 10~14 钩,平均每钩 150+ 才算高效。

**结算:**淘得金币、历史最高分。
