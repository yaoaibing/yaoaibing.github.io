# 合堰截流 (🌊 合堰截流 · 一堰一龙)

> 分类:**建造物理** · 入口:/cofferdam/ · 免费在线 · 手机即点即玩

**目标:**抢配合龙:**砌七候落**,三堰递进。

| 元素 | 效果 |
|---|---|
| 🌊 堰弧 | 一段一段砌 |
| 👆 下石 | 点弧即砌 |
| 💧 水势 | 满百即垮 |
| ⚠️ 冲垮 | 折六十重来 |
| 🏆 结算 | 截流折分 |

**操作:**点**堰弧下石**,最后**合龙口**。

> 💡 **打法:**① **七段先砌满**,别急着堵口;② 水势**回落那两三息**是命,盯死条;③ 冲垮**折六十**,宁等一息不抢;④ 堰号越深**水涨越急**,手要麻利;⑤ 三堰合龙,**县志上记你一笔**!

**结算:**堰号、水势、本局得分、历史最高分、已玩局数。
