# 红包雨 (🧧 红包雨 · 接福大作战)

> 分类:**解压休闲** · 入口:/hongbao/ · 免费在线 · 手机即点即玩

**目标:**45 秒内拖动福筐接住天上掉的**红包(10 分)/金币(25 分)/福袋(50 分)**,连续接住涨连击倍率,接到**炸弹**扣 40 分并清空连击。时间到按总分结算。

| 元素 | 效果 |
|---|---|
| 🧧 红包 | 常见物,10 分,掉落最快 |
| 💰 金币 | 25 分,体积小容易漏 |
| 🛍️ 福袋 | 50 分,数量少且会左右飘 |
| 💣 炸弹 | 接到 -40 分并清空连击,千万别碰 |
| 🔥 连击 | 连续接中涨倍率(x1→x5),漏接或炸弹清零 |

**操作:****按住屏幕左右拖动**控制福筐(键盘 ← → 也行);**重开**立刻重开一局。掉落速度随时间越来越快。

> 💡 **打法:**① 筐别死跟一个物,**预判落点**提前到位;② 福袋会左右飘,看到就优先,50 分顶 5 个红包;③ 连击是分数核心,漏接一个就断,宁可稳接小物;④ 炸弹是深色尖刺,和红包颜色差异明显,余光扫一眼就知道躲;⑤ 最后 10 秒下红包雨最密,提前把筐往屏幕中央移。

**结算:**总分、接住个数、最大连击、漏接与炸弹次数、历史最高分、已玩局数。
