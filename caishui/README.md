**目标:**呼吸节奏:**踩浮相济**,三河横渡。

| 元素 | 效果 |
|---|---|
| 🌊 大河 | 一河一程 |
| 👆 踩水 | 左钮连点 |
| 🫁 浮息 | 右钮攒气 |
