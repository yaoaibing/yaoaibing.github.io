# 认识路标 (🛑 认识路标 · 出行安全课)

> 分类:**学习教育** · 入口:/roadsign/ · 免费在线 · 手机即点即玩

**目标:**交通标志速答:20 枚常见标志**四选一**;连对滚分,45 秒结算。

| 元素 | 效果 |
|---|---|
| 🛑 题库 | 警告/禁令/指引三类 |
| 🔵 蓝方 | 蓝底方块多是指引 |
| 🔴 红圆 | 红圈多是禁令 |
| ⚠️ 黄三 | 黄三角多是警告 |
| 🏆 评级 | 连对 12 标志通 |

**操作:****点选项**(键盘 **1-4**)作答。

> 💡 **打法:**① **先看形状颜色**:红圆禁、黄角警、蓝方指;② 禁令里**斜杠=解除**,别混;③ 施工标志是**黄底黑图**;④ 答错记形状,**下次秒选**;⑤ 连对是分差核心,**稳中求快**!

**结算:**连对、本局得分、历史最高分、已玩局数。
