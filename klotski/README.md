# 曹操逃生 (🟥 曹操逃生 · 经典华容道)

> 分类:**烧脑益智** · 入口:/klotski/ · 免费在线 · 手机即点即玩

**目标:**拖动棋子滑入空格,把 **2x2 的曹操**移动到棋盘下方中央的出口。每滑动一格算一步,步数越少成绩越好。

| 元素 | 效果 |
|---|---|
| 🟥 曹操 | 2x2 大块,目标是挪到下方出口 |
| 🟦 武将 | 1x2 竖块和 2x1 横块,只能整块滑动 |
| ⬜ 士兵 | 1x1 小块,用来腾出通道 |
| 💡 提示 | 自动算出当前局面通往出口的一步 |
| 🎲 换残局 | 从经典局随机走若干步得到的新残局,保证可解 |

**操作:**手指按住棋子朝空格方向拖动;也可以先点棋子选中,再按方向键移动。**提示**算一步,**换残局**生成可解新局,**重来**回到经典开局。

> 💡 **打法:**① 先给曹操**腾出下方两列**,别急着直接往下推;② 两个小兵是钥匙,先把它们调到曹操脚下;③ 关羽横块最容易挡路,尽量往边上赶;④ 每次移动前想好下一步,步数是唯一评分;⑤ 提示只在真正卡住时用,自己推出来更有成就感。

**结算:**步数、提示次数、本局得分(1500 - 步数 x8 - 提示 x60,最低 100)、历史最高分、已玩局数、最佳步数。
