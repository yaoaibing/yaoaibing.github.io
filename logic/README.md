# 逻辑电路 (🔌 逻辑电路 · 通电挑战)

> 分类:**烧脑益智** · 入口:/logic/ · 免费在线 · 手机即点即玩

**目标:**每关一个电路:**点开关**改变通断,理解与门(全通才通)、或门(一通即通)、非门(反转)的规则,让所有灯泡亮起即过关。12 关难度递增。

| 元素 | 效果 |
|---|---|
| 🔌 开关 | 点开关切换,电路实时重算 |
| 🚦 与门 | 两输入全通,输出才通 |
| 🚦 或门 | 任一输入通,输出即通 |
| 🚦 非门 | 输出与输入相反 |
| 🏁 过关 | 全部灯泡点亮进入下一关 |

**操作:****点开关**切换;**回第1关**重头玩。先看灯泡需要什么,再倒推每个开关的状态!

> 💡 **打法:**① 从<b>灯泡倒推</b>:它需要哪个门输出为通;② 与门有两个输入,逐个确认,漏一个全盘黑;③ 非门是反转利器,卡关时想想它;④ 前几关是教学,认真读懂门的规则;⑤ 最后一关把三个门连着用,画在纸上推一遍就懂!

**结算:**通关数、开关操作数、用时、本局得分(过关 x150)、历史最高分、已玩局数。
