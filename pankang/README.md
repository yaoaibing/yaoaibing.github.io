# 热炕通烟 (🔥 热炕通烟 · 一道一暖)

> 分类:**建造物理** · 入口:/pankang/ · 免费在线 · 手机即点即玩

**目标:**路径盘炕:**连格通烟**,三炕递进。

| 元素 | 效果 |
|---|---|
| 🔥 灶口 | 烟从这起 |
| 👆 通道 | 点格开通 |
| 🏮 烟囱 | 终点在别端 |
| ⚠️ 倒灌 | 断路即呛 |
| 🏆 结算 | 盘炕折分 |

**操作:**点**格子开通烟道**,点「点火」验。

> 💡 **打法:**① **先找暗格**,绕开它们铺路;② **一条路走到黑**,岔路全拆掉;③ 点火**不通折三十**,多看一眼少赔多;④ 炕号越深**暗格越多**,先规划再下手;⑤ 三炕盘通,**一屋人抢着睡炕头**!

**结算:**炕号、烟道数、本局得分、历史最高分、已玩局数。
