# 造塔吊装 (🏗️ 造塔吊装 · 力矩平衡)

> 分类:**建造物理** · 入口:/towercrane/ · 免费在线 · 手机即点即玩

**目标:**力矩平衡模拟:右端吊 **2-6 吨重物**,左侧配重在 **2 倍力臂**上——配重只需重物一半即可平衡;加减配重块把倾角调到 0 并保持 1.2 秒过关,倾角超 45% 塔吊倾覆,五关重物递增。

| 元素 | 效果 |
|---|---|
| 🏗️ 吊臂 | 右端重物 1 倍力臂,左端配重 2 倍力臂 |
| ⚙️ 配重 | 加减 1/3 吨,上限 12 吨 |
| 📐 力矩公式 | 配重 = 重物 ÷ 2(2 倍力臂抵消) |
| 🟢 判定 | 倾角 <3% 保持 1.2 秒 |
| 💥 倾覆 | 倾角 >45% 直接失败 |

**操作:****加减配重块**(键盘 **1=+1 2=+3 3=-1 4=-3**)把倾角调到接近 0,**自动保持 1.2 秒过关**!

> 💡 **打法:**① 公式很简单:<b>配重 = 重物 ÷ 2</b>(2 倍力臂),4 吨重物配 2 吨;② 倾角是<b>连续模拟</b>不是开关——接近 0 时会自动回正,大胆微调;③ 起始倾角随机左右偏,<b>先看倾斜方向再加</b>;④ 重物 6 吨时配 3 吨,**但随机偏差可能要 +1 微调**;⑤ 保持 1.2 秒需要倾角 <3%——**绿字就是安全区**,别看到 0% 就以为稳了!
