# 套圈圈 (⭕ 套圈圈 · 庙会神投)

> 分类:**解压休闲** · 入口:/ringtoss/ · 免费在线 · 手机即点即玩

**目标:**两段投掷:锁**瞄准**(左右扫动)+锁**力度**,圈抛物线飞出;命中木桩按分值计分;60 秒结算。

| 元素 | 效果 |
|---|---|
| 🎯 瞄准 | 决定圈的横向落点 |
| 💪 力度 | 决定距离与高度 |
| 💰 高桩 | 内侧两根 80 分 |
| 🔵 低桩 | 外侧三根 30-50 分 |
| 🏆 评级 | 12 圈庙会圈神 |

**操作:**点「**⭕ 出圈**」或按**空格**:一次锁瞄准,一次锁力度。

> 💡 **打法:**① **内侧高桩**:瞄准走到正中再出手;② 力度条**中段最稳**,满力容易过头;③ 记住**瞄准和力度的联动**,偏了就补力度;④ 高桩套不中**就吃低桩**,30 分也是分;⑤ 节奏感:**出手间隔固定**,手感自然来!

**结算:**套中圈数、本局得分、历史最高分、已玩局数。
