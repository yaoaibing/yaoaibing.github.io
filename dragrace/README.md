# 直线加速 (🏁 直线加速 · 换挡大师)

> 分类:**竞速赛车** · 入口:/dragrace/ · 免费在线 · 手机即点即玩

**目标:**直线竞速:等绿灯起步(抢跑判负),自动加速下在**转速绿区按升挡**触发完美换挡;400 米先冲线者胜,五挡赛制。

| 元素 | 效果 |
|---|---|
| 🚦 起跑 | 3 红灯依次亮,绿灯起步 |
| ⏫ 升挡 | 转速 82-96% 完美 |
| 💨 五挡 | 每挡极速 70→290 |
| 🤖 AI | 88% 上下随机换挡 |
| 🏆 计分 | 胜 300 + 完美 x30 |

**操作:**点「⏫ 升挡」或按**空格**;起步与换挡都是它。

> 💡 **打法:**① 起步屏住呼吸,**绿灯亮再按**,抢跑血亏;② 一挡进二挡**转速拉满也不亏**,后段才讲究;③ 绿区很窄,**听发动机音调变化**辅助;④ 完美换挡 +6 km/h 是实打实的,**宁等一拍**;⑤ 对比 AI:它 88% 换,**你压 90% 稳赢半车身**!
