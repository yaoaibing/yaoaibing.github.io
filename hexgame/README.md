# 六贯棋 (⬡ 六贯棋 · 连通两岸)

> 分类:**对战棋牌** · 入口:/hexgame/ · 免费在线 · 手机即点即玩

**目标:**11x11(本作为 9x9)菱形棋盘轮流落子:**蓝方连左右、红方连上下**。相邻六格算连通,棋盘满之前必有一方连通,先连成者胜。支持悔棋。

| 元素 | 效果 |
|---|---|
| ⬡ 落子 | 点任意空格放蓝子,电脑立即回应 |
| 🔵 蓝方 | 连接左右两条蓝边获胜 |
| 🔴 红方 | 电脑连接上下两条红边 |
| ↶ 悔棋 | 退回你的上一手 |
| 🏁 胜负 | BFS 判连通,先连成者赢 |

**操作:**点空格落子;**悔棋**退一手,**新局**重开。电脑会算最短通路,别只顾自己连,记得堵它!

> 💡 **打法:**① 开局抢<b>中心</b>,中心格六向通吃;② 六贯棋的斜格是白送的桥,尽量走对角线;③ 对方快连成时,堵它<b>唯一缺口</b>比自己连一条新线更急;④ 两端同建:左边搭一点,右边搭一点,中间会师;⑤ 悔棋是老师,输了就悔回去看看哪步错了。

**结算:**胜负、手数、用时、本局得分(胜 600 + (121-手数) x3)、历史最高分、已玩局数。
