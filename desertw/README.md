# 沙漠求生 (🏜️ 沙漠求生 · 七天绿洲)

> 分类:**生存挑战** · 入口:/desertw/ · 免费在线 · 手机即点即玩

**目标:**生存权衡:每天 **3 点行动力**分配给夜行赶路(+18~31 里)/挖水/觅食;夜晚**水与食物各消耗 1**,断水 -22 断粮 -14,沙暴随机扒水囊;7 天内走满 100 里到达绿洲。

| 元素 | 效果 |
|---|---|
| 🚶 赶路 | +18~31 里,核心目标 |
| 💧 挖水 | +2~3 水 |
| 🌵 觅食 | +2~3 食物 |
| 💧 消耗 | 每晚水+食物各 1,断水 -22 |
| ⛺ 绿洲 | 100 里,到达即胜 |

**操作:**点 **赶路/挖水/觅食**(键盘 **1/2/3**);**回车=连赶两次路**;行动力用尽自动入夜。

> 💡 **打法:**① 黄金节奏:<b>赶路 2 次 + 补给 1 次</b>,5 天可到;② 水比食物珍贵,**水低于 2 优先挖水**;③ 行动是即时的,<b>行动力用完才结算夜晚</b>,别浪费半点;④ 沙暴只扒水不扒食物,<b>水囤 4 以上</b>防身;⑤ 最后一天别管补给,**三次全赶路**冲线!

**结算:**行程里数、存活天数、本局得分(胜 500 + 剩余天数 x60 + 生命 x3)、历史最高分、已玩局数。
