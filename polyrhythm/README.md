# 双手节拍 (👏 双手节拍 · 左右开弓)

> 分类:**音乐节奏** · 入口:/polyrhythm/ · 免费在线 · 手机即点即玩

**目标:**复合节奏:双轨音符分别按 **2 拍/3 拍**周期逼近击打线,**±80ms 内**判定命中;中段提速,双手独立计连击。

| 元素 | 效果 |
|---|---|
| 🤚 左手 | 每 2 拍一个蓝点 |
| ✋ 右手 | 每 3 拍一个橙点 |
| 🎯 判定 | ±80ms 完美 |
| 📈 提速 | 半程后节拍加快 |
| 🏆 评级 | 700 分节奏大脑 |

**操作:**点「**🤚 左拍 / 右拍 ✋**」(键盘 **z / m**)。

> 💡 **打法:**① **先只练左手**,连击稳了再加右手;② 口念「1-2、1-2」左手自然准;③ 右手**别跟左手**,它有自己的心跳;④ 重合点(2和3的公倍数)**最容易乱**,提前深呼吸;⑤ 失误连掉别慌,**单手先回到拍上**!

**结算:**左右连击、本局得分、历史最高分、已玩局数。
