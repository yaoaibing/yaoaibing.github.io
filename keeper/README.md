# 守门员扑救 (🧤 守门员扑救 · 十指关)

> 分类:**街机动作** · 入口:/keeper/ · 免费在线 · 手机即点即玩

**目标:**守住球门:射手助跑最后一步会出现**提示圈**,但有 25% 是假动作;球出脚后**点球门 6 个区域**扑救,球飞行中还能再点一次修正。失球 3 个比赛结束。

| 元素 | 效果 |
|---|---|
| 👀 提示圈 | 助跑最后一步闪烁,75% 是真实落点 |
| 👆 扑救 | 点 6 个区域之一,与实际落点一致即扑出 |
| ⚡ 果断出击 | 起脚前提前预判并扑对,额外 +40 分 |
| 🔄 空中修正 | 球飞行前 60% 时间可再点一次改扑救点 |
| 📈 加速 | 球速和助跑节奏逐球加快 |

**操作:****点击球门区域**扑救,或按 **1-6** 数字键(上排 1-3 下排 4-6);**重开**随时重赛。

> 💡 **打法:**① 提示圈有 1/4 是假动作,**等球出脚再确认**最稳;② 敢在出脚前提前扑对的奖励 +40,比分落后时值得赌;③ 球飞行途中还能改扑救点,别急着放弃;④ 连扑有连击分,**保住扑救节奏**比单次英勇更重要;⑤ 射手助跑会越来越快,后段靠预判不靠反应!

**结算:**扑救数、最长连扑、果断出击次数、失球数、本局得分(扑救 x100 + 连扑 x40 + 出击 x30)、历史最高分、已玩局数。
