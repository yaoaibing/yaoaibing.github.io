# 导弹拦截 (🚀 导弹拦截 · 城市防卫)

> 分类:**街机动作** · 入口:/defend/ · 免费在线 · 手机即点即玩

**目标:**敌方导弹从天而降飞向三座城市:**点击导弹前方的空域**发射拦截弹,爆炸范围内的导弹全部摧毁;城市被击中即失去,三城全毁结束,拦截数与波次计分。

| 元素 | 效果 |
|---|---|
| 🚀 导弹 | 从上方斜飞而下,带尾焰 |
| 💥 拦截 | 点空域引爆,半径 60 内全灭 |
| 🏙️ 城市 | 三座,被击中即摧毁 |
| 📈 波次 | 每波导弹数量+速度提升 |
| 🏆 计分 | 拦截 x15 + 守波 x200 |

**操作:****点击空域**拦截(键盘也行);**重整**重开。别只顾一颗导弹,一波一起拦才是效率!

> 💡 **打法:**① 拦截弹有飞行时间,瞄准<b>导弹前方</b>而不是它本身;② 多颗导弹扎堆时,炸它们的<b>交汇点</b>;③ 优先保中间城市,两侧起飞拦截更快;④ 一波结束有短暂喘息,提前把手指放在常用拦截高度;⑤ 最后的城市被锁定时,拼了!

**结算:**拦截导弹数、守住波次、存活城市、本局得分(拦截 x15 + 守波 x200)、历史最高分、已玩局数。
