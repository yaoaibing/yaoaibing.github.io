# 塔台指挥 (🛫 塔台指挥 · 三圈空域)

> 分类:**烧脑益智** · 入口:/atc/ · 免费在线 · 手机即点即玩

**目标:**三圈环形空域上不断来飞机:**点一架选中**,用「升层」把它挪到别的圈避免同圈相撞,层高错开后按「降落」引导进近;燃油耗尽或空中相撞即摔机,摔满 3 架结束,安全降落计分。

| 元素 | 效果 |
|---|---|
| 🛫 三班 | 低/中/高三圈,同圈间距过近即撞 |
| ⬆ 升层 | 选中飞机往上循环一圈 |
| 🛬 降落 | 脱离航圈直冲跑道,途中仍可被撞 |
| ⛽ 燃油 | 持续下降,归零摔机 |
| 🏁 结束 | 摔满 3 架空管停摆 |

**操作:****点飞机**选中,「升层」调高度、「降落」放人;**重开**重排。进近航线是最容易撞的一段,先清空它!

> 💡 **打法:**① 永远保证<b>最高圈</b>空着,那是降落专用通道;② 燃油少的优先放,别贪多;③ 两架同圈时,升层的那架要往<b>没人的圈</b>去;④ 波次越高来机越密,提前两架就把层排好;⑤ 一次只处理一架,手忙脚乱必摔机!

**结算:**安全降落架数、波次、本局得分(每架 100 + 剩余燃油)、历史最高分、已玩局数。
