# 打桩机 (🏗️ 打桩机 · 稳准狠)

> 分类:**建造物理** · 入口:/piledrive/ · 免费在线 · 手机即点即玩

**目标:**落锤时机:锤针在轨道振荡,**绿区(±22%)内落锤**伤害最深;打歪累积倾斜,超 70% 桩报废;每桩 3m、共 5 桩。

| 元素 | 效果 |
|---|---|
| 🔨 锤速 | 每根桩加快 20% |
| 💥 正中 | 深度 +1.1m、倾斜最小 |
| ⚠ 打歪 | 深度 +0.25m、倾斜大增 |
| ⛔ 报废 | 倾斜 ≥70% 拔起重打 |
| 🏆 计分 | 每桩 100 + 正中 x10 |

**操作:**点「**💥 落锤**」或按**空格**。

> 💡 **打法:**① **等正中别贪快**,歪一锤等于白打三锤;② 锤越打越快,**节奏提前量跟着加**;③ 倾斜到 40% 就该**收着打求正中**;④ 报废不可怕,**重打比斜桩得分高**;⑤ 最后一根锤最快,**深呼吸再按**!

**结算:**完工桩数、正中次数、本局得分、历史最高分、已玩局数。
