# 竹楼搭建 (🎍 竹楼搭建 · 层层上架)

> 分类:**建造物理** · 入口:/bambooloft/ · 免费在线 · 手机即点即玩

**目标:**上架建造:**每层选柱子粗细**,层数越高风越大;竹材有限,塌架即终。

| 元素 | 效果 |
|---|---|
| 🪵 宽柱 | 最稳,费 3 竹材 |
| 🎋 中柱 | 均衡,费 2 竹材 |
| 🌿 细柱 | 省料,费 1 竹材 |
| 🪢 加固 | 摇晃减半,费 2 |
| 🏆 结局 | 竹材用完或塌架 |

**操作:**点底部**柱子按钮**上架(键盘无效,只用按钮)。

> 💡 **打法:**① **底层用宽柱**打底,楼稳才谈高;② **上层换细柱**省料,高度分才多;③ **换层宽度差**太大也会晃,别忽宽忽窄;④ 摇晃过半就**果断加固**,塌了全白搭;⑤ 十层以上,**你就是架楼师傅**!

**结算:**建成层数、本局得分、历史最高分、已玩局数。
