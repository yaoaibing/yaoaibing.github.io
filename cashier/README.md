# 收银员 (💵 收银员 · 精准找零)

> 分类:**解压休闲** · 入口:/cashier/ · 免费在线 · 手机即点即玩

**目标:**看小票合计与顾客支付金额,**点纸币硬币凑出正确找零**。8 位顾客,找错扣一颗心共 3 颗。

**操作:**点面值按钮投入(可重复点),点「↩撤回」取回最后一枚,点「✓收银完成」结算。面值:100/50/20/10/5/2/1/0.5 元。

> 💡 **心算要点:**① 找零=支付-总价,**先算好总数再点**;② 和真收银一样:**从大面值凑起**(50→20→10→5…),张数最少不易错;③ 例:总价 23.5 支付 50 → 找 26.5 = 20+5+1+0.5;④ 点错的币用撤回取回,**确认合计再按完成**;⑤ 后期顾客买的东西多,总价有小数,细心是唯一秘诀。

**结算:**服务顾客数、总得分、历史最高分。
