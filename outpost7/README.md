# 深山哨所 (🏔️ 深山哨所 · 雪线电台)

> 分类:**生存挑战** · 入口:/outpost7/ · 免费在线 · 手机即点即玩

**目标:**多资源生存:七夜风雪,**每夜柴粮各-1**(加固哨所省柴两晚),任一归零即败;第七天电报≥3 获救。

| 元素 | 效果 |
|---|---|
| 🌲 砍柴 | 柴火 +2 |
| 🥔 领粮 | 存粮 +2 |
| 📻 发电报 | 电报+1(耗柴 1) |
| 🏔️ 巡逻 | 随机捡拾/损耗 |
| 🏆 获救 | 电报≥3 才等来队伍 |

**操作:****点行动卡**(键盘 **1-3**)过夜。

> 💡 **打法:**① **前三天各发一封电报**,求援要趁早;② 巡逻有惊喜也可能亏柴,**稳的时候再赌**;③ 加固哨所省柴两晚,**卡在第六七天最值**;④ 每夜必耗,**别让任何一项见底**;⑤ 最后一天**只做保命的事**!
