**目标:**蓄力投掷:**两段出手**,六索套马。

| 元素 | 效果 |
|---|---|
| 🪢 套索 | 杆头活扣 |
| 👆 蓄撒 | 点蓄点撒 |
| 🐎 骏马 | 褐马贵种马 |
