# 翻山棋 (⛰️ 翻山棋 · 跳吃登顶)

> 分类:**对战棋牌** · 入口:/ridgechess/ · 免费在线 · 手机即点即玩

**目标:**对弈跳吃:**山梁对进**,登顶定胜负。

| 元素 | 效果 |
|---|---|
| ⛰️ 山梁 | 三行四列 |
| ➡️ 直走 | 一步空位 |
| 🦘 跳吃 | 隔子吃子 |
| 🚩 登顶 | 到对面底线 |
| 🏆 结算 | 吃子折分 |

**操作:**点**己子**看绿圈,**点落点**行棋。

> 💡 **打法:**① **绿圈=能走的点**,先看全再落子;② 跳吃**稳赚三十**,能吃别客气;③ 对方**也会跳吃**,留个跟手;④ **登顶一百**,比连吃三子还值;⑤ 抢山头时,**别忘了家里的空门**!

**结算:**对弈回合、吃子数、本局得分、历史最高分、已玩局数。
