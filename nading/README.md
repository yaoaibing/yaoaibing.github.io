**目标:**交替支撑:**换手找平**,三排缸沿。

| 元素 | 效果 |
|---|---|
| 🤸 倒立 | 头下脚上 |
| 👆 撑手 | 左右交替 |
| 🛢 缸沿 | 一步一缸 |
| ⚠️ 栽葱 | 折四十五 |
| 🏆 结算 | 拿顶折分 |
