# 讨价还价 (🤝 讨价还价 · 跳蚤市场)

> 分类:**拍卖竞价** · 入口:/haggle/ · 免费在线 · 手机即点即玩

**目标:**砍价模拟:卖家开价虚高,你**低报试探→加价→接受或放弃**,四轮内谈成;成交转手按真值结算,8 件后比利润。

| 元素 | 效果 |
|---|---|
| 🤝 谈判 | 低报试探→卖家降价→加价→… |
| 📉 降价 | 每轮约 -12%,不低于 floor |
| 🚫 走人 | 报价 <55% 真值,卖家收摊 |
| ✅ 成交 | 出价 ≥ 开价即成交 |
| 💎 结算 | 真值 - 成交价 = 利润 |

**操作:****+25/+100** 加价、**✅接受**(回车)出价=开价;**键盘 1/2/3/回车**同效。

> 💡 **打法:**① 开价的 55% 是底线,<b>低于它卖家直接走</b>;② 第一轮低报 50%,<b>看卖家降多少</b>判断真值范围;③ 每轮约降 12%,<b>三轮后接近 floor</b>;④ 接受出价 = 开价,<b>比一轮一轮加省时间</b>;⑤ 真值在成色 x0.55~1.3 之间,<b>成色好的物件利润空间大</b>!

**结算:**成交件数、总利润、现金余额、本局得分、历史最高分、已玩局数。
