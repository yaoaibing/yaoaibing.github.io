# 马术障碍 (🐴 马术障碍 · 跃栏计时)

> 分类:**体育竞技** · 入口:/equestrian/ · 免费在线 · 手机即点即玩

**目标:**马术计时赛:马自动前进,**接近障碍时点屏幕/空格起跳**;跳过 +100,碰倒 -30;六个障碍全过是冠军,25 秒计时。

| 元素 | 效果 |
|---|---|
| 🐴 马匹 | 自动 90px/s 前进 |
| 🦘 跳跃 | 按屏幕/空格,初速 -420 |
| 🚧 障碍 | 6 道,间距递减 |
| 💥 碰撞 | 碰倒 -30 分 |
| 🏁 完成 | 跳过全部或 25 秒到 |

**操作:**接近障碍时**点屏幕/空格**起跳;马自动前进,你只管跳!

> 💡 **打法:**① 跳跃有<b>抛物线</b>,提前 2 秒按才有高度;② 距离障碍 30px 内按,<b>高度刚好过栏</b>;③ 碰倒只扣分不中断,<b>保持节奏继续跳</b>;④ 六道障碍间距递减,<b>后三道反应要快</b>;⑤ 连续跳比单跳好——<b>落地的瞬间就能再跳</b>!

**结算:**跳过障碍数、碰倒数、本局得分、历史最高分、已玩局数。
