> 分类:**卡牌构筑** · 入口:/tianjiu/ · 免费在线 · 手机即点即玩

**目标:**配对接龙:**衔点出牌**,先空者胜。

| 元素 | 效果 |
|---|---|
| 🀄 骨牌 | 廿八去其半 |
| 🔗 衔点 | 对上就出 |
| 🎯 对牌 | 双点加倍 |
| ♻️ 重开 | 两头死换头 |
| 🏆 结算 | 接龙折分 |

**操作:**点**手牌**出牌。

> 💡 **打法:**① 红框牌**都能衔**,挑留着能连出的一路;② **对牌捏手里**,死局重开时最值钱;③ 对方**没牌可衔就等着**,趁机多走两手;④ 重开牌头**看自己手牌选角**,别送对手方便;⑤ 先出完牌,**通盘二百落袋**!

**结算:**余牌张数、对方余牌、本局得分、历史最高分、已玩局数。
