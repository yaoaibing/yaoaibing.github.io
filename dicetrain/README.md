# 骰子火车 (🚂 骰子火车 · 点数接龙)

> 分类:**骰子冒险** · 入口:/dicetrain/ · 免费在线 · 手机即点即玩

**目标:**骰子接龙:手牌 2 骰,**点骰接到车头或车尾**(差 ±1 即可);接上 +100 + 车长 x10,接不上扣信号灯;列车长到 6 节获胜。

| 元素 | 效果 |
|---|---|
| 🚂 火车 | 3→6 节 |
| 🎲 手牌 | 2 骰,接不上自动换 |
| 🔗 接龙 | 差 ±1 即可,头尾皆可 |
| ❤️ 信号灯 | 三条命 |
| 🏆 胜利 | 6 节即大亨 |

**操作:****点手牌骰子**(键盘 **1/2**)接龙;接不上自动换牌。

> 💡 **打法:**① 车头和车尾都能接,<b>选接上后更灵活的那端</b>;② 3 和 6 是端点,<b>只有 2/4 或 5/7 能接</b>,中间数更灵活;③ 接不上扣命但换手牌,<b>不要气馁</b>;④ 列车越长分越高,<b>珍惜每一次接上</b>!

**结算:**列车长度、信号灯、本局得分、历史最高分、已玩局数。
