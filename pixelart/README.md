# 像素画家 (🎨 像素画家 · 编号填色)

> 分类:**解压休闲** · 入口:/pixelart/ · 免费在线 · 手机即点即玩

**目标:**6 幅 8x8 像素画:底部色板选颜色,**点格子**填色;格子编号提示应填的颜色,全部填对自动完成进入下一幅,填错会闪红提示。

| 元素 | 效果 |
|---|---|
| 🎨 色板 | 底部选色,一次一种 |
| 🔢 编号 | 格子角标 = 应填颜色编号 |
| ✅ 完成 | 全部正确自动判过 |
| ❌ 提示 | 填错闪红,可随时重填 |
| 🖼️ 通关 | 6 幅全部完成 |

**操作:**色板**选色**,再**点格子**填色;**清空**重填本幅。先填数量多的颜色,效率翻倍!

> 💡 **打法:**① 先填<b>同一编号</b>的所有格子,减少换色次数;② 边缘格子最后填,轮廓自然清晰;③ 编号 0 是背景色,可以最后统一铺;④ 填错闪红不用慌,点回正确色就覆盖;⑤ 完成的作品值得截图留念!

**结算:**完成作品数、填格数、用时、本局得分(作品 x200)、历史最高分、已玩局数。
