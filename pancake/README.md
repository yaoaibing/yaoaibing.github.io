# 煎饼排序 (🥞 煎饼排序 · 锅铲翻饼)

> 分类:**烧脑益智** · 入口:/pancake/ · 免费在线 · 手机即点即玩

**目标:**一叠大小随机的煎饼:**点第 N 张饼**,把其上(含自身)整体翻转;目标是从上到下从小到大。次数越少分越高,10 关饼数从 4 张到 8 张递增。

| 元素 | 效果 |
|---|---|
| 🥞 翻饼 | 点任意一张,翻转其上所有饼 |
| 📏 目标 | 顶部最小、底部最大 |
| 🔁 计数 | 每次翻转换一关内累计 |
| 🧠 参考 | 显示理论最少翻数的近似值 |
| 🏁 过关 | 排好序自动进入下一关 |

**操作:****点饼**翻转;**重摆**重排本关,**新一关**直接跳关重抽。先定大饼,从下往上锁定!

> 💡 **打法:**① 经典策略:先把<b>最大的饼</b>翻到顶,再整体翻到底部,一步归位;② 逐个锁定底部,从大到小处理;③ 相邻两张已有序时,别去拆散它们;④ 翻数超过参考值 2 次就重摆,别硬磨;⑤ 心里把栈倒过来看,方向感立刻清晰!

**结算:**总翻数、各关成绩、通关数、本局得分(每关 300 - 超额翻数 x20)、历史最高分、已玩局数。
