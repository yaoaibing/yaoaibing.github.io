# 月球车巡坡 (🛞 月球车巡坡 · 灰海车辙)

> 分类:**太空导航** · 入口:/moonrover/ · 免费在线 · 手机即点即玩

**目标:**月面行驶:车辆自动前进,推进加速但**电耗×3**;坡度影响速度;电池补电,信标过站,电量见底即败。

| 元素 | 效果 |
|---|---|
| ⚡ 推进 | 加速但电耗 3 倍 |
| ⛰️ 坡度 | 上坡减速下坡飞驰 |
| 🔋 电池 | 途中 6 块各 +16% |
| 📡 信标 | 三站,逐站加远 |
| 🏆 评级 | 三站全达月面车神 |

**操作:****按住「⚡ 推进」**(空格)加速。

> 💡 **打法:**① **下坡绝不推进**,滑行免费;② 看到绿电池,**宁可绕一点也要吃**;③ 上坡前**把电攒到一半以上**;④ 电量 30% 是警戒线,**规划最后一段**;⑤ 站间越来越远,**省电是唯一技巧**!
