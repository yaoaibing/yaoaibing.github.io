# 猪圈密码 (🐷 猪圈密码 · 符号解字)

> 分类:**密码破译** · 入口:/pigpen/ · 免费在线 · 手机即点即玩

**目标:**图形替换密码:字母映射为**井字/X 格形状 + 圆点**;看密文符号对照部分规则表,四选一猜单词;8 轮计分。

| 元素 | 效果 |
|---|---|
| ▦ 井字 | A-I 三三网格无点 |
| ▦ 井字加点 | J-R 同形加点 |
| ✕ 叉格 | S-Z 对角格加点 |
| 👀 观察 | 线条位置+有无点 |
| 🏆 评级 | 连对 6 段符号破译家 |

**操作:****点选项**(键盘 **1-4**)作答。

> 💡 **打法:**① 先背对照表里的 **A B C**:**没有上边线、缺左线、缺右线**;② **有圆点**就是 J-R 或 S-Z;③ 首字母确定后,**用单词长度缩小范围**;④ 三个字母的词多半是 **CAT/DOG/SUN**;⑤ 玩几局就背下全表,**从此看符号如看字母**!

**结算:**连对、本局得分、历史最高分、已玩局数。
