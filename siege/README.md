# 围堵棋 (🛡️ 围堵棋 · 走投无路)

> 分类:**策略战棋** · 入口:/siege/ · 免费在线 · 手机即点即玩

**目标:**追围博弈:5×5 盘双方各 2 子正交移动;**对方所有棋子无法移动**即获胜;AI 贪心逼近+封锁。

| 元素 | 效果 |
|---|---|
| 👣 移动 | 上下左右一格 |
| 🔒 困杀 | 对方全子无路即胜 |
| 🤖 AI | 逼近+堵路双策略 |
| 📐 小盘 | 5×5,一分钟一局 |
| 🏆 计分 | 胜 380 连胜滚 |

**操作:****点蓝子**选中,**点绿圈**移动。

> 💡 **打法:**① **双子保持连线**,互相支援;② **把对手往边角赶**,角落的活动空间最少;③ 自己的子**留一条退路**,别自陷死角;④ AI 贪心逼近,**用空间换先手**;⑤ 中盘想想:**对方下一步会堵我哪**?

**结算:**对局比分、本局得分、历史最高分、已玩局数。
