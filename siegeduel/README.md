# 攻守暗牌 (🏯 攻守暗牌 · 六门博弈)

> 分类:**策略战棋** · 入口:/siegeduel/ · 免费在线 · 手机即点即玩

**目标:**暗牌博弈:攻守各按规则选门,**同时揭晓比对**;攻破≥2 门或守住全城计胜;六轮定胜负。

| 元素 | 效果 |
|---|---|
| 🏯 六门 | 东西南北水角 |
| ⚔️ 攻方 | 选 3 门,避开守军即破 |
| 🛡️ 守方 | 布 4 军,全堵住则胜 |
| 🔁 换位 | 攻守各三轮 |
| 🏆 评级 | 三胜名震六门 |

**操作:****点城门**选择,点「**⚔️ 确认**」(空格)揭晓。

> 💡 **打法:**① 守方**爱堵东南西北正门**,水门角门常空;② 攻方**连着两轮别用同一组门**;③ 当守方时,**想想自己刚才会攻哪**;④ 攻破两门才算赢,**三门全押冷门更狠**;⑤ 六轮制,**先赢两轮稳住心态**!

**结算:**攻破数、失手数、本局得分、历史最高分、已玩局数。
