# 记忆轨迹 (🧠 记忆轨迹 · 看路走位)

> 分类:**烧脑益智** · 入口:/memorypath/ · 免费在线 · 手机即点即玩

**目标:**5x5 网格每回合**亮出一条轨迹**(起点+若干步),消失后凭记忆**按顺序点击每一步**;点错扣 1 命,3 命用完结束。轨迹逐回合加长,路障逐渐增多。

| 元素 | 效果 |
|---|---|
| 🧠 演示 | 轨迹逐格亮起 0.5 秒/格 |
| 👆 复现 | 从起点开始按顺序点击 |
| ❌ 失误 | 点错即扣 1 命并重播本回合 |
| 🧱 路障 | 第 3 回合起出现灰色障碍格 |
| 🏁 结束 | 3 命用完,按回合数结算 |

**操作:****点格子**复现轨迹;**重来**重开。用「上上右右下」这种方位口诀记忆最稳!

> 💡 **打法:**① 别记格子颜色,记<b>方位口诀</b>:上下左右;② 长轨迹分段记:前 3 步一组;③ 路障出现后,轨迹不会穿过路障,可排除;④ 复现时手指悬停在下一格上,节奏快;⑤ 3 命很宝贵,记不清宁可慢两秒!

**结算:**坚持回合数、最长轨迹、失误次数、本局得分(回合 x120)、历史最高分、已玩局数。
