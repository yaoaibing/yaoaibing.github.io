# 密室逃脱 (🚪 密室逃脱 · 十室之约)

> 分类:**烧脑益智** · 入口:/escape/ · 免费在线 · 手机即点即玩

**目标:**连闯 10 间密室:每间房**点击搜查**地点,搜出钥匙与道具,解开机关后开门进入下一间。搜错不死,放心乱点;提示 3 次,10 间全过即通关。

| 元素 | 效果 |
|---|---|
| 🚪 搜查 | 点房间里的地点按钮,出现线索或道具 |
| 🔑 钥匙 | 搜到即入背包,点门自动使用 |
| 🧩 机关 | 按线索选正确选项,选错重选不扣分 |
| 💡 提示 | 高亮本房关键地点,每局 3 次 |
| 🏁 通关 | 第 10 间房的门打开即胜利 |

**操作:****点地点**搜查,**点门**用道具/机关开门;**提示**高亮,**本房重搜**重置本房。全程点按,零操作门槛。

> 💡 **打法:**① 每进新房先把<b>所有地点</b>点一遍,道具一般不会藏太深;② 看到数字线索先记下来,多半是后面房间的密码;③ 门打不开就是缺道具,回搜一遍带钥匙图标的地点;④ 机关题选错没惩罚,大胆试;⑤ 提示别乱用,留给最后一两间真卡关的时候。

**结算:**通关房间数、使用提示次数、用时、本局得分(房间 x150 - 提示 x50)、历史最高分、已玩局数。
