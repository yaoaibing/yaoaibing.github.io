# 渔翁对弈 (🎣 渔翁对弈 · 一钓一放)

> 分类:**对战棋牌** · 入口:/fishing2/ · 免费在线 · 手机即点即玩

**目标:**时机钓鱼:**点水面抛竿**,鱼靠近鱼钩自动上钩;六轮结算渔获分。

| 元素 | 效果 |
|---|---|
| 🎣 抛竿 | 点水面位置 |
| 🐟 鱼 | 五条随机游 |
| 💰 分值 | 20-80 随机 |
| 📈 六轮 | 累计得分 |
| 🏆 评级 | 60 分渔获丰富的渔翁 |

**操作:****点水面**抛竿,鱼靠近鱼钩自动上钩。

> 💡 **打法:**① **鱼越多越好钓**,等鱼游近再抛;② **鱼钩在水面下方**,深度自动;③ 大鱼分高**但也跑得快**,看准;④ 六轮鱼**自动刷新**,别空等;⑤ 60 分以上,**今天的渔获够吃了**!

**结算:**渔得分、历史最高分、已玩局数。
