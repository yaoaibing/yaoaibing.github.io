# 骰子渡海 (⛵ 骰子渡海 · 风信航程)

> 分类:**骰子冒险** · 入口:/dicevoyage/ · 免费在线 · 手机即点即玩

**目标:**风信博弈:两骰定风,**选骰决定航速**;小骰安全减半,大骰有风暴风险;先满 20 浬胜。

| 元素 | 效果 |
|---|---|
| 🎲 风信 | 两骰之和定倍率 |
| ⛵ 选骰 | 大骰冲,小骰稳 |
| ⛈️ 风暴 | 大骰 18% 折帆 |
| 🏁 赛点 | 先满 20 浬 |
| 🏆 评级 | 四程夺岛老船长 |

**操作:****点一颗骰子**(键盘 **1/2**),点「**⛵ 启航**」(空格)。
