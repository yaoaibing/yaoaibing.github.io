# 拉火车 (🚂 拉火车 · 牌尾大战)

> 分类:**对战棋牌** · 入口:/train/ · 免费在线 · 手机即点即玩

**目标:**52 张牌双方各 26 张,轮流把牌堆顶翻到桌面长龙尾部;翻出的牌与长龙中某张**同点数**时,把从那张牌到龙尾的**整段收走**垫到自己的牌堆底。轮到谁却没牌谁输,收得多者为王。

| 元素 | 效果 |
|---|---|
| 🚂 翻牌 | 轮到自己时点牌堆翻一张进长龙 |
| 🎯 收牌 | 与龙内任意同点数牌匹配,收走匹配点到龙尾整段 |
| 📥 垫底 | 收走的牌按原顺序垫进自己牌堆底部 |
| 💀 没牌 | 轮到你但牌堆为空即落败 |
| 🔁 循环 | 收来的牌还会再翻出来,局势随时反转 |

**操作:**轮到自己时**点自己的牌堆**翻牌;**新局**重开。电脑自动翻牌,长龙太长会自动压缩显示。

> 💡 **打法:**① 长龙越长,翻出同点的概率越大,别嫌它占屏;② 收牌时注意<b>段里有几组对</b>,对子越多后续越容易再收;③ 自己牌堆快空时,长龙里你熟悉的牌就是救命的;④ 电脑不会记牌,你记:大牌位置就是你的提款机;⑤ 运气七分技巧三分,落后别急,一波大收牌就能翻盘。

**结算:**胜负、双方剩牌、收牌次数、最长长龙、本局得分(胜 400 + 收牌总数 x8)、历史最高分、已玩局数。
