# 幸运大转盘 (🎡 幸运大转盘)

> 分类:**解压休闲** · 入口:/wheel/ · 免费在线 · 手机即点即玩

**目标:**解压/聚会神器,没有输赢。四个转盘随你切:**🍜今天吃什么**(12 种美食)、**💬真心话**(10 个问题)、**🔥大冒险**(10 个挑战)、**💪运动打卡**(8 项运动)。点转盘让它飞转,指针停在谁就是谁!

**操作:**开局选转盘,游戏中**点转盘任意位置**即可开转(旋转约 4~6 秒,越转越慢,扇格扫过指针会哒哒作响)。结果以大字横幅弹出并记入历史,最近 3 次结果显示在转盘下方。

**计分:**转动次数跨局永久累计,冲"历史累计"纪录;转盘结果**仅供娱乐**。底部可随时"🏁收工结算"看本局战绩。

> 💡 **玩法建议:**① 聚会时投屏,真心话+大冒险双转盘交替,被转中的人二选一;② 吃什么转盘治"选择困难症",**转出来的不许反悔**;③ 运动打卡转盘可以自己定规则:赖账的人接受一次大冒险;④ 真心话问题都是合家欢级别,适合朋友/家人一起玩。

**结算:**本局转动次数、历史累计最高、最近转出的结果。
