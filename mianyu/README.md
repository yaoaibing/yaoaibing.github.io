# 面鱼入锅 (🐟 面鱼入锅 · 一鱼一锅)

> 分类:**解压休闲** · 入口:/mianyu/ · 免费在线 · 手机即点即玩

**目标:**时机投放:**候温下鱼**,四锅递进。

| 元素 | 效果 |
|---|---|
| 🐟 面鱼 | 搓成小鱼形 |
| 👆 下鱼 | 水温对即投 |
| 🍲 六条 | 一锅的量 |
| ⚠️ 粘锅 | 水温不足 |
| 🏆 结算 | 面鱼折分 |

**操作:**水温**合了点屏下鱼**。

> 💡 **打法:**① **水温七五到九二**之间最正;② 早投**粘锅底**,晚投**扑锅**;③ 一条**一百加锅号**,连投更厚;④ 锅号越深**水凉越快**,出手要快;⑤ 四锅面鱼,**滑溜完整汤清亮**!

**结算:**锅号、下锅数、本局得分、历史最高分、已玩局数。
