# 优诺 (🃏 优诺 · 疯狂出牌)

> 分类:**对战棋牌** · 入口:/uno/ · 免费在线 · 手机即点即玩

**目标:**出牌要和桌面**同色或同数字/同功能**,先出完手牌的人获胜。禁止、转向、+2、变色、+4 全部生效,没牌出就摸一张。

| 元素 | 效果 |
|---|---|
| 🃏 出牌 | 同色、同数字或同功能都能出,变色牌随时能出 |
| ⛔ 禁止/转向 | 两人对局时效果相同,电脑跳过一手 |
| ➕ +2 | 电脑摸 2 张并跳过,你继续出牌 |
| 🌈 变色 | 出牌后点颜色自选,+4 还让电脑摸 4 张 |
| 🃏 摸牌 | 没牌出摸一张,能出就出,不然点「过牌」 |

**操作:**点手牌出牌;变色牌出后点四个颜色之一;**摸牌**在没牌可出时摸一张,摸到的牌能出就出,不能出再点一次变「过牌」。键盘 <kbd>1</kbd>-<kbd>4</kbd> 选牌,<kbd>D</kbd> 摸牌或过牌。

> 💡 **打法:**① 手里**颜色单一**时别急着打变色,不然 +4 会卡在手里;② 电脑只剩 1-2 张时优先打禁止和 +2 拖住它;③ 出牌前瞄一眼双方的牌数,决定抢出还是留牌;④ 摸到的牌能出就直接出,过牌等于把节奏送人;⑤ 变色时选手里最多的颜色,后面才出得顺。

**结算:**胜负、双方剩余手牌、本局得分(胜利 600 + 电脑剩余张数 x80)、历史最高分、已玩局数。
