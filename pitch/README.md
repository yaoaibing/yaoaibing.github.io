# 听音辨阶 (🎹 听音辨阶 · 绝对音感)

> 分类:**音乐节奏** · 入口:/pitch/ · 免费在线 · 手机即点即玩

**目标:**听一个钢琴音,从三个琴键中**点出相同音高**;do 到 fa 六个半音随机,连对加分,12 轮测音感。

| 元素 | 效果 |
|---|---|
| 🎹 听音 | 自动播放目标音 |
| 🎹 选键 | 三键对应三个半音 |
| 🔥 连对 | 连对每题 +15 |
| 📈 半音 | do/#do/re/#re/mi/fa |
| 🏆 评级 | 连对 8 次绝对音感 |

**操作:****听完点琴键**(键盘 1-3);**戴耳机**更准。

> 💡 **打法:**① 先记住 do 最稳的低音感,当锚点;② #do/re 是微升关系,**听紧张感**;③ 连对是复利,不确定时选听感最亮的;④ 错了会重播目标音,**对比学习**;⑤ 每天一节,耳朵是练出来的!

**结算:**得分、连对、历史最高分、已玩局数。
