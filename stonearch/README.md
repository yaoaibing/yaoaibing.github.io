# 石拱桥 (🌉 石拱桥 · 砌拱合龙)

> 分类:**建造物理** · 入口:/stonearch/ · 免费在线 · 手机即点即玩

**目标:**节奏落石:**摆锤绿区落石**,拱心合龙;三桥结算。

| 元素 | 效果 |
|---|---|
| 🌉 拱券 | 逐石向中收 |
| 🪨 落石 | 绿区才稳 |
| 🐉 拱心石 | 合龙定成败 |
| ⚠️ 滑石 | 晃区 -5 |
| 🏆 结算 | 滑石少奖励高 |

**操作:**摆锤进绿区**点屏落石**。

> 💡 **打法:**① **前几石随便落**,越到高处越要等;② 摆锤**减速时落**,不是 fastest;③ 拱心石**最关键**,合龙差一次全塌;④ 滑石**只扣五分**,别慌;⑤ 三桥全合,**桥碑刻你的名**!

**结算:**建桥数、落石数、本局得分、历史最高分、已玩局数。
