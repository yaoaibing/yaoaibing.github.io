# 撵鸭进笼 (🦆 撵鸭进笼 · 一哄而圈)

> 分类:**街机动作** · 入口:/duckdrive/ · 免费在线 · 手机即点即玩

**目标:**驱赶引导:**划墙赶鸭入笼**,限时五只。

| 元素 | 效果 |
|---|---|
| 🦆 鸭群 | 八只游走 |
| 🧱 短墙 | 划线即立 |
| ⏱ 自散 | 一秒半消 |
| 🚪 笼口 | 东南角 |
| 🏆 结算 | 入笼折分 |

**操作:**按住**划短墙**,把鸭往笼口赶。

> 💡 **打法:**① **墙划在鸭身后**,推着走别堵着走;② 笼口**别划墙**,进笼的路要敞着;③ 三道墙**轮着用**,拆东墙补西墙;④ 鸭**躲墙就往反跑**,顺毛捋;⑤ 剩鸭越少越贼,**逼角落里堵笼边**!

**结算:**入笼数、剩余时限、本局得分、历史最高分、已玩局数。
