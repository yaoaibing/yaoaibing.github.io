# 跑旱船 (🚣 跑旱船 · 摇摆有度)

> 分类:**竞速赛车** · 入口:/hanchuan/ · 免费在线 · 手机即点即玩

**目标:**节奏平衡:**交替划桨控摇摆**,翻船罚停;三赛两胜。

| 元素 | 效果 |
|---|---|
| 🚣 左桨 | 点左半屏 |
| 🚣 右桨 | 点右半屏 |
| ⚖️ 摇摆 | 同侧连划涨 |
| 💥 翻船 | 摇摆满格 |
| 🏁 赛制 | 百米三赛 |

**操作:**点**左半屏**划左桨,**右半屏**划右桨。

> 💡 **打法:**① **左右左右**打拍子,节奏比手速重要;② 摇摆条**过半就该换侧**,别硬顶;③ 翻船**一秒起步**,亏得最狠;④ 对手**逐赛提速**,后两赛桨要密;⑤ 三连胜,**正月社火你打头船**!

**结算:**参赛局数、比分、摇摆度、本局得分、历史最高分、已玩局数。
